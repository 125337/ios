# 微信优化 — "设置已保存，重启生效" 弹窗 + 自动重启 实现文档

---

## 功能描述

- 用户在界面简化设置页修改任意配置项后，点击返回
- 弹出 UIAlertController 提示 **"设置已保存，重启生效"**
- 左边按钮 **"稍后重启"** → 关闭弹窗，不做任何操作
- 右边按钮 **"立即重启"** → 自动关闭微信 → 自动重新打开微信

---

## 一、整体流程

```
用户修改配置 → 保存到 NSUserDefaults → 发 Darwin 通知 → 用户点返回
→ 弹出 "设置已保存" 弹窗
  ├─ 稍后重启 → dismiss
  └─ 立即重启 →
       1. [[UIApplication sharedApplication] suspend]  → 挂起到后台
       2. dispatch_after 1秒 →
       3. LSApplicationWorkspace openApplicationWithBundleID:  → 重新打开
       4. exit(0)  → 杀死当前进程
```

---

## 二、关键技术点

### 2.1 挂起微信（suspend）

```objc
[[UIApplication sharedApplication] suspend];
```

调用 UIApplication 的私有方法 `suspend`，等同于用户按 Home 键，将微信退到后台。

> 微信优化反编译对应函数：`FUN_000a7430` (L107461-107463)

### 2.2 重新打开微信（LSApplicationWorkspace）

```objc
NSString *bundleID = [[NSBundle mainBundle] bundleIdentifier];

Class workspace = NSClassFromString(@"LSApplicationWorkspace");
id defaultWorkspace = [workspace performSelector:NSSelectorFromString(@"defaultWorkspace")];
SEL openSel = NSSelectorFromString(@"openApplicationWithBundleID:");
[defaultWorkspace performSelector:openSel withObject:bundleID];
```

`LSApplicationWorkspace` 是 iOS 私有框架 MobileCoreServices 中的应用管理类：
- `+ defaultWorkspace` 获取单例
- `- openApplicationWithBundleID:` 启动指定 bundle ID 的应用

这里传入的是微信自己的 bundleID → 微信会被系统重新启动。

> 微信优化反编译对应函数：`FUN_000a7494` (L107482-107497)

### 2.3 杀死当前进程（exit）

```objc
exit(0);
```

> 反编译 L107497：`_exit(0);` — "WARNING: Subroutine does not return"

### 2.4 1秒延迟（dispatch_after）

```objc
dispatch_after(dispatch_time(DISPATCH_TIME_NOW, 1 * NSEC_PER_SEC),
               dispatch_get_main_queue(), ^{
    // LSApplicationWorkspace 重新打开微信
    // exit(0)
});
```

suspend 后需要等微信完全进入后台状态（约1秒），再由 LSApplicationWorkspace 唤起。如果不延迟，可能在 suspend 完成前就 exit，导致拉起失败。

> 反编译 L107465：`dispatch_time(0, 1000000000)` = 1秒

### 2.5 配置保存通知

```objc
// 保存配置
[[NSUserDefaults standardUserDefaults] synchronize];

// 通知所有监听者配置已变更
CFNotificationCenterPostNotification(
    CFNotificationCenterGetDarwinNotifyCenter(),
    CFSTR("com.wechat.tweak.settings_changed"),
    NULL, NULL, kCFNotificationDeliverImmediately
);
```

Interface Simplification Hook 模块通过 `CFNotificationCenterAddObserver` 监听这个通知，实现热更新（无需重启就生效的配置项）。

## 三、弹窗实现

### 3.1 UIAlertController（微信优化方式）

```objc
UIAlertController *alert = [UIAlertController
    alertControllerWithTitle:@"提示"
                     message:@"设置已保存，重启生效"
              preferredStyle:UIAlertControllerStyleAlert];

// 稍后重启
UIAlertAction *laterAction = [UIAlertAction
    actionWithTitle:@"稍后重启"
              style:UIAlertActionStyleCancel
            handler:nil];
[alert addAction:laterAction];

// 立即重启
UIAlertAction *restartAction = [UIAlertAction
    actionWithTitle:@"立即重启"
              style:UIAlertActionStyleDefault
            handler:^(UIAlertAction *action) {
                [self restartWeChat];
            }];
[alert addAction:restartAction];

[self presentViewController:alert animated:YES completion:nil];
```

### 3.2 WCUIAlertView（WeChat 私有弹窗，备选方案）

Mio助手 已封装 `WeChatAlertHelper`（`/Core/WeChatAlertHelper.m`），支持 WeChat 私有弹窗类 `WCUIAlertView`。如果 UIAlertController 在某些 WeChat 版本中表现异常，可改用 `WeChatAlertHelper` 的 `showConfirmAlert:confirmTitle:onConfirm:` 方法。

## 四、完整代码实现

### 4.1 头文件声明

```objc
// WeChatRestartHelper.h
@interface WeChatRestartHelper : NSObject

/// 显示"设置已保存"弹窗
/// @param viewController 用于 present 弹窗的 VC
+ (void)showRestartAlertFromVC:(UIViewController *)viewController;

/// 立即重启微信（suspend → relaunch → exit）
+ (void)restartWeChat;

@end
```

### 4.2 实现

```objc
// WeChatRestartHelper.m
#import "WeChatRestartHelper.h"
#import <UIKit/UIKit.h>

@implementation WeChatRestartHelper

+ (void)showRestartAlertFromVC:(UIViewController *)vc {
    if (!vc) return;
    
    UIAlertController *alert = [UIAlertController
        alertControllerWithTitle:@"提示"
                         message:@"设置已保存，重启生效"
                  preferredStyle:UIAlertControllerStyleAlert];
    
    // 稍后重启
    [alert addAction:[UIAlertAction
        actionWithTitle:@"稍后重启"
                  style:UIAlertActionStyleCancel
                handler:nil]];
    
    // 立即重启
    [alert addAction:[UIAlertAction
        actionWithTitle:@"立即重启"
                  style:UIAlertActionStyleDefault
                handler:^(UIAlertAction *action) {
                    [self restartWeChat];
                }]];
    
    [vc presentViewController:alert animated:YES completion:nil];
}

+ (void)restartWeChat {
    // 第1步：挂起到后台
    [[UIApplication sharedApplication] suspend];
    
    // 第2步：延迟1秒后重新唤起
    dispatch_after(dispatch_time(DISPATCH_TIME_NOW, (int64_t)(1.0 * NSEC_PER_SEC)),
                   dispatch_get_main_queue(), ^{
        // 获取 bundle ID
        NSString *bundleID = [[NSBundle mainBundle] bundleIdentifier];
        
        // 通过 LSApplicationWorkspace 打开微信
        Class workspace = NSClassFromString(@"LSApplicationWorkspace");
        if (workspace) {
            id defaultWorkspace = [workspace performSelector:
                NSSelectorFromString(@"defaultWorkspace")];
            if (defaultWorkspace) {
                SEL openSel = NSSelectorFromString(@"openApplicationWithBundleID:");
                if ([defaultWorkspace respondsToSelector:openSel]) {
                    [defaultWorkspace performSelector:openSel withObject:bundleID];
                }
            }
        }
        
        // 第3步：杀死当前进程
        exit(0);
    });
}

@end
```

### 4.3 调用方式

在设置页的 `viewWillDisappear:` 或自定义的"返回"按钮中调用：

```objc
- (void)viewWillDisappear:(BOOL)animated {
    [super viewWillDisappear:animated];
    
    // 只在用户做了修改时才弹窗
    if (self.didModifySettings) {
        [WeChatRestartHelper showRestartAlertFromVC:self];
    }
}
```

或在 `UINavigationControllerDelegate` 的 `willShowViewController` 中检测设置页即将被 pop：

```objc
- (void)navigationController:(UINavigationController *)navCtrl
      willShowViewController:(UIViewController *)vc
                    animated:(BOOL)animated {
    // 如果正在从设置页返回
    if ([navCtrl.topViewController isKindOfClass:CSWCEnhanceViewController.class]) {
        [WeChatRestartHelper showRestartAlertFromVC:navCtrl.topViewController];
    }
}
```

## 五、注意事项

1. **`suspend` 是 UIApplication 的私有方法**，不会触发 App Store 审核问题（tweak 环境下使用）
2. **LSApplicationWorkspace 是私有 API**，来自 MobileCoreServices 私有框架
3. **1秒延迟不能省略**：suspend 是异步操作，立即 exit 会导致微信进程在完全挂起前被杀死，LSApplicationWorkspace 可能无法正确拉起
4. **`exit(0)` 而非 `abort()`**：exit 是正常退出，不会生成崩溃日志；abort 会产生 SIGABRT 信号和崩溃报告
5. 如果 `LSApplicationWorkspace` 不可用（极旧的 iOS 版本），可回退为仅 `exit(0)` — 微信会在下次用户手动点击图标时启动
