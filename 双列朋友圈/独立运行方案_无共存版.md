# 双列朋友圈 · 独立运行方案（无 WCMoments 共存版）

> 前提（头文件实证）：`WCFacade : MMUserService` 是微信原生服务（665 方法），Mio 使用的全部方法均为原生声明——**不装 WCMoments 完全可运行**，不存在第三方依赖。
> 本方案 = 会话修复固化 + 预热前移 + 收尾三件，即最终形态。

---

## 一、最终架构（数据流）

```
发现页 viewDidAppear（入口钩子，已有——按钮追加处）
  └── 预热：beginTimeline → reloadTimelineDataItems → updateTimelineHead
      （会话开启 + 本地库重载 + 网络拉新：数据在用户点按钮前就落地，count 0→N）
点「双列」：
  面板打开（常驻复用，秒显）
  → countOfTimelineDataItem / getTimelineDataItemOfIndex: 直读 → 渲染（本地库数据）
  → updateTimelineHead（会话内真正走网络）→ 新帖落地
数据变化：onTimelineDataChanged（WCFacade 原生回调 L415，已 hook）
  → 0.5s 尾沿防抖 → 行级 diff 增量 patch → 秒级上屏
关面板：endTimeline（会话关闭，对齐 WCM endTimeline）
图片：mioimg 持久注册表（MD5 稳定 key）→ resolveKey 文件校验 → imgCdn CDN 回落
```

---

## 二、接线清单（三处代码）

### 2.1 MioDualTimelineStore 加会话方法

```objc
- (void)beginSession {
    id facade = MioDualFacade();
    if (!facade) return;
    SEL s1 = NSSelectorFromString(@"beginTimeline");
    if ([facade respondsToSelector:s1])
        ((id(*)(id, SEL))objc_msgSend)(facade, s1);
    SEL s2 = NSSelectorFromString(@"reloadTimelineDataItems");
    if ([facade respondsToSelector:s2])
        ((id(*)(id, SEL))objc_msgSend)(facade, s2);   // 本地库→数据源，count 立即非零
}

- (void)endSession {
    id facade = MioDualFacade();
    SEL sel = NSSelectorFromString(@"endTimeline");
    if (facade && [facade respondsToSelector:sel])
        ((id(*)(id, SEL))objc_msgSend)(facade, sel);
}
```

（.h 同步声明；MioDualFacade 已迁入 Store.m，Panel 引用 Store 即可）

### 2.2 PanelOpen / PanelClose 接线

```objc
// MioDualPanelOpen：updateTimelineHead 之前
[[MioDualTimelineStore shared] beginSession];   // 开会话 + 本地库重载
// 原有 updateTimelineHead 保留（会话内才真正走网络）

// MioDualPanelClose：detach 之前
[[MioDualTimelineStore shared] endSession];
```

### 2.3 预热前移（入口钩子，MomentsDualHook.m）

```objc
// viewDidAppear 钩子内，追加按钮之后：
[[MioDualTimelineStore shared] beginSession];
[[MioDualTimelineStore shared] refreshHead];    // 现有方法（updateTimelineHead 包装）
```

效果：用户在发现页浏览的几秒里数据已同步落地 → 点双列时 count 非零 → **live 数据直显，快照基本轮不到上场**。

## 三、收尾三件（此前审查遗留）

1. **B11 兜底接线**：MomentsDualHook.m 让位分支（他方插件先挂 onTimelineDataChanged 时）加
   `[MioDualFeedBridge enablePollingFallback];` —— 不共存环境下更简单：无他方竞争时此分支根本不触发，留着纯保险
2. **mediaSrc 去 stat**：删注册前的 fileExistsAtPath（resolveKey 已校验，注册无条件）——消除主线程 stat 风暴
3. **imgCdn 闭环**：itemDict 的 media 加 cdn 字段 + row 加 imgCdn + JS onerror 换源（微信清缓存后图片自动回落 CDN）

## 四、快照的新定位

预热后快照基本轮不到上场（数据在点按钮前已就绪）。**保留**，定位收窄为：微信刚启动几秒内极速点击双列时的兜底显示。无需再改。
