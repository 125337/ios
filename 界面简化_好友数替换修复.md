# 好友数替换显示问题 — 解决方案

---

## 问题表现

微信优化填写 `999` → 通讯录底部显示 **"999个朋友"**

Mio助手填写 `999` → 通讯录底部显示 **"999"**

"个朋友" 被吞掉了。

---

## 根因

当前代码在 setText 和 setAttributedText 两处用了 `stringWithFormat`:

```objc
// ❌ 当前写法
NSString *number = [text substringWithRange:match.range];       // "123"
NSString *formatted = [NSString stringWithFormat:_friendsCount, number];
```

`_friendsCount` 是用户填的 `"999"`。执行 `[NSString stringWithFormat:@"999", @"123"]` 永远只返回 `"999"`——格式串 `"999"` 里没有任何占位符，第二个参数直接被丢弃。原文中正则匹配到的数字部分和后面的 `"个朋友"` 全部丢失。

---

## 微信优化怎么做的

微信优化不是 `stringWithFormat`，而是**范围替换**——正则匹配原文中的数字部分，把匹配到的范围直接替换成配置值，其余文字原样保留:

```
原文:   "123个朋友"
正则匹配范围: [0, 3]  →  "123"
替换为:     "999"
结果:       "999个朋友"
```

---

## 修改位置

两个函数，各改一行:
- `hook_MMUILabel_setText` (当前约 行258)
- `hook_MMUILabel_setAttributedText` (当前约 行359)

---

## 具体改法

### setText

```objc
// ❌ 当前
NSString *number = [text substringWithRange:match.range];
NSString *formatted = [NSString stringWithFormat:_friendsCount, number];

// ✅ 改为
NSString *formatted = [text stringByReplacingCharactersInRange:match.range
                                                    withString:_friendsCount];
```

完整上下文:

```objc
if (_friendsCount && _friendsCount.length > 0) {
    if (![text containsString:@"个朋友"]) {
        ((void (*)(id, SEL, id))_orig_MMUILabel_setText)(self, _cmd, text);
        return;
    }
    NSRegularExpression *regex = [NSRegularExpression
        regularExpressionWithPattern:@"\\d+" options:0 error:nil];
    if (regex) {
        NSTextCheckingResult *match = [regex firstMatchInString:text
            options:0 range:NSMakeRange(0, text.length)];
        if (match && match.range.location != NSNotFound) {
            NSString *formatted = [text stringByReplacingCharactersInRange:match.range
                                                                withString:_friendsCount];
            if (formatted) {
                ((void (*)(id, SEL, id))_orig_MMUILabel_setText)(self, _cmd, formatted);
                return;
            }
        }
    }
}
```

### setAttributedText

```objc
// ❌ 当前
NSString *number = [text substringWithRange:match.range];
NSString *formatted = [NSString stringWithFormat:_friendsCount, number];

// ✅ 改为
NSString *formatted = [text stringByReplacingCharactersInRange:match.range
                                                    withString:_friendsCount];
```

完整上下文:

```objc
if (_friendsCount && _friendsCount.length > 0) {
    if (![text containsString:@"个朋友"]) {
        ((void (*)(id, SEL, id))_orig_MMUILabel_setAttributedText)(self, _cmd, attrText);
        return;
    }
    NSRegularExpression *regex = [NSRegularExpression
        regularExpressionWithPattern:@"\\d+" options:0 error:nil];
    if (regex) {
        NSTextCheckingResult *match = [regex firstMatchInString:text
            options:0 range:NSMakeRange(0, text.length)];
        if (match && match.range.location != NSNotFound) {
            NSString *formatted = [text stringByReplacingCharactersInRange:match.range
                                                                withString:_friendsCount];
            if (formatted) {
                NSDictionary *attrs = nil;
                if (attrText.length > 0) {
                    attrs = [attrText attributesAtIndex:0 effectiveRange:NULL];
                }
                NSMutableAttributedString *replaced = [[NSMutableAttributedString alloc]
                    initWithString:formatted attributes:attrs ?: @{}];
                if (replaced) {
                    ((void (*)(id, SEL, id))_orig_MMUILabel_setAttributedText)(self, _cmd, replaced);
                    [replaced release];
                    return;
                }
            }
        }
    }
}
```

## 效果对比

| 用户配置 | 原文 | 改前 | 改后 |
|---------|------|------|------|
| `999` | 123个朋友 | 999 | 999个朋友 |
| `0` | 123个朋友 | 0 | 0个朋友 |
| `∞` | 123个朋友 | ∞ | ∞个朋友 |

和微信优化行为完全一致。
