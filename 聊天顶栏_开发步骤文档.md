## 问题现象

```
点击头像 → haptic 震动正常（"有动静"）→ 联系人信息弹窗没有弹出
```

## 诊断结论

### 根因：`findViewController` 找不到有效的 VC

[presentUserInfoPopoverWithContact:sourceView:](file:///www/wwwroot/ios/WeChatPlugin/Modules/ChatTopBar/CSChatAvatarTitleView.m#L607-L642) 中用 `[self findViewController]` 获取 parentVC，但 **CSChatAvatarTitleView 是作为 `navigationItem.titleView` 嵌入 UINavigationBar 的**。

UINavigationBar 内部的 `titleView` 子视图的 `nextResponder` 链走向为：

```
CSChatAvatarTitleView → _UINavigationBarContentView → UINavigationBar → ???
```

UINavigationBar 的 `nextResponder` **不一定** 返回 UINavigationController。在微信深度自定义的导航栏架构下（MMUINavigationBar 等），titleView 的 responder chain 很可能在 UINavigationBar 处断链或返回非 ViewController 对象。`findViewController` 的 `isKindOfClass:[UIViewController class]` 永远不会匹配，返回 nil。

而 `presentUserInfoPopoverWithContact:` 依赖 `parentVC.navigationController`：
```objc
UIViewController *parentVC = [self findViewController];  // ← nil!
if (parentVC && parentVC.navigationController) {         // ← false!
    // 永远不会进入这里
}
```

### 为什么 123456.c 的 findViewController 能工作？

**123456.c 也用 `[self findViewController]`**（确认：L131104 `objc_msgSend(param_1, "findViewController")`），实现与项目完全一致（responder chain 遍历 + `isKindOfClass:UIViewController`）。

但 123456.c 的 `presentUserInfoPopoverWithContact:` 获得 VC 后做的是 **popover present**（`presentViewController:animated:completion:`），不是 push。如果 findViewController 返回 nil 或不对的 VC，popover present 会失败但不 crash。

更重要的是：123456.c 注入的微信版本可能与用户当前运行的微信版本不同，UINavigationBar 内部结构差异会导致 findViewController 在某些版本成功、某些版本失败。

### 为什么 haptic 能触发但弹窗不能？

调用链是线性的：

```
onLeftAvatarTapped: 
  → playHapticFeedback()    ✓ 成功（不需要 parentVC，直接创建 generator）
  → presentUserInfoPopoverWithContact:
      → WCUserInfoViewController 不存在? 
      → ContactInfoViewController fallback
          → findViewController()  ✗ 失败（UINavigationBar 的 titleView responder chain 不通）
          → parentVC == nil → 静默返回
```

### 修复方案

**直接使用 `self.chatController` 代替 `findViewController`**。

`chatController` 是 ChatTopBarHook 在创建 CSChatAvatarTitleView 时设置的聊天页 ViewController（BaseMsgContentViewController），一定在 UINavigationController 的栈中，`navigationController` 属性必然非 nil：

```objc
- (void)presentUserInfoPopoverWithContact:(id)contact sourceView:(UIView *)sourceView {
    if (!contact) return;

    // ★ 直接用 chatController，不要 findViewController
    // chatController 是 BaseMsgContentViewController，必定有 navigationController
    UIViewController *parentVC = (UIViewController *)self.chatController;

    Class infoVCClass = objc_getClass("WCUserInfoViewController");
    if (infoVCClass) {
        NSString *wxid = ((id (*)(id, SEL))objc_msgSend)(contact, NSSelectorFromString(@"m_nsUsrName"));
        id infoVC = ((id (*)(Class, SEL))objc_msgSend)(infoVCClass, NSSelectorFromString(@"alloc"));
        infoVC = ((id (*)(id, SEL, id, id))objc_msgSend)(infoVC,
            NSSelectorFromString(@"initWithUsrName:contact:"), wxid, contact);
        if (infoVC) {
            if (parentVC && parentVC.navigationController) {
                [parentVC.navigationController pushViewController:infoVC animated:YES];
                [infoVC release];
                return;
            }
            [infoVC release];
        }
    }

    // Fallback: ContactInfoViewController (init + setM_contact:)
    Class contactInfoVC = objc_getClass("ContactInfoViewController");
    if (contactInfoVC) {
        id vc = ((id (*)(Class, SEL))objc_msgSend)(contactInfoVC, NSSelectorFromString(@"alloc"));
        vc = ((id (*)(id, SEL))objc_msgSend)(vc, @selector(init));
        if (vc && [vc respondsToSelector:NSSelectorFromString(@"setM_contact:")]) {
            ((void (*)(id, SEL, id))objc_msgSend)(vc,
                NSSelectorFromString(@"setM_contact:"), contact);
            if (parentVC && parentVC.navigationController) {
                [parentVC.navigationController pushViewController:vc animated:YES];
                [vc release];
            }
        }
    }
}
```

**修改要点**：

| 位置 | 修改前 | 修改后 |
|------|--------|--------|
| L617 | `UIViewController *parentVC = [self findViewController];` | `UIViewController *parentVC = (UIViewController *)self.chatController;` |
| L635 | `UIViewController *parentVC = [self findViewController];` | 删掉（复用 L617 的 parentVC，移到方法开头） |

## 123456.c findViewController vs 项目 findViewController 逐行对比

```
123456.c (L12966-12987)                       项目 (L644-653)
─────────────────────────────────────────      ──────────────────────────────
lVar1 = _objc_retain(param_1); // self        UIResponder *responder = self;
while (lVar1 != 0) {                           while (responder) {
    isKindOfClass:UIViewController                 isKindOfClass:UIViewController
    if yes → break                                 if yes → return responder
    [lVar1 nextResponder]                          responder = [responder nextResponder]
    lVar4 = retain result                      }
    release lVar1                               return nil;
    lVar1 = lVar4
}
return autorelease(lVar1);
```

两者算法 100% 一致。区别：
- 123456.c 开头多 `_objc_retain(param_1)` — 多余的 retain（自身参数已有引用计数），不影响功能
- 123456.c 返回 `autorelease` — 项目返回普通值（MRC下方法返回值不走autorelease，调用方需自行管理）

**这两个差异都不会导致"一个工作一个不工作"**。根因是微信运行时的 UINavigationBar 内部 titleView 的 nextResponder 链在特定版本下不通往 UIViewController。

## 调用链全景图

```
点击头像
  │
  ├─→ onLeftAvatarTapped: / onRightAvatarTapped:
  │     │
  │     ├─→ playHapticFeedback()                       ✓ 有动静
  │     │     └─ UIImpactFeedbackGenerator → impactOccurred → haptic pulse
  │     │
  │     └─→ presentUserInfoPopoverWithContact:sourceView:
  │           │
  │           ├─ WCUserInfoViewController?              ← 微信 8.0.x 可能不存在
  │           │   └─ initWithUsrName:contact:           ← selector 可能也不存在
  │           │       └─ pushViewController:animated:    ← 需要 parentVC.navController
  │           │
  │           └─ ContactInfoViewController fallback     ← 微信内部类，应该存在
  │               └─ init + setM_contact:               ← 正确
  │                   └─ pushViewController:animated:    ← ★ 卡在这里！
  │                       需要 parentVC.navigationController
  │                       parentVC = [self findViewController] → nil
  │                       → 静默退出，无弹窗
```

修复后：

```
presentUserInfoPopoverWithContact:
  parentVC = self.chatController  ← 直接取聊天VC，不是titleView的responder chain
  parentVC.navigationController   ← 一定有效（聊天VC在nav栈中）
  pushViewController:animated:     ← ✓ 弹窗出现！
```
