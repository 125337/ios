## 问题现象

```
点击头像 → haptic 震动正常（"有动静"）→ 联系人信息弹窗没有弹出
```

## 诊断结论（第九次 — 推翻第八次 findViewController 诊断）

### 真正根因：项目没有弹窗 UI

第八次诊断认为是 `findViewController` 找不到 parentVC 导致 push 失败。**这是错的**。

真正的问题是：**项目根本没有实现联系人信息弹窗 UI**。

[presentUserInfoPopoverWithContact:sourceView:](file:///www/wwwroot/ios/WeChatPlugin/Modules/ChatTopBar/CSChatAvatarTitleView.m#L607-L642) 里尝试 push 微信内部类：

```objc
// 当前项目做法 — 根本行不通
Class infoVCClass = objc_getClass("WCUserInfoViewController");  // 可能不存在
[parentVC.navigationController pushViewController:infoVC animated:YES];

Class contactInfoVC = objc_getClass("ContactInfoViewController"); // 可能不存在
[parentVC.navigationController pushViewController:vc animated:YES];
```

这个方案有两个致命问题：

1. **`WCUserInfoViewController` / `ContactInfoViewController` 可能在当前微信版本中根本不存在**，`objc_getClass` 返回 nil
2. 即使类存在，微信内部 VC 的初始化链很复杂，简单 `alloc + init + setM_contact:` 推上去很可能是空页面或直接崩溃

**确认**：在 123456.c 反编译代码（12905-12959行）中完全搜索不到 `WCUserInfoViewController`、`ContactInfoViewController`、`pushViewController` 这些关键词。123456.c 从未 push 微信内部 VC — 它用的是**自己的自定义弹窗**。

### 123456.c 的实际做法

[presentUserInfoPopoverWithContact_sourceView_:](file:///www/wwwroot/ios/插件/微信优化反编译最新/123456.c#L12909-L12960) 的流程：

```
1. [[CSUserInfoPopoverController alloc] init]       // 创建自定义弹窗VC
2. [popover setupWithContact:contact]               // 传入联系人数据
3. [self findViewController]                        // 找parentVC
4. popover.modalPresentationStyle = 7               // UIModalPresentationPopover
5. popover.preferredContentSize = (272, 400)        // 弹窗尺寸
6. popover.popoverPresentationController.sourceView = sourceView  // 弹出锚点
7. popover.popoverPresentationController.sourceRect = sourceView.bounds
8. [parentVC presentViewController:popover animated:YES completion:nil]  // ★ popover present，不是 push
```

关键区别：

| | 123456.c | 当前项目 |
|---|---|---|
| 弹窗 VC | `CSUserInfoPopoverController`（自定义，50+ 方法）| **不存在** |
| 展示方式 | `presentViewController:` popover | `pushViewController:` |
| 内容来源 | 自己画 UI，KVC 读取 contact | 依赖微信内部 VC |
| 数据字段 | 动态从 contact KVC 读取 | 无 |

## 联系人信息弹窗 — 实现方案

### 目标 UI 参考

[Code_20260527.html](file:///www/wwwroot/ios/Code_20260527.html) 提供了弹窗 UI 原型，布局结构：

```
┌──────────────────────────────┐
│         [头像 120x120]        │  ← 圆形头像
│           过客.               │  ← 昵称
├──────────────────────────────┤
│  主页     点击进入信息页      │  ← 点击跳转微信资料页
├──────────────────────────────┤
│  类型     私聊                │
├──────────────────────────────┤
│  微信     wxid_vosn7r...     │  ← 点击复制到剪贴板

├──────────────────────────────┤
│  性别     未知                │
├──────────────────────────────┤
```

#### 3. createInfoCardView — 信息行卡片

信息行结构：左侧 label（60pt 宽）+ 右侧 value，底部分割线。

```objc
- (UIView *)createInfoCardView {
    CGFloat cardWidth = self.view.bounds.size.width - 32;
    UIView *card = [[UIView alloc] init];
    card.backgroundColor = [UIColor whiteColor];
    card.layer.cornerRadius = 16;
    card.clipsToBounds = YES;

    NSArray *items = @[
        @{@"label": @"主页",   @"key": @"homepage",   @"copiable": @NO},
        @{@"label": @"类型",   @"key": @"chatType",   @"copiable": @NO},
        @{@"label": @"微信",   @"key": @"wxid",       @"copiable": @YES},
        @{@"label": @"备注",   @"key": @"remark",     @"copiable": @YES},
        @{@"label": @"性别",   @"key": @"gender",     @"copiable": @NO},
        @{@"label": @"地区",   @"key": @"location",   @"copiable": @NO},
        @{@"label": @"签名",   @"key": @"signature",  @"copiable": @YES},
    ];

    CGFloat rowH = 50;
    for (NSInteger i = 0; i < items.count; i++) {
        NSDictionary *item = items[i];
        CGFloat y = i * rowH;

        UILabel *label = [[UILabel alloc] initWithFrame:CGRectMake(20, 0, 60, rowH)];
        label.text = item[@"label"];
        label.font = [UIFont systemFontOfSize:14];
        label.textColor = [UIColor blackColor];
        [card addSubview:label];
        [label release];

        UILabel *value = [[UILabel alloc] initWithFrame:CGRectMake(100, 0, cardWidth - 120, rowH)];
        value.text = [self valueForKey:item[@"key"]];
        value.font = [UIFont systemFontOfSize:13];
        value.textColor = [UIColor colorWithRed:0.56 green:0.56 blue:0.58 alpha:1.0];
        [card addSubview:value];
        [value release];

        // 分割线
        if (i < items.count - 1) {
            UIView *sep = [[UIView alloc] initWithFrame:CGRectMake(0, y + rowH - 0.5, cardWidth, 0.5)];
            sep.backgroundColor = [UIColor colorWithRed:0.92 green:0.92 blue:0.93 alpha:1.0];
            [card addSubview:sep];
            [sep release];
        }

        // 可复制行加点击手势
        if ([item[@"copiable"] boolValue]) {
            UITapGestureRecognizer *tap = [[UITapGestureRecognizer alloc]
                initWithTarget:self action:@selector(onInfoRowTapped:)];
            UIView *rowView = [[UIView alloc] initWithFrame:CGRectMake(0, y, cardWidth, rowH)];
            rowView.backgroundColor = [UIColor clearColor];
            [rowView addGestureRecognizer:tap];
            [tap release];
            objc_setAssociatedObject(rowView, "copyText", value.text, OBJC_ASSOCIATION_COPY_NONATOMIC);
            [card addSubview:rowView];
            [rowView release];
        }
    }

    return card;
}
```

#### 4. 数据获取 — 参考 123456.c 的 KVC 方式

从 contact 对象通过 KVC 取值，空值兜底为 "未设置"：

```objc
// 类型：判断 wxid 中含 "chatroom" 为群聊，含 "gh_" 开头为公众号，其余为私聊
- (NSString *)chatTypeValue {
    if ([self.wxid containsString:@"@chatroom"]) return @"群聊";
    if ([self.wxid hasPrefix:@"gh_"]) return @"公众号";
    return @"私聊";
}

// 备注：m_nsRemark → m_nsRemarkName → "未设置"（与123456.c L11720-11752一致）
- (NSString *)remarkValue {
    id remark = ((id (*)(id, SEL, NSString *))objc_msgSend)(
        self.contact, NSSelectorFromString(@"valueForKey:"), @"m_nsRemark");
    if (remark && [remark isKindOfClass:[NSString class]] && [(NSString *)remark length] > 0) {
        return remark;
    }
    id remarkName = ((id (*)(id, SEL, NSString *))objc_msgSend)(
        self.contact, NSSelectorFromString(@"valueForKey:"), @"m_nsRemarkName");
    if (remarkName && [remarkName isKindOfClass:[NSString class]] && [(NSString *)remarkName length] > 0) {
        return remarkName;
    }
    return @"未设置";
}

// 性别：m_uiSex → 0=未知, 1=男, 2=女（与123456.c L11758-11795一致）
- (NSString *)genderValue {
    if (!((BOOL (*)(id, SEL, SEL))objc_msgSend)(self.contact, @selector(respondsToSelector:),
        NSSelectorFromString(@"m_uiSex"))) {
        return @"未知";
    }
    NSInteger sex = (NSInteger)((int (*)(id, SEL))objc_msgSend)(
        self.contact, NSSelectorFromString(@"m_uiSex"));
    if (sex == 1) return @"男";
    if (sex == 2) return @"女";
    return @"未知";
}

// 地区："m_nsProvince" + " " + "m_nsCity"（与123456.c L11796-11741一致）
- (NSString *)locationValue {
    id province = ((id (*)(id, SEL, NSString *))objc_msgSend)(
        self.contact, NSSelectorFromString(@"valueForKey:"), @"m_nsProvince");
    id city = ((id (*)(id, SEL, NSString *))objc_msgSend)(
        self.contact, NSSelectorFromString(@"valueForKey:"), @"m_nsCity");
    if (!province || [(NSString *)province length] == 0) {
        if (city && [(NSString *)city length] > 0) return city;
        return @"未设置";
    }
    // trim 空格
    NSString *trimmed = [province stringByTrimmingCharactersInSet:
        [NSCharacterSet whitespaceCharacterSet]];
    if ([trimmed length] == 0) return @"未设置";
    return [NSString stringWithFormat:@"%@ %@", trimmed, city ?: @""];
}

// 签名：m_nsSignature（与123456.c L11747-11763一致）
- (NSString *)signatureValue {
    id sig = ((id (*)(id, SEL, NSString *))objc_msgSend)(
        self.contact, NSSelectorFromString(@"valueForKey:"), @"m_nsSignature");
    if (sig && [sig isKindOfClass:[NSString class]] && [(NSString *)sig length] > 0) {
        return sig;
    }
    return @"未设置";
}
```

#### 5. 点击信息行 — 复制到剪贴板（123456.c L118466-118484）

```objc
- (void)onInfoRowTapped:(UITapGestureRecognizer *)gesture {
    NSString *text = objc_getAssociatedObject(gesture.view, "copyText");
    if (!text || text.length == 0) return;

    // 复制到剪贴板
    [UIPasteboard generalPasteboard].string = text;

    // haptic 反馈

    [gen impactOccurred];

    // 或直接用微信内部 MMToastViewController
}
```

#### 6. "主页" 行 — 跳转微信资料页（123456.c L118351 handleProfileNavigation_）

```objc
- (void)onHomepageTapped {
    // 从 contact 取 m_nsUsrName，构造跳转
    NSString *usrName = ((id (*)(id, SEL, NSString *))objc_msgSend)(
        self.contact, NSSelectorFromString(@"valueForKey:"), @"m_nsUsrName");
    if (!usrName) return;

    // 推送微信内部联系人资料页
    Class infoVC = objc_getClass("WCUserInfoViewController");
    if (infoVC) {
        id vc = ((id (*)(Class, SEL))objc_msgSend)(infoVC, NSSelectorFromString(@"alloc"));
        vc = ((id (*)(id, SEL, id, id))objc_msgSend)(vc,
            NSSelectorFromString(@"initWithUsrName:contact:"), usrName, self.contact);
        if (vc) {
            // dismiss 当前 popover，然后 push
            [self dismissViewControllerAnimated:YES completion:^{
                // 需要持有 parentVC 引用
                UIViewController *parent = self.presentingViewController;
                if (parent && parent.navigationController) {
                    [parent.navigationController pushViewController:vc animated:YES];
                }
                [vc release];
            }];
        }
    }
}
```

### 修改现有代码：presentUserInfoPopoverWithContact:

替换 [CSChatAvatarTitleView.m](file:///www/wwwroot/ios/WeChatPlugin/Modules/ChatTopBar/CSChatAvatarTitleView.m#L607-L642) 的旧实现：

```objc
- (void)presentUserInfoPopoverWithContact:(id)contact sourceView:(UIView *)sourceView {
    if (!contact) return;

    // 获取头像（从 titleView 现有头像读）
    UIImage *avatar = nil;
    if (sourceView == self.leftAvatarView) {
        avatar = self.leftAvatarView.image;
    } else {
        avatar = self.rightAvatarView.image;
    }

    // ★ 创建自定义弹窗
    CSContactInfoPopoverController *popover =
        [[CSContactInfoPopoverController alloc] initWithContact:contact avatar:avatar];

    // ★ popover 配置
    popover.modalPresentationStyle = UIModalPresentationPopover;
    popover.preferredContentSize = CGSizeMake(300, 520);

    UIPopoverPresentationController *popPC = popover.popoverPresentationController;
    popPC.sourceView = sourceView;
    popPC.sourceRect = sourceView.bounds;
    popPC.permittedArrowDirections = UIPopoverArrowDirectionUp;  // 箭头朝上
    popPC.backgroundColor = [UIColor whiteColor];

    // ★ 直接用 chatController present（不用 findViewController）
    UIViewController *parentVC = (UIViewController *)self.chatController;
    if (parentVC) {
        [parentVC presentViewController:popover animated:YES completion:nil];
    }

    [popover release];
}
```
