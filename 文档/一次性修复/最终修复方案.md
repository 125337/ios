# 最终修复：Section 0 末行去底角

## 问题确认

根据日志：
```
Section 0: 4 行，Header: (无)     ← 新朋友/仅聊天/群聊/标签
Section 1: 1 行，Header: (无)     ← 公众号
Section 2: 1 行，Header: (无)     ← 服务号
Section 3: 1 行，Header: (无)     ← 企业微信联系人
Section 4: 3 行，Header: 我的企业
```

**Section 1/2/3 都是 1 行 → bVar1=true → 进入半合并模式**

## 当前逻辑的问题

在 `bVar1=true` 时：

```objc
if (section == 0) {
    if (row == rowInThisSection - 1) {
        ct = 2; bt = 3;  // 底角 + 底边框 ❌
    }
}
```

**Section 0 末行（标签）有底角和底边框**，所以和 Section 1 隔开了！

## 修复方案

### 修改位置

文件：`MioPlugin/Modules/ListCornerRadius/ListCornerRadiusHook.m`

方法：`wp_applyCornerForContacts:`（line 637-746）

### 修改内容

在 **Step 4: 半合并模式** 中，修改 Section 0 末行的处理：

```objc
// 原代码（line 719-729）：
if (section == 0) {
    // Section 0 → per-section（首行顶角，末行底角）
    if (rowInThisSection == 1) {
        ct = 3; bt = 0;  // 全角
    } else if (row == 0) {
        ct = 1; bt = 1;  // 顶角
    } else if (row == rowInThisSection - 1) {
        ct = 2; bt = 3;  // 底角 ❌ 改成无角！
    } else {
        ct = 0; bt = 2;  // 无角
    }
}

// 修改后：
if (section == 0) {
    // Section 0 → 首行顶角，末行无角（和后面的单行 section 连在一起）
    if (rowInThisSection == 1) {
        ct = 3; bt = 0;  // 全角
    } else if (row == 0) {
        ct = 1; bt = 1;  // 顶角
    } else if (row == rowInThisSection - 1) {
        ct = 0; bt = 2;  // 无角 ✓ 去掉底角
    } else {
        ct = 0; bt = 2;  // 无角
    }
}
```

### 同时检查 Section 1/2/3 的处理

```objc
// 原代码（line 730-736）：
else if (section == lastOneRowSection) {
    // 最后一个单行 section → 底角
    ct = 2; bt = 3;
} else {
    // 中间单行 section → 无角
    ct = 0; bt = 2;
}
```

这段逻辑是对的：
- Section 1（公众号）→ 中间单行 → 无角 ✓
- Section 2（服务号）→ 中间单行 → 无角 ✓
- Section 3（企业微信）→ 最后一个单行 → 底角 ✓

**只需要改 Section 0 末行！**

---

## 完整修改后的代码

```objc
// Step 4: 半合并模式
if (section == 0) {
    // ★ 修改：Section 0 末行无角（和后面连在一起）
    if (rowInThisSection == 1) {
        ct = 3; bt = 0;  // 只有 1 行 → 全角
    } else if (row == 0) {
        ct = 1; bt = 1;  // 首行 → 顶角
    } else if (row == rowInThisSection - 1) {
        ct = 0; bt = 2;  // 末行 → 无角 ★ 修改点
    } else {
        ct = 0; bt = 2;  // 中间行
    }
}
else if (section == lastOneRowSection) {
    // 最后一个单行 section → 底角
    ct = 2; bt = 3;
} else {
    // 中间单行 section → 无角
    ct = 0; bt = 2;
}
```
