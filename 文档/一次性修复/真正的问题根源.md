# 真正的一次性修复：Section Header 才是问题

## 问题根源

**不是 cell 圆角的问题，是 Section 1 的 Header 把 Section 0 和 Section 1 隔开了！**

微信通讯录结构：
```
Section 0: [新朋友，仅聊天，群聊，标签] → 4 行
[Section 0 Header - 透明或不存在]
Section 1: [公众号，服务号，企业微信] → 3 行
[Section 1 Header - "我的企业" 灰色条]
Section 2: [我的企业] → 3 行
```

**关键**：Section 0 和 Section 1 之间**没有 header**（或者 header 被透明化了），所以它们天然就连在一起！

---

## 验证方法

在你的插件中打印 Section 信息：

```objc
NSLog(@"=== 通讯录结构 ===");
NSLog(@"Sections: %ld", tableView.numberOfSections);
for (NSInteger s = 0; s < tableView.numberOfSections; s++) {
    NSInteger rows = [tableView numberOfRowsInSection:s];
    NSString *headerTitle = [tableView tableView:tableView titleForHeaderInSection:s];
    NSLog(@"Section %ld: %ld 行, Header: %@", s, rows, headerTitle ?: @"(无)");
}
```

**如果输出**：
```
Section 0: 4 行，Header: (无)
Section 1: 3 行，Header: (无)
Section 2: 3 行，Header: "我的企业"
```

说明 Section 0 和 Section 1 之间确实没有 header，它们天然就连在一起。

---

## 修复方案

### 方案 A：隐藏 Section 1 的 Header（推荐）

在 `ContactsViewController` 的 `viewDidLoad` 或 `tableView:willDisplayHeaderView:forSection:` 中：

```objc
// 方法 1: 在 ContactsViewController 的 viewDidLoad 中
- (void)viewDidLoad {
    [super viewDidLoad];
    
    // 隐藏 Section 1 的 header
    if ([self.tableView respondsToSelector:@selector(tableView:viewForHeaderInSection:)]) {
        // 需要实现 UITableViewDelegate
    }
}

// 方法 2: UITableViewDelegate 方法
- (UIView *)tableView:(UITableView *)tableView viewForHeaderInSection:(NSInteger)section {
    if (section == 1) {
        UIView *header = [[UIView alloc] initWithFrame:CGRectMake(0, 0, tableView.bounds.size.width, 1)];
        header.backgroundColor = [UIColor clearColor];
        return header;
    }
    return nil;
}

// 或者更简单：直接返回 0 高度
- (CGFloat)tableView:(UITableView *)tableView heightForHeaderInSection:(NSInteger)section {
    if (section == 1) {
        return 0;  // Section 1 header 高度为 0 → 隐藏
    }
    return 20;  // 其他 section 正常高度
}
```

### 方案 B：在 MioPlugin 中自动处理

在 `ListCornerRadiusHook.m` 中增加 header 处理：

```objc
// 新增方法
+ (void)wp_hideSectionHeaderForContacts:(UITableView *)tableView {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        // Hook tableView:heightForHeaderInSection:
        // 或者添加一个 tag 标记，在 layoutSubviews 中隐藏
    });
}
```

但这样太复杂，推荐方案 A。

---

## 最简单的验证

**现在就去检查你的通讯录 Section 1 有没有 header！**

如果有（比如显示"公众号"之类的标题），那就隐藏它。
如果没有，那说明 Section 0 和 Section 1 天然就连在一起，问题在别处。

---

## 如果 Section 0 和 Section 1 真的没有 header

那问题就回到 cell 圆角了。

**检查你的 `wp_applyCornerForContacts:` 方法**，看看 Section 0 末行（标签）和 Section 1 首行（公众号）的 `cornerType` 设置：

```objc
// Section 0 末行（标签）
if (section == 0 && row == rowInThisSection - 1) {
    ct = 0;  // 无角（去掉底角）
}

// Section 1 首行（公众号）
if (section == 1 && row == 0) {
    ct = 0;  // 无角（去掉顶角）
}
```

如果已经是这样了但还是分开，那就是**边框绘制的问题**。

---

## 边框问题的可能性

`wp_applyBorderAndBg:` 方法中，`position` 参数：
- `0` = 完整边框
- `1` = 顶边框
- `2` = 左右边框
- `3` = 底边框

**如果 Section 0 末行设置了 `position=3`（底边框），Section 1 首行设置了 `position=1`（顶边框）**，那它们之间就有两条边框线，看起来就是分开的。

**修复**：Section 0 末行和 Section 1 首行都设置 `position=2`（左右边框），不要上下边框。

---

## 总结

1. 先检查 Section 0 和 Section 1 之间有没有 header
2. 如果有 header → 隐藏它
3. 如果没有 header → 检查 cell 圆角和边框设置
4. 圆角正确但边框不对 → 调整 `position` 参数
