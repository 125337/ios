# 通讯录圆角代码清理方案

## 问题清单

逐一检查 `wp_applyCornerForContacts:` 后发现 **4 处死代码 + 3 处冗余**：

---

### 死代码 ①：Step 2.5（line 677-723）

```objc
// ★ Step 2.5: 检查 Section 0 和 Section 1 是否需要合并 ★
NSInteger section1Rows = [rowCounts[1] integerValue];
if (section0Rows == 4 && section1Rows == 3) {
    // 合并 Section 0 和 Section 1
    ...
    return;
}
```

**问题**：这是上一轮加的条件，但日志显示 Section 1 永远是 **1 行**（不是 3 行），这个分支**永远进不去**，100% 死代码。

**删掉**：整个 `if` 块（line 677-723）。

---

### 死代码 ②：Section 0 `rowInThisSection == 1` 判断（line 758）

```objc
if (rowInThisSection == 1) {
    ct = 3; bt = 0;  // 只有 1 行 → 全角
}
```

**问题**：进入这里的条件是 `section0Rows >= 3 && section0Rows <= 4`，即 Section 0 至少 3 行。**`rowInThisSection == 1` 永远不可能成立**。

**删掉**：这个 `if` 分支。

---

### 死代码 ③：`lastOneRowSection` 循环（line 746-752）

```objc
// 找到最后一个单行 section（从后扫描）
NSInteger lastOneRowSection = 3;
for (NSInteger s = 3; s >= 1; s--) {
    if ([rowCounts[s] integerValue] == 1) {
        lastOneRowSection = s;
        break;
    }
}
```

**问题**：`bVar1=true` 意味着 section 1/2/3 **全部**是 1 行。循环从 s=3 开始立刻满足条件，**等价于 `lastOneRowSection = 3`**。

没必要循环，直接写死。

**简化**：`NSInteger lastOneRowSection = 3;`

---

### 死代码 ④：`totalSections` 变量（line 652）

```objc
NSInteger totalSections = [tableView numberOfSections];
NSMutableArray *rowCounts = [NSMutableArray array];
for (NSInteger s = 0; s < MIN(4, totalSections); s++) {
```

**问题**：`totalSections` 只被使用这一次，且 `MIN(4, totalSections)` 最多限制到 4。当 `section > 3` 时已经 return，这里的 section 是 0-3，**`totalSections` 肯定 >= 4**（否则 section 0-3 不存在）。所以 `MIN(4, totalSections)` 恒等于 4。

**简化**：直接写 `s < 4`。

---

### 冗余 ①：4 次相同的 per-section 降级调用

```objc
// line 637-645: section > 3
[self wp_applyStandardCorner:cell...];

// line 665-674: section0Rows 不在 3-4 范围
[self wp_applyStandardCorner:cell...];

// line 702-712: Step 2.5 中 section ≥ 2（死代码，删掉）
[self wp_applyStandardCorner:cell...];

// line 731-741: bVar1 = false
[self wp_applyStandardCorner:cell...];
```

**问题**：4 个地方用完全相同的参数调用 `wp_applyStandardCorner:`，除了 className 外都相同。

**简化**：把 `wp_applyStandardCorner:` 调用封装成一个局部函数/宏，或者统一在方法末尾做一次 return 前的「兜底 per-section」。

---

### 冗余 ②：两处相同的应用圆角和边框

```objc
// line 715-721（Step 2.5 中的）
// line 775-782（Step 4 中的）
cell.layer.cornerRadius = (ct == 0) ? 0 : radius;
cell.layer.maskedCorners = ct == 1 ? (...)
                             : ct == 2 ? (...)
                             : ct == 3 ? (...)
                             : 0;
[self wp_applyBorderAndBg:cell radius:radius position:bt isFTSHome:isFTSHome];
```

**问题**：两段代码完全一样。

**简化**：放在方法末尾统一执行。

---

### 冗余 ③：`rowInThisSection` 和 `section0Rows` 重复

Section 0 的处理中既用 `rowInThisSection` 又用 `section0Rows`，其实是一回事。建议统一用 `rowInThisSection`（函数参数）判断末行位置。

---

## 清理后的代码

```objc
+ (void)wp_applyCornerForContacts:(UIView *)cell
                        tableView:(UITableView *)tableView
                        indexPath:(NSIndexPath *)indexPath
                          section:(NSInteger)section
                              row:(NSInteger)row
                            total:(NSInteger)rowInThisSection
                     cornerRadius:(NSInteger)radius
                         isFTSHome:(BOOL)isFTSHome {

    // ─── 分支 A：section > 3 → per-section ───
    if (section > 3) {
        [self wp_applyStandardCorner:cell tableView:tableView indexPath:indexPath
                              section:section row:row total:rowInThisSection
                         cornerRadius:radius isFTSHome:isFTSHome
                            className:@"ContactsViewController"];
        return;
    }

    // ─── 分支 B：section 0-3 特殊算法 ───

    // 收集 Section 0-3 行数（不足补 0）
    NSMutableArray *rowCounts = [NSMutableArray array];
    for (NSInteger s = 0; s < 4; s++) {
        [rowCounts addObject:@(s < [tableView numberOfSections]
                              ? [tableView numberOfRowsInSection:s] : 0)];
    }

    // Section 0 行数必须 3-4 行
    if ([rowCounts[0] integerValue] < 3 || [rowCounts[0] integerValue] > 4) {
        [self wp_applyStandardCorner:cell tableView:tableView indexPath:indexPath
                              section:section row:row total:rowInThisSection
                         cornerRadius:radius isFTSHome:isFTSHome
                            className:@"ContactsViewController"];
        return;
    }

    // bVar1：section 1/2/3 是否都是 1 行
    BOOL bVar1 = ([rowCounts[1] integerValue] == 1 &&
                  [rowCounts[2] integerValue] == 1 &&
                  [rowCounts[3] integerValue] == 1);

    if (!bVar1) {
        [self wp_applyStandardCorner:cell tableView:tableView indexPath:indexPath
                              section:section row:row total:rowInThisSection
                         cornerRadius:radius isFTSHome:isFTSHome
                            className:@"ContactsViewController"];
        return;
    }

    // ─── 半合并模式（bVar1=true） ───

    NSInteger ct = 0, bt = 2;  // cornerType / borderType

    if (section == 0) {
        // Section 0：首行顶角，末行无角（和后面单行连一起）
        if (row == 0) {
            ct = 1; bt = 1;  // 顶角
        } else {
            ct = 0; bt = 2;  // 无角（末行/中间行都一样）
        }
    } else if (section == 3) {
        // Section 3：最后一个单行 → 底角
        ct = 2; bt = 3;
    } else {
        // Section 1/2：中间单行 → 无角
        ct = 0; bt = 2;
    }

    // 应用圆角
    cell.layer.cornerRadius = (ct == 0) ? 0 : radius;
    cell.layer.maskedCorners = ct == 1 ? (kCALayerMinXMinYCorner|kCALayerMaxXMinYCorner)
                             : ct == 2 ? (kCALayerMinXMaxYCorner|kCALayerMaxXMaxYCorner)
                             : ct == 3 ? (kCALayerMinXMinYCorner|kCALayerMaxXMinYCorner|
                                          kCALayerMinXMaxYCorner|kCALayerMaxXMaxYCorner)
                             : 0;
    [self wp_applyBorderAndBg:cell radius:radius position:bt isFTSHome:isFTSHome];
}
```
