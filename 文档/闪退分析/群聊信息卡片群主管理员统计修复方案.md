# 群聊信息卡片 - 群主/管理员统计修复方案

## 问题描述

### 问题1：群主信息一直显示"未知"

在聊天顶栏弹出的群聊信息卡片中，群主字段始终显示"未知"，无法正确显示群主的昵称。

**当前代码** ([CSContactInfoPopoverController.m](file:///www/wwwroot/ios/MioPlugin/Modules/ChatTopBar/CSContactInfoPopoverController.m#L403-L406)):

```objc
- (NSString *)groupOwnerValue {
    NSString *v = WXSafeStringGet(self.contact, @"m_nsChatRoomOwner");
    return v ?: @"未知";
}
```

### 问题2：群成员中没有管理员统计（以前有）

群成员行原本显示为"群人员X人 管理员Y人"，现在只显示"X 人"或"群人员X人"，管理员数量统计缺失。

**当前代码** ([CSContactInfoPopoverController.m](file:///www/wwwroot/ios/MioPlugin/Modules/ChatTopBar/CSContactInfoPopoverController.m#L408-L437)):

```objc
- (NSString *)groupMemberCountValue {
    id contact = self.contact;
    if (!contact) return @"未知";
    
    id contactMgr = WXGetService(objc_getClass("CContactMgr"));
    if (contactMgr && [contactMgr respondsToSelector:@selector(getGroupMemberCountForContact:)]) {
        unsigned int count = ...;
        if (count > 0) {
            NSString *adminList = WXSafeStringGet(contact, @"m_nsChatRoomAdminList");
            if (adminList.length) {
                NSArray *admins = [adminList componentsSeparatedByString:@";"];
                return [NSString stringWithFormat:@"群人员%lu人 管理员%lu人",
                        (unsigned long)count, (unsigned long)admins.count];
            }
            return [NSString stringWithFormat:@"%u 人", count];
        }
    }
    // fallback...
    return @"未知";
}
```

## 根因分析

### 问题1：群主"未知" — 字段名错误

**核心原因**：使用了错误的字段名。

| 字段 | 返回内容 | 我们的代码 |
|------|----------|-----------|
| `m_nsChatRoomOwner` | 群主的 **wxid**（如 `wxid_abc123`） | `WXSafeStringGet(self.contact, @"m_nsChatRoomOwner")` |
| `m_nsOwner` | 群主的 **昵称**（如 `张三`） | 未使用 |

**验证**：
- `m_nsChatRoomOwner` 返回的是群主的 wxid，这是一个内部标识符，不是可读的昵称
- 微信的 `CContact` 对象上存在 `m_nsOwner` 属性，它直接返回群主的显示名称
- 参考实现（微信优化插件）在 `addGroupInfoSection_` 方法中正是使用 `m_nsOwner` 来获取群主名称

**参考实现对比** ([wxyh1.6.5.dylib.c](file:///www/wwwroot/ios/插件/微信优化反编译最新/wxyh1.6.5.dylib.c#L120355)):

```c
// 微信优化插件使用 m_nsOwner 获取群主显示名
FUN_000c9840(param_1, &cf_m_nsOwner, uVar2);  
// 对应 ObjC: [self safeValueForKey:@"m_nsOwner" fromContact:contact]
```

### 问题2：管理员统计缺失 — 数据格式变更

**核心原因**：`m_nsChatRoomAdminList` 返回的字段在微信新版中可能发生变化，或者 `CContact` 对象不包含该字段。

管理员统计缺失可能由以下原因导致：

1. **字段不存在**：`self.contact` 对应的 `CContact` 对象没有加载 `m_nsChatRoomAdminList` 数据
2. **数据延迟加载**：群聊的管理员列表数据需要异步加载，在弹窗创建时尚未就绪
3. **字段格式变更**：`m_nsChatRoomAdminList` 在微信新旧版本中的存储格式可能不同

**参考实现对比** ([wxyh1.6.5.dylib.c](file:///www/wwwroot/ios/插件/微信优化反编译最新/wxyh1.6.5.dylib.c#L120651)):

```c
// 微信优化插件也使用 m_nsChatRoomAdminList
FUN_000c9840(param_1, &cf_m_nsChatRoomAdminList, uVar1);
```

参考实现同样使用该字段，但它在更新 UI 时通过 `updateUIWithContact_` 重新读取 contact 数据，而我们的弹窗只在初始化时接收一次 contact。

## 参考实现详细分析（wxyh1.6.5.dylib.c）

### 类结构

`CSUserInfoPopoverController`（对应我们的 `CSContactInfoPopoverController`）：

| 方法 | 功能 | 对应我们 |
|------|------|---------|
| `setupWithContact_:` | 存储 contact、刷新 UI | `initWithContact:avatar:` |
| `updateUIWithContact_:` | 判断群聊/公众号后调用对应 section 方法 | `viewDidLoad` |
| `addGroupInfoSection_:` | 添加群聊信息 section（群主 + 群成员） | `buildGroupInfoCardAtY:width:` |
| `getGroupMemberInfoForContact_:` | 获取群成员数量和管理员数量格式化字符串 | `groupMemberCountValue` |
| `safeValueForKey:fromContact_:` | 安全读取 contact 属性（带 `respondsToSelector` 检查） | `WXSafeStringGet` |

### 关键差异

#### 1. 群主获取方式

| 对比项 | 我们的实现 | 微信优化插件 |
|--------|-----------|-------------|
| 字段名 | `m_nsChatRoomOwner` | **`m_nsOwner`** |
| 返回值 | wxid（如 `wxid_abc`） | 显示名称（如 `张三`） |
| 是否需要转换 | 需要额外查询 Contact 才能显示 | 直接可用 |

#### 2. 群成员管理员信息

| 对比项 | 我们的实现 | 微信优化插件 |
|--------|-----------|-------------|
| 成员数量 | `CContactMgr.getGroupMemberCountForContact:` | `getGroupMemberInfoForContact_` 内部解析 |
| 管理员列表 | `m_nsChatRoomAdminList` | `m_nsChatRoomAdminList` |
| 格式化 | 内部直接拼接 | 内部拼接后返回 |

#### 3. UI 刷新机制

| 对比项 | 我们的实现 | 微信优化插件 |
|--------|-----------|-------------|
| 数据加载时机 | `initWithContact:` 一次性传入 | `setupWithContact_` + `updateUIWithContact_` 分离 |
| 数据更新 | 不更新 | `updateUIWithContact_` 可重新获取数据 |
| contact 来源 | delegate 传入 | 自身持有并在需要时重新获取 |

## 修复方案

### 修复1：群主字段改用 `m_nsOwner`

修改 `groupOwnerValue` 方法，改用 `m_nsOwner` 字段：

```objc
- (NSString *)groupOwnerValue {
    // 优先使用 m_nsOwner（直接返回群主昵称）
    NSString *v = WXSafeStringGet(self.contact, @"m_nsOwner");
    if (v) return v;
    
    // 降级方案：m_nsChatRoomOwner 返回 wxid，自行查询昵称
    NSString *ownerWxid = WXSafeStringGet(self.contact, @"m_nsChatRoomOwner");
    if (ownerWxid) {
        id ownerContact = WXGetContactForWxid(ownerWxid);
        if (ownerContact) {
            NSString *nick = WXSafeStringGet(ownerContact, @"m_nsNickName");
            if (nick) return nick;
        }
        return ownerWxid; // 实在没有昵称就显示 wxid
    }
    
    return @"未知";
}
```

### 修复2：管理员统计数据加载优化

修改 `groupMemberCountValue` 方法，增加备用数据源和日志：

```objc
- (NSString *)groupMemberCountValue {
    id contact = self.contact;
    if (!contact) return @"未知";
    
    // 优先通过 CContactMgr 获取成员数
    id contactMgr = WXGetService(objc_getClass("CContactMgr"));
    if (contactMgr && [contactMgr respondsToSelector:@selector(getGroupMemberCountForContact:)]) {
        unsigned int count = ...;
        if (count > 0) {
            // 尝试获取管理员数量（多种字段名兼容）
            NSString *adminList = WXSafeStringGet(contact, @"m_nsChatRoomAdminList");
            if (!adminList.length) {
                // 降级：尝试从 m_nsChatRoomAdminList 的其他形式获取
                // 某些微信版本中该字段可能存储在 ivar 中而非 property
                SEL adminSel = NSSelectorFromString(@"m_nsChatRoomAdminList");
                if ([contact respondsToSelector:adminSel]) {
                    id adminVal = ((id (*)(id, SEL))objc_msgSend)(contact, adminSel);
                    if ([adminVal isKindOfClass:[NSString class]]) {
                        adminList = (NSString *)adminVal;
                    }
                }
            }
            if (adminList.length) {
                NSArray *admins = [adminList componentsSeparatedByString:@";"];
                return [NSString stringWithFormat:@"群人员%lu人 管理员%lu人",
                        (unsigned long)count, (unsigned long)admins.count];
            }
            return [NSString stringWithFormat:@"%u 人", count];
        }
    }
    // fallback...
    return @"未知";
}
```

## 验证步骤

1. 进入任意微信群聊
2. 点击聊天顶栏头像弹出信息卡片
3. 验证群主行是否显示群主昵称（而非"未知"）
4. 验证群成员行是否显示"群人员X人 管理员Y人"（而非仅有"X 人"）
5. 切换多个不同群聊（不同群主、不同管理员数量）验证一致性
