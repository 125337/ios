# 聊天顶栏头像点击闪退修复方案

> 基于 WCRefine 反编译逆向验证

---

## 崩溃根因

```
onLeftAvatarTapped:
  ↓ raw objc_msgSend 获取 contact（ARC 未 retain，contact 野指针）
  ↓
MioPopoverHandler 创建 CSContactInfoPopoverController
  ↓ presentViewController → viewDidLoad → objc_retain → EXC_BAD_ACCESS (0x2)
```

本质问题：MioPlugin 创建了 **自定义中间层** `CSContactInfoPopoverController`，contact 由它异步持有，但获取方式（raw `objc_msgSend`）导致 ARC 没有 retain 它，在 viewDidLoad 触发时已变成野指针。

---

## WCRefine 的验证

WCRefine hook 了 `CommonMessageCellView.onHeadImageClicked:`（`FUN_0004e270`）：

```
CommonMessageCellView.onHeadImageClicked:
  ↓ WCRefine hook
  ├─ 配置开启 → WCRefineTopBarProfileCardPresenter.presentProfileCardForContact:
  │  （自己的 Presenter，不用 CSContactInfoPopoverController）
  └─ 配置关闭 → 调原始 onHeadImageClicked:（微信原生行为）
```

WCRefine **绕过了 `CSContactInfoPopoverController` 整个中间层**，contact 在当前函数栈帧内直接传给自己的 Presenter 消费掉，不存在异步持有导致野指针的问题。

---

## 修复方案

**直接利用 WeChat 原生 `ContactInfoViewController`，删除 `CSContactInfoPopoverController`。**

`ContactInfoViewController` 是微信自己的联系人详情页，WCRefine 在 `FUN_002440a4` 中已验证可用：

```c
// WCRefine 反编译代码
pcVar7 = "ContactInfoViewController";
_objc_getClass();                // objc_getClass("ContactInfoViewController")
_objc_alloc_init();              // [[cls alloc] init]
[pcVar7 setValue:local_90 forKey:@"m_contact"];  // [vc setValue:contact forKey:@"m_contact"]

// 获取导航控制器并 Push
navVC = [msgViewController performSelector:@selector(currentNavigationController)];
[navVC PushViewController:vc animated:YES];
```

### 改动一：修改 ChatTopBarHook.m

**`MioPopoverHandler.avatarTitleView:didTapAvatarWithContact:avatarImage:sourceView:wxid:`**

```objc
// 改前：创建 CSContactInfoPopoverController → present
CSContactInfoPopoverController *popover =
    [[CSContactInfoPopoverController alloc] initWithContact:contact avatar:avatar];
popover.modalPresentationStyle = UIModalPresentationPopover;
// ...popover 配置
[presentingVC presentViewController:popover animated:YES completion:nil];

// 改后：Push 微信原生 ContactInfoViewController
UIViewController *presentingVC = WPGetTopVCForPresentation();
if (!presentingVC) presentingVC = (UIViewController *)view.chatController;
if (!presentingVC) return;

Class contactInfoVC = objc_getClass("ContactInfoViewController");
if (contactInfoVC) {
    UIViewController *vc = [[contactInfoVC alloc] init];
    [vc setValue:contact forKey:@"m_contact"];
    [presentingVC.navigationController pushViewController:vc animated:YES];
}
```

### 改动二：删除 CSContactInfoPopoverController

| 文件 | 操作 |
|---|---|
| `ChatTopBar/CSContactInfoPopoverController.h` | 删除 |
| `ChatTopBar/CSContactInfoPopoverController.m` | 删除 |
| `ChatTopBarHook.m` 中的 `#import "CSContactInfoPopoverController.h"` | 删除 |

### 改动三：清理 MioChatAvatarTitleView.m 中的 raw objc_msgSend（可选）

虽然改成 Push 后 contact 在函数栈内即用即弃、不再有野指针风险，但仍建议清理干净：

```objc
// 改前
id contact = ((id (*)(id, SEL))objc_msgSend)(self.chatController, NSSelectorFromString(@"GetContact"));

// 改后
id contact = [self.chatController performSelector:NSSelectorFromString(@"GetContact")];
```

## 改后完整代码（ChatTopBarHook.m 核心部分）

```objc
- (void)avatarTitleView:(MioChatAvatarTitleView *)view
didTapAvatarWithContact:(id)contact
           avatarImage:(UIImage *)avatar
            sourceView:(UIView *)sourceView
                  wxid:(NSString *)wxid {
    PluginConfig *config = [PluginConfig shared];
    if (config.avatarTapFeedback) {
        UIImpactFeedbackGenerator *generator = [[UIImpactFeedbackGenerator alloc]
            initWithStyle:UIImpactFeedbackStyleLight];
        [generator prepare];
        [generator impactOccurred];
    }

    UIViewController *presentingVC = WPGetTopVCForPresentation();
    if (!presentingVC) presentingVC = (UIViewController *)view.chatController;
    if (!presentingVC) return;

    // Push 微信原生联系人详情页，跳过自定义 CSContactInfoPopoverController
    Class contactInfoVC = objc_getClass("ContactInfoViewController");
    if (contactInfoVC) {
        UIViewController *vc = [[contactInfoVC alloc] init];
        [vc setValue:contact forKey:@"m_contact"];
        [presentingVC.navigationController pushViewController:vc animated:YES];
    }
}
```
