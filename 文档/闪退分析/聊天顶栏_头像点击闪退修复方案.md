# 聊天顶栏头像点击闪退修复方案

> 基于 WCRefine 反编译逆向验证，只修根因不改结构

---

## 崩溃根因

```
onLeftAvatarTapped:
  ↓ ((id (*)(id,SEL))objc_msgSend)(chatController, @selector(GetContact))
  ↓ contact 返回值 ARC 未 retain（C 函数调用，__unsafe_unretained）
  ↓ delegate → CSContactInfoPopoverController init
  ↓ _contact = contact（直接 ivar 赋值，ARC 未 retain）
  ↓ onLeftAvatarTapped 结束，contact 出栈释放
  ↓ viewDidLoad → _contact 已野指针 → objc_retain → EXC_BAD_ACCESS (0x2)
```

两个地方都绕过了 ARC 的 retain 机制：

| 位置 | 写法 | 问题 |
|---|---|---|
| `MioChatAvatarTitleView.m:449` | `((id (*)(id,SEL))objc_msgSend)(...)` | C 函数指针强转，ARC 视为普通 C 函数调用，不 retain 返回值 |
| `CSContactInfoPopoverController.m:69` | `_contact = contact;` | 直接对 ivar 赋值，不经过 property setter，ARC 不 retain |

---

## 修复方案

不改结构、不改 UI、不加文件。只改 2 个地方。

### 改动一：MioChatAvatarTitleView.m（第 449/451/459 行）

把 raw `objc_msgSend` 改为 `performSelector:`，让 ARC 能 retain 返回值：

```objc
// 第 449 行：改前
id contact = ((id (*)(id, SEL))objc_msgSend)(self.chatController, NSSelectorFromString(@"GetContact"));

// 第 449 行：改后
id contact = [self.chatController performSelector:NSSelectorFromString(@"GetContact")];
```

```objc
// 第 451 行：改前
NSString *wxid = ((id (*)(id, SEL))objc_msgSend)(contact, NSSelectorFromString(@"m_nsUsrName"));

// 第 451 行：改后
NSString *wxid = [contact performSelector:NSSelectorFromString(@"m_nsUsrName")];
```

```objc
// 第 459 行（右头像同理）：改前
NSString *wxid = ((id (*)(id, SEL))objc_msgSend)(selfContact, NSSelectorFromString(@"m_nsUsrName"));

// 第 459 行：改后
NSString *wxid = [selfContact performSelector:NSSelectorFromString(@"m_nsUsrName")];
```

### 改动二：CSContactInfoPopoverController.m（第 69/70/72 行）

把 ivar 直接赋值改为 property 赋值，让 ARC 通过 setter 插入 retain：

```objc
// 第 66-76 行：改前
- (instancetype)initWithContact:(id)contact avatar:(UIImage *)avatar {
    self = [super init];
    if (self) {
        _contact = contact;        // ← ivar 直接赋值，ARC 不 retain
        _avatarImage = avatar;     // ← 同上
        if (contact) {
            _wxid = contactValueForKey(contact, @"m_nsUsrName");  // ← 同上
        }
    }
    return self;
}

// 第 66-76 行：改后
- (instancetype)initWithContact:(id)contact avatar:(UIImage *)avatar {
    self = [super init];
    if (self) {
        self.contact = contact;        // ← property setter，ARC 插入 retain
        self.avatarImage = avatar;     // ← 同上
        if (contact) {
            self.wxid = contactValueForKey(contact, @"m_nsUsrName");  // ← 同上
        }
    }
    return self;
}
```

> `CSContactInfoPopoverController.h` 中 `contact`、`wxid`、`avatarImage` 已声明为 `@property (nonatomic, strong)`，不需要额外修改头文件。

## 原理说明

`performSelector:` 是标准 Objective-C 消息发送方式，编译器能正确处理返回值的内存管理：

```objc
// 编译器视角
id contact = [self.chatController performSelector:@selector(GetContact)];
// → objc_msgSend(self.chatController, @selector(GetContact))
// → objc_retainAutoreleasedReturnValue()  ← ARC 自动插入
```

`self.property = value` 走 property setter，ARC 自动 retain：

```objc
// 编译器视角
self.contact = contact;
// → objc_retain(contact)
// → [self setContact:contact]
// → objc_release(old_contact)
// 等效于 MRC: [_contact release]; _contact = [contact retain];
```

两处改完后的 retain 链：

```
contact = [chatController performSelector:@selector(GetContact)]  ← retain count +1
  ↓
self.contact = contact  ← retain count +1（CSContactInfoPopoverController 持有）
  ↓
onLeftAvatarTapped: 结束 → ARC release contact  ← retain count -1
  ↓
CSContactInfoPopoverController 仍持有 → contact 存活 ✅
```
