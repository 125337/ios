# 布局字号不生效 — 深度诊断与修复

## 一、现象

| 现象 | 说明 |
|------|------|
| Hook 安装成功 | 日志第 78-80 行显示 `[+] MMUILabel.setFont: hooked`、`[+] MMTableViewCell.layoutSubviews hooked`、`✓ FontLayoutHook install complete` |
| 字号未变化 | 开启功能后重启微信，所有文字大小没有变化 |
| 无相关异常日志 | FontLayout 无 error/warning 日志 |

## 二、根因分析

两个 Hook 都命中了**错误的类**。

### 2.1 全局字号 Hook：MMUILabel 覆盖面不足

**当前行为**：
```
hook MMUILabel.setFont:
    → 仅拦截 MMUILabel 实例的 setFont: 调用
    → 不是 MMUILabel 的 UILabel 全部漏掉
```

**项目中其他 Hook 的证据**：

| 被 Hook 的类 | 来源 | 用途 |
|-------------|------|------|
| `MMUILabel` | FontLayoutHook（当前） | WeChat 自定义 UILabel 子类 |
| `MMGrowTextView` | PlaceholderTextHook | 文本输入框（不是 UILabel） |
| `CommonMessageCellView` | MessageTimeHook | 聊天消息显示（不是 MMUILabel） |
| `UILabel` | **未使用** | **系统类，所有标签的基类** |

在 WeChat 中，文本元素使用的类包括：
- `MMUILabel`（继承自 UILabel）— 大部分 UI 标签
- 直接使用 `UILabel` — 部分 UI 标签
- `YYLabel`（YYText 框架，不继承 UILabel）— 富文本
- `MMGrowTextView` / `UITextView` — 输入框

`MMUILabel.setFont:` 只能拦截第一类，漏掉了第二类。

### 2.2 对话字号 Hook：目标类完全错误

**当前行为**：
```
hook MMTableViewCell.layoutSubviews
    → 拦截的是"表格容器 Cell"的布局
    → MMTableViewCell → UIScrollView → UIView
    → 它里面包含的是 CommonMessageCellView 等消息视图
```

**项目中其他 Hook 的证据**：

| 被 Hook 的类 | 所属 Hook | 说明 |
|-------------|----------|------|
| `CommonMessageCellView` | MessageTimeHook | 聊天消息的主显示视图 |
| `TextMessageCellView` | MessageTimeHook | 文本消息专用视图 |
| `AppPatMessageCellView` | UIPurifyHook | 拍一拍消息视图 |
| `SystemMessageCellView` | UIPurifyHook | 系统提示消息视图 |
| `VoiceMessageCellView` | UIPurifyHook | 语音消息视图 |
| `MMTableViewCell` | **当前（错误）** | 只是容器，不含消息文本 |

**微信聊天界面的 View 层级**：

```
┌─────────────────────────────────┐
│ MMTableView (聊天列表)            │
├─────────────────────────────────┤
│ ┌── MMTableViewCell ──────────┐ │  ← 当前 hook 的目标（错误！！！）
│ │ ┌── CommonMessageCellView─┐ │ │  ← 实际含文本的视图
│ │ │ ┌─────────────────────┐ │ │ │
│ │ │ │ MMUILabel (消息内容)  │ │ │ │  ← 文本在这里
│ │ │ └─────────────────────┘ │ │ │
│ │ └─────────────────────────┘ │ │
│ └─────────────────────────────┘ │
│ ┌── MMTableViewCell ──────────┐ │
│ │ ┌── TextMessageCellView ──┐ │ │
│ │ │ ┌─────────────────────┐ │ │ │
│ │ │ │ MMUILabel (消息内容)  │ │ │ │
│ │ │ └─────────────────────┘ │ │ │
│ │ └─────────────────────────┘ │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

`MMTableViewCell.layoutSubviews` 执行时，`CommonMessageCellView` 内部的文本 UILabel 可能还未创建，或即使创建了，也很快会被 WeChat 重新设置 font。

**关键问题**：`collectLabelsInView` 遍历 `MMTableViewCell.contentView` 找到的 UILabel 不是消息文本本身，而是 MMTableViewCell 级别的辅助标签（如时间、分隔线等），消息文本在 `CommonMessageCellView` 的深层子视图中。

## 三、修复方案

### 3.1 全局字号：从 MMUILabel 改为 UILabel

```objc
// ★ 旧（错误）：仅拦截 MMUILabel
MSHookMessageEx(objc_getClass("MMUILabel"), @selector(setFont:), ...);

// ★ 新（正确）：拦截所有 UILabel（含 MMUILabel 等所有子类）
MSHookMessageEx(objc_getClass("UILabel"), @selector(setFont:), ...);
```

**原理**：`UILabel` 是 `MMUILabel` 的父类。hook 父类方法会通过继承机制被子类继承，`MMUILabel` 实例调用 `setFont:` 时也会经过这个 hook。同时，直接使用 `UILabel` 的实例也会被拦截。

### 3.2 对话字号：从 MMTableViewCell 改为 CommonMessageCellView

使用项目中**已有验证**的类 `CommonMessageCellView`：

```objc
// ★ 旧（错误）：hook 表格容器
MSHookMessageEx(objc_getClass("MMTableViewCell"), @selector(layoutSubviews), ...);

// ★ 新（正确）：hook 真实的聊天消息视图
MSHookMessageEx(objc_getClass("CommonMessageCellView"), @selector(layoutSubviews), ...);
```

**为什么选 `layoutSubviews`**：
- `initWithViewModel:` 调用时，内部的 UILabel 可能还没创建
- `layoutSubviews` 在布局完成后执行，所有子视图已就绪
- 执行频率高但我们的操作只是遍历和设字体，性能可接受

## 四、完整修复后的代码

### 4.1 FontLayoutHook.m（修改后）

```objc
#import "FontLayoutHook.h"
#import "FontLayoutConfig.h"
#import "../../Core/LogManager.h"
#import <substrate.h>
#import <objc/runtime.h>
#import <UIKit/UIKit.h>

#pragma mark - 原始 IMP 指针

static IMP orig_UILabel_setFont = NULL;
static IMP orig_CommonMessageCellView_layoutSubviews = NULL;

#pragma mark - 递归收集 UILabel

static void collectLabelsInView(UIView *view, NSMutableArray<UILabel *> *labels) {
    for (UIView *sub in view.subviews) {
        if ([sub isKindOfClass:[UILabel class]]) {
            [labels addObject:(UILabel *)sub];
        }
        if (sub.subviews.count > 0) {
            collectLabelsInView(sub, labels);
        }
    }
}

#pragma mark - 全局字号 Hook

/// 拦截所有 UILabel（含 MMUILabel 等子类）的 setFont:
/// 按比例缩放: scale = config.globalFontSize / 16.0
static void hook_UILabel_setFont(id self, SEL _cmd, UIFont *font) {
    FontLayoutConfig *config = [FontLayoutConfig shared];

    if (config.globalLayoutEnabled) {
        CGFloat target = config.globalFontSize;
        if (fabs(target - 16.0) > 0.01) {
            CGFloat scale = target / 16.0;
            CGFloat newSize = font.pointSize * scale;
            if (newSize < 6) newSize = 6;
            if (newSize > 48) newSize = 48;
            UIFont *newFont = [font fontWithSize:newSize];
            if (newFont) {
                ((void (*)(id, SEL, UIFont *))orig_UILabel_setFont)(self, _cmd, newFont);
                return;
            }
        }
    }

    ((void (*)(id, SEL, UIFont *))orig_UILabel_setFont)(self, _cmd, font);
}

#pragma mark - 对话字号 Hook

/// 拦截聊天消息视图的 layoutSubviews
/// 遍历其所有子 UILabel，直接设为 config.chatFontSize
static void hook_CommonMessageCellView_layoutSubviews(id self, SEL _cmd) {
    // 1. 先调原始布局
    ((void (*)(id, SEL))orig_CommonMessageCellView_layoutSubviews)(self, _cmd);

    // 2. 读取配置
    FontLayoutConfig *config = [FontLayoutConfig shared];
    if (!config.chatLayoutEnabled) return;

    CGFloat chatSize = config.chatFontSize;
    if (fabs(chatSize - 16.0) <= 0.01) return;

    // 3. 递归收集所有 UILabel
    NSMutableArray *labels = [NSMutableArray array];
    collectLabelsInView((UIView *)self, labels);

    // 4. 逐个设置字号
    for (UILabel *label in labels) {
        // 跳过时间标签（时间格式由 MessageTimeHook 控制）
        NSString *cls = NSStringFromClass([label class]);
        if ([cls containsString:@"ChatTime"] || [cls containsString:@"TimeLabel"]) continue;

        UIFont *newFont = [UIFont fontWithDescriptor:label.font.fontDescriptor size:chatSize];
        if (newFont) {
            label.font = newFont;
        }
    }
}

#pragma mark - 安装

@implementation FontLayoutHook

+ (void)install {
    // ── 全局字号：Hook UILabel（覆盖所有 UILabel 子类） ──
    Class uiLabelClass = objc_getClass("UILabel");
    if (uiLabelClass) {
        MSHookMessageEx(uiLabelClass, @selector(setFont:),
                        (IMP)hook_UILabel_setFont,
                        (IMP *)&orig_UILabel_setFont);
        WPLog(@"FontLayout", @"[+] UILabel.setFont: hooked (全局字号)");
    } else {
        WPLog(@"FontLayout", @"[-] UILabel class not found");
    }

    // ── 对话字号：Hook CommonMessageCellView（聊天消息实体视图） ──
    Class msgCellClass = objc_getClass("CommonMessageCellView");
    if (msgCellClass) {
        MSHookMessageEx(msgCellClass, @selector(layoutSubviews),
                        (IMP)hook_CommonMessageCellView_layoutSubviews,
                        (IMP *)&orig_CommonMessageCellView_layoutSubviews);
        WPLog(@"FontLayout", @"[+] CommonMessageCellView.layoutSubviews hooked (对话字号)");
    } else {
        WPLog(@"FontLayout", @"[-] CommonMessageCellView class not found");

        // 降级：尝试 TextMessageCellView
        Class textCellClass = objc_getClass("TextMessageCellView");
        if (textCellClass) {
            MSHookMessageEx(textCellClass, @selector(layoutSubviews),
                            (IMP)hook_CommonMessageCellView_layoutSubviews,
                            (IMP *)&orig_CommonMessageCellView_layoutSubviews);
            WPLog(@"FontLayout", @"[+] TextMessageCellView.layoutSubviews hooked (降级)");
        }
    }

    WPLog(@"FontLayout", @"✓ FontLayoutHook install complete");
}

@end
```

## 五、修复前后对比

### 5.1 全局字号覆盖范围

```
★ 修复前：MMUILabel.setFont:
┌─────────────────────────────────┐
│ MMUILabel 的子类实例              │  ← ✓ 拦截
│   (聊天列表标签、设置项标签等)     │
│ 普通 UILabel 实例                 │  ← ✗ 漏掉
│   (部分 WeChat UI 元素)          │
│ YYLabel (YYText)                 │  ← ✗ 不继承 UILabel
└─────────────────────────────────┘

★ 修复后：UILabel.setFont:
┌─────────────────────────────────┐
│ MMUILabel 的子类实例              │  ← ✓ 拦截（继承机制）
│ 普通 UILabel 实例                 │  ← ✓ 拦截
│ YYLabel (YYText)                 │  ← ✗ 不继承 UILabel（需另处理）
└─────────────────────────────────┘
```

> YYLabel 是一个独立的 UIView 子类，不继承 UILabel。它的文本通过 `NSAttributedString` 的字体属性控制，无法通过 `setFont:` 拦截。如需覆盖 YYLabel 的字体，需要额外的 Hook。

### 5.2 对话字号命中路径

```
★ 修复前：MMTableViewCell.layoutSubviews
MMTableViewCell.contentView
    └── 遍历 → 找到的是 TableView 级别的辅助标签
    └── 消息文本在 CommonMessageCellView 内部深层，collectionLabelsInView
        没有从 CommonMessageCellView 开始遍历，所以找不到

★ 修复后：CommonMessageCellView.layoutSubviews
CommonMessageCellView (self)
    └── collectLabelsInView(self, labels)
        ├── ┌─ 消息内容 UILabel ─┐  ← ✓ 找到
        ├── ┌─ 发送者昵称 UILabel ┐  ← ✓ 找到
        └── ┌─ 其他子 UILabel ────┘  ← ✓ 找到
```


## 八、总结

| 问题 | 原来 | 修正 |
|------|------|------|
| **全局字号目标类** | `MMUILabel`（子系统类） | `UILabel`（系统基类，覆盖所有子类） |
| **对话字号目标类** | `MMTableViewCell`（表格容器） | `CommonMessageCellView`（消息视图实体） |
| **对话字号范围判断** | `isInChatListView` 双重判断（复杂易错） | 不再需要，`CommonMessageCellView` 天然就是聊天上下文 |
| **已投产验证** | ❌ 无 | ✅ `MessageTimeHook` 和 `UIPurifyHook` 都使用相同的类 |
