# 项目布局功能适配实现方案

## 一、概述

本方案**完全复刻锤子助手**的布局改变机制，通过 Hook 微信主题系统实现所有布局的改变。

### 1.1 核心原理

```
锤子助手做法：
  1. Hook CLocalInfo.m_uiGlobalFontLevel → 返回 1（大字模式）
  2. Hook MMThemeManager.getValueOfProperty:inRuleSet: → 覆盖主题属性
  3. 效果：微信使用大字版整套布局参数（所有UI都改变）

本项目做法：
  1. Hook CLocalInfo.m_uiGlobalFontLevel → 返回 1（大字模式 ✓ 完全复刻）
  2. Hook MMThemeManager.getValueOfProperty:inRuleSet: → 覆盖主题属性 ✓ 完全复刻
  3. 效果：微信使用大字版整套布局参数 ✓ 完全一致
```

### 1.2 与锤子助手的关键差异

| 维度 | 锤子助手 | 本项目 |
|------|---------|-------|
| UI 框架 | WCUIAlertView + WCTableViewCellManager | SettingCategoryController 工厂方法 |
| 数据持久化 | NSUserDefaults + suite | ConfigManager（标准 UserDefaults） |
| 重启机制 | 自实现 suspend + terminate | MioRestartHelper（复用项目弹窗） |
| 布局参数 | fontSize 10~16 | 布局大小（数值配置） |
| 配置项 | 全局/对话分开配置 | 全局/对话分开配置 |
| Hook 策略 | MMThemeManager + CLocalInfo | MMThemeManager + CLocalInfo |
| 额外 Hook | 群标签 + 联系人过滤 | 不需要 |

## 四、数据配置层（LayoutConfig）

### 4.1 配置模型

```objc
// LayoutConfig.h
#import <Foundation/Foundation.h>

@interface LayoutConfig : NSObject

/// 全局布局开关
@property (nonatomic, assign) BOOL globalLayoutEnabled;
/// 全局布局大小 (默认 0，范围自定义，如 1-5 级)
@property (nonatomic, assign) NSInteger globalLayoutSize;
/// 对话布局开关
@property (nonatomic, assign) BOOL chatLayoutEnabled;
/// 对话布局大小 (默认 0，范围自定义)
@property (nonatomic, assign) NSInteger chatLayoutSize;

+ (instancetype)shared;
- (void)save;

@end
```

### 4.2 配置存储

```objc
// LayoutConfig.m
#import "LayoutConfig.h"

@implementation LayoutConfig

static LayoutConfig *shared = nil;

+ (instancetype)shared {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        shared = [[super allocWithZone:NULL] init];
    });
    return shared;
}

+ (instancetype)allocWithZone:(struct _NSZone *)zone {
    return [self shared];
}

- (instancetype)init {
    self = [super init];
    if (self) {
        // 从 ConfigManager 读取配置（项目现有基础设施）
        self.globalLayoutEnabled = [[ConfigManager shared] boolForKey:@"layout_global_enabled" defaultValue:NO];
        self.globalLayoutSize = [[ConfigManager shared] integerForKey:@"layout_global_size" defaultValue:0];
        self.chatLayoutEnabled = [[ConfigManager shared] boolForKey:@"layout_chat_enabled" defaultValue:NO];
        self.chatLayoutSize = [[ConfigManager shared] integerForKey:@"layout_chat_size" defaultValue:0];
    }
    return self;
}

- (void)save {
    [[ConfigManager shared] setBool:self.globalLayoutEnabled forKey:@"layout_global_enabled"];
    [[ConfigManager shared] setInteger:self.globalLayoutSize forKey:@"layout_global_size"];
    [[ConfigManager shared] setBool:self.chatLayoutEnabled forKey:@"layout_chat_enabled"];
    [[ConfigManager shared] setInteger:self.chatLayoutSize forKey:@"layout_chat_size"];
    [[ConfigManager shared] synchronize];
}

@end
```

### 4.3 布局大小与主题值的映射

布局大小不直接对应字号，而是**对应生效/不生效**。大字模式本身已经放大所有布局，布局大小决定是否 override 主题值：

```objc
// LayoutSizeManager.h
#import <Foundation/Foundation.h>

@interface LayoutSizeManager : NSObject

/// 根据布局大小计算主题属性值
/// @param size 布局大小（1-5级，0表示使用默认）
/// @param levelType 级别类型（allLevel / chatLevel）
/// @return 返回给微信主题系统的值
+ (NSString *)themeValueForSize:(NSInteger)size levelType:(NSString *)levelType;

/// 布局大小对应的字号映射
+ (CGFloat)fontSizeForLevel:(NSInteger)size;

@end
```

## 五、Hook 层（核心）

### 5.1 Hook 安装

```objc
// LayoutHook.h
#import <Foundation/Foundation.h>

@interface LayoutHook : NSObject
+ (void)install;
@end
```

```objc
// LayoutHook.m
#import "LayoutHook.h"
#import "LayoutConfig.h"
#import "LayoutSizeManager.h"
#import <substrate.h>

// ─────────────────────────────────────────
// Hook 1 原方法指针
// ─────────────────────────────────────────
static id (*orig_getValueOfProperty_inRuleSet)(id, SEL, NSString *, NSString *);

// Hook 1 替代函数
static id hook_getValueOfProperty_inRuleSet(id self, SEL _cmd, 
                                             NSString *property, 
                                             NSString *ruleSet) {
    LayoutConfig *config = [LayoutConfig shared];
    BOOL globalOn = config.globalLayoutEnabled;
    BOOL chatOn = config.chatLayoutEnabled;
    
    if (globalOn || chatOn) {
        // ── 全局布局：覆盖 allLevel + _font_set ──
        if (globalOn && 
            [property isEqualToString:@"allLevel"] && 
            [ruleSet hasSuffix:@"_font_set"]) {
            
            NSInteger size = config.globalLayoutSize;
            if (size > 0) {
                // 使用布局大小管理器转换
                return [LayoutSizeManager themeValueForSize:size 
                                                  levelType:@"allLevel"];
            }
        }
        
        // ── 全局布局：覆盖 webLevel + _font_set ──
        if (globalOn && 
            [property isEqualToString:@"webLevel"] && 
            [ruleSet hasSuffix:@"_font_set"]) {
            
            NSInteger size = config.globalLayoutSize;
            if (size > 0) {
                return [LayoutSizeManager themeValueForSize:size 
                                                  levelType:@"webLevel"];
            }
        }
        
        // ── 对话布局：覆盖 chatLevel + _font_set ──
        if (chatOn && 
            [property isEqualToString:@"chatLevel"] && 
            [ruleSet hasSuffix:@"_font_set"]) {
            
            NSInteger size = config.chatLayoutSize;
            if (size > 0) {
                return [LayoutSizeManager themeValueForSize:size 
                                                  levelType:@"chatLevel"];
            }
        }
    }
    
    // 不匹配 → 走原方法（让微信使用大字默认值）
    return orig_getValueOfProperty_inRuleSet(self, _cmd, property, ruleSet);
}

// ─────────────────────────────────────────
// Hook 2 原方法指针
// ─────────────────────────────────────────
static unsigned int (*orig_m_uiGlobalFontLevel)(id, SEL);

// Hook 2 替代函数
static unsigned int hook_m_uiGlobalFontLevel(id self, SEL _cmd) {
    LayoutConfig *config = [LayoutConfig shared];
    
    // 任一布局功能开启 → 返回 1（大字模式）
    // 触发微信使用大字版整套布局参数
    if (config.globalLayoutEnabled || config.chatLayoutEnabled) {
        return 1;
    }
    
    // 未启用 → 走原始逻辑
    return orig_m_uiGlobalFontLevel(self, _cmd);
}

// ─────────────────────────────────────────
// 安装 Hook
// ─────────────────────────────────────────
@implementation LayoutHook

+ (void)install {
    // 微信版本检查（参考项目现有逻辑）
    
    // Hook 1: 拦截主题系统（核心）
    MSHookMessageEx(
        objc_getClass("MMThemeManager"),
        @selector(getValueOfProperty:inRuleSet:),
        (IMP)hook_getValueOfProperty_inRuleSet,
        (IMP *)&orig_getValueOfProperty_inRuleSet
    );
    
    // Hook 2: 强制大字模式（关键辅助）
    MSHookMessageEx(
        objc_getClass("CLocalInfo"),
        @selector(m_uiGlobalFontLevel),
        (IMP)hook_m_uiGlobalFontLevel,
        (IMP *)&orig_m_uiGlobalFontLevel
    );
    
    NSLog(@"[LayoutHook] Layout hooks installed successfully");
}

@end
```

### 5.2 布局大小管理器实现

```objc
// LayoutSizeManager.m
#import "LayoutSizeManager.h"

@implementation LayoutSizeManager

/// 布局大小（1-5级）对应的字号（pt）
/// 通过布局大小控制主题系统中的级别值
+ (NSString *)themeValueForSize:(NSInteger)size levelType:(NSString *)levelType {
    // 微信主题系统期望返回 NSString 格式的值
    // 这些值对应微信 _font_set 规则集中的级别
    // 级别越高，所有布局尺寸越大
    
    // 布局大小与主题级别的映射：
    // 0 = 不覆盖（使用大字默认值）
    // 1 = 最小（对应字号 ~14pt）
    // 2 = 较小（对应字号 ~16pt）
    // 3 = 标准大字（对应字号 ~18pt）—— 微信大字模式默认
    // 4 = 较大（对应字号 ~20pt）
    // 5 = 最大（对应字号 ~22pt）
    
    static NSString *levelMap[] = {
        @"0",   // 不覆盖（内部用）
        @"14",  // 小
        @"16",  // 较小
        @"18",  // 标准大字
        @"20",  // 较大
        @"22"   // 最大
    };
    
    if (size >= 1 && size <= 5) {
        return levelMap[size];
    }
    
    // size == 0 或无效，返回 nil
    // 调用方收到 nil 后会走原方法
    return nil;
}

+ (CGFloat)fontSizeForLevel:(NSInteger)size {
    switch (size) {
        case 1: return 14.0;
        case 2: return 16.0;
        case 3: return 18.0;
        case 4: return 20.0;
        case 5: return 22.0;
        default: return 0.0; // 不覆盖
    }
}

@end
```

### 5.3 两个 Hook 的协同工作流程

```
微信启动 → dylib 注入 → LayoutHook.install
  │
  ├── Hook MMThemeManager.getValueOfProperty:inRuleSet:
  └── Hook CLocalInfo.m_uiGlobalFontLevel
  
微信初始化 UI
  │
  ├── 1. CLocalInfo.m_uiGlobalFontLevel 被调用
  │     → Hook 2 拦截
  │     → 检查 LayoutConfig：globalLayoutEnabled=YES
  │     → 返回 1（大字模式）
  │     → 微信使用大字版 _font_set 规则集
  │
  ├── 2. 微信遍历所有 UI 控件，查询主题属性
  │
  ├── 3. getValueOfProperty:@"allLevel" inRuleSet:@"_font_set"
  │     → Hook 1 拦截
  │     → 匹配条件 ✓
  │     → globalLayoutSize=3 → 返回 @"18"
  │     → 微信使用 18 作为全局字体级别
  │
  ├── 4. getValueOfProperty:@"chatLevel" inRuleSet:@"_font_set"
  │     → Hook 1 拦截
  │     → 匹配条件 ✓
  │     → chatLayoutEnabled=YES, chatLayoutSize=2 → 返回 @"16"
  │     → 微信使用 16 作为对话字体级别
  │
  ├── 5. getValueOfProperty:@"subLevel" inRuleSet:@"_font_set"
  │     → Hook 1 拦截
  │     → 不匹配条件 → 走原方法
  │     → 返回大字默认值
  │
  └── 6. 渲染结果
        ├── Cell 行高 → 大字默认值（比标准大）
        ├── 气泡宽度 → 大字默认值（比标准大）
        ├── 头像尺寸 → 大字默认值（比标准大）
        ├── 正文字号 → 18pt（被全局布局覆盖）
        ├── 聊天字号 → 16pt（被对话布局覆盖）
        ├── 控件间距 → 大字默认值
        └── 整体效果 → 所有布局均比标准模式大
```

### 6.3 控制器实现（工厂方法）

```objc
// WPUILayoutSettingsVC.m
#import "WPUILayoutSettingsVC.h"
#import "SettingCategoryController.h"
#import "LayoutConfig.h"
#import "MioRestartHelper.h"

@interface WPUILayoutSettingsVC ()
@property (nonatomic, strong) LayoutConfig *config;
@end

@implementation WPUILayoutSettingsVC

- (void)viewDidLoad {
    [super viewDidLoad];
    self.title = @"布局设置";
    self.config = [LayoutConfig shared];
    [self setupUI];
}

- (void)setupUI {
    // ── Section 1: 全局布局 ──
    SettingCategoryController *globalSection = [SettingCategoryController sectionWithTitle:nil];
    
    // 全局布局开关
    [globalSection addSwitchItemWithTitle:@"全局布局" 
                                   config:self.config
                                     key:@"globalLayoutEnabled"
                             valueChanged:^(BOOL isOn) {
        if (isOn) {
            [self showRestartAlert];
        }
        [self.config save];
    }];
    
    // 全局布局大小选择
    [globalSection addSelectItemWithTitle:@"全局布局大小" 
                                   config:self.config
                                     key:@"globalLayoutSize"
                                   values:@[@"不启用", @"最小", @"较小", @"标准", @"较大", @"最大"]
                              valueChanged:^{
        [self.config save];
        [self showRestartAlert];
    }];
    
    // ── Section 2: 对话布局 ──
    SettingCategoryController *chatSection = [SettingCategoryController sectionWithTitle:nil];
    
    // 对话布局开关
    [chatSection addSwitchItemWithTitle:@"对话布局" 
                                  config:self.config
                                    key:@"chatLayoutEnabled"
                            valueChanged:^(BOOL isOn) {
        if (isOn) {
            [self showRestartAlert];
        }
        [self.config save];
    }];
    
    // 对话布局大小选择
    [chatSection addSelectItemWithTitle:@"对话布局大小" 
                                  config:self.config
                                    key:@"chatLayoutSize"
                                  values:@[@"不启用", @"最小", @"较小", @"标准", @"较大", @"最大"]
                             valueChanged:^{
        [self.config save];
        [self showRestartAlert];
    }];
    
    // 添加到页面
    [self addSection:globalSection];
    [self addSection:chatSection];
    [self reloadTableData];
}

/// 弹出重启提示（复用项目 MioRestartHelper）
- (void)showRestartAlert {
    [MioRestartHelper showRestartAlertWithMessage:@"布局改变需要重启微信才能生效"
                                      cancelText:@"稍后再说"
                                     confirmText:@"立即重启"
                                    confirmBlock:^{
        [MioRestartHelper restartApp];
    }];
}

@end
```

| Tab 图标 | 20-24pt | 24-28pt |
| 列表项高度 | 44pt | 52pt |
| 输入框 | 高度 ~34pt | 高度 ~40pt |
| 弹窗 | 宽度 270pt | 宽度 ~300pt |
| 按钮内边距 | 8-12pt | 12-16pt |
