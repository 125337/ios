# 项目布局功能适配实现方案（完整版）

## 一、概述

在"界面定制"页面中新增一个"布局设置"二级页面，允许用户调整微信的**全局字号**和**对话字号**。核心逻辑分为两层：

```
┌──────────────────────────────────────────────────┐
│                   UI 层（设置页面）                  │
│  WPUIVC → push → WPUILayoutSettingsVC            │
│  用户操作 → ConfigManager 持久化                    │
└──────────────────────┬───────────────────────────┘
                       ↓ 读取配置
┌──────────────────────┴───────────────────────────┐
│                  Hook 层（运行时注入）               │
│  ① 全局字号 Hook: MMUILabel.setFont: → 按比例缩放  │
│  ② 对话字号 Hook: MMTableViewCell.layoutSubviews   │
│                    → 聊天列表内 UILabel 字号覆盖     │
└──────────────────────────────────────────────────┘
```

### 文件清单

| 文件 | 操作 | 说明 |
|------|------|------|
| **Modules/FontLayout/FontLayoutConfig.h/.m** | 新增 | 配置定义（2 个 BOOL + 2 个 CGFloat） |
| **Modules/FontLayout/FontLayoutHook.h/.m** | 新增 | Hook 安装（全局字号 + 对话字号） |
| **Settings/Controllers/WPUILayoutSettingsVC.h/.m** | 新增 | 布局设置二级页面 UI |
| **Modules/SettingEntry/WPUIVC.m** | 修改 | +3 行：items + navigateTo case 107 |
| **Registry/MioModuleRegistry.m** | 修改 | +1 行：注册 FontLayout 模块（自动安装 Hook） |

## 二、Config 层：FontLayoutConfig

### 2.1 配置项

| Key | 类型 | 默认值 | 说明 |
|-----|------|--------|------|
| `globalLayoutEnabled` | BOOL | NO | 全局布局总开关 |
| `globalFontSize` | CGFloat | 16.0 | 全局字号(px)，范围 10~24 |
| `chatLayoutEnabled` | BOOL | NO | 对话布局总开关 |
| `chatFontSize` | CGFloat | 16.0 | 对话字号(px)，范围 10~24 |

> 字号 16 = 微信默认字号，设为 16 表示不做调整。

### 2.2 头文件

```objc
@property (nonatomic, assign) CGFloat globalFontSize;

/// 对话布局
@property (nonatomic, assign) BOOL chatLayoutEnabled;
@property (nonatomic, assign) CGFloat chatFontSize;

@end
```

### 2.3 实现文件

```objc

    return @"FontLayout_";

    return @[
        [ConfigDescriptor itemWithKey:@"globalLayoutEnabled" type:ConfigValueTypeBool default:@(NO)],
        [ConfigDescriptor itemWithKey:@"globalFontSize"      type:ConfigValueTypeFloat default:@(16.0f)],
```

> `@dynamic` 让 `ConfigManager` 自动合成 getter/setter，底层通过 `modulePrefix` + key 读写 NSUserDefaults。

## 三、Hook 层：FontLayoutHook（核心）

### 3.1 架构总览

```
FontLayoutHook.install()
  │
  ├── 1. 获取 MMUILabel 类
  │     └── MSHookMessageEx(setFont:) → hook_MMUILabel_setFont
  │           └── 职责: 全局字号缩放
  │                 读取 config.globalFontSize
  │                 计算缩放比例 scale = fontSize / 16.0
  │                 所有 MMUILabel.font = font × scale
  │
  ├── 2. 获取 MMTableViewCell 类
  │     └── MSHookMessageEx(layoutSubviews) → hook_MMTableViewCell_layoutSubviews
  │           └── 职责: 对话字号覆盖
  │                 判断 isInChatListView
  │                 遍历 contentView 下所有 UILabel
  │                 直接设置 label.font = [UIFont systemFontOfSize:chatFontSize]
  │
  └── 3. 向 MMTableViewCell 动态添加 isInChatListView 方法
```

### 3.2 两级 Hook 的优先级模型

```
MMUILabel.setFont: 被调用
    │
    ├─ globalLayoutEnabled = NO → 不做缩放，直接走 orig
    ├─ globalLayoutEnabled = YES → 按比例缩放字号
    │     scale = globalFontSize / 16.0
    │     newFont = oldFont × scale
    │
    └── 然后（同一 runloop 稍后）→ layoutSubviews
          │
          ├─ chatLayoutEnabled = NO → 不做任何事
          └─ chatLayoutEnabled = YES + 在聊天列表中
                → 对当前 Cell 内所有 UILabel 直接设置为 chatFontSize
                → 覆盖 MMUILabel 阶段设置的缩放字号
```

**为什么需要两级 Hook？**

| 层级 | 目标 | 实现方式 | 覆盖范围 |
|------|------|---------|---------|
| **全局字号** | 整个微信 App 的界面文本 | Hook MMUILabel.setFont: 按比例缩放 | 所有 MMUILabel（通讯录、设置页、朋友圈等） |
| **对话字号** | 仅聊天对话中的消息文本 | Hook MMTableViewCell.layoutSubviews 直接覆盖 | 仅聊天列表内的 UILabel |

**优先级**：对话字号 > 全局字号。即对话字号在聊天列表中完全覆盖全局字号的效果。

### 3.3 辅助方法：isInChatListView

```objc
/// 判断 Cell 是否在聊天列表中
/// 双重验证：m_delegate 类型 + superview 层级
static BOOL isInChatListView(id cell) {
    // 方法1：通过 m_delegate 判断（微信私有属性）
    id delegate = [cell valueForKey:@"m_delegate"];
    if (delegate) {
        NSString *delegateClass = NSStringFromClass([delegate class]);
        if ([delegateClass hasPrefix:@"BaseMsgContent"] ||
            [delegateClass hasPrefix:@"Chat"] ||
            [delegateClass containsString:@"MsgContent"]) {
            return YES;
        }
    }

    // 方法2：遍历 superview 链判断
    UIView *superview = [cell superview];
    while (superview) {
        NSString *svClass = NSStringFromClass([superview class]);
        if ([svClass hasPrefix:@"BaseMsgContent"] ||
            [svClass hasPrefix:@"Chat"] ||
            [svClass hasPrefix:@"MMTableView"]) {
            return YES;
        }
        superview = [superview superview];
    }

    return NO;
}
```

### 3.4 全局字号 Hook：MMUILabel.setFont:

```objc
// ★★★ 核心原理 ★★★
// WeChat 几乎所有界面元素使用的是 MMUILabel（UILabel 的子类），
// 包括通讯录、设置页、聊天列表、朋友圈等。
// Hook MMUILabel.setFont: 可以覆盖整个 App 的字体。
//
// 缩放逻辑：scale = config.globalFontSize / 16.0
// 不直接设置固定字号，而是按比例缩放，保留不同 UI 元素之间的层级关系
// （标题依然比正文大，小字依然比正文小）。

static IMP orig_MMUILabel_setFont = NULL;

static void hook_MMUILabel_setFont(id self, SEL _cmd, UIFont *font) {
    FontLayoutConfig *config = [FontLayoutConfig shared];

    if (config.globalLayoutEnabled) {
        CGFloat baseSize = 16.0;                      // 微信基准字号
        CGFloat targetSize = config.globalFontSize;   // 用户设定的全局字号

        if (fabs(targetSize - baseSize) > 0.01) {
            CGFloat scale = targetSize / baseSize;    // 缩放比例
            CGFloat newSize = font.pointSize * scale;

            // 范围保护：防止缩放导致字号过小或过大
            if (newSize < 6) newSize = 6;
            if (newSize > 48) newSize = 48;

            UIFont *newFont = [font fontWithSize:newSize];
            if (newFont) {
                ((void (*)(id, SEL, UIFont *))orig_MMUILabel_setFont)(self, _cmd, newFont);
                return;
            }
        }
    }

    // 未启用或缩放失败 → 走原始调用
    ((void (*)(id, SEL, UIFont *))orig_MMUILabel_setFont)(self, _cmd, font);
}
```

### 3.5 对话字号 Hook：MMTableViewCell.layoutSubviews

```objc
// ★★★ 核心原理 ★★★
// 在聊天列表 Cell 布局完成后，遍历其 contentView 内所有 UILabel，
// 直接设置它们的 font 为 config.chatFontSize。
// 使用递归遍历而非单层遍历，因为微信 Cell 内的 UILabel 可能嵌在多层子视图中。
//
// 调用时机：orig 之后（微信完成基础布局之后才修改，不影响微信布局逻辑）。

static IMP orig_MMTableViewCell_layoutSubviews = NULL;

/// 递归收集所有 UILabel
static void collectLabelsInView(UIView *view, NSMutableArray<UILabel *> *labels) {
    for (UIView *subview in view.subviews) {
        if ([subview isKindOfClass:[UILabel class]]) {
            [labels addObject:(UILabel *)subview];
        }
        if (subview.subviews.count > 0) {
            collectLabelsInView(subview, labels);
        }
    }
}

static void hook_MMTableViewCell_layoutSubviews(id self, SEL _cmd) {
    // 1. 先调原始 layoutSubviews（微信完成基础布局）
    ((void (*)(id, SEL))orig_MMTableViewCell_layoutSubviews)(self, _cmd);

    // 2. 判断是否在聊天列表中
    if (!isInChatListView(self)) return;

    // 3. 读取配置
    FontLayoutConfig *config = [FontLayoutConfig shared];
    if (!config.chatLayoutEnabled) return;

    CGFloat chatSize = config.chatFontSize;

    // 4. 默认值 16.0 = 不调整
    if (fabs(chatSize - 16.0) <= 0.01) return;

    // 5. 遍历 contentView 下所有 UILabel
    NSMutableArray *labels = [NSMutableArray array];
    collectLabelsInView([self valueForKey:@"contentView"], labels);

    for (UILabel *label in labels) {
        UIFont *newFont = [UIFont fontWithDescriptor:label.font.fontDescriptor size:chatSize];
        if (newFont) {
            label.font = newFont;
            [label sizeToFit];
        }
    }
}
```

### 3.6 Hook 安装：FontLayoutHook.install

```objc
// FontLayoutHook.m 完整实现
#import "FontLayoutHook.h"
#import "FontLayoutConfig.h"
#import "../../Core/LogManager.h"
#import <substrate.h>
#import <objc/runtime.h>
#import <UIKit/UIKit.h>

#pragma mark - 原始 IMP 指针

static IMP orig_MMUILabel_setFont = NULL;
static IMP orig_MMTableViewCell_layoutSubviews = NULL;

#pragma mark - isInChatListView 判断

static BOOL isInChatListView(id cell) {
    // (见 3.3 节)
}

#pragma mark - 全局字号 Hook

static void hook_MMUILabel_setFont(id self, SEL _cmd, UIFont *font) {
    // (见 3.4 节)
}

#pragma mark - 对话字号 Hook

static void collectLabelsInView(UIView *view, NSMutableArray<UILabel *> *labels) {
    // (见 3.5 节)
}

static void hook_MMTableViewCell_layoutSubviews(id self, SEL _cmd) {
    // (见 3.5 节)
}

#pragma mark - Hook 安装

@implementation FontLayoutHook

+ (void)install {
    Class mmuiLabelClass = objc_getClass("MMUILabel");
    if (mmuiLabelClass) {
        MSHookMessageEx(mmuiLabelClass,
                        @selector(setFont:),
                        (IMP)hook_MMUILabel_setFont,
                        (IMP *)&orig_MMUILabel_setFont);
        WPLog(@"FontLayout", @"[+] MMUILabel.setFont: hooked (全局字号)");
    } else {
        WPLog(@"FontLayout", @"[-] MMUILabel class not found");
    }

    Class mmtvCellClass = objc_getClass("MMTableViewCell");
    if (mmtvCellClass) {
        MSHookMessageEx(mmtvCellClass,
                        @selector(layoutSubviews),
                        (IMP)hook_MMTableViewCell_layoutSubviews,
                        (IMP *)&orig_MMTableViewCell_layoutSubviews);
        WPLog(@"FontLayout", @"[+] MMTableViewCell.layoutSubviews hooked (对话字号)");
    } else {
        WPLog(@"FontLayout", @"[-] MMTableViewCell class not found");
    }

    if (!mmuiLabelClass && !mmtvCellClass) {
        WPLog(@"FontLayout", @"✗ FontLayoutHook: 所有目标类均未找到");
    } else {
        WPLog(@"FontLayout", @"✓ FontLayoutHook install complete");
    }
}

@end
```

```objc
// WPUILayoutSettingsVC.m
#import "WPUILayoutSettingsVC.h"
#import "../../Modules/FontLayout/FontLayoutConfig.h"
#import "../../Core/MioRestartHelper.h"

static NSString *const kGlobalLayoutEnabled = @"globalLayoutEnabled";
static NSString *const kGlobalFontSize = @"globalFontSize";
static NSString *const kChatLayoutEnabled = @"chatLayoutEnabled";
static NSString *const kChatFontSize = @"chatFontSize";

static const CGFloat kMinFontSize = 10.0;
static const CGFloat kMaxFontSize = 24.0;

@implementation WPUILayoutSettingsVC

- (void)viewDidLoad {
    [super viewDidLoad];
    self.title = @"布局设置";
    [self buildUI];
}

- (void)buildUI {
    for (UIView *v in self.contentView.subviews) {
        [v removeFromSuperview];
    }
    self.masterSwitchKeys = [NSMutableSet set];

    CGFloat w = self.view.bounds.size.width;
    CGFloat y = 8;

    // ═════════════════════════════
    // Section 1: 全局布局
    // ═════════════════════════════
    y = [self addSectionHeader:@"全局布局" y:y width:w];

    UIView *group1 = [self addTableGroupAtY:y width:w];
    CGFloat cy = 0;

    BOOL globalOn = [[ConfigManager valueForKey:kGlobalLayoutEnabled] boolValue];
    CGFloat globalFontSize = [[ConfigManager valueForKey:kGlobalFontSize] floatValue];
    if (globalFontSize < kMinFontSize) globalFontSize = 16;

    [self.masterSwitchKeys addObject:kGlobalLayoutEnabled];
    cy = [self addMasterSwitchRowInGroup:group1
                                   title:@"修改全局布局"
                                     key:kGlobalLayoutEnabled
                                    isOn:globalOn
                              subBuilder:^(UIView *expand, CGFloat *ecy) {
        if (globalOn) {
            *ecy = [self addInputRowInGroup:expand
                                      title:@"全局字号(px)"
                                        key:kGlobalFontSize
                                      value:[NSString stringWithFormat:@"%.0f", globalFontSize]
                                       hint:@"16"
                                  valueType:InputValueTypeNumber
                                 alertTitle:@"设置全局字号"
                               alertMessage:[NSString stringWithFormat:@"请输入字号(%.0f-%.0f)", kMinFontSize, kMaxFontSize]
                                         cy:*ecy width:w];
        }
    }                                    cy:cy width:w];

    y = [self finishGroup:group1 atY:y height:cy];

    // ═════════════════════════════
    // Section 2: 对话布局
    // ═════════════════════════════
    y = [self addSectionHeader:@"对话布局" y:y width:w];

    UIView *group2 = [self addTableGroupAtY:y width:w];
    cy = 0;

    BOOL chatOn = [[ConfigManager valueForKey:kChatLayoutEnabled] boolValue];
    CGFloat chatFontSize = [[ConfigManager valueForKey:kChatFontSize] floatValue];
    if (chatFontSize < kMinFontSize) chatFontSize = 16;

    [self.masterSwitchKeys addObject:kChatLayoutEnabled];
    cy = [self addMasterSwitchRowInGroup:group2
                                   title:@"修改对话布局"
                                     key:kChatLayoutEnabled
                                    isOn:chatOn
                              subBuilder:^(UIView *expand, CGFloat *ecy) {
        if (chatOn) {
            *ecy = [self addInputRowInGroup:expand
                                      title:@"对话字号(px)"
                                        key:kChatFontSize
                                      value:[NSString stringWithFormat:@"%.0f", chatFontSize]
                                       hint:@"16"
                                  valueType:InputValueTypeNumber
                                 alertTitle:@"设置对话字号"
                               alertMessage:[NSString stringWithFormat:@"请输入字号(%.0f-%.0f)", kMinFontSize, kMaxFontSize]
                                         cy:*ecy width:w];
        }
    }                                    cy:cy width:w];

    y = [self finishGroup:group2 atY:y height:cy];

    self.contentView.frame = CGRectMake(0, 0, w, y + 40);
    self.scrollView.contentSize = CGSizeMake(w, y + 40);
}

#pragma mark - 开关回调（与项目 SettingListCornerRadiusController 模式一致）

- (void)switchChanged:(UISwitch *)sender {
    [super switchChanged:sender];

    NSString *key = objc_getAssociatedObject(sender, "key");
    if (!key) return;

    // 主开关变化 → 弹重启弹窗
    if ([key isEqualToString:kGlobalLayoutEnabled]
        || [key isEqualToString:kChatLayoutEnabled]) {
        [MioRestartHelper showRestartAlertFromVC:self];
    }
}

@end
```

## 六、完整执行流程

```
用户打开界面定制
    → 看到"布局设置"列表项 (tag=107)
    → 点击 → navigateTo: 创建 WPUILayoutSettingsVC
    → viewDidLoad → buildUI
    → 显示两个 Section

用户开启"修改全局布局"
    → 展开显示"全局字号(px)"输入行
    → 输入 18 → 保存到 ConfigManager (globalFontSize=18)
    → 返回上级页面 → switchChanged: → MioRestartHelper 弹重启弹窗
    → 点击"立即重启" → 微信杀死并重启
    → 重启后 FontLayoutHook.install 被调用
    → 所有 MMUILabel.setFont: 被 Hook
    → 缩放比例 scale = 18 / 16 = 1.125
    → 微信界面所有文本放大 1.125 倍

用户开启"修改对话布局"
    → 展开显示"对话字号(px)"输入行
    → 输入 20 → 保存到 ConfigManager (chatFontSize=20)
    → 重启后：
    → MMTableViewCell.layoutSubviews Hook 生效
    → 在聊天列表中遍历所有 UILabel → 字号统一设为 20
    → 对话界面文本 = 20px（覆盖全局缩放效果）
```

## 七、生效机制

### 7.1 重启触发点

| 场景 | 触发方式 | 弹窗 |
|------|---------|------|
| 开启/关闭"修改全局布局" | `switchChanged:` | `MioRestartHelper.showRestartAlertFromVC:` |
| 开启/关闭"修改对话布局" | `switchChanged:` | 同上 |
| 修改字号数值 | `addInputRowInGroup:` 的编辑弹窗"确定" | 自动保存，不弹（下次重启生效） |

### 7.2 MioRestartHelper 流程

```
用户点击"立即重启"
    → [UIApplication suspend]                    → 微信挂起到后台
    → dispatch_after 1秒
        → LSApplicationWorkspace 拉起微信         → 微信重新启动
        → exit(0)                                → 杀死当前进程
    → iOS 重新运行微信
    → CydiaSubstrate 重新注入所有 dylib
    → MioModuleRegistry.registerAll
        → [ConfigManager loadAll]                 → 读取已保存的配置
        → [FontLayoutHook install]                → 安装 Hook
    → MMUILabel.setFont: 被拦截 → 全局字号缩放
    → MMTableViewCell.layoutSubviews → 对话字号覆盖
    → 用户看到调整后的字体大小
```

### 8.4 FontLayoutHook.m（完整）

```objc
#import "FontLayoutHook.h"
#import "FontLayoutConfig.h"
#import "../../Core/LogManager.h"
#import <substrate.h>
#import <objc/runtime.h>
#import <UIKit/UIKit.h>

#pragma mark - 原始 IMP 指针

static IMP orig_MMUILabel_setFont = NULL;
static IMP orig_MMTableViewCell_layoutSubviews = NULL;

#pragma mark - 辅助方法

static BOOL isInChatListView(id cell) {
    id delegate = [cell valueForKey:@"m_delegate"];
    if (delegate) {
        NSString *cls = NSStringFromClass([delegate class]);
        if ([cls hasPrefix:@"BaseMsgContent"] ||
            [cls hasPrefix:@"Chat"] ||
            [cls containsString:@"MsgContent"]) {
            return YES;
        }
    }
    UIView *sv = [cell superview];
    while (sv) {
        NSString *cls = NSStringFromClass([sv class]);
        if ([cls hasPrefix:@"BaseMsgContent"] ||
            [cls hasPrefix:@"Chat"] ||
            [cls containsString:@"MsgContent"] ||
            [cls hasPrefix:@"MMTableView"]) {
            return YES;
        }
        sv = [sv superview];
    }
    return NO;
}

static void collectLabelsInView(UIView *view, NSMutableArray<UILabel *> *labels) {
    for (UIView *sub in view.subviews) {
        if ([sub isKindOfClass:[UILabel class]]) {
            [labels addObject:(UILabel *)sub];
        }
        if (sub.subviews.count > 0) {
            collectLabelsInView(sub, labels);
        }
    }
}

#pragma mark - 全局字号 Hook

static void hook_MMUILabel_setFont(id self, SEL _cmd, UIFont *font) {
    FontLayoutConfig *config = [FontLayoutConfig shared];
    if (config.globalLayoutEnabled) {
        CGFloat target = config.globalFontSize;
        if (fabs(target - 16.0) > 0.01) {
            CGFloat scale = target / 16.0;
            CGFloat newSize = font.pointSize * scale;
            if (newSize < 6) newSize = 6;
            if (newSize > 48) newSize = 48;
            UIFont *newFont = [font fontWithSize:newSize];
            if (newFont) {
                ((void (*)(id, SEL, UIFont *))orig_MMUILabel_setFont)(self, _cmd, newFont);
                return;
            }
        }
    }
    ((void (*)(id, SEL, UIFont *))orig_MMUILabel_setFont)(self, _cmd, font);
}

#pragma mark - 对话字号 Hook

static void hook_MMTableViewCell_layoutSubviews(id self, SEL _cmd) {
    ((void (*)(id, SEL))orig_MMTableViewCell_layoutSubviews)(self, _cmd);
    if (!isInChatListView(self)) return;
    FontLayoutConfig *config = [FontLayoutConfig shared];
    if (!config.chatLayoutEnabled) return;
    CGFloat chatSize = config.chatFontSize;
    if (fabs(chatSize - 16.0) <= 0.01) return;
    NSMutableArray *labels = [NSMutableArray array];
    collectLabelsInView([self valueForKey:@"contentView"], labels);
    for (UILabel *label in labels) {
        UIFont *newFont = [UIFont fontWithDescriptor:label.font.fontDescriptor size:chatSize];
        if (newFont) {
            label.font = newFont;
            [label sizeToFit];
        }
    }
}
```

## 十、注意事项

1. **MMUILabel 的可用性**：如果微信未来版本修改了 MMUILabel 的继承关系或移除了这个类，全局 Hook 会失效，需要用其他方式替代（如 hook `UILabel setFont:` 但会更暴力）
2. **对话覆盖优先级**：对话 Hook 在 layoutSubviews 中执行，在 MMUILabel setFont: 之后，确保能覆盖全局缩放效果
3. **sizeToFit 的影响**：`hook_MMTableViewCell_layoutSubviews` 中调用了 `[label sizeToFit]`，可能导致文本换行改变，如果出现排版问题应移除 sizeToFit
4. **性能考虑**：`collectLabelsInView` 每次 layoutSubviews 都会执行递归遍历，但聊天列表 Cell 的 view hierarchy 通常较浅，性能影响可忽略
5. **字号边界保护**：全局缩放有 6~48 的范围保护，对话字号有 ConfigurationManager 层的 10~24 范围限制
6. **重启需要**：配置修改后必须重启微信才能看到效果（Hook 在启动时安装，运行中无法动态加载/卸载 Hook）
7. **模块注册顺序**：`FontLayoutHook.install` 会在 `MioModuleRegistry.registerAll` 时自动调用，不需要在 Tweak.m 或 constructor 中手动调用
