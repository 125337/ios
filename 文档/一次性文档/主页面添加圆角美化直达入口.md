# 主页面添加"圆角美化"直达入口改造文档

---

## 一、需求说明

在主页面（MioPluginEntryVC）的常用功能列表中，**"界面定制"下方新增"圆角美化"条目**，点击直接进入 `SettingCornerRadiusController`（与当前"界面定制"→"圆角美化"的二级页面一致）。

### 改造前后对比

**改前：**
```
┌─ 主页面 ─────────────────────┐
│  常用功能                     │
│  界面定制          → WPUIVC  │
│  红包设置                     │
│  其他功能                     │
│  ...                          │
└──────────────────────────────┘
                ┌→ WPUIVC → 圆角美化 → SettingCornerRadiusController
```

**改后：**
```
┌─ 主页面 ─────────────────────┐
│  常用功能                     │
│  界面定制          → WPUIVC  │
│  圆角美化          → Corner  │  ← 新增
│  红包设置                     │
│  其他功能                     │
│  ...                          │
└──────────────────────────────┘
                ┌→ WPUIVC
                │
                └→ SettingCornerRadiusController（直达）
```

> **注：** "界面定制"中的"圆角美化"入口保留不动，新增的是主页面上的**直达入口**。

## 三、改造步骤

### 步骤 1：添加 import

在 [SettingEntryHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/SettingEntryHook.m) 的 `#import` 区域（L1-L7）末尾新增：

```objc
#import "../../Settings/Controllers/SettingCornerRadiusController.h"
```

当前 import 区域（L1-L7）：
```objc
#import "SettingEntryHook.h"
#import "WPCommonUI.h"
#import "../../Config/PluginConfig.h"
#import "../../Settings/Common/SettingController.h"
#import <objc/runtime.h>
#import <objc/message.h>
#import "../../Core/LogManager.h"
// ← 在这里添加
```

添加后：
```objc
#import "../../Settings/Controllers/SettingCornerRadiusController.h"
```

### 步骤 2：添加 navItem 条目

在 `viewWillAppear` 的 `navItems` 数组（L102）中，**"界面定制"条目之后插入"圆角美化"**：

**改前（L102）：**
```objc
NSArray *navItems = @[@[@"常用功能", @"openCommon:"], @[@"界面定制", @"openUI:"], @[@"红包设置", @"openRedEnvelop:"], @[@"其他功能", @"openOther:"], @[@"备份", @"openBackup:"], @[@"关于", @"openAbout:"]];
```

**改后：**
```objc
NSArray *navItems = @[@[@"常用功能", @"openCommon:"], @[@"界面定制", @"openUI:"], @[@"圆角美化", @"openCorner:"], @[@"红包设置", @"openRedEnvelop:"], @[@"其他功能", @"openOther:"], @[@"备份", @"openBackup:"], @[@"关于", @"openAbout:"]];
```

> `openCorner:` 是新增的 selector，命名遵循现有 `openUI:` / `openCommon:` 等命名规范。

### 步骤 3：添加 `openCorner:` 方法

在 `MioPluginSwitchHandler` 的 `@implementation` 中，**`openUI:` 方法之后、`openRedEnvelop:` 之前**（L235 之后）新增：

```objc
- (void)openCorner:(id)sender {
    UIViewController *vc = [self currentVCFrom:sender];
    if (!vc) { WPLog(@"Setting", @"[Nav] openCorner: currentVC nil"); return; }
    SettingCornerRadiusController *subVC = [[SettingCornerRadiusController alloc] init];
    [vc.navigationController pushViewController:subVC animated:YES];
    WPLog(@"Setting", @"[Nav] pushed SettingCornerRadiusController");
}
```

**插入位置参考** — 放在 `openUI:` 之后、`openRedEnvelop:` 之前（L236 与 L237 之间）：

```objc
- (void)openUI:(id)sender {                 // L223
    ...
}                                           // L235

// ★ 在这里插入 openCorner: 方法 ★

- (void)openRedEnvelop:(id)sender {         // L237
    ...
}
```

## 六、风险分析

| 风险 | 说明 | 等级 |
|:----|:-----|:----:|
| 列表顺序 | 只插入一个数组元素，不影响其他元素索引 | 🟢 无风险 |
| 点击事件 | `openCorner:` 使用与 `openUI:` 完全相同的导航模式 | 🟢 无风险 |
| 页面复用 | `SettingCornerRadiusController` 本身无状态，可多次 push | 🟢 无风险 |
| 相互影响 | 新增入口不修改 "界面定制" 内任何逻辑，两入口互不干扰 | 🟢 无风险 |
