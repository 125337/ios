# 背景素材职责划分重构方案

---

## 一、现状：混乱在哪

当前涉及背景素材的四段代码**职责重叠**：

```
createBackgroundImageViewInButton      ← 创建 + 配置 contentMode + 配置 frame
    ↓
loadImageAsyncForImageView (回调)       ← 设 image + 单独算偏移 + 改 frame
    ↑
setupBackgroundMaterialInButton
  ├── 分支A (已有):                      ← 再来一遍 contentMode + 算偏移 + 改 frame
  └── 分支B (新建): → 调上面两个方法
```

**重复的配置逻辑（3 份）：**

| 配置项 | 创建时 L477-482 | 分支A L555-560 | 异步回调 L520-528 |
|:------:|:--------------:|:--------------:|:----------------:|
| `contentMode` switch | ✅ | ✅ | ❌（没设，用了创建时的值） |
| `clipsToBounds=NO` | ✅（刚修） | ✅ | ❌（没设，用了创建时的值） |
| frame 含偏移 | ❌（无偏移） | ✅ | ✅ |
| 层级调整 | ✅ | ✅ | ❌ |

> 改一个策略要改三处，之前 `clipsToBounds=YES` 的 bug 就是这么漏的。

---

## 二、重构目标

1. **配置逻辑只有一份** — 不管创建还是更新，`contentMode` / `clipsToBounds` / frame 偏移都走同一个方法
2. **创建只负责创建** — alloc/init、设 tag、加 subview，不做配置
3. **异步回调只负责设图片** — 图片设完后调用配置方法，不单独算偏移

---

## 三、新职责划分

### 3.1 方法清单

| 方法 | 职责 | 调用者 |
|:----|------|:------:|
| `createBackgroundImageViewInButton:` | **只创建+添加**：alloc/init → tag → addSubview | `setupBackgroundMaterialInButton` |
| `configureBackgroundImageView:inButton:` | **统一配置**：clipsToBounds → contentMode → frame含偏移 | 分支A + 异步回调 |
| `loadImageAsyncForImageView:button:isDark:` | **异步加载+设图**：后台加载 → 主线程设 image → 调 configure | `setupBackgroundMaterialInButton` |
| `setupBackgroundMaterialInButton:isDark:` | **主入口**：查找 → 存在则 configure / 不存在则 create+load | `handleVisiblePath` / `handleHiddenPath` |

### 3.2 调用链路

```
setupBackgroundMaterialInButton
  │
  ├── 已有 bgImgView ──→ configureBackgroundImageView:inButton:
  │                              │
  │                              ├── clipsToBounds = NO
  │                              ├── contentMode (fillMode)
  │                              ├── 算偏移 (image 存在时)
  │                              └── frame = (ox, oy+offset, W, H)
  │
  └── 无 bgImgView ──→ createBackgroundImageViewInButton:
  │       │               └── alloc/init → tag → addSubview
  │       └──→ loadImageAsyncForImageView:button:isDark:
  │               └── 后台加载
  │                   └── 主线程回调:
  │                       ├── imageView.image = image
  │                       └── configureBackgroundImageView:inButton:
  │                               ← 此时 image 存在，偏移正确计算
  │
  └── button.layer.masksToBounds = YES
```

## 四、代码示例

### 4.1 统一配置方法（新增）

```objc
/// 统一配置 imageView：clipsToBounds、contentMode、frame（含对齐偏移）
/// 创建和更新都走这里，保证行为一致
+ (void)configureBackgroundImageView:(UIImageView *)imageView
                            inButton:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];

    // ── 裁剪 ──
    imageView.clipsToBounds = NO;

    // ── 填充模式 ──
    NSInteger fillMode = config.cardBgFillMode;
    switch (fillMode) {
        case 1: imageView.contentMode = UIViewContentModeScaleAspectFill; break;
        case 2: imageView.contentMode = UIViewContentModeScaleToFill; break;
        default: imageView.contentMode = UIViewContentModeScaleAspectFill; break;
    }

    // ── frame（含对齐偏移）──
    CGFloat alignOffset = 0;
    if (imageView.image && imageView.image.size.width > 0) {
        alignOffset = [self calcImageAlignmentOffsetWithImageSize:imageView.image.size
                                                          inView:button];
    }

    CGFloat ox = config.cardBgOffsetX;
    CGFloat oy = config.cardBgOffsetY;
    imageView.frame = CGRectMake(ox, oy + alignOffset,
                                 button.bounds.size.width,
                                 button.bounds.size.height);

    // ── 层级 ──
    if (config.cardBgLayer == 1) {
        [button bringSubviewToFront:imageView];
    }
}
```

### 4.2 创建方法（精简后）

```objc
+ (UIImageView *)createBackgroundImageViewInButton:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];
    UIImageView *newBg = [[UIImageView alloc] init];
    newBg.tag = kProfileCardBgImageTag;
    newBg.userInteractionEnabled = NO;

    if (config.cardBgLayer == 1) {
        [button addSubview:newBg];
        [button bringSubviewToFront:newBg];
    } else {
        [button insertSubview:newBg atIndex:0];
    }

    // ❌ 不再设 contentMode、clipsToBounds、frame
    //    由 configureBackgroundImageView:inButton: 统一处理
    return newBg;
}
```

### 4.3 异步加载（回调简化）

```objc
+ (void)loadImageAsyncForImageView:(UIImageView *)imageView
                            button:(UIView *)button
                            isDark:(BOOL)isDark {
    __weak UIImageView *weakBg = imageView;
    __weak UIView *weakButton = button;

    dispatch_async(dispatch_get_global_queue(DISPATCH_QUEUE_PRIORITY_DEFAULT, 0), ^{
        UIImage *resultImage = [ProfileCardBgHook loadBackgroundImageSync];

        dispatch_async(dispatch_get_main_queue(), ^{
            __strong UIImageView *strongBg = weakBg;
            __strong UIView *strongButton = weakButton;
            if (!strongBg || !strongButton) return;

            if (resultImage) {
                strongBg.image = resultImage;
                strongBg.alpha = 1.0;
                strongBg.hidden = NO;

                // ★ 统一配置：clipsToBounds + contentMode + frame含偏移
                [ProfileCardBgHook configureBackgroundImageView:strongBg
                                                      inButton:strongButton];
            } else {
                PluginConfig *cfg = [PluginConfig shared];
                UIColor *cardBg = [cfg colorFromHex:isDark
                    ? cfg.listCardDarkBgColor : cfg.listCardLightBgColor];
                if (cardBg) strongButton.backgroundColor = cardBg;
            }
        });
    });
}
```

### 4.4 主入口（分支统一）

```objc
+ (void)setupBackgroundMaterialInButton:(UIView *)button
                                 isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];

    // ── 查找已有 bg ──
    UIImageView *bgImgView = [ProfileCardBgHook findBackgroundImageViewInButton:button];

    if (bgImgView) {
        // ── 分支 A：已存在 → 统一配置 ──
        [ProfileCardBgHook configureBackgroundImageView:bgImgView inButton:button];
    } else {
        // ── 分支 B：不存在 → 创建（不配置）→ 异步加载 ──
        bgImgView = [ProfileCardBgHook createBackgroundImageViewInButton:button];
        [ProfileCardBgHook loadImageAsyncForImageView:bgImgView
                                               button:button
                                               isDark:isDark];
    }

    // ── 适应模式（fillMode=1）─ 不变 ──
    NSInteger fillMode = config.cardBgFillMode;
    if (fillMode == 1) {
        UIImage *img = [ProfileCardBgHook loadBackgroundImageSync];
        if (img && img.size.width > 0 && img.size.height > 0) {
            CGFloat btnW = button.bounds.size.width;
            CGFloat imgRatio = img.size.height / img.size.width;
            CGFloat targetH = btnW * imgRatio;
            if (targetH > button.bounds.size.height) {
                CGRect bf = button.frame;
                bf.size.height = targetH;
                button.frame = bf;
                if (bgImgView) {
                    CGRect bgf = bgImgView.frame;
                    bgf.size.height = targetH;
                    bgImgView.frame = bgf;
                }
                UIView *tableView = button.superview;
                if (tableView && [tableView isKindOfClass:[UIScrollView class]]) {
                    if (((UITableView *)tableView).tableHeaderView == button) {
                        [((UITableView *)tableView) setTableHeaderView:button];
                    }
                }
            }
        }
    }

    button.backgroundColor = [UIColor clearColor];
    [ProfileCardBgHook cleanNativeBgImageView:button];
    button.layer.masksToBounds = YES;
}
```

## 五、变更清单

| 文件 | 方法 | 操作 | 说明 |
|:----|:-----|:----:|:-----|
| `ProfileCardBgHook.m` | `createBackgroundImageViewInButton:` | 精简 | 删 contentMode / clipsToBounds / frame / bringSubviewToFront |
| `ProfileCardBgHook.m` | **`configureBackgroundImageView:inButton:`** | **新增** | 统一配置：clipsToBounds=NO + contentMode + frame含偏移 + 层级 |
| `ProfileCardBgHook.m` | `loadImageAsyncForImageView:button:isDark:` | 简化 | 回调删偏移计算，改用 configure |
| `ProfileCardBgHook.m` | `setupBackgroundMaterialInButton:isDark:` | 简化 | 分支A 改用 configure，分支B 只 create |
| `ProfileCardBgHook.h` | 接口声明 | 改 | 删/改/增对应的方法声明 |

## 六、效果对比

| 维度 | 重构前 | 重构后 |
|:----|:------:|:------:|
| `contentMode` 代码份数 | 3 份（创建+分支A+异步里有但没写） | **1 份**（configure） |
| `clipsToBounds` 设置处 | 2 份（分支A+创建） | **1 份**（configure） |
| frame 偏移计算处 | 2 份（分支A+异步回调） | **1 份**（configure） |
| 加新配置项要改几处 | 2~3 处 | **1 处**（改 configure 即可） |
| 分支A/分支B 行为一致性 | ❌ 不一致（曾是 clipsToBounds 的 bug 来源） | ✅ 完全一致，都走 configure |

---

## 七、风险

| 风险 | 说明 | 缓解 |
|:----|:-----|:-----|
| create 不再设初始 frame | 图片加载前 imageView 位置/尺寸不确定 | configure 在异步回调中立即调用，肉眼不可见；也可以在 create 中设一个粗略 frame（含 ox/oy 但不含偏移） |
| bringSubviewToFront 移到 configure | 分支A 已存在时每次更新都会调一次 | 不影响，bringSubviewToFront 是幂等的 |
| 重构涉及修改多处 | 接口变化 + 方法实现变化 | 统一修改，完成后用验证清单逐条测试 |
