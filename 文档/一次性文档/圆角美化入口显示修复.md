# 圆角美化入口显示修复

---

## 问题现象

主页面"界面定制"下方看不到"圆角美化"入口。

## 根因

`SettingEntryHook.m` L103 的 `navItems` 数组**未插入**"圆角美化"条目。其余改动（import、openCorner: 方法、WPUIVC.m 删除）均正确完成。

## 修复

仅需在 [SettingEntryHook.m L103](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/SettingEntryHook.m#L103) 的 `navItems` 数组中，在 `@[@"界面定制", @"openUI:"]` 之后插入 `@[@"圆角美化", @"openCorner:"]`。

**改前：**
```objc
NSArray *navItems = @[@[@"常用功能", @"openCommon:"], @[@"界面定制", @"openUI:"], @[@"红包设置", @"openRedEnvelop:"], @[@"其他功能", @"openOther:"], @[@"备份", @"openBackup:"], @[@"关于", @"openAbout:"]];
```

**改后：**
```objc
NSArray *navItems = @[@[@"常用功能", @"openCommon:"], @[@"界面定制", @"openUI:"], @[@"圆角美化", @"openCorner:"], @[@"红包设置", @"openRedEnvelop:"], @[@"其他功能", @"openOther:"], @[@"备份", @"openBackup:"], @[@"关于", @"openAbout:"]];
```

## 验证

改完重新打开主页面，应看到：

```
功能列表
┌─────────────────────┐
│ 常用功能             │
│ 界面定制             │
│ 圆角美化    ← 新增   │
│ 红包设置             │
│ 其他功能             │
│ 备份                 │
│ 关于                 │
└─────────────────────┘
```

点击"圆角美化"直接进入 `SettingCornerRadiusController`。
