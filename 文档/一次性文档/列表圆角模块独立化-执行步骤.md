## 第一步：资料卡功能独立化

### 1a. ProfileCardBgHook 自我注册 MMUIButton Hook

> **目标：** ProfileCardBgHook 不再依赖 ListCornerRadiusHook 代为注册，能够独立管理自己的 MMUIButton Hook。

#### 操作 1a-1：在 ProfileCardBgHook.m 中新增 Hook 函数

在 `@implementation` 之前、`#import` 之后添加：

```objc
static IMP _orig_MMUIButton_layoutSubviews = NULL;
static void replaced_MMUIButton_layoutSubviews(id self, SEL _cmd) {
    if (_orig_MMUIButton_layoutSubviews) {
        ((void (*)(id, SEL))_orig_MMUIButton_layoutSubviews)(self, _cmd);
    }
    [ProfileCardBgHook handleButtonLayout:(UIView *)self];
}
```

#### 操作 1a-2：在 ProfileCardBgHook.m 中新增入口方法

在 `@implementation` 内部添加：

```objc
+ (void)initProfileCardHook {
    Class cls = objc_getClass("MMUIButton");
    if (cls) {
        MSHookMessageEx(cls, @selector(layoutSubviews),
            (IMP)replaced_MMUIButton_layoutSubviews,
            (IMP *)&_orig_MMUIButton_layoutSubviews);
    }
}
```

#### 操作 1a-3：在 ProfileCardBgHook.h 中声明

添加一行：

```objc
+ (void)initProfileCardHook;
```

#### 操作 1a-4：在 Tweak.m 中注册调用

在 `initListCornerRadiusHook` 之后添加：

```objc
[ListCornerRadiusHook initListCornerRadiusHook];
[ProfileCardBgHook initProfileCardHook];    // ← 新增
WPInstallSessionSpacingHooks();
WPInstallAuxiliaryHooks();
```

> **为什么加在 initListCornerRadiusHook 之后？** 保证 ListCorner 的媒体圆角 Hook 先注册（作为链式调用的外层），资料卡分发 Hook 后注册（叠加在上面）。如果顺序颠倒，旧版微信布局可能受影响。
