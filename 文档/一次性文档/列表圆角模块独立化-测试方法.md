## 测试执行顺序建议

```
第一步：批次 A（资料卡功能）
  │  确保核心功能 OK
  │
第二步：批次 B（列表圆角核心）
  │  确保列表圆角基础功能 OK
  │
第三步：批次 C（辅助功能）
  │  确保所有子功能 OK
  │
第四步：批次 D（设置页开关）
  │
第五步：批次 E（综合回归）
      最终确认无冲突
```

> **建议：** 每个批次通过后打一个 tag 或 commit，方便回溯。
>
> 如果某个功能失败，优先检查：
> 1. `initProfileCardHook` 是否在 `initListCornerRadiusHook` **之后** 调用
> 2. `replaced_MMUIButton_layoutSubviews` 是否迁移到 ProfileCardBgHook 
> 3. `_hooked_MMUIButton_layoutSubviews`（媒体圆角）是否保留在 ListCornerRadiusHook
