| 策略 | 命中目标 | 说明 |
|---|---|---|
| accessibilityLabel | ❌ 全部不命中 | 当前版本箭头/二维码的 label 不是三个已知值 |

## 改造后完整代码

```objc
#pragma mark - 箭码/二维码识别

+ (BOOL)isArrowQRView:(UIView *)view {
    // 箭头：UIImageView + 帧 + 右侧位置（排除 TextState 按钮）
    if ([view isKindOfClass:[UIImageView class]]) {
        CGFloat w = view.frame.size.width;
        CGFloat h = view.frame.size.height;
        CGFloat x = view.frame.origin.x;
        CGFloat parentW = view.superview.bounds.size.width;
        // ★ parentW - 25 需根据实测调整，原则是「箭头在范围内、状态在范围外」
        if (w >= 10 && w <= 18 && h >= 8 && h <= 40 && x >= parentW - 25) {
            return YES;
        }
    }
    // 二维码：MMUIButton 精准匹配（容器内唯一 MMUIButton）
    if ([view isKindOfClass:NSClassFromString(@"MMUIButton")]) {
        return YES;
    }
    return NO;
}

+ (void)hideArrowQRInCell:(UIView *)cell {
    for (UIView *sub in cell.subviews) {
        if ([self isArrowQRView:sub]) {
            sub.hidden = YES;
        }
    }
}
```

## 帧启发式误伤原因

帧启发式误伤状态按钮是因为：

1. **TextState 按钮可能也是 UIImageView**（或其内部图标是直接子视图）
2. **位置重叠**：`x >= parentW - 40` → 状态按钮也在右侧 40pt 区域内
3. **尺寸重叠**：状态图标也可能宽 10-18pt、高 8-40pt

**解决办法**就是收紧位置范围。假设：
- 箭头在最右侧：`x >= parentW - 25`
- 状态按钮略靠左：`x < parentW - 25`

具体阈值需要你**开启隐藏→测试→调整**。

## 验证方法

1. `parentW - 20` 测试 → 箭头隐藏？状态按钮隐藏？
2. 如果箭头隐藏但状态也隐藏 → 继续收紧到 `parentW - 15`
3. 如果箭头不隐藏 → 放宽到 `parentW - 25`
4. 找到临界值即可
