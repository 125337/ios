# 隐藏箭码/二维码功能迁移方案

> 目标：将「隐藏右侧二维码」（箭码/二维码）从列表圆角模块完全迁移到卡片背景设置页面的"我的页面美化"独立节段。
> 功能逻辑上完全独立，不依赖「资料卡片美化」的总开关、素材、圆角等任何配置。

---

### 2.7 Tweak.m / ProfileCardBgHook.m — 调用点调整

**★ 核心架构变化：** 箭码隐藏不再受 `cardBgBeautifyEnabled` 保护。

**在 `replaced_MMUIButton_layoutSubviews` 中，将箭码隐藏放在总开关守卫之前：**

```objc
// replaced_MMUIButton_layoutSubviews（Tweak.m 或 ProfileCardBgHook 的注册回调）

// ★ 独立功能：箭码隐藏（不受资料卡片美化总开关保护）
[ProfileCardBgHook handleArrowQRHiding:button];

// ★ 资料卡片美化总开关
PluginConfig *config = [PluginConfig shared];
if (!config.cardBgBeautifyEnabled) {
    [origSelf layoutSubviews];
    return;
}

// ↓ 原有逻辑继续（findMoreViewController / hasHeadImageView / 场景路由...）
```

**同时新增方法：**

```objc
// ProfileCardBgHook.m 新增
+ (void)handleArrowQRHiding:(UIView *)button {
    // 只做守卫：必须是资料卡按钮
    UIViewController *vc = [self findMoreViewController:button];
    if (!vc) return;
    if (![self hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;

    PluginConfig *config = [PluginConfig shared];
    if (config.myPageHideArrow) {
        [self hideArrowQRInCell:button];
    }
}

// ProfileCardBgHook.h 新增声明
+ (void)handleArrowQRHiding:(UIView *)button;
```

**原有的 `handleButtonLayout:` 内的 `handleCornerAndQR:` 保留，但其中只处理圆角：**

```objc
// 改前
+ (void)handleCornerAndQR:(UIView *)button isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];
    if (config.cardBgCornerEnabled) {
        [self applyProfileCardCorner:button isDark:isDark];
    }
    if (config.listHideRightQRCode) {          // ← 移出去
        [self hideQRButtonInCell:button];
    }
}

// 改后
+ (void)handleCornerAndQR:(UIView *)button isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];
    if (config.cardBgCornerEnabled) {
        [self applyProfileCardCorner:button isDark:isDark];
    }
    // ★ QR/箭码隐藏已移到 handleArrowQRHiding:，不再在此处理
}
```

> `handleHiddenPath` 中的 2 处调用（L734、L759）保留不变，因为进入隐藏路径时不受总开关影响（隐藏路径也是 `cardBgBeautifyEnabled` 后方可进入），但属性引用已改为 `myPageHideArrow`。

## 三、功能独立性验证

### 3.1 调用链路

```
replaced_MMUIButton_layoutSubviews:
  │
  ├─ handleArrowQRHiding:          ← 完全独立，在总开关之前
  │    └─ myPageHideArrow? → YES → hideArrowQRInCell:
  │
  ├─ cardBgBeautifyEnabled? → NO → return
  │
  └─ handleButtonLayout:           ← 素材、圆角、隐藏路径等
       └─ handleCornerAndQR:       ← 现在只处理圆角
```

### 3.2 功能开关矩阵

| 资料卡片美化总开关 | 隐藏箭码 | 箭码/二维码是否隐藏 |
|:-----------------:|:--------:|:----------------:|
| OFF | ON | ✅ 隐藏 |
| OFF | OFF | ❌ 不隐藏 |
| ON | ON | ✅ 隐藏 |
| ON | OFF | ❌ 不隐藏 |

> **「隐藏箭码」功能完全独立于「资料卡片美化」总开关，关闭总开关后该功能依然生效。**
