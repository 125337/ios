# 圆角美化入口迁移改造文档

---

## 一、需求说明

将"圆角美化"入口从 **"界面定制"二级页面** 迁移到 **主页面常用功能列表**"界面定制"下方。

### 改造前后对比

**改前：**
```
主页面                           界面定制页 (WPUIVC)
┌───────────────────┐            ┌───────────────────┐
│ 常用功能           │            │ 聊天顶栏           │
│ 界面定制  → WPUIVC │            │ 名字颜色           │
│ 红包设置           │            │ 附件布局           │
│ 其他功能           │            │ ...               │
│ ...                │            │ 圆角美化  → Corner │ ← 删掉
└───────────────────┘            └───────────────────┘
```

**改后：**
```
主页面
┌───────────────────┐
│ 常用功能           │
│ 界面定制  → WPUIVC │
│ 圆角美化  → Corner │  ← 新增（原入口已删）
│ 红包设置           │
│ 其他功能           │
│ ...                │
└───────────────────┘
```

## 三、改造步骤

### 步骤 1：SettingEntryHook.m — 添加 import

在 [SettingEntryHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/SettingEntryHook.m) L7 后添加：

```objc
#import "../../Settings/Controllers/SettingCornerRadiusController.h"
```

### 步骤 2：SettingEntryHook.m — 添加 navItem 条目

在 [L102](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/SettingEntryHook.m#L102) 的 `navItems` 数组中，在 `@[@"界面定制", @"openUI:"]` 之后、`@[@"红包设置", @"openRedEnvelop:"]` 之前插入：

```objc
NSArray *navItems = @[@[@"常用功能", @"openCommon:"], @[@"界面定制", @"openUI:"], @[@"圆角美化", @"openCorner:"], @[@"红包设置", @"openRedEnvelop:"], @[@"其他功能", @"openOther:"], @[@"备份", @"openBackup:"], @[@"关于", @"openAbout:"]];
```

### 步骤 3：SettingEntryHook.m — 添加 `openCorner:` 方法

在 [openUI: 方法之后、openRedEnvelop: 方法之前](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/SettingEntryHook.m#L235-L237) 插入：

```objc
- (void)openCorner:(id)sender {
    UIViewController *vc = [self currentVCFrom:sender];
    if (!vc) { WPLog(@"Setting", @"[Nav] openCorner: currentVC nil"); return; }
    SettingCornerRadiusController *subVC = [[SettingCornerRadiusController alloc] init];
    [vc.navigationController pushViewController:subVC animated:YES];
    WPLog(@"Setting", @"[Nav] pushed SettingCornerRadiusController");
}
```

### 步骤 4：WPUIVC.m — 删除 items 数组中的"圆角美化"

删除 [WPUIVC.m L40](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/WPUIVC.m#L40)：

```objc
    NSArray *items = @[
        @[@"聊天顶栏", @(100)],
        @[@"名字颜色", @(101)],
        @[@"附件布局", @(102)],
        @[@"文本占位", @(103)],
        @[@"界面简化", @(104)],
        @[@"界面净化", @(105)],
        @[@"隐藏头像", @(106)],
        @[@"圆角美化", @(107)],   // ← 删除这一行
    ];
```

### 步骤 5：WPUIVC.m — 删除 navigateTo: 中的 case 107

删除 [WPUIVC.m L87-89](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/WPUIVC.m#L87-L89)：

```objc
        case 107:                              // ← 删除
            subVC = [[SettingCornerRadiusController alloc] init];  // ← 删除
            break;                             // ← 删除
```

### 步骤 6（可选）：WPUIVC.m — 删除不再需要的 import

如果 `SettingCornerRadiusController.h` 在 [WPUIVC.m L5](file:///www/wwwroot/ios/MioPlugin/Modules/SettingEntry/WPUIVC.m#L5) 不再被任何代码引用，可一并删除：

```objc
#import "../../Settings/Controllers/SettingCornerRadiusController.h"  // ← 步骤5删完后可删除
```

## 六、风险分析

| 风险 | 说明 | 等级 |
|:----|:-----|:----:|
| 入口重复 | 已删除 WPUIVC 内的"圆角美化"，不会出现两个入口 | 🟢 无 |

| 代码清理 | L5 import 删除前确认无其他引用（本文件仅有 L88 引用） | 🟢 安全 |
