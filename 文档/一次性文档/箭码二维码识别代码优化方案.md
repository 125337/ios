# 箭码/二维码识别代码优化方案

## 当前代码现状

```objc
// 5 个方法，约 36 行
+ (BOOL)isArrowQRByAccessibilityLabel:(UIView *)view;     // ① 8行
+ (BOOL)isArrowQRByFrameHeuristic:(UIView *)view;         // ② 10行
+ (BOOL)isQRCodeButton:(UIView *)view;                     // ③ 8行
+ (BOOL)isArrowQRView:(UIView *)view;                      // ④ 4行（OR组合）
+ (void)hideArrowQRInCell:(UIView *)cell;                  // ⑤ 6行
```

---

## 优化方向分析

### 箭头识别 — 两个方法可以合并

| 方法 | 原理 | 性能 |
|---|---|---|
| ① accessibilityLabel | 一次字符串比较 | 极快 |
| ② frame启发式 | isKindOfClass + 3次frame计算 + parentWidth | 较慢 |

**帧启发式（②）本质是备胎**：当 accessibilityLabel 因微信版本变化而失效时，用 frame 兜底。但如果只考虑当前版本，accessibilityLabel 已经足够。

### 二维码识别 — 位置条件是多余的

已实测确认：`isKindOfClass:MMUIButton` 在资料卡按钮内唯一命中二维码，位置条件 `x >= parentW - 60` 是多余的。

---

## 方案对比

### 方案A：极致精简（推荐）

**思想**：将 3 个识别方法 + 1 个组合方法，合并为 1 个方法。

```objc
#pragma mark - 箭码/二维码识别

+ (BOOL)isArrowQRView:(UIView *)view {
    // ① 箭头：accessibilityLabel 匹配（轻量）
    NSString *label = view.accessibilityLabel;
    if ([label isEqualToString:@"More_CardInfo"] ||
        [label isEqualToString:@"•"] ||
        [label isEqualToString:@"• N"]) {
        return YES;
    }
    // ② 二维码：MMUIButton 类型匹配 + 右侧位置
    if ([view isKindOfClass:NSClassFromString(@"MMUIButton")]) {
        CGFloat x = view.frame.origin.x;
        CGFloat parentW = view.superview.bounds.size.width;
        return x >= parentW - 60;
    }
    return NO;
}

+ (void)hideArrowQRInCell:(UIView *)cell {
    for (UIView *sub in cell.subviews) {
        if ([self isArrowQRView:sub]) {
            sub.hidden = YES;
        }
    }
}
```

**结果：2 个方法，约 25 行，减少 30% 代码。**

### 方案B：完全分离（最清晰）

**思想**：两个功能完全独立，各自一个方法，互不干扰。

```objc
#pragma mark - 箭码/二维码识别

+ (void)hideArrowQRInCell:(UIView *)cell {
    for (UIView *sub in cell.subviews) {
        // 箭头：accessibilityLabel 匹配
        NSString *label = sub.accessibilityLabel;
        if ([label isEqualToString:@"More_CardInfo"] ||
            [label isEqualToString:@"•"] ||
            [label isEqualToString:@"• N"]) {
            sub.hidden = YES;
            continue;
        }
        // 二维码：MMUIButton 类型匹配 + 右侧位置
        if ([sub isKindOfClass:NSClassFromString(@"MMUIButton")]) {
            CGFloat x = sub.frame.origin.x;
            CGFloat parentW = sub.superview.bounds.size.width;
            sub.hidden = (x >= parentW - 60);
        }
    }
}
```

**结果：1 个方法，约 20 行，减少 45% 代码。**

### 方案C：去掉帧启发式 + 去掉位置条件

**思想**：保留 3 个方法结构，只去掉冗余逻辑。

```objc
#pragma mark - 箭码/二维码识别

+ (BOOL)isArrowQRView:(UIView *)view {
    // 箭头：accessibilityLabel
    NSString *label = view.accessibilityLabel;
    if ([label isEqualToString:@"More_CardInfo"] ||
        [label isEqualToString:@"•"] ||
        [label isEqualToString:@"• N"]) {
        return YES;
    }
    // 二维码：精准类型匹配
    if ([view isKindOfClass:NSClassFromString(@"MMUIButton")]) {
        return YES;
    }
    return NO;
}

+ (void)hideArrowQRInCell:(UIView *)cell {
    for (UIView *sub in cell.subviews) {
        if ([self isArrowQRView:sub]) {
            sub.hidden = YES;
        }
    }
}
```

**结果：2 个方法，约 22 行，减少 40% 代码。**

## 性能对比

| 操作 | 当前代码 | 优化后（方案C） |
|---|---|---|
| 每个子视图的判断次数 | 最多 3 次调用 | **最多 1 次调用** |
| NSStringFromClass | 1 次 | **0 次**（改用 isKindOfClass） |
| frame 计算 | 3 次 getter + parentW | **0 次** |
| isKindOfClass 调用 | 1 次（UIImageView）+ 1 次（MMUIButton） | **1 次**（MMUIButton） |

---

## 建议操作步骤

1. 删除 `isArrowQRByAccessibilityLabel:`、`isArrowQRByFrameHeuristic:`、`isQRCodeButton:` 三个方法
2. 删除 `isArrowQRView:` 方法
3. 重写 `hideArrowQRInCell:` 为方案B，或将所有逻辑合并到 `isArrowQRView:` 为方案A/C
4. 不需要改动 `handleArrowQRHiding:` 和 `ListCornerRadiusHook.m`
