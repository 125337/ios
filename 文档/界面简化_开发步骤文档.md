#### 2.4.2 策略A: 字典查找 - WCTableViewCellLeftConfig.title

```objc
// Hook 返回值
static id hook_WCTableViewCellLeftConfig_title(id self, SEL _cmd) {
    id orig = ((id (*)(id, SEL))_orig_WCTableViewCellLeftConfig_title)(self, _cmd);
    if (!SimplifyEnabled() || !orig) return orig;
    
    NSString *key = orig;  // 原始标题如 "服务"
    // 尝试完整匹配
    id replacement = MenuNames()[key];
    if (replacement) {
        return replacement;
    }
    // 尝试处理复合标题 (如 "服务\n支付") - 匹配 \n 后的部分
    NSRange nlRange = [key rangeOfString:@"\n"];
    if (nlRange.location != NSNotFound) {
        NSString *suffix = [key substringFromIndex:nlRange.location + 1];
        id subReplacement = MenuNames()[suffix];
        if (subReplacement) return subReplacement;
    }
    return orig;
}
```

#### 2.4.3 策略A: 字典查找 - 参数替换模式

`MMTabbarItem.initWithTitle:`, `setNormalTitle:`, `MMTabBarItemView.setTitle:`, `MMTabBarController.setTabBarItemTitle:forIndex:` 四个 Hook 使用相同的模式：

```objc
// 以 setNormalTitle: 为例
static void hook_MMTabbarItem_setNormalTitle(id self, SEL _cmd, id title) {
    if (SimplifyEnabled() && title) {
        id replacement = TabNames()[title];
        if (replacement) {
            title = replacement;
        }
    }
    ((void (*)(id, SEL, id))_orig_MMTabbarItem_setNormalTitle)(self, _cmd, title);
}
```

#### 2.4.4 策略B: 核心 Hook - MMUILabel.setText: (FUN_00044a80 对等实现)

这是整个功能最复杂的 Hook，完整的匹配决策树：

```objc
static void hook_MMUILabel_setText(id self, SEL _cmd, NSString *text) {
    // 1. 基础守卫
    if (!text || !SimplifyEnabled()) {
        ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, text);
        return;
    }
    
    // 2. 白名单过滤 - 防止修改 badge 数字 (如 "[5条]", "[3]" 等)
    if ([text hasPrefix:@"["]) {
        ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, text);
        return;
    }
    
    PluginConfig *cfg = [PluginConfig shared];
    
    // 3. 上下文检测层1: 导航栏标题 → main_title_replacement
    if (cfg.mainTitleReplacement && cfg.mainTitleReplacement.length > 0) {
        id responder = self;
        while ((responder = [responder nextResponder])) {
            NSString *className = NSStringFromClass([responder class]);
            // 微信 NavigationBar 是 MMUINavigationBar, MMMNavigationBar 等
            if ([className containsString:@"NavigationBar"]) {
                ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, cfg.mainTitleReplacement);
                return;
            }
        }
    }
    
    // 4. 上下文检测层2: 通讯录标题 → contacts_replacement
    // 匹配模式: 通过验证 UILabel 是否在通讯录页面中
    // (具体匹配模式需要根据微信版本适配，以下为通用实现)
    if (cfg.contactsReplacement && cfg.contactsReplacement.length > 0) {
        // 查找 text 是否匹配通讯录标题模式
        // 例如: text 为 "通讯录" 或所在的 ViewController 是通讯录页
        id responder = self;
        while ((responder = [responder nextResponder])) {
            NSString *className = NSStringFromClass([responder class]);
            if ([className containsString:@"Contacts"] || [className containsString:@"Contact"]) {
                if ([text isEqualToString:@"通讯录"] || [text hasPrefix:@"通讯录"]) {
                    ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, cfg.contactsReplacement);
                    return;
                }
            }
        }
    }
    
    // 5. 上下文检测层3: 发现页标题 → discover_replacement
    if (cfg.discoverReplacement && cfg.discoverReplacement.length > 0) {
        id responder = self;
        while ((responder = [responder nextResponder])) {
            NSString *className = NSStringFromClass([responder class]);
            if ([className containsString:@"Discover"] || [className containsString:@"FindFriend"]) {
                if ([text isEqualToString:@"发现"] || [text hasPrefix:@"发现"]) {
                    ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, cfg.discoverReplacement);
                    return;
                }
            }
        }
    }
    
    // 6. 通讯录好友数替换 → friends_count_replacement
    if (cfg.friendsCountReplacement && cfg.friendsCountReplacement.length > 0) {
        // 正则匹配数字 + 位联系人
        NSRegularExpression *regex = [NSRegularExpression regularExpressionWithPattern:@"\\d+" options:0 error:nil];
        NSTextCheckingResult *match = [regex firstMatchInString:text options:0 range:NSMakeRange(0, text.length)];
        if (match && [text containsString:@"位"] && [text containsString:@"联系人"]) {
            NSString *number = [text substringWithRange:match.range];
            NSString *formatted = [NSString stringWithFormat:cfg.friendsCountReplacement, number];
            ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, formatted);
            return;
        }
    }
    
    // 7. 默认: 调用原始方法
    ((void (*)(id, SEL, NSString *))_orig_MMUILabel_setText)(self, _cmd, text);
}
```

#### 2.4.7 策略C: 钱包余额替换

**简化实现方案：** 微信优化的钱包余额替换需要 Hook 4个 WCPayWalletEntryHeaderView 方法 + 2个 TimeoutNumber 方法。考虑到不同微信版本的差异和复杂度，**建议先实现核心替换逻辑**。

```objc
// 辅助函数: 替换余额显示文本
static void ApplyWalletBalance(id timeOutNumber, id balanceLabel) {
    NSString *replacement = [PluginConfig shared].walletBalanceReplacement;
    if (!replacement || replacement.length == 0) return;
    
    // 方式1: 数字模式 - 尝试解析
    NSScanner *scanner = [NSScanner scannerWithString:replacement];
    double value = 0;
    if ([scanner scanDouble:&value] && scanner.atEnd) {
        // 数字: ×100 (微信用分存储)
        long cents = (long)(value * 100);
        if (timeOutNumber) {
            [timeOutNumber performSelector:@selector(setText:) withObject:[NSString stringWithFormat:@"%ld", cents]];
        }
    } else {
        // 文本: 直接设置
        if (timeOutNumber) {
            [timeOutNumber performSelector:@selector(setText:) withObject:replacement];
        }
    }
    
    // 同时更新余额标签
    if (balanceLabel && [balanceLabel respondsToSelector:@selector(text)]) {
        NSString *origText = [balanceLabel performSelector:@selector(text)];
        if (origText) {
            // 正则替换数字部分
            NSRegularExpression *regex = [NSRegularExpression regularExpressionWithPattern:@"\\d+(\\.\\d+)?" options:0 error:nil];
            NSString *newText = [regex stringByReplacingMatchesInString:origText options:0 range:NSMakeRange(0, origText.length) withTemplate:replacement];
            [balanceLabel performSelector:@selector(setText:) withObject:newText];
        }
    }
}
```

**覆盖的4个 WCPayWalletEntryHeaderView Hook:**

```objc
// 每个 Hook 的模式: 先调原方法 → 再覆盖余额显示
static void hook_WCPayWalletEntryHeaderView_handleUpdateWalletBalance(id self, SEL _cmd) {
    ((void (*)(id, SEL))_orig_handleUpdateWalletBalance)(self, _cmd);
    if (SimplifyEnabled()) {
        id timeoutNumber = [self valueForKey:@"_timeoutNumber"];
        id balanceLabel = [self valueForKey:@"_balanceMoneyLabel"];
        ApplyWalletBalance(timeoutNumber, balanceLabel);
    }
}
// setupTimeoutNumber, updateBalanceEntryView, updateBalanceAndRefreshView 同理
```

**覆盖的2个 TimeoutNumber Hook:**

```objc
// TimeoutNumber 需要通过 nextResponder 确认父级是 WCPayWalletEntryHeaderView
static void hook_TimeoutNumber_updateNumber(id self, SEL _cmd, long number) {
    if (SimplifyEnabled()) {
        id responder = self;
        while ((responder = [responder nextResponder])) {
            if ([responder isKindOfClass:objc_getClass("WCPayWalletEntryHeaderView")]) {
                NSString *replacement = [PluginConfig shared].walletBalanceReplacement;
                if (replacement && replacement.length > 0) {
                    NSScanner *scanner = [NSScanner scannerWithString:replacement];
                    double value = 0;
                    if ([scanner scanDouble:&value] && scanner.atEnd) {
                        number = (long)(value * 100);
                    } else {
                        // 文本模式不改变 number
                    }
                }
                break;
            }
        }
    }
    ((void (*)(id, SEL, long))_orig_TimeoutNumber_updateNumber)(self, _cmd, number);
}
```

- (void)openUISimplify:(id)sender {
    UIResponder *responder = (UIResponder *)sender;
    while (responder) {
        if ([responder isKindOfClass:[UIViewController class]]) break;
        responder = [responder nextResponder];
    }
    UIViewController *vc = (UIViewController *)responder;
    if (!vc) return;
    
    Class helperClass = objc_getClass("WPUISimplifyVCHelper");
    if (!helperClass) return;
    
    UIViewController *subVC = [helperClass performSelector:@selector(makeVC)];
    if (subVC) {
        [vc.navigationController pushViewController:subVC animated:YES];
    }
}

## 关键注意事项

### 1. 白名单保护
`MMUILabel.setText:` 是微信所有 UILabel 的入口，`[text hasPrefix:@"["]` 白名单是防止修改 badge 数字的关键保护。**缺少此保护会导致消息角标丢失、列表项文字错乱。**

### 2. 字典键名对齐
`customMenuNames` 和 `customTabNames` 的 key 必须与微信实际使用的文字完全匹配（包括本地化后的文字）。建议首次实现时打印日志确认微信实际传递的文字。

### 3. 钱包余额的数值单位
微信余额内部使用"分"作为单位。用户输入 `"99.99"` → 转换为 `9999` 分 → 微信显示为 `¥99.99`。如果用户输入非数字文本如 `"已隐藏"`，则直接使用文本。

### 4. 上下文匹配的可靠性
- `nextResponder` 链查找 NavigationBar 依赖微信的 View 层级结构
- 不同微信版本中 NavigationBar 类名可能不同（`MMUINavigationBar`, `MMNavigationBar` 等）
- 建议打印日志确认实际命中的类名

### 5. 富文本保留
`setAttributedText:` Hook 在替换文本内容时必须保留原 NSAttributedString 的属性，否则会导致字体、颜色样式丢失。

### 6. 钱包类的可选性
`WCPayWalletEntryHeaderView` 和 `TimeoutNumber` 类在某些微信版本中可能不存在或改名。Hook 安装时需要检查 `objc_getClass` 返回值是否为 nil。

### 7. 与界面净化的共存
两个模块都涉及 UI 相关 Hook，但它们 Hook 的目标类完全不同，不会产生冲突。`UIPurifyHook` Hook 的是消息 Cell/气泡类，`UISimplifyHook` Hook 的是标签/Tab/标题类。

## 第一步开发建议

**推荐先实现策略A（字典查找替换），验证可行性后再逐步添加策略B和策略C：**

1. **第一阶段：** 实现 6 个字典替换 Hook（菜单名 + Tab名），不涉及复杂的上下文匹配
2. **第二阶段：** 实现 MMUILabel.setText: Hook（核心上下文匹配），添加白名单保护
3. **第三阶段：** 实现 setAttributedText: 和 MFTitleView Hook
4. **第四阶段：** 实现钱包余额替换（可选，依赖 WCPayWalletEntryHeaderView 类存在）
