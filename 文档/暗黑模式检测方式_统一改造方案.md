# 暗黑模式检测方式 · 统一改造方案

> 目标：将全项目 3 种不同的暗黑模式检测方式统一为 1 个入口，彻底消除代码重复

---

## 1. 改造范围总览

### 1.1 当前现状

| 检测方式 | 所在文件 | 行号 | 使用场景 |
|---------|---------|------|---------|
| A. `UITraitCollection.currentTraitCollection...` | PluginConfig.m（`isDarkMode`） | L802-L807 | 定义 |
| A. `[config isDarkMode]` | MessageTimeHook.m | L599 | 调用 |
| B. `vc.traitCollection.userInterfaceStyle...`（内联 x4） | ListCornerRadiusHook.m | L197-L200, L268-L271, L296-L299, L361-L364 | 调用 |
| B. `vc.traitCollection.userInterfaceStyle...`（封装类方法） | ProfileCardBgHook.m（`isDarkModeForVc:`） | L437-L442 | 定义+调用 |
| B. `self.traitCollection.userInterfaceStyle...`（内联） | SettingCategoryController.m | L973-L978 | 调用 |
| C. `window.traitCollection.userInterfaceStyle...`（内联） | ListCornerRadiusHook.m | L892-L902 | 调用 |

### 1.2 改造后目标

全项目仅保留 **1 个定义 + 2 个方法**：

```
PluginConfig.m  —  isDarkMode（无参，全局检测）
                —  isDarkModeForViewController:（有 VC 参数，精确检测）

所有调用处统一调用以上 2 个方法，不再有任何内联 `UIUserInterfaceStyleDark`。
```

## 2. 改代码：PluginConfig.h / .m

### PluginConfig.h — 新增方法声明

**文件：** `/www/wwwroot/ios/MioPlugin/Config/PluginConfig.h`

```objc
// 在第 215 行后追加
- (BOOL)isDarkMode;
- (BOOL)isDarkModeForViewController:(UIViewController *)vc;
```

### PluginConfig.m — 新增方法实现

**文件：** `/www/wwwroot/ios/MioPlugin/Config/PluginConfig.m`

旧代码（L802-L807）——保留不动，它是全局检测方法：
```objc
- (BOOL)isDarkMode {
    if (@available(iOS 13.0, *)) {
        return UITraitCollection.currentTraitCollection.userInterfaceStyle == UIUserInterfaceStyleDark;
    }
    return NO;
}
```

在 `isDarkMode` 方法后面插入新方法（L808 后）：
```objc
- (BOOL)isDarkModeForViewController:(UIViewController *)vc {
    if (@available(iOS 13.0, *)) {
        return vc.traitCollection.userInterfaceStyle == UIUserInterfaceStyleDark;
    }
    return NO;
}
```

## 9. 注意事项

- `config` 在 Hook 文件中通常通过 `[MMPluginConfig sharedConfig]` 获取，确保所有使用处已导入 PluginConfig.h
- PluginConfig.h 需要 `@class UIViewController;` 前向声明，或在顶部 `#import <UIKit/UIKit.h>`
- 改造完成后，全局搜索 `UIUserInterfaceStyleDark` 应只剩 PluginConfig.m 中的 2 处（2 个方法的定义处），其他位置全部消失
