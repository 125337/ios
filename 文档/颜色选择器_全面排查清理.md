## 问题 1 & 2：Key 与实际属性名不匹配（崩溃级）

### 根因

`SettingNameColorController.m` 传给 `addColorRowInGroup:` 的 `key` 参数是自定义名称（`chatNameLightColor`、`momentsNameLightColor`），但 `PluginConfig` 的实际属性名是 `senderTextColorHex`、`receiverTextColorHex`。

而 `colorButtonTapped:` 最终会执行：

```objc
// line 694
NSString *lightHex = lightKey ? [config valueForKey:lightKey] ...
//  lightKey = @"chatNameLightColor" → PluginConfig 没有这个属性 → ✕

// line 704
[config setValue:lHex forKey:lightKey];
//  ↑ 同样崩溃
```

**ObjC KVC 找不到这个 key → 抛 `NSUnknownKeyException` → 闪退。**

### 修复

#### 改 SettingNameColorController.m（第 103-142 行）

```diff
// 聊天名字颜色
*ecy = [self addColorRowInGroup:expand
                          title:@"聊天名字颜色"
-                           key:@"chatNameLightColor"
-                         value:config.senderTextColorHex
+                           key:@"senderTextColorHex"
+                         value:config.senderTextColorHex
                            cy:*ecy width:w
-                     darkKey:@"chatNameDarkColor"
-                   darkValue:config.senderTextColorDarkHex];
+                     darkKey:@"senderTextColorDarkHex"
+                   darkValue:config.senderTextColorDarkHex];

// 朋友圈名字颜色
*ecy = [self addColorRowInGroup:expand
                          title:@"朋友圈名字颜色"
-                           key:@"momentsNameLightColor"
-                         value:config.receiverTextColorHex
+                           key:@"receiverTextColorHex"
+                         value:config.receiverTextColorHex
                            cy:*ecy width:w
-                     darkKey:@"momentsNameDarkColor"
-                   darkValue:config.receiverTextColorDarkHex];
+                     darkKey:@"receiverTextColorDarkHex"
+                   darkValue:config.receiverTextColorDarkHex];
```

#### 改 ColorPairMap()（SettingCategoryController.m 第 641-645 行）

```diff
- // SettingNameColorController (聊天名字)
- @"chatNameLightColor": @"chatNameDarkColor",
- 
- // SettingNameColorController (朋友圈名字)
- @"momentsNameLightColor": @"momentsNameDarkColor",

+ // 无需再添加 senderTextColorHex / receiverTextColorHex
+ // 已在 SettingMessageTimeController 覆盖
```

> `senderTextColorHex → senderTextColorDarkHex` 和 `receiverTextColorHex → receiverTextColorDarkHex` 已在 `ColorPairMap()` 第 647-651 行存在，删除假 key 后自动生效。

## 问题 3：`cellColor:` 表模式不支持双按钮（功能缺失）

### 根因

`cellColor:`（SettingCategoryController.m 第 806-831 行）只创建了 1 个按钮。当 `row[@"darkKey"]` 存在时，应该创建 2 个按钮。

### 修复

```objc
- (UITableViewCell *)cellColor:(UITableView *)tableView row:(NSDictionary *)row {
    UITableViewCell *cell = [tableView dequeueReusableCellWithIdentifier:kCellColor];
    if (!cell) {
        cell = [[UITableViewCell alloc] initWithStyle:UITableViewCellStyleDefault reuseIdentifier:kCellColor];
        cell.selectionStyle = UITableViewCellSelectionStyleNone;
        cell.backgroundColor = WPCardBg();
        cell.textLabel.font = [UIFont systemFontOfSize:15];
        cell.textLabel.textColor = WPT1();
    }

    cell.textLabel.text = row[@"title"];

    // 清理旧按钮
    UIView *existingSwatch = [cell.contentView viewWithTag:888];
    [existingSwatch removeFromSuperview];
    UIView *existingSwatch2 = [cell.contentView viewWithTag:889];
    [existingSwatch2 removeFromSuperview];

    CGFloat cellW = tableView.bounds.size.width;
    NSString *darkKey = row[@"darkKey"];
    NSString *darkValue = row[@"darkValue"];

    if (darkKey.length > 0) {
        // ─── 双按钮 ───
        CGFloat btnSize = 24;
        CGFloat gap = 8;

        // 深色按钮
        UIColor *darkColor = [[WPColorUtil class] colorFromHexString:darkValue] ?: [UIColor darkGrayColor];
        UIButton *darkBtn = [WPColorPicker makeColorButtonWithColor:darkColor];
        darkBtn.tag = 889;
        CGFloat darkX = cellW - kCellHPadding - btnSize - 4;
        darkBtn.frame = CGRectMake(darkX, (kRowH - btnSize) / 2, btnSize, btnSize);
        objc_setAssociatedObject(darkBtn, "key", darkKey, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
        [darkBtn addTarget:self action:@selector(colorButtonTapped:) forControlEvents:UIControlEventTouchUpInside];
        [cell.contentView addSubview:darkBtn];

        // 浅色按钮
        UIColor *lightColor = [[WPColorUtil class] colorFromHexString:row[@"value"]] ?: [UIColor whiteColor];
        UIButton *lightBtn = [WPColorPicker makeColorButtonWithColor:lightColor];
        lightBtn.tag = 888;
        lightBtn.frame = CGRectMake(darkX - gap - btnSize, (kRowH - btnSize) / 2, btnSize, btnSize);
        objc_setAssociatedObject(lightBtn, "key", row[@"key"], OBJC_ASSOCIATION_RETAIN_NONATOMIC);
        [lightBtn addTarget:self action:@selector(colorButtonTapped:) forControlEvents:UIControlEventTouchUpInside];
        [cell.contentView addSubview:lightBtn];
    } else {
        // ─── 单按钮（原逻辑） ───
        UIColor *color = [[WPColorUtil class] colorFromHexString:row[@"value"]] ?: [UIColor grayColor];
        UIButton *swatch = [WPColorPicker makeColorButtonWithColor:color];
        swatch.tag = 888;
        swatch.frame = CGRectMake(cellW - kCellHPadding - 36, (kRowH - 30) / 2, 30, 30);
        objc_setAssociatedObject(swatch, "key", row[@"key"], OBJC_ASSOCIATION_RETAIN_NONATOMIC);
        [swatch addTarget:self action:@selector(colorButtonTapped:) forControlEvents:UIControlEventTouchUpInside];
        [cell.contentView addSubview:swatch];
    }

    return cell;
}
```

## 问题 4：`addColorRowInGroup:` 双按钮分支用错颜色工具（一致性）

### 当前代码

```objc
// line 479, 489
UIColor *darkColor = [[PluginConfig shared] colorFromHex:darkValue];
UIColor *lightColor = [[PluginConfig shared] colorFromHex:value];
```

### 修复

```diff
- UIColor *darkColor = [[PluginConfig shared] colorFromHex:darkValue] ?: [UIColor darkGrayColor];
+ UIColor *darkColor = [[WPColorUtil class] colorFromHexString:darkValue] ?: [UIColor darkGrayColor];

- UIColor *lightColor = [[PluginConfig shared] colorFromHex:value] ?: [UIColor whiteColor];
+ UIColor *lightColor = [[WPColorUtil class] colorFromHexString:value] ?: [UIColor whiteColor];
```

同时清理不再需要的 `#import`：

```diff
  // SettingCategoryController.m 头部
  #import "PluginConfig.h"
+ #import "WPColorUtil.h"
```

> `getDiagnostics` 会提示 `PluginConfig` 的 import 现在是多余的（只被 `colorButtonTapped:` 的 `PluginConfig *config = [PluginConfig shared]` 使用，这是合理的）。
