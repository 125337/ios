# 背景图深浅合并改造文档

## 现状

目前有2个背景图路径属性，区分浅色/深色模式：

```objc
@property (nonatomic, copy) NSString *cardBgLightImagePath;  // 浅色背景图
@property (nonatomic, copy) NSString *cardBgDarkImagePath;   // 深色背景图
```

在 Hook 代码中根据当前模式二选一：

```objc
// loadBackgroundImageSync:（第141-142行）
NSString *imagePath = isDark ? config.cardBgDarkImagePath : config.cardBgLightImagePath;

// loadBackgroundImageForImageView:isDark:（第282-283行）
NSString *imagePath = isDark ? config.cardBgDarkImagePath : config.cardBgLightImagePath;
```

默认文件也有两套（第149-152行、第289行附近）：

```objc
isDark ? @"MioCardBgDark.gif" : @"MioCardBgLight.gif"
isDark ? @"MioCardBgDark.png" : @"MioCardBgLight.png"
```

UI 上也有两个入口（浅色背景图 + 深色背景图），各有选择/删除逻辑。

**问题**：跟层级/偏移/对齐的理由一样——用户设置一张背景图，不会根据深浅模式分别设置。合并后参数减半，UI 更简洁，默认文件也只有一套。

### 1.7 UI — 合并 action 方法

将 `onLightImageTap` 和 `onDarkImageTap` 合并为 `onImageTap`：

```objc
- (void)onImageTap {
    PluginConfig *config = [PluginConfig shared];
    UIAlertController *alert = [UIAlertController alertControllerWithTitle:@"背景图"
                                                                   message:nil
                                                            preferredStyle:UIAlertControllerStyleActionSheet];

    [alert addAction:[UIAlertAction actionWithTitle:@"选择静态图片"
                                             style:UIAlertActionStyleDefault
                                           handler:^(UIAlertAction *action) {
        [self pickImageForMode:100];  // mode 不再区分深浅
    }]];

    [alert addAction:[UIAlertAction actionWithTitle:@"选择GIF动图"
                                             style:UIAlertActionStyleDefault
                                           handler:^(UIAlertAction *action) {
        [self pickImageForMode:101];
    }]];

    if (config.cardBgImagePath.length > 0) {
        [alert addAction:[UIAlertAction actionWithTitle:@"删除背景图"
                                                 style:UIAlertActionStyleDestructive
                                               handler:^(UIAlertAction *action) {
            WPLog(@"CardBg-Diag", @"[PICKER] Deleting image path: %@", config.cardBgImagePath);
            if (config.cardBgImagePath.length > 0) {
                NSFileManager *fm = [NSFileManager defaultManager];
                if ([fm fileExistsAtPath:config.cardBgImagePath]) {
                    [fm removeItemAtPath:config.cardBgImagePath error:nil];
                    WPLog(@"CardBg-Diag", @"[PICKER] Deleted image file from disk");
                }
            }
            // 删除默认目录下的同名文件
            NSString *bgDir = [NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, YES) firstObject];
            bgDir = [bgDir stringByAppendingPathComponent:@"MioCardBackground"];
            NSFileManager *fm = [NSFileManager defaultManager];
            [fm removeItemAtPath:[bgDir stringByAppendingPathComponent:@"MioCardBg.png"] error:nil];
            [fm removeItemAtPath:[bgDir stringByAppendingPathComponent:@"MioCardBg.gif"] error:nil];
            WPLog(@"CardBg-Diag", @"[PICKER] Removed default image files from MioCardBackground/");
            config.cardBgImagePath = nil;
            [config save];
            [self buildUI];
        }]];
    }

    [alert addAction:[UIAlertAction actionWithTitle:@"取消" style:UIAlertActionStyleCancel handler:nil]];

    if (@available(iOS 13.0, *)) {
        alert.popoverPresentationController.sourceView = self.view;
        alert.popoverPresentationController.sourceRect = CGRectMake(
            self.view.bounds.size.width / 2, self.view.bounds.size.height / 2, 1, 1);
    }
    [self presentViewController:alert animated:YES completion:nil];
}
```

## 二、执行步骤

| 步骤 | 文件 | 操作 |
|------|------|------|
| 1 | PluginConfig.h | 2个路径属性 → 1个 `cardBgImagePath` |
| 2 | PluginConfig.m:loadDefaults | `LightImagePath` + `DarkImagePath` → `ImagePath` |
| 3 | PluginConfig.m:save | `LightImagePath` + `DarkImagePath` → `ImagePath` |
| 4 | ProfileCardBgHook.m | `loadBackgroundImageSync:` 去掉 `isDark` 参数，内部改用 `cardBgImagePath` |
| 5 | ProfileCardBgHook.m | `loadBackgroundImageForImageView:isDark:` 去掉 `isDark` 参数 |
| 6 | ProfileCardBgHook.m | 两处调用处更新签名 |
| 7 | SettingCardBackgroundController.m | 新 UI 中"浅色背景图"+"深色背景图"2行 → "背景图"1行 |
| 8 | SettingCardBackgroundController.m | 合并 `onLightImageTap` + `onDarkImageTap` → `onImageTap` |
| 9 | SettingCardBackgroundController.m | 简化 `pickImageForMode:` 中的深浅逻辑 |
| 10 | 验证编译 | `make package` 无报错 |

> 旧 UI 中的"浅色背景图"和"深色背景图"行随[旧 UI 删除方案](file:///www/wwwroot/ios/文档/WCRefine圆角功能分析/卡片背景页面新旧UI清理改造文档.md)一并清理，不需要单独处理。

## 三、不兼容旧数据

旧 key `Mio_CardBgLightImagePath`、`Mio_CardBgDarkImagePath` 残留在 NSUserDefaults 中，永远不会被读取。旧默认文件 `MioCardBgLight.png/gif`、`MioCardBgDark.png/gif` 也残留在磁盘上不会被使用。

## 四、合并前后对比

| | 改前 | 改后 |
|--|------|------|
| 属性数 | 2个（light + dark） | 1个 |
| loadDefaults/save | 各2段 | 各1段 |
| Hook 函数参数 | 需传 `isDark` | 无需 `isDark` |
| 默认文件名 | `MioCardBgLight/Dark.png/gif` | `MioCardBg.png/gif` |
| UI 入口 | 2行导航（浅+深） | 1行导航 |
| 用户心智负担 | 需设置2次 | 设置1次即可 |
