# 我的页面顶部变灰修复文档

## 问题描述

**场景**：只开启资料卡片美化（`cardBgBeautifyEnabled = YES`），未开启背景素材（`materialEnabled = NO`），未开启隐藏信息卡片（`isHidden = NO`）

**现象**：我的页面顶部区域从微信原生的**白色**变成**灰色**，底色（微信的深色背景）透了出来

**关键线索**：在 8:35 的"背景丢失Bug"修复后这个问题不存在，是 handleCardHidden 提取改造后才出现的。

---

## 根因分析

### 三版代码的关键差异

| 版本 | beautify=YES, material=NO, hidden=NO 时是否清理原生 m_bgImageView |
|------|---------------------------------------------------------------|
| 背景丢失Bug修复后（正常工作） | **✅ 清理** |
| handleCardHidden 提取后（出问题） | **❌ 未清理** |

### handleCardHidden 提取移除了什么

**提取前**（背景丢失Bug修复版本）：

```
needsNewCardBg:
  if (hasMaterial) {
    bg 生命周期
    clear native m_bgImageView     ← 只在有素材时
  }
  if (isHidden) {
    hide content, keep bg           ← Scene A
  } else {
    button.hidden = NO
    clear native m_bgImageView     ← ← ← ★ 非隐藏态也清理
  }
  FIX-WHITE
```

**提取后**（handleCardHidden 版本）：

```
needsNewCardBg:
  if (hasMaterial) {
    bg 生命周期
    clear native m_bgImageView     ← 只在有素材时
  }
  handleCardHidden(isHidden, hasMaterial)
    → non-hide: button.hidden = NO ← ← ← ★ 没清原生 bg！
  FIX-WHITE
```

### m_bgImageView 是什么

`m_bgImageView` 是 MMUIButton 内部的图片视图，微信用它来展示按钮的背景图片。在我的页面场景中，MMUIButton 覆盖了整个资料卡区域（含顶部装饰区），`m_bgImageView` 中包含微信原生的背景装饰。

当 `hasMaterial=NO` 时：
- **清理原生 bg** → 微信的装饰背景被移除，按钮只显示纯背景色（白色） ✅
- **不清理原生 bg** → 微信的装饰背景残留，其覆盖层在顶部区域显示为灰色 ❌

## 修复方案

### 方案 A：在 handleCardHiddenInButton non-hide 路径追加原生 bg 清理（推荐）

**[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m) — handleCardHiddenInButton 方法**

```objc
+ (BOOL)handleCardHiddenInButton:(UIView *)button
                       isHidden:(BOOL)isHidden
                    hasMaterial:(BOOL)hasMaterial {
    
    // ══════════════════════════════════════════
    // 非隐藏态：确保可见，清理原生 bg
    // ══════════════════════════════════════════
    if (!isHidden) {
        button.hidden = NO;
        
        // ★★ 追加：清理原生 m_bgImageView ★★
        // 防止微信原生背景装饰的灰色效果透出
        Ivar bgIvar = class_getInstanceVariable([button class], "m_bgImageView");
        if (bgIvar) {
            id bgImgView = object_getIvar(button, bgIvar);
            if (bgImgView && [bgImgView isKindOfClass:[UIImageView class]]) {
                [(UIImageView *)bgImgView setImage:nil];
                [(UIImageView *)bgImgView setBackgroundColor:[UIColor clearColor]];
                [(UIImageView *)bgImgView setHidden:YES];
            }
            object_setIvar(button, bgIvar, nil);
        }
        
        return NO;  // 让调用者继续处理背景和布局
    }
```

### 方案 B：在 handleButtonLayout 通用段清理

在 `if (hasMaterial) { }` 块之后、`handleCardHidden:` 调用之前，加通用清理：

```objc
        }  // if (hasMaterial)

        // ══════════════════════════════════════════
        // ★ 通用清理：无论有无素材，都清除原生 bg
        // ══════════════════════════════════════════
        Ivar bgIvar = class_getInstanceVariable([button class], "m_bgImageView");
        if (bgIvar) {
            id bgImgView = object_getIvar(button, bgIvar);
            if (bgImgView && [bgImgView isKindOfClass:[UIImageView class]]) {
                [(UIImageView *)bgImgView setImage:nil];
                [(UIImageView *)bgImgView setBackgroundColor:[UIColor clearColor]];
                [(UIImageView *)bgImgView setHidden:YES];
            }
            object_setIvar(button, bgIvar, nil);
        }

        // ══════════════════════════════════════════
        // 隐藏信息卡片（独立方法）
        // ══════════════════════════════════════════
        if ([ProfileCardBgHook handleCardHiddenInButton:...]) {
            return;
        }
```

## 方案对比

| 维度 | 方案 A（推荐） | 方案 B |
|------|---------------|--------|
| 改动位置 | `handleCardHiddenInButton` 的 non-hide 路径 | `handleButtonLayout` 主流程 |
| 职责合理性 | 清理原生 bg 是"恢复按钮视觉"的一部分，放在 non-hide 重建态合理 | 放在通用段也行，但会和 `if (hasMaterial)` 内的清理重复 |
| 代码重复 | 无重复（只有本分支一份） | `if (hasMaterial)` 内也有一份 |
| 理解成本 | 低——"非隐藏时清理原生 bg 让按钮干净显示" | 中——"通用段清理"意图泛泛 |

**推荐方案 A**：在 `handleCardHiddenInButton` 的 non-hide 分支内追加原生 bg 清理，改动集中、语义清晰。

---

## 场景验证（方案 A）

| 场景 | beautify | material | hidden | handleCardHidden 路径 | 原生 bg 是否清理 | 预期 |
|------|----------|----------|--------|----------------------|-----------------|------|
| 1 | ON | OFF | OFF | **non-hide** ← 修复点 | ✅ 新增清理 | 顶部白色 ✅ |
| 2 | ON | ON | OFF | non-hide | ✅ `if (hasMaterial)` 内清理 | 背景图正常 ✅ |
| 3 | ON | OFF | ON | hide + Scene B | ✅ 隐藏态自清理 | 全隐藏 ✅ |
| 4 | ON | ON | ON | hide + Scene A | ✅ 隐藏态自清理 | 隐藏内容留 bg ✅ |

所有场景验证通过，其中场景 1 是本次修复的目标场景。
