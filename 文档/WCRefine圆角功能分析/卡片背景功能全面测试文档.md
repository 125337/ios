# 卡片背景功能全面测试文档

日期：2026-06-06
适用范围：资料卡片美化手风琴（卡片背景页面所有功能）

---

## 一、功能结构总览

```
卡片背景页面 (SettingCardBackgroundController)
│
├── 第1层：资料卡片美化总开关 (cardBgBeautifyEnabled)
│   │
│   ├── 子手风琴1：使用背景素材 (cardBgMaterialEnabled)
│   │   ├── 列表向下间距 (cardBgListSpacing)
│   │   ├── 背景图 (cardBgImagePath)
│   │   ├── 背景填充模式 (cardBgFillMode：0填充/1适应/2拉伸/3顶部)
│   │   ├── 对齐方式 (cardBgAlignment：0底部/1居中/2顶部)
│   │   ├── 背景显示层级 (cardBgLayer：0底层/1顶层)
│   │   ├── 背景Y轴偏移 (cardBgOffsetY)
│   │   └── 背景X轴偏移 (cardBgOffsetX)
│   │
│   ├── 平铺开关：隐藏信息卡片 (cardBgHidden)
│   │
│   └── 子手风琴3：开启资料圆角 (cardBgCornerEnabled)
│       ├── 平铺开关：使用全局配置 (cardBgCornerUseGlobal)
│       └── 非全局模式下的独立配置：
│           ├── 圆角大小 (cardBgCornerRadius)
│           ├── 边距大小 (cardBgCornerMargin)
│           ├── 浅色模式背景颜色 (cardBgCornerBgColor)
│           ├── 深色模式背景颜色 (cardBgCornerDarkBgColor)
│           └── 描边大小 (cardBgStrokeWidth)
```

**额外独立功能**：`listHideRightQRCode`（来自列表设置页面的"隐藏右边QR码"，在资料卡也生效）

## 二、已知问题（待修复）

### 问题 1：QR 码隐藏被重复调用（轻微）

**位置**：隐藏路径 Scene A（L734）和 Scene B（L708）中调用了 `hideQRButtonInCell`，然后 `handleCornerAndQR`（L609）又调了一遍。

**影响**：无视觉影响，`sub.hidden = YES` 是幂等的。只是多了一次遍历子视图的循环，性能影响极小。

---

### 问题 2：边距在隐藏模式下仍计算（轻微）

**位置**：`handleButtonLayout` L608 无条件调用 `handleMarginAdjustment`。

**影响**：Scene B（隐藏 + 无素材）时，button 所有子视图已隐藏，边距改动不可见。无实际影响。

---

### 问题 3：`cardBgListSpacing` UI 位置与生效条件不匹配

**位置**：UI 中"列表向下间距"放在"使用背景素材"（cardBgMaterialEnabled）的子项中，但实际生效只受 `cardBgBeautifyEnabled` 控制（`_hooked_heightForHeader` L16）。

**影响**：
- 如果用户设了间距然后关闭素材开关 → 间距仍然生效（界面不显示该字段，用户以为关闭了）
- 如果用户不开启素材但开启总开关 → 间距无法设置（UI 不显示）

**建议**：把间距移到总开关下一级（与素材平级）或独立显示。
