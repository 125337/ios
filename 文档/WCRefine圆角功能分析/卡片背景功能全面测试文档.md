# 卡片背景功能全面测试文档

日期：2026-06-06
适用范围：资料卡片美化手风琴（卡片背景页面所有功能）

---

## 一、功能结构总览

```
卡片背景页面 (SettingCardBackgroundController)
│
├── 第1层：资料卡片美化总开关 (cardBgBeautifyEnabled)
│   │   ★ 总开关关闭 → 下面所有功能全部不生效
│   │
│   ├── 子手风琴1：使用背景素材 (cardBgMaterialEnabled)
│   │   ├── 列表向下间距 (cardBgListSpacing)  ← 受总开关控制，不依赖素材开关
│   │   ├── 背景图 (cardBgImagePath)
│   │   ├── 背景填充模式 (cardBgFillMode：0填充/1适应/2拉伸/3顶部)
│   │   ├── 对齐方式 (cardBgAlignment：0居中/1顶部/2底部)
│   │   ├── 背景显示层级 (cardBgLayer：0底层/1顶层)
│   │   ├── 背景Y轴偏移 (cardBgOffsetY)
│   │   └── 背景X轴偏移 (cardBgOffsetX)
│   │
│   ├── 平铺开关：隐藏信息卡片 (cardBgHidden)
│   │
│   └── 子手风琴3：开启资料圆角 (cardBgCornerEnabled)
│       ├── 平铺开关：使用全局配置 (cardBgCornerUseGlobal)
│       └── 非全局模式下的独立配置：
│           ├── 圆角大小 (cardBgCornerRadius)
│           ├── 边距大小 (cardBgCornerMargin)
│           ├── 浅色模式背景颜色 (cardBgCornerBgColor)
│           ├── 深色模式背景颜色 (cardBgCornerDarkBgColor)
│           └── 描边大小 (cardBgStrokeWidth)
│
└── 额外独立功能：隐藏右边QR码 (listHideRightQRCode)
    （来自列表设置页面，在资料卡也生效）
```

## 二、代码执行流程

### 2.1 入口方法 `handleButtonLayout`

```
handleButtonLayout(button):
  │
  ├─ 第1层守卫：if (!cardBgBeautifyEnabled) return;  ← 总开关关闭，全部不执行
  │
  ├─ 通用安全检查：
  │   ├─ findMoreViewController(button) → 找不到则 return
  │   ├─ hasHeadImageViewInView(button) → 没有则 return
  │   ├─ button.frame.size.height <= 50 → 跳过
  │   └─ isDark = isDarkModeForVc(vc)
  │
  ├─ 场景路由：
  │   ├─ if (cardBgHidden) → handleHiddenPath(button, isDark)
  │   └─ else if (cardBgMaterialEnabled || cardBgCornerEnabled) → handleVisiblePath(button, isDark)
  │
  ├─ 独立功能：handleMarginAdjustment(button)
  │   └─ 内部守卫：if (!cardBgCornerEnabled) return;
  │
  └─ 独立功能：handleCornerAndQR(button, isDark)
      ├─ if (cardBgCornerEnabled) → applyProfileCardCorner
      └─ if (listHideRightQRCode) → hideQRButtonInCell
```

### 2.2 隐藏路径 `handleHiddenPath`

```
handleHiddenPath(button, isDark):
  │
  ├─ 共有清除：清背景色、清 layer 背景色、关 masksToBounds、关圆角、关描边
  ├─ cleanNativeBgImageView(button)  ← 清原生 m_bgImageView
  │
  ├─ Scene B（隐藏 + 无素材）：
  │   ├─ 隐藏所有子视图（button.subviews 全部 hidden=YES）
  │   ├─ if (listHideRightQRCode) → hideQRButtonInCell
  │   └─ return  ← 不进入背景段
  │
  └─ Scene A（隐藏 + 有素材）：
      ├─ setupBackgroundMaterialInButton(button, isDark)  ← 加载背景图
      ├─ 隐藏所有子视图，只保留背景图（tag=999902）
      └─ if (listHideRightQRCode) → hideQRButtonInCell
```

### 2.3 可见态美化路径 `handleVisiblePath`

```
handleVisiblePath(button, isDark):
  │
  ├─ button.hidden = NO  ← 确保可见
  │
  ├─ hasMaterial=YES：
  │   ├─ hasImagePath = config.cardBgImagePath.length > 0
  │   ├─ if (hasImagePath) → 清背景色 + 清 layer 背景色
  │   ├─ 关 masksToBounds、关圆角、关描边
  │   ├─ if (hasImagePath) → cleanNativeBgImageView
  │   ├─ setupBackgroundMaterialInButton(button, isDark)  ← 加载背景图
  │   └─ if (hasImagePath) → FIX-WHITE（隐藏白色/动态背景子视图）
  │
  └─ hasMaterial=NO：什么都不做，保持原生
```

### 2.4 背景素材加载 `setupBackgroundMaterialInButton`

```
setupBackgroundMaterialInButton(button, isDark):
  │
  ├─ 查找已有 bgImgView（tag=999902）
  │
  ├─ 分支 A（已存在）：
  │   ├─ 更新 contentMode
  │   ├─ 重新计算对齐偏移
  │   ├─ 更新 frame
  │   └─ 处理层级（bringSubviewToFront）
  │
  ├─ 分支 B（不存在）：
  │   ├─ createBackgroundImageViewInButton(button)
  │   │   ├─ newBg.clipsToBounds = YES  ← 图片不溢出
  │   │   ├─ 根据 cardBgFillMode 设置 contentMode
  │   │   └─ 根据 cardBgLayer 设置层级（底层/顶层）
  │   └─ loadImageAsyncForImageView(bgImgView, button, isDark)
  │       └─ 异步加载图片，失败则 fallback 设置背景色
  │
  ├─ ★ 适应模式/顶部填充 → 向下延伸 button 高度（WCRefine 风格）：
  │   ├─ if (fillMode == 1 || fillMode == 3)：
  │   │   ├─ 按图片比例计算目标高度 targetH
  │   │   ├─ if (targetH > button.当前高度)：
  │   │   │   ├─ button.frame.size.height = targetH（origin.y 不变，向下延伸）
  │   │   │   ├─ 同步更新 bgImgView.frame.size.height
  │   │   │   ├─ button 新底部下方的子视图向下推 deltaH
  │   │   │   └─ 更新 contentSize（height += deltaH）
  │
  ├─ button.backgroundColor = clearColor  ← 让背景图透出
  └─ cleanNativeBgImageView(button)  ← 清原生 m_bgImageView
```

### 2.5 边距调整 `handleMarginAdjustment`

```
handleMarginAdjustment(button):
  │
  ├─ 内部守卫：if (!cardBgCornerEnabled) return;
  │
  ├─ 计算 margin：
  │   ├─ cardBgCornerUseGlobal=YES → margin = listCellMargin
  │   └─ cardBgCornerUseGlobal=NO → margin = cardBgCornerMargin（无默认值）
  │
  ├─ if (margin <= 0) return;
  │
  ├─ 浮点比较防递归：fabs(currentX - targetX) > 0.5 || fabs(currentW - targetW) > 0.5
  │   └─ 是 → button.frame = (targetX, y, targetW, height)
  │       └─ Label sizeToFit
  └─ 否 → 跳过（已对齐）
```

### 2.6 圆角 + QR `handleCornerAndQR`

```
handleCornerAndQR(button, isDark):
  │
  ├─ if (cardBgCornerEnabled) → applyProfileCardCorner(button, isDark)
  │   └─ 设置 cornerRadius、masksToBounds、borderWidth、borderColor
  └─ if (listHideRightQRCode) → hideQRButtonInCell(button)
```

- 设备：iPhone 真机或模拟器
