# 背景显示层级合并改造文档

## 现状

目前有两个独立的层级属性，区分浅色/深色模式：

```objc
@property (nonatomic, assign) NSInteger cardBgLightLayer;  // 浅色模式层级
@property (nonatomic, assign) NSInteger cardBgDarkLayer;    // 深色模式层级
```

在 `handleButtonLayout:` 中根据当前模式二选一：

```objc
NSInteger layerPos = isDark ? config.cardBgDarkLayer : config.cardBgLightLayer;
```

**问题**：这个区分没有必要。层级的含义是"背景图放在最底层还是最顶层"，用户通常不会根据浅色/深色模式切换这个设置。合并后也减少了新 UI 的参数数量。

---

## 一、改动清单

### 1.1 属性定义

**PluginConfig.h** — 替换为单个属性：

```objc
// 改前（第 204-205 行）：
@property (nonatomic, assign) NSInteger cardBgLightLayer;
@property (nonatomic, assign) NSInteger cardBgDarkLayer;

// 改后：
@property (nonatomic, assign) NSInteger cardBgLayer;
```

### 1.2 读写逻辑

**PluginConfig.m — loadDefaults**（第 510-511 行）：

```objc
// 改前：
_cardBgLightLayer = [d integerForKey:[kPluginPrefix stringByAppendingString:@"CardBgLightLayer"]];
_cardBgDarkLayer = [d integerForKey:[kPluginPrefix stringByAppendingString:@"CardBgDarkLayer"]];

// 改后：
_cardBgLayer = [d integerForKey:[kPluginPrefix stringByAppendingString:@"CardBgLayer"]];
```

**PluginConfig.m — save**（第 744-745 行）：

```objc
// 改前：
[d setInteger:_cardBgLightLayer forKey:[kPluginPrefix stringByAppendingString:@"CardBgLightLayer"]];
[d setInteger:_cardBgDarkLayer forKey:[kPluginPrefix stringByAppendingString:@"CardBgDarkLayer"]];

// 改后：
[d setInteger:_cardBgLayer forKey:[kPluginPrefix stringByAppendingString:@"CardBgLayer"]];
```

### 1.3 Hook 代码

**ProfileCardBgHook.m — handleButtonLayout:**（第 473-474 行、第 492-498 行）：

```objc
// 改前（第 473-474 行）：
NSInteger layerPos = isDark ? config.cardBgDarkLayer : config.cardBgLightLayer;
if (layerPos == 1) [button bringSubviewToFront:bgImgView];

// 改后：
if (config.cardBgLayer == 1) [button bringSubviewToFront:bgImgView];
```

```objc
// 改前（第 492-498 行）：
NSInteger layerPos = isDark ? config.cardBgDarkLayer : config.cardBgLightLayer;
if (layerPos == 1) {
    [button addSubview:newBg];
    [button bringSubviewToFront:newBg];
} else {
    [button insertSubview:newBg atIndex:0];
}

// 改后：
if (config.cardBgLayer == 1) {
    [button addSubview:newBg];
    [button bringSubviewToFront:newBg];
} else {
    [button insertSubview:newBg atIndex:0];
}
```

### 1.4 UI — 添加到新 UI

结合已确定的**旧 UI 删除方案**，层级控制只在旧 UI 中存在（浅色/深色各一个），合并后需要在新 UI 的"使用背景素材"手风琴中补一个。

**SettingCardBackgroundController.m** — 在"使用背景素材"手风琴最后（深色对齐方式之后，第 112 行之后）添加：

```objc
*e2y = [self addSeparatorInGroup:e2 cy:*e2y width:w];

NSArray *layerNames = @[@"底层显示", @"顶层显示"];
NSString *layerSub = (cfg.cardBgLayer >= 0 && cfg.cardBgLayer < (NSInteger)layerNames.count)
    ? layerNames[cfg.cardBgLayer] : @"底层显示";
*e2y = [self addNavRowInGroup:e2
                        title:@"背景显示层级"
                      subtitle:layerSub
                          tag:203
                       action:@selector(onLayerTap)
                           cy:*e2y width:w];
```

同时添加事件处理方法（可以复用旧 UI 的 `onLightLayerTap`，但改名为 `onLayerTap`，逻辑改为读写 `cardBgLayer`）：

```objc
#pragma mark - 背景显示层级

- (void)onLayerTap {
    PluginConfig *config = [PluginConfig shared];
    NSArray *layerNames = @[@"底层显示", @"顶层显示"];

    UIAlertController *alert = [UIAlertController alertControllerWithTitle:@"背景显示层级"
                                                                   message:nil
                                                            preferredStyle:UIAlertControllerStyleActionSheet];

    for (NSInteger i = 0; i < (NSInteger)layerNames.count; i++) {
        NSString *title = layerNames[i];
        if (i == config.cardBgLayer) {
            title = [NSString stringWithFormat:@"✓ %@", title];
        }
        [alert addAction:[UIAlertAction actionWithTitle:title
                                                 style:UIAlertActionStyleDefault
                                               handler:^(UIAlertAction *action) {
            config.cardBgLayer = i;
            [config save];
            [self buildUI];
        }]];
    }

    [alert addAction:[UIAlertAction actionWithTitle:@"取消" style:UIAlertActionStyleCancel handler:nil]];

    if (@available(iOS 13.0, *)) {
        alert.popoverPresentationController.sourceView = self.view;
        alert.popoverPresentationController.sourceRect = CGRectMake(
            self.view.bounds.size.width / 2, self.view.bounds.size.height / 2, 1, 1);
    }
    [self presentViewController:alert animated:YES completion:nil];
}
```

## 三、不兼容旧数据

```objc
// ❌ 不要这样迁移：
if ([d objectForKey:@"Mio_CardBgLightLayer"] && ![d objectForKey:@"Mio_CardBgLayer"]) {
    _cardBgLayer = [d integerForKey:@"Mio_CardBgLightLayer"]; // 不做兼容
}
```

旧 key `Mio_CardBgLightLayer`、`Mio_CardBgDarkLayer` 会残留在 NSUserDefaults 中，但永远不会被读取。

## 四、合并前后对比

| | 改前 | 改后 |
|--|------|------|
| 属性数 | 2 个（light + dark） | 1 个 |
| UI 入口 | 旧 UI 中 2 个导航行 | 新 UI 中 1 个导航行 |
| Hook 代码 | `isDark ? dark : light` 三元 | 直接读取 `cardBgLayer` |
| 用户心智负担 | 需配置两次 | 配置一次即可 |
| 旧数据残留 | — | 2 个旧 key 留在 NSUserDefaults 中，永不读取 |
