## 改后判断链

```
globalCornerRadiusEnabled = NO?   ← 唯一总开关
    ↓ NO：orig，返回

shouldSkipCorner(vc) → YES?       ← 黑名单
    ↓ YES：orig，返回

shouldApplyGlobalCorner(vc) → NO? ← 页面开关过滤
    ↓ NO：orig，返回

应用 margin + radius + border + bgColor
```

`listCornerRadiusEnabled` 不再被任何代码引用，可以后续从 Config.h/.m 和 NSUserDefaults 中清理掉。
