# 独立功能开关架构改造方案

## 现状：嵌套耦合架构

### 当前 `handleButtonLayout` 结构

```
handleButtonLayout(button):
  │
  ├─ if (!cardBgBeautifyEnabled) return;    ← 总开关
  │
  ├─ [VC 类型守卫]                           ← 通用守卫
  ├─ [MMHeadImageView 守卫]
  ├─ [高度过滤守卫]
  │
  ├─ if (needsNewCardBg) {                   ← 总开关再次判断
  │    │
  │    ├─ if (hasMaterial) {                 ← 素材开关
  │    │    bg 生命周期                       │── 背景加载/更新
  │    │    button.backgroundColor = clear    │── 清按钮背景
  │    │    清理 m_bgImageView               │── 清原生背景
  │    │    }
  │    │
  │    ├─ handleCardHiddenInButton()         ← 隐藏开关
  │    │    ├─ non-hide: 清理 m_bgImageView
  │    │    ├─ Scene B: 完全隐藏 → return
  │    │    └─ Scene A: 隐藏内容保留 bg
  │    │
  │    ├─ if (isHidden) { FIX-WHITE }        ← 依附于隐藏态
  │    │
  │    }  ← ends needsNewCardBg
  │
  ├─ [高度调整]                               ← 游离在外
  ├─ [圆角 + QR 码隐藏]                        ← 独立但有条件
```

### 嵌套耦合的问题

```
┌──────────────────────────────────────────────────────────┐
│ cardBgBeautifyEnabled ← 既是总开关，又是 needsNewCardBg   │
│                                                          │
│  ├─ 第1层: if (needsNewCardBg) {                         │
│  │   ├─ 第2层: if (hasMaterial) { bg 生命周期 }          │
│  │   ├─ 第2层: handleCardHiddenInButton(isHidden)        │
│  │   │   ├─ non-hide: 清理 m_bgImageView                 │
│  │   │   ├─ Scene B: 完全隐藏 → return                   │
│  │   │   └─ Scene A: 隐藏内容保留 bg                     │
│  │   ├─ 第2层: if (isHidden) { FIX-WHITE }               │
│  │   └─ 第2层结束                                       │
│  ├─ 高度调整                                             │
│  └─ DO_CORNER: 圆角 + QR                                 │
└──────────────────────────────────────────────────────────┘
```

**问题本质：4 层嵌套 + 状态共享 = bug 温床**

```
第1层 needsNewCardBg  ────────────── 决定是否进入美化块
    │
第2层 hasMaterial    ────────────── hasMaterial=NO 时跳过素材块
    │                     ←── 但 isHidden 仍然在 handleCardHidden 中传递
第2层 isHidden       ────────────── 决定隐藏行为
    │                     ←── FIX-WHITE 在非隐藏态误伤白色子视图
第2层 FIX-WHITE      ────────────── 依赖 isHidden + hasMaterial 隐式判断
```

**问题 1：状态变量穿梭于嵌套层之间**
- `hasMaterial`、`isHidden`、`isDark` 在 4 层嵌套中反复传递
- 一个分支的副作用（如 `clearColor`）泄漏到下一个分支
- 这就是"非隐藏态 FIX-WHITE 误伤"和"清理 m_bgImageView 遗漏"的根因

**问题 2：`cardBgBeautifyEnabled` 承担了两个角色**
- 既是**总开关守卫**（让不美化的人跳过所有代码）
- 又是**嵌套块的进入条件**（`needsNewCardBg = cardBgBeautifyEnabled`）
- 导致圆角被它卡住：`cardBgCornerEnabled` 有独立开关，但必须等 `cardBgBeautifyEnabled` 放行

**问题 3：没有隐藏路径没有独立出口**
- 隐藏态代码（FIX-WHITE）嵌套在美化块里面
- 非隐藏态也跑到美化块里面 → 执行了不该执行的逻辑
- WCRefine 的做法是：hide 路径和 non-hide 路径**直接是两个独立分支**，互不嵌套

### 关键是代码结构，不是总开关

你观察得很对——**功能效果上两者一样**：子开关全关时总开关开了也没效果。区别不在功能的开关方式，在于**代码结构**：

| 对比 | WCRefine | MioPlugin |
|------|----------|-----------|
| 代码路径 | hide/non-hide 两个独立分支，互不嵌套 | 4 层嵌套：`needsNewCardBg > hasMaterial > handleCardHidden > FIX-WHITE` |
| 状态变量 | 每个路径内部自包含 | hasMaterial、isHidden 在嵌套层间穿梭 |
| 副作用隔离 | 隐藏态的 clearColor 不会影响美化态 | 一个块的副作用可能泄漏到另一个块 |
| 圆角开关 | `profileCornerEnabled` 独立生效 | 被 `cardBgBeautifyEnabled` 卡住 |

### WCRefine 参考

```c
// FUN_0032b0d0 的核心结构（第286628-286921行）

// 1. OR 聚合守卫（只是性能优化，不做逻辑分流）
masterEnabled = profileCornerEnabled || profileHideArrowQR || ...

// 2. 直接两个独立分支，没有嵌套
if (profileHideEnabled == YES) {
    // ── 隐藏态路径 ──
    loadBackground(button);
    adjustHeight(button);
    for (subview in button.subviews) { 按 tag 选择性隐藏 }
    setBackgroundColor(clearColor);
    reloadBackground(button);
    applyCorner(button);
} else {
    // ── 美化态路径 ──
    loadBackground(button);
    applyCorner(button);
    // 无嵌套，不碰背景色，不碰子视图
}
```

**关键结构差异**：
- WCRefine 的 hide 和 non-hide 是**同级**的两个分支，不嵌套
- 每个分支**代码完整自包含**，不共享代码段
- 隐藏态的 `clearColor` 不会泄漏到美化态
- `profileCornerEnabled` 不带"总开关"属性，就是一个普通的子开关

### MioPlugin 改造目标

```
入口守卫 = cardBgCornerEnabled || cardBgBeautifyEnabled || cardBgHidden  ← OR 聚合
  │
  ├─ [通用守卫] ← 保留（VC类型、高度过滤等）
  │
  ├─ ★ 场景路由 ★
  │  if (cardBgHidden) {
  │      handleHiddenPath(button);          ← 完整隐藏路径
  │  } else if (cardBgMaterialEnabled || cardBgCornerEnabled) {
  │      handleVisiblePath(button);         ← 完整美化路径
  │  }
  │
  ├─ handleHeightAdjustment(button);        ← 独立高度调整
  │
  └─ handleCornerAndQR(button);             ← 独立圆角 + QR隐藏
```

## 改造方案详解

### 第一步：拆解 `needsNewCardBg` 大块

**当前代码**（约 250 行的 `needsNewCardBg` 块）：

```objc
+ (void)handleButtonLayout:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];
    if (!config.cardBgBeautifyEnabled) return;
    // ... 守卫 ...
    
    BOOL hasMaterial = config.cardBgMaterialEnabled;
    BOOL isHidden = config.cardBgHidden;
    
    if (needsNewCardBg) {
        if (hasMaterial) { /* 背景生命周期 */ }
        if ([ProfileCardBgHook handleCardHiddenInButton:...isHidden:isHidden...]) return;
        if (isHidden) { /* FIX-WHITE */ }
    }
    
    // 高度调整
    // 圆角 + QR
}
```

**改为独立路径**：

```objc
+ (void)handleButtonLayout:(UIView *)button {
    // ══════════════════════════════════════════
    // 通用守卫（OR 聚合型总开关）
    // 等效于 WCRefine 的 local_1d6 = corner || hideArrow || hideButtons
    // ══════════════════════════════════════════
    PluginConfig *config = [PluginConfig shared];
    BOOL anyFeatureEnabled = config.cardBgBeautifyEnabled 
                          || config.cardBgHidden
                          || config.cardBgCornerEnabled;
    if (!anyFeatureEnabled) return;
    
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    
    CGFloat selfHeight = button.frame.size.height;
    if (selfHeight <= 50.0) return;
    
    BOOL isDark = [ProfileCardBgHook isDarkMode:vc];
    BOOL hasMaterial = config.cardBgMaterialEnabled;
    
    // ══════════════════════════════════════════
    // ★ 场景路由：根据隐藏开关选择完整路径
    // ══════════════════════════════════════════
    if (config.cardBgHidden) {
        // ── 隐藏路径（完整） ──
        [ProfileCardBgHook handleHiddenPath:button
                                 hasMaterial:hasMaterial];
    } else {
        // ── 非隐藏路径（完整） ──
        [ProfileCardBgHook handleVisiblePath:button
                                 hasMaterial:hasMaterial
                                     isDark:isDark];
    }
    
    // ══════════════════════════════════════════
    // 独立功能（不受上方路径影响）
    // ══════════════════════════════════════════
    [ProfileCardBgHook handleHeightAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];
}
```

### 第二步：提取 `handleHiddenPath`（完全独立）

**职责**：完整处理"隐藏资料卡片"场景，不依赖外部状态。

```objc
/// 隐藏态完整路径
/// 对应 WCRefine 的 profileHideEnabled == YES 分支
+ (void)handleHiddenPath:(UIView *)button
            hasMaterial:(BOOL)hasMaterial {
    
    PluginConfig *config = [PluginConfig shared];
    
    // ── 有素材：先加载背景图 ──
    if (hasMaterial) {
        [ProfileCardBgHook ensureBackgroundForButton:button];
        button.backgroundColor = [UIColor clearColor];
        [ProfileCardBgHook cleanNativeBgImageView:button];
    }
    
    // ── Scene B：无素材 → 完全隐藏 ──
    if (!hasMaterial) {
        for (UIView *sub in button.subviews) {
            sub.hidden = YES;
        }
        [ProfileCardBgHook hideQRIfNeeded:button];
        return;  // 早返，不执行后续
    }
    
    // ── Scene A：有素材 → 隐藏内容，保留背景 ──
    for (UIView *sub in button.subviews) {
        if ([sub isKindOfClass:[UIImageView class]] &&
            sub.tag == kProfileCardBgImageTag) {
            continue;  // 保留背景图
        }
        sub.hidden = YES;
    }
    
    // ── FIX-WHITE：隐藏白色子视图（只在 Scene A 执行） ──
    for (NSInteger i = button.subviews.count - 1; i >= 0; i--) {
        UIView *sub = button.subviews[i];
        if (sub.tag == kProfileCardBgImageTag) continue;
        if ([ProfileCardBgHook isEssentialSubview:sub]) continue;
        
        if ([ProfileCardBgHook hasWhiteOrDynamicBackground:sub]) {
            sub.hidden = YES;
        }
    }
    
    [ProfileCardBgHook hideQRIfNeeded:button];
}
```

### 第三步：提取 `handleVisiblePath`（完全独立）

**职责**：完整处理"美化但不隐藏"场景。**不设 clearColor，不隐藏子视图**。

```objc
/// 非隐藏态完整路径
/// 对应 WCRefine 的 profileHideEnabled == NO + profileCornerEnabled 分支
+ (void)handleVisiblePath:(UIView *)button
             hasMaterial:(BOOL)hasMaterial
                 isDark:(BOOL)isDark {
    
    PluginConfig *config = [PluginConfig shared];
    
    // ── 有素材：加载背景图 ──
    if (hasMaterial) {
        [ProfileCardBgHook ensureBackgroundForButton:button];
        button.backgroundColor = [UIColor clearColor];
        [ProfileCardBgHook cleanNativeBgImageView:button];
    }
    // ★★ 无素材时：不碰 button 背景色，不碰 m_bgImageView，不隐藏子视图 ★★
    // 这就是 WCRefine 的做法——保持原生状态
}
```

### 第四步：提取独立功能方法

```objc
/// 高度调整（独立于隐藏/美化状态）
+ (void)handleHeightAdjustment:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];
    CGFloat targetH = config.cardBgHeight;
    if (targetH <= 0 || button.frame.size.height >= targetH) return;
    
    // 查找视图层级
    UIView *tableView = button.superview;
    if (!tableView || ![NSStringFromClass([tableView class]) isEqualToString:@"TextStateProfileTableView"]) return;
    
    UIView *container = tableView.superview;
    if (!container || ![container isKindOfClass:NSClassFromString(@"MMUIButton")]) return;
    
    // 修改尺寸
    CGRect bf = button.frame;
    bf.size.height = targetH;
    CGFloat margin = config.cardBgCornerUseGlobal
        ? config.listCellMargin
        : (config.cardBgCornerMargin > 0 ? config.cardBgCornerMargin : 9.0);
    if (margin > 0) {
        bf.origin.x += margin;
        bf.size.width -= margin * 2;
    }
    button.frame = bf;
    
    // Label sizeToFit
    if (margin > 0) {
        for (UIView *sub in button.subviews) {
            if ([sub isKindOfClass:[UILabel class]]) {
                [(UILabel *)sub sizeToFit];
            }
        }
    }
}

/// 圆角 + QR 码隐藏（独立于隐藏/美化状态）
+ (void)handleCornerAndQR:(UIView *)button isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];
    
    if (config.cardBgCornerEnabled) {
        [ProfileCardBgHook applyProfileCardCorner:button isDark:isDark];
    }
    
    if (config.listHideRightQRCode) {
        [ProfileCardBgHook hideQRButtonInCell:button];
    }
}
```

### 第五步：提取通用辅助方法（减少重复代码）

将现有的一些重复代码提取为独立的辅助方法：

```objc
/// 查找 MoreViewController
+ (UIViewController *)findMoreViewController:(UIView *)button {
    UIResponder *responder = button.nextResponder;
    while (responder) {
        if ([responder isKindOfClass:[UIViewController class]]) {
            if ([NSStringFromClass([(UIViewController *)responder class]) isEqualToString:@"MoreViewController"]) {
                return (UIViewController *)responder;
            }
        }
        responder = responder.nextResponder;
    }
    return nil;
}

/// 判断暗色模式
+ (BOOL)isDarkMode:(UIViewController *)vc {
    if (@available(iOS 13.0, *)) {
        return (vc.traitCollection.userInterfaceStyle == UIUserInterfaceStyleDark);
    }
    return NO;
}

/// 清理原生 m_bgImageView
+ (void)cleanNativeBgImageView:(UIView *)button {
    Ivar bgIvar = class_getInstanceVariable([button class], "m_bgImageView");
    if (!bgIvar) return;
    id bgImgView = object_getIvar(button, bgIvar);
    if (bgImgView && [bgImgView isKindOfClass:[UIImageView class]]) {
        [(UIImageView *)bgImgView setImage:nil];
        [(UIImageView *)bgImgView setBackgroundColor:[UIColor clearColor]];
        [(UIImageView *)bgImgView setHidden:YES];
    }
    object_setIvar(button, bgIvar, nil);
}

/// 判断是否为关键子视图（FIX-WHITE 豁免）
+ (BOOL)isEssentialSubview:(UIView *)sub {
    if ([sub isKindOfClass:NSClassFromString(@"MMHeadImageView")]) return YES;
    if ([sub isKindOfClass:[UILabel class]]) return YES;
    NSString *cn = NSStringFromClass([sub class]);
    if ([cn isEqualToString:@"MMCPLabel"]) return YES;
    if ([cn isEqualToString:@"MMUILabel"]) return YES;
    if ([cn isEqualToString:@"TextStatePublishEntryButton"]) return YES;
    if ([cn isEqualToString:@"TextStateFriendTopicButton"]) return YES;
    if ([sub isKindOfClass:[UIImageView class]] && sub.tag != 0) return YES;
    return NO;
}

/// 判断是否白色/动态背景
+ (BOOL)hasWhiteOrDynamicBackground:(UIView *)sub {
    UIColor *bg = sub.backgroundColor;
    if (!bg) return NO;
    
    NSString *cn = NSStringFromClass([bg class]);
    if ([cn containsString:@"DynamicProvider"] || [cn containsString:@"UIDynamic"]) return YES;
    if ([bg isEqual:[UIColor whiteColor]]) return YES;
    
    CGFloat r=0,g=0,b=0,a=0;
    if ([bg getRed:&r green:&g blue:&b alpha:&a]) {
        if (r>0.95 && g>0.95 && b>0.95 && a>0.95) return YES;
    }
    if ([NSStringFromClass([sub class]) isEqualToString:@"UIView"] && bg) return YES;
    return NO;
}

/// QR 码隐藏（条件守卫内置）
+ (void)hideQRIfNeeded:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];
    if (config.listHideRightQRCode) {
        [ProfileCardBgHook hideQRButtonInCell:button];
    }
}
```

## 改造后的完整代码

```objc
+ (void)handleButtonLayout:(UIView *)button {
    // ══════════════════════════════════════════
    // 通用守卫（OR 聚合型总开关）
    // ══════════════════════════════════════════
    PluginConfig *config = [PluginConfig shared];
    BOOL anyFeatureEnabled = config.cardBgBeautifyEnabled
                          || config.cardBgHidden
                          || config.cardBgCornerEnabled;
    if (!anyFeatureEnabled) return;

    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;

    BOOL foundHead = NO;
    for (UIView *sub in button.subviews) {
        if ([sub isKindOfClass:NSClassFromString(@"MMHeadImageView")]) {
            foundHead = YES; break;
        }
    }
    if (!foundHead) return;

    if (button.frame.size.height <= 50.0) return;

    BOOL isDark = [ProfileCardBgHook isDarkMode:vc];
    BOOL hasMaterial = config.cardBgMaterialEnabled;

    // ══════════════════════════════════════════
    // 场景路由：隐藏 vs 可见
    // ══════════════════════════════════════════
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button hasMaterial:hasMaterial];
    } else if (hasMaterial || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button hasMaterial:hasMaterial isDark:isDark];
    }

    // ══════════════════════════════════════════
    // 独立功能
    // ══════════════════════════════════════════
    [ProfileCardBgHook handleHeightAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];
}

+ (void)handleHiddenPath:(UIView *)button hasMaterial:(BOOL)hasMaterial {
    PluginConfig *config = [PluginConfig shared];

    if (hasMaterial) {
        [ProfileCardBgHook ensureBackgroundForButton:button];
        button.backgroundColor = [UIColor clearColor];
        [ProfileCardBgHook cleanNativeBgImageView:button];
    }

    // Scene B：无素材 → 完全隐藏
    if (!hasMaterial) {
        for (UIView *sub in button.subviews) {
            sub.hidden = YES;
        }
        [ProfileCardBgHook hideQRIfNeeded:button];
        return;
    }

    // Scene A：有素材 → 隐藏内容保留背景 + FIX-WHITE
    for (UIView *sub in button.subviews) {
        if ([sub isKindOfClass:[UIImageView class]] && sub.tag == kProfileCardBgImageTag) continue;
        sub.hidden = YES;
    }

    for (NSInteger i = button.subviews.count - 1; i >= 0; i--) {
        UIView *sub = button.subviews[i];
        if (sub.tag == kProfileCardBgImageTag) continue;
        if ([ProfileCardBgHook isEssentialSubview:sub]) continue;
        if ([ProfileCardBgHook hasWhiteOrDynamicBackground:sub]) {
            sub.hidden = YES;
        }
    }

    [ProfileCardBgHook hideQRIfNeeded:button];
}

+ (void)handleVisiblePath:(UIView *)button hasMaterial:(BOOL)hasMaterial isDark:(BOOL)isDark {
    if (!hasMaterial) return;  // 无素材时保持原生，什么都不做
    
    // 有素材：加载背景
    [ProfileCardBgHook ensureBackgroundForButton:button];
    button.backgroundColor = [UIColor clearColor];
    [ProfileCardBgHook cleanNativeBgImageView:button];
}
```

## 架构对比

| 维度 | 当前（嵌套耦合） | 改造后（独立路径） |
|------|-----------------|-------------------|
| **代码结构** | 4 层嵌套：`needsNewCardBg > hasMaterial > handleCardHidden > FIX-WHITE` | 2 个平级分支：`handleHiddenPath` \|\| `handleVisiblePath` |
| **状态隔离** | `hasMaterial`、`isHidden` 穿越所有嵌套层共享 | 每个路径内部自包含，不外传 |
| **副作用** | hide 态的 `clearColor` 可能泄漏到非隐藏态 | 隐藏路径的 clearColor 绝不泄漏 |
| **FIX-WHITE** | 放在 `needsNewCardBg` 块下无条件执行，依赖隐式条件 | 内聚在 `handleHiddenPath` 的 Scene A 内，只有隐藏态执行 |
| **高度调整** | 需用 `goto DO_CORNER` 跳出 | 独立方法，无需 goto |
| **圆角** | 被 `cardBgBeautifyEnabled` 卡住，不能单独生效 | 独立方法，入口 OR 聚合守卫放行 |
| **辅助方法** | 散落在各处 | 提取为独立方法，可复用 |

## 与 WCRefine 的对应关系

| WCRefine | MioPlugin 改造后 | 说明 |
|----------|-----------------|------|
| `corner\|\|hideArrow\|\|hideButtons` OR 聚合入口 | `beautify\|\|hidden\|\|corner` OR 聚合入口 | 都是运行时由子功能计算 |
| `profileHideEnabled == YES` 路径 | `handleHiddenPath` | 完整隐藏路径 |
| `profileHideEnabled == NO` 路径 | `handleVisiblePath` | 完整美化路径（不碰原生 UI） |
| 隐藏态遍历子视图 by tag | FIX-WHITE 内聚在 Scene A | tag 豁免逻辑保留 |
| 非隐藏态不设 clearColor | `handleVisiblePath` 无素材时不设 clearColor | 保持原生 |
| `FUN_003345b0` 高度调整 | `handleHeightAdjustment` | 独立方法 |
| `FUN_00330f7c` 圆角 | `handleCornerAndQR` | 独立方法 |

## 改动收益

1. **消除副作用**：隐藏路径和美化路径完全隔离，不会互相影响
2. **消除 goto**：高度调整和圆角变为独立方法，无需 `goto DO_CORNER`
3. **消除总开关阻塞**：圆角不再依赖 `cardBgBeautifyEnabled`，用户可单独开圆角
4. **非隐藏态安全**：无素材时完全不碰 button 背景色和子视图 → 导航栏不会透明
5. **代码可读性**：每个路径清晰独立，新功能添加只需新增独立方法
6. **WCRefine 级别稳定性**：bug 不会跨功能传播，一个路径的改动不影响另一个路径
