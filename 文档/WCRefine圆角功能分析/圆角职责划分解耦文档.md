# 圆角职责划清 + 使用全局配置设计

---

## 一、设计决策：使用全局配置

### 结构

```
cardBgCornerEnabled（开启资料圆角）
└── cardBgCornerUseGlobal（使用全局配置）
    ├── ON  → 全部四项跟随列表圆角的全局配置
    └── OFF → 全部四项用自己的单独配置
```

### 全局配置 ON 时的取值来源

| 资料卡参数 | `cardBgCornerUseGlobal = YES` 时从哪读 |
|-----------|--------------------------------------|
| 圆角半径 | `listCellCornerRadius` |
| 边距大小 | `listCellMargin` |
| 背景颜色 | `listCellLightBgColor` / `listCellDarkBgColor`（根据深色模式） |
| 描边大小 | `listCellBorderWidth` |
| 描边颜色 | `listCellBorderLightColor` / `listCellBorderDarkColor`（根据深色模式） |

### 全局配置 OFF 时的取值来源

| 资料卡参数 | `cardBgCornerUseGlobal = NO` 时从哪读 |
|-----------|--------------------------------------|
| 圆角半径 | `cardBgCornerRadius` |
| 边距大小 | `cardBgCornerMargin` |
| 背景颜色（浅色） | `cardBgCornerBgColor` |
| 背景颜色（深色） | `cardBgCornerDarkBgColor` |
| 描边大小 | `cardBgStrokeWidth` |
| 描边颜色 | `cardBgCornerBgColor` 半透明（无独立的描颜色） |

## 二、Config — 新增属性

PluginConfig.h：

```objc
@property (nonatomic, assign) BOOL cardBgCornerUseGlobal;     // 默认 YES
@property (nonatomic, copy)   NSString *cardBgCornerDarkBgColor; // 深色模式背景颜色
```

PluginConfig.m — loadDefaults：

```objc
cardBgCornerUseGlobal = [dict objectForKey:@"cardBgCornerUseGlobal"] ? [[dict objectForKey:@"cardBgCornerUseGlobal"] boolValue] : YES;
cardBgCornerDarkBgColor = [dict objectForKey:@"cardBgCornerDarkBgColor"] ?: @"#1C1C1E";
```

PluginConfig.m — save：

```objc
[dict setObject:@(self.cardBgCornerUseGlobal) forKey:@"cardBgCornerUseGlobal"];
[dict setObject:self.cardBgCornerDarkBgColor forKey:@"cardBgCornerDarkBgColor"];
```

## 四、ProfileCardBgHook.m — 改动

### 改动 1：applyProfileCardCorner — 全部跟随全局配置

```objc
+ (void)applyProfileCardCorner:(UIView *)cell isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];

    if (!config.cardBgCornerEnabled) {
        cell.layer.cornerRadius = 0;
        cell.layer.masksToBounds = NO;
        cell.layer.borderWidth = 0;
        cell.layer.borderColor = nil;
        return;
    }

    if (config.cardBgCornerUseGlobal) {
        // ── 使用全局配置 ──
        NSInteger radius = (NSInteger)config.listCellCornerRadius;
        if (radius <= 0) radius = 18;
        cell.layer.cornerRadius = radius;
        cell.layer.masksToBounds = YES;

        cell.backgroundColor = [config colorFromHex:isDark
            ? config.listCellDarkBgColor : config.listCellLightBgColor];

        CGFloat bw = config.listCellBorderWidth;
        if (bw > 0) {
            cell.layer.borderWidth = bw;
            cell.layer.borderColor = [config colorFromHex:isDark
                ? config.listCellBorderDarkColor : config.listCellBorderLightColor].CGColor;
        } else {
            cell.layer.borderWidth = 0;
            cell.layer.borderColor = nil;
        }
    } else {
        // ── 使用单独配置 ──
        NSInteger radius = (NSInteger)config.cardBgCornerRadius;
        if (radius <= 0) radius = 18;
        cell.layer.cornerRadius = radius;
        cell.layer.masksToBounds = YES;

        UIColor *bgColor = [config colorFromHex:isDark
            ? config.cardBgCornerDarkBgColor : config.cardBgCornerBgColor];
        if (bgColor) {
            cell.backgroundColor = bgColor;
        }

        CGFloat bw = config.cardBgStrokeWidth;
        if (bw > 0) {
            cell.layer.borderWidth = bw;
            UIColor *strokeColor = [bgColor colorWithAlphaComponent:0.5];
            cell.layer.borderColor = strokeColor.CGColor;
        } else {
            cell.layer.borderWidth = 0;
            cell.layer.borderColor = nil;
        }
    }
}
```
