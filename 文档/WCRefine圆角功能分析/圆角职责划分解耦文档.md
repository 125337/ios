# 圆角职责划清 — 列表圆角与资料卡圆角解耦

> 列表圆角（MMTableViewCell 层）和资料卡圆角（MMUIButton 层）本就运行在不同视图层级，互不冲突。本方案只做两件事：**把 ListCornerRadiusHook 中的资料卡专属代码移走**，**让 ProfileCardBgHook 使用自己的配置项**。

---

## 一、当前架构

```
视图层级                             代码归属
┌────────────────────────┐
│ MMTableViewCell        │ ← 列表圆角 Hook（replaced_MMTableViewCell_layoutSubviews）
│  ├ 边距/背景色/圆角/边框 │   使用: listCellMargin / listCellCornerRadius / listCellBorder*
│  │                      │
│  └── MMUIButton         │ ← 资料卡 Hook（handleButtonLayout → applyProfileCardCorner）
│       ├ 圆角             │   使用: listCellCornerRadius（❌ 用错配置）
│       ├ 描边             │   使用: listProfileCardBorder*（❌ 用旧配置）
│       ├ 背景图/FIX-WHITE │
│       └ 高度调整         │   使用: listCellMargin（❌ 用错配置）
└────────────────────────┘
```

### 问题

| 位置 | 问题 |
|------|------|
| `ListCornerRadiusHook.m:301-317` | 在列表圆角中设置 MMUIButton 背景色（`listCardDarkBgColor`），这是资料卡专属逻辑 |
| `ProfileCardBgHook.m:704` | 资料卡的圆角读的是 `listCellCornerRadius`，不是自己的 `cardBgCornerRadius` |
| `ProfileCardBgHook.m:674` | 资料卡的边距读的是 `listCellMargin`，不是自己的 `cardBgCornerMargin` |
| `ProfileCardBgHook.m:66-84` | 资料卡描边读的是 `listProfileCardBorder*` 旧配置 |

### 改动 2：ProfileCardBgHook.m applyProfileCardCorner — 改用新配置

旧代码（约第 49-85 行）：

```objc
+ (void)applyProfileCardCorner:(UIView *)cell
                    cornerRadius:(NSInteger)radius
                         isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];
    cell.layer.cornerRadius = radius;         // ← 外部传入，实际来自 listCellCornerRadius
    cell.layer.masksToBounds = YES;

    if (!config.globalCornerRadiusEnabled) {   // ← 守卫逻辑混乱
        UIColor *cardBg = [config colorFromHex:isDark
            ? config.listCardDarkBgColor : config.listCardLightBgColor];  // ← 用旧配置
        ...
    }

    if (config.listProfileCardBorderEnabled) { // ← 用旧配置
        CGFloat bw = config.listProfileCardBorderWidth;
        UIColor *borderColor = [config colorFromHex:isDark
            ? config.listProfileCardBorderDarkColor
            : config.listProfileCardBorderLightColor];  // ← 用旧配置
        ...
    }
}
```

新代码：

```objc
+ (void)applyProfileCardCorner:(UIView *)cell isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];

    if (!config.cardBgCornerEnabled) {
        cell.layer.cornerRadius = 0;
        cell.layer.masksToBounds = NO;
        cell.layer.borderWidth = 0;
        cell.layer.borderColor = nil;
        return;
    }

    // ★ 圆角
    NSInteger radius = (NSInteger)config.cardBgCornerRadius;
    if (radius <= 0) radius = 18;
    cell.layer.cornerRadius = radius;
    cell.layer.masksToBounds = YES;

    // ★ 背景色
    UIColor *bgColor = [config colorFromHex:config.cardBgCornerBgColor];
    if (bgColor) {
        cell.backgroundColor = bgColor;
    }

    // ★ 描边
    CGFloat bw = config.cardBgStrokeWidth;
    if (bw > 0) {
        cell.layer.borderWidth = bw;
        UIColor *strokeColor = [bgColor colorWithAlphaComponent:0.5];
        cell.layer.borderColor = strokeColor.CGColor;
    } else {
        cell.layer.borderWidth = 0;
        cell.layer.borderColor = nil;
    }
}
```

> 如果后续需要独立描边色，在 Config 加 `cardBgStrokeColor`，UI 加一个颜色选择器即可。
