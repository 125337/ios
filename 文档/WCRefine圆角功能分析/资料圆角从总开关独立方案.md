# 资料圆角从总开关独立方案

## 现状

`handleButtonLayout:` 中（L674-L694），所有资料卡功能（素材、圆角、隐藏、边框、边距）全部被 `cardBgBeautifyEnabled` 总开关守卫拦截：

```
handleButtonLayout:
  ├─ hideStateElementsInCell           ✅ 已独立（L667）
  ├─ hideArrowQRInCell                 ✅ 已独立（L671）
  │
  ├─ if (!cardBgBeautifyEnabled) → return  ← 总开关（L674-675）
  │
  ├─ VC + 头像 + 高度检测              （L678-682）
  ├─ hidden / visible 路由              （L684-689）
  ├─ handleMarginAdjustment             （L692）
  └─ handleCornerAndQR                  （L693）
```

用户希望资料圆角（含边框、边距）能像状态隐藏、箭码隐藏一样，**不依赖总开关**独立生效。

---

## 改动方案

### 核心思路

将 VC/头像/高度检测**提前**，然后把 `handleMarginAdjustment:` 和 `handleCornerAndQR:` 移到总开关之前。这两者的内部已经有 `cardBgCornerEnabled` 守卫，不会在圆角关闭时做任何事。

### 改动：`handleButtonLayout:` 调整顺序

**文件**：[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L664-L694)

```objc
// ════════════════════════════════════════
// 改前（L663-L694）：
// ════════════════════════════════════════
+ (void)handleButtonLayout:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];

    // ☆ 独立功能：状态隐藏（不受总开关保护）
    [ProfileCardBgHook hideStateElementsInCell:button
                                   shouldHide:config.cardBgHideStateEnabled];

    // ☆ 独立功能：箭码隐藏（不受总开关保护）
    [ProfileCardBgHook hideArrowQRInCell:button
                              shouldHide:config.myPageHideArrow];

    // ★ 第1层：总开关守卫
    if (!config.cardBgBeautifyEnabled) return;

    // 通用守卫
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    if (![ProfileCardBgHook hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;
    BOOL isDark = [ProfileCardBgHook isDarkModeForVc:vc];

    // ★ 场景路由：隐藏 vs 可见
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button isDark:isDark];
    } else if (config.cardBgMaterialEnabled || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button isDark:isDark];
    }

    // 独立功能
    [ProfileCardBgHook handleMarginAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];
}

// ════════════════════════════════════════
// 改后（L663-L696）：
// ════════════════════════════════════════
+ (void)handleButtonLayout:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];

    // ☆ 独立功能：状态隐藏（不受总开关保护）
    [ProfileCardBgHook hideStateElementsInCell:button
                                   shouldHide:config.cardBgHideStateEnabled];

    // ☆ 独立功能：箭码隐藏（不受总开关保护）
    [ProfileCardBgHook hideArrowQRInCell:button
                              shouldHide:config.myPageHideArrow];

    // ☆ 通用守卫（提前到总开关之前，圆角/边距也需要）
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    if (![ProfileCardBgHook hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;
    BOOL isDark = [ProfileCardBgHook isDarkModeForVc:vc];

    // ☆ 独立功能：资料圆角 + 边框 + 边距（不受总开关保护）
    // handleMarginAdjustment 和 handleCornerAndQR 内部已有
    // cardBgCornerEnabled 守卫，圆角关闭时不会做任何事。
    [ProfileCardBgHook handleMarginAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];

    // ★ 第1层：总开关守卫（素材/隐藏/背景图等需要）
    if (!config.cardBgBeautifyEnabled) return;

    // ★ 场景路由：隐藏 vs 可见
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button isDark:isDark];
    } else if (config.cardBgMaterialEnabled || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button isDark:isDark];
    }
}
```

### 本质变化

| 项目 | 改前 | 改后 |
|------|:---:|:---:|
| VC/头像/高度检测位置 | 总开关后面 | 总开关前面 |
| `handleMarginAdjustment:` 位置 | 总开关后面 | 总开关前面 |
| `handleCornerAndQR:` 位置 | 总开关后面 | 总开关前面 |
| `handleHiddenPath:` 位置 | 总开关后面 | 总开关后面（不变） |
| `handleVisiblePath:` 位置 | 总开关后面 | 总开关后面（不变） |

### 为什么安全

两个移到总开关前面的函数**内部已有自守卫**：

**`handleCornerAndQR:`**（L761）：
```objc
if (config.cardBgCornerEnabled) {
    [ProfileCardBgHook applyProfileCardCorner:button isDark:isDark];
}
```

**`handleMarginAdjustment:`**（L702）：
```objc
if (!config.cardBgCornerEnabled) return;
```

所以总开关 OFF 时：
- `cardBgCornerEnabled = YES` → 圆角 + 边框 + 边距正常生效
- `cardBgCornerEnabled = NO` → 两个函数直接返回，无任何开销

## 附带好处

1. **用户体验提升**：用户可以先开启资料圆角体验效果，再决定是否开启卡片美化总开关
2. **逻辑分层更清晰**：圆角/边框属于"外观微调"，素材/隐藏属于"卡片美化"，前者应该可以独立使用
3. **与状态隐藏/箭码隐藏的设计理念一致**：这三个都是独立的小功能，不依赖总开关
