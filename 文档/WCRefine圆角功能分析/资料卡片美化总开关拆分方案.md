# 资料卡片美化总开关拆分改造方案

## 现状

当前「卡片背景」设置页面的 UI 结构：

```
┌─ 资料卡片美化 ──────────────────────┐
│ [资料卡片美化] cardBgBeautifyEnabled  │  ← 总开关
│  ├─ 使用背景素材 (子手风琴)            │
│  │    ├─ 列表向下间距                  │
│  │    ├─ 背景图                       │
│  │    ├─ 背景填充模式                  │
│  │    ├─ 对齐方式                     │
│  │    ├─ 背景显示层级                  │
│  │    ├─ 背景Y轴偏移                  │
│  │    └─ 背景X轴偏移                  │
│  ├─ 隐藏信息卡片 (平铺开关)            │
│  └─ 开启资料圆角 (子手风琴)            │
│       ├─ 使用全局配置                  │
│       ├─ 圆角大小                      │
│       ├─ 边距大小                      │
│       ├─ 卡片背景颜色                  │
│       └─ 描边大小                      │

└──────────────────────────────────────┘
```

三个功能全部依赖总开关 `cardBgBeautifyEnabled` 的后台守卫（L674-675），总开关 OFF 时所有功能不生效。

```objc
+ (void)handleButtonLayout:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];

    // ☆ 独立功能：状态隐藏、箭码隐藏
    [ProfileCardBgHook hideStateElementsInCell:button shouldHide:config.cardBgHideStateEnabled];
    [ProfileCardBgHook hideArrowQRInCell:button shouldHide:config.myPageHideArrow];

    // ☆ 通用守卫
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    if (![ProfileCardBgHook hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;
    BOOL isDark = [ProfileCardBgHook isDarkModeForVc:vc];

    // ☆ 资料圆角 + 边框 + 边距
    [ProfileCardBgHook handleMarginAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];

    // ★ 场景路由：隐藏 vs 可见
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button isDark:isDark];
    } else if (config.cardBgMaterialEnabled || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button isDark:isDark];
    }
}
```

**路由逻辑不变**：
- `cardBgHidden=YES` → 隐藏路径
- `cardBgMaterialEnabled=YES` 或 `cardBgCornerEnabled=YES` → 可见路径
- 都不满足 → 什么都不做（原生样式）

| # | 文件 | 行 | 用途 | 处理方式 |

| 1 | `PluginConfig.h` | 179 | 属性声明 | 删除 |
| 2 | `PluginConfig.h` | 189 | 注释（`// 不受 cardBgBeautifyEnabled 保护`） | 可选清理 |
| 3 | `PluginConfig.m` | 468 | `load:` 中读取 | 删除 |
| 4 | `PluginConfig.m` | 710 | `save` 中写入 | 删除 |

### 每条引用的删除验证

**1-4. Config 属性 + 读写（PluginConfig.h/.m）**
- 纯声明和持久化，无副作用
- 旧 key 值残留在 NSUserDefaults 中，不再读取 → 不影响任何功能

**5. `_hooked_heightForHeader`（L16）**
```
改前: if (!config.cardBgBeautifyEnabled) return result;
改后: if (!config.cardBgMaterialEnabled) return result;
```
`cardBgListSpacing`（列表向下间距）是「使用背景素材」的子功能，语义上应由 `cardBgMaterialEnabled` 守卫。
- `cardBgMaterialEnabled=YES` → 间距生效 ✅
- `cardBgMaterialEnabled=NO` → 间距不生效 ✅

**6. `handleButtonLayout:` 总开关守卫（L674-675）**

删除后，路由逻辑变为：

```
handleButtonLayout:
  ├─ hideStateElementsInCell        (独立，有内部守卫)
  ├─ hideArrowQRInCell              (独立，有内部守卫)
  ├─ VC / 头像 / 高度检测            (守卫，非资料卡则 return)
  │
  ├─ cardBgHidden=YES  → hiddenPath
  ├─ material卡ON || corner卡ON  → visiblePath
  │
  ├─ handleMarginAdjustment:        (内部有 cardBgCornerEnabled 守卫)
  └─ handleCornerAndQR:             (内部有 cardBgCornerEnabled 守卫)
```

路由条件 `cardBgMaterialEnabled || cardBgCornerEnabled` 本身已正确表达「有任意功能需处理 → 走 visiblePath」，不需要总开关。

**7-8. UI 重构（SettingCardBackgroundController.m）**
- 删除外层总开关卡片
- 两个子功能各占独立卡片
- "隐藏信息卡片"移至"我的页面美化"
- 纯 UI 布局调整，不影响逻辑

### 残留数据

- `CardBgBeautifyEnabled` key 保留在 NSUserDefaults 中不再读取

### 性能影响

唯一变化：VC / 头像 / 高度检测（L678-681）从总开关之后移到之前。

- 之前：总开关 OFF → 直接 return，不跑检测
- 之后：所有 MMUIButton 的 `layoutSubviews` 都会跑一次检测
- 检测内容：`responder chain` 查找 + `subviews` 查找 + `frame.height` 读取
- **影响可忽略**（`layoutSubviews` 不频繁、检测成本低，且此前总开关 ON 时同样跑这些检测）
