## 新增函数：shouldApplyGlobalCorner

**文件**：`ListCornerRadiusHook.m`

在 `shouldSkipCorner` 函数后面（第140行左右）新增一个函数，不要去修改原有的黑名单：

```objc
// ★★★ 新增：全局开关过滤 ★★★
// 三个受控页面的 VC 类名
static NSString * const kMyPageVCClassName        = @"MoreViewController";           // 我的页面
static NSString * const kContactsVCClassName       = @"ContactsViewController";      // 通讯录页面
static NSString * const kDiscoverVCClassName       = @"FindFriendEntryViewController"; // 发现页面

/// 根据四个全局开关判断当前页面是否应该应用圆角
/// 返回值：YES = 应该应用，NO = 跳过
/// 注意：只在 shouldSkipCorner 通过后才调用
static BOOL shouldApplyGlobalCorner(UIViewController *vc) {
    if (!vc) return NO;

    PluginConfig *config = [PluginConfig shared];

    // ==== 第一步：主开关检查 ====
    // 主开关（主页圆角）关闭 → 所有页面都不应用（由全局开关控制）
    if (!config.globalCornerRadiusEnabled) return NO;

    // ==== 第二步：识别三个受控页面 ====
    NSString *vcName = NSStringFromClass([vc class]);

    // 我的页面 → 查 myPage 开关
    if ([vcName isEqualToString:kMyPageVCClassName]) {
        return config.globalCornerMyPageEnabled;
    }
    // 通讯录页面 → 查 contacts 开关
    if ([vcName isEqualToString:kContactsVCClassName]) {
        return config.globalCornerContactsPageEnabled;
    }
    // 发现页面 → 查 discover 开关
    if ([vcName isEqualToString:kDiscoverVCClassName]) {
        return config.globalCornerDiscoverPageEnabled;
    }

    // ==== 第三步：其他页面 ====
    // 不在三个受控页面中 → 自动跟随主开关（主开关已通过，返回 YES）
    return YES;
}
```

### 判断逻辑速查

| 场景 | globalCornerRadiusEnabled | 页面类型 | 对应子开关 | 结果 |
|------|--------------------------|---------|-----------|------|
| 主开关关 | NO | 任何页面 | — | 不应用 |
| 主开关开 + 我的页面(MoreViewController) | YES | 我的 | `globalCornerMyPageEnabled` | 按该子开关 |
| 主开关开 + 通讯录页面(ContactsViewController) | YES | 通讯录 | `globalCornerContactsPageEnabled` | 按该子开关 |
| 主开关开 + 发现页面(FindFriendEntryViewController) | YES | 发现 | `globalCornerDiscoverPageEnabled` | 按该子开关 |
| 主开关开 + 其他页面 | YES | 其他 | — | **应用** |

## 修改 Hook 函数：增加一道过滤

**文件**：`ListCornerRadiusHook.m`，函数 `replaced_MMTableViewCell_layoutSubviews`

在第205行 `shouldSkipCorner(vc)` 的判断后面，增加新的判断：

```objc
// ★ 黑名单过滤（已有，不动）★
if (shouldSkipCorner(vc)) {

        ((void (*)(id, SEL))_orig_MMTableViewCell_layoutSubviews)(self, _cmd);

// ★★★ 新增：全局开关过滤 ★★★

}
```

## 新增开关与已有开关的关系

```
┌─ 列表圆角设置 ──────────────────┐
│  ☑ 圆角开关（listCornerRadiusEnabled）  ← 功能总开关
│  └─ Cell圆角半径、左右边距、边框...     ← 参数配置
└──────────────────────────────────┘

┌─ 全局圆角 ─────────────────────┐
│  ☑ 主页圆角（globalCornerRadiusEnabled） ← 页面主开关
│  ├ ☑ 我的页面(MoreViewController)        ← 排除开关
│  ├ ☑ 通讯录页面(ContactsViewController)  ← 排除开关
│  └ ☑ 发现页面(FindFriendEntryViewController) ← 排除开关
└──────────────────────────────────┘

两个开关串行工作，必须同时通过：
    listCornerRadiusEnabled = ON
    AND  shouldSkipCorner = NO（不在黑名单）
    AND  shouldApplyGlobalCorner = YES（全局开关允许）
    → 应用圆角
```
