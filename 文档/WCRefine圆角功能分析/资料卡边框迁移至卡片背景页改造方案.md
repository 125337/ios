# 资料卡边框迁移至卡片背景页改造方案

## 变更概要

将「资料卡边框」设置从圆角设置页面迁移到卡片背景页面，使其作为「开启资料圆角」的子功能。

---

## 涉及文件

| 文件 | 操作 |
|:----|:----|
| `SettingCardBackgroundController.m` | UI：新增卡片3「资料卡边框」（手风琴） |
| `SettingListCornerRadiusController.m` | UI：删除卡片5「资料卡边框」（L159-L194） |
| `ProfileCardBgHook.m` | 逻辑：`applyProfileCardCorner:` 中统一边框绘制，依赖 `cardBgCornerEnabled` |

`PluginConfig.h/.m` **无需改动**——属性已声明并持久化。

## 二、逻辑改动

### `ProfileCardBgHook.m` —— `applyProfileCardCorner:`

当前 `applyProfileCardCorner:` 中，边框绘制分散在两处：

- **全局模式（L73-L81）**：使用 `listCellBorderWidth` + `listCellBorderColor`
- **独立模式（L95-L103）**：使用 `cardBgStrokeWidth` + 从 bgColor 推导半透明色

改造后，去除这两个分支内的边框代码，统一在末尾加一段「资料卡边框」：

```objc
+ (void)applyProfileCardCorner:(UIView *)cell isDark:(BOOL)isDark {
    PluginConfig *config = [PluginConfig shared];

    if (!config.cardBgCornerEnabled) {
        cell.layer.cornerRadius = 0;
        cell.layer.masksToBounds = NO;
        cell.layer.borderWidth = 0;
        cell.layer.borderColor = nil;
        return;
    }

    if (config.cardBgCornerUseGlobal) {
        // ── 使用全局配置 ──
        NSInteger radius = (NSInteger)config.listCellCornerRadius;
        if (radius <= 0) radius = 18;
        cell.layer.cornerRadius = radius;
        cell.layer.masksToBounds = YES;

        UIColor *bgColor = isDark
            ? [config colorFromHex:config.listCellDarkBgColor]
            : [config colorFromHex:config.listCellLightBgColor];
        if (bgColor) {
            cell.backgroundColor = bgColor;
        }

        // ★ 删除原 L73-L81 的边框代码

    } else {
        // ── 使用单独配置 ──
        NSInteger radius = (NSInteger)config.cardBgCornerRadius;
        if (radius <= 0) radius = 18;
        cell.layer.cornerRadius = radius;
        cell.layer.masksToBounds = YES;

        UIColor *bgColor = [config colorFromHex:isDark
            ? config.cardBgCornerDarkBgColor : config.cardBgCornerBgColor];
        if (bgColor) {
            cell.backgroundColor = bgColor;
        }

        // ★ 删除原 L95-L103 的边框代码
    }

    // ★★★ 统一资料卡边框（依赖 cardBgCornerEnabled，此时已确认开启） ★★★
    if (config.listProfileCardBorderEnabled) {
        CGFloat bw = config.listProfileCardBorderWidth;
        if (bw > 0) {
            cell.layer.borderWidth = bw;
            UIColor *borderColor = isDark
                ? [config colorFromHex:config.listProfileCardBorderColorDarkHex]
                : [config colorFromHex:config.listProfileCardBorderColor];
            cell.layer.borderColor = borderColor.CGColor;
        } else {
            cell.layer.borderWidth = 0;
            cell.layer.borderColor = nil;
        }
    } else {
        cell.layer.borderWidth = 0;
        cell.layer.borderColor = nil;
    }
}
```

## 三、功能逻辑说明

### 依赖关系

```
cardBgCornerEnabled == YES
    ├── 圆角 + 背景色 + 边距（按全局/独立模式）
    └── listProfileCardBorderEnabled == YES
            └── 应用边框宽度 + 颜色
```

- `cardBgCornerEnabled == NO` → 函数顶部直接 return，边框、圆角、颜色全部清除
- `cardBgCornerEnabled == YES` → 正常设置圆角 + 背景色
- 边框单独由 `listProfileCardBorderEnabled` 控制：ON 时应用，OFF 时不应用

### 与旧逻辑的差异

| 场景 | 改造前 | 改造后 |
|:----|:------|:------|
| 全局模式 + listProfileCardBorderEnabled=OFF | 使用 `listCellBorderWidth` 边框 | **无边框** |
| 全局模式 + listProfileCardBorderEnabled=ON | 使用 `listCellBorderWidth` 边框 | **使用 `listProfileCardBorderWidth` 边框** |
| 独立模式 + listProfileCardBorderEnabled=OFF | 使用 `cardBgStrokeWidth` 半透明边框 | **无边框** |
| 独立模式 + listProfileCardBorderEnabled=ON | 使用 `cardBgStrokeWidth` 半透明边框 | **使用 `listProfileCardBorderWidth` 边框** |
