# 删除圆角设置中的「卡片背景色」清理方案

## 背景

圆角设置页面有一个「卡片背景色」(`listCardBgColor` / `listCardBgColorDarkHex`)，卡片背景设置页面也有一个「资料卡片圆角→背景颜色」(`cardBgCornerBgColor` / `cardBgCornerDarkBgColor`)。两者功能重叠，且圆角设置中的卡片背景色会与卡片背景中的颜色冲突，导致用户设置的背景色不生效。

**决定**：删除圆角设置中的「卡片背景色」，将唯一的功能入口保留在「卡片背景」设置页面。

---

## 冲突根因

两者都被用于设置资料卡的背景色，但作用在不同路径：

| 属性 | 设置页面 | 使用位置 | 作用时机 |
|------|---------|---------|---------|
| `listCardBgColor` | 圆角设置 | `setupBackgroundMaterialInButton:` fallback（L593） | 有素材但图片加载失败时的备用色 |
| `cardBgCornerBgColor` | 卡片背景 | `applyProfileCardCorner:`（L90）+ `handleVisiblePath:`（L877） | 开启资料圆角时主动设色 |

当用户同时开启两者的背景色，`listCardBgColor` 会覆盖 `cardBgCornerBgColor` 的效果。

### 改动 2：ProfileCardBgHook.m — 替换 fallback 颜色来源

**文件**：[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m)

改 L590-L594。当背景素材图片加载失败时，原先 fallback 使用 `listCardBgColor`，改为使用 `cardBgCornerBgColor`：

```objc
// 改前（L590-L594）：
            } else {
                // fallback：无图片时设置背景色
                PluginConfig *cfg = [PluginConfig shared];
                BOOL isDark = [cfg isDarkMode];
                UIColor *cardBg = [cfg colorFromHex:isDark ? cfg.listCardBgColorDarkHex : cfg.listCardBgColor];
                if (cardBg) strongButton.backgroundColor = cardBg;
            }

// 改后：
            } else {
                // fallback：无图片时设置背景色（复用卡片圆角背景色）
                PluginConfig *cfg = [PluginConfig shared];
                UIColor *cardBg = [cfg colorFromHex:cfg.cardBgCornerBgColor];
                if (cardBg) strongButton.backgroundColor = cardBg;
            }
```

> 说明：fallback 只取浅色模式色，因为深色模式场景下图片失败的逻辑与浅色相同。
