# 对齐方式深浅合并改造文档

## 现状

目前有2个对齐属性，区分浅色/深色模式：

```objc
@property (nonatomic, assign) NSInteger cardBgLightAlignment;  // 浅色模式对齐
@property (nonatomic, assign) NSInteger cardBgDarkAlignment;   // 深色模式对齐
```

在 `handleButtonLayout:` 中根据当前模式二选一：

```objc
// 第453行
NSInteger alignment = isDark ? config.cardBgDarkAlignment : config.cardBgLightAlignment;

// 第521-522行（异步加载回调）
NSInteger alignment = capturedIsDark ? cfg.cardBgDarkAlignment : cfg.cardBgLightAlignment;
```

**额外发现**：这两个属性在 `PluginConfig.m` 的 `loadDefaults` 和 `save` 中**完全没有持久化代码**。用户设置的对齐方式不会保存到 NSUserDefaults，每次 App 重启都会回到默认值0（底部对齐）。合并正好修复这个问题。

**问题**：跟层级/偏移的理由一样——对齐方式表示"背景图在卡片中靠上/居中/靠下"，用户不会根据深浅模式分别设置。合并后统一处理，顺便补上持久化。

## 一、改动清单

### 1.1 属性定义

**PluginConfig.h**（第 201-202 行）— 替换为单个属性：

```objc
// 改前：
@property (nonatomic, assign) NSInteger cardBgLightAlignment;
@property (nonatomic, assign) NSInteger cardBgDarkAlignment;

// 改后：
@property (nonatomic, assign) NSInteger cardBgAlignment;
```

### 1.2 读写逻辑（补上持久化）

**PluginConfig.m — loadDefaults**（在 `_cardBgFillMode` 之后，第509行后追加）：

```objc
_cardBgAlignment = [d integerForKey:[kPluginPrefix stringByAppendingString:@"CardBgAlignment"]];
```

**PluginConfig.m — save**（在 `_cardBgFillMode` 之后，第740行后追加）：

```objc
[d setInteger:_cardBgAlignment forKey:[kPluginPrefix stringByAppendingString:@"CardBgAlignment"]];
```

### 1.3 Hook 代码

**ProfileCardBgHook.m — handleButtonLayout:**（第 453 行）：

```objc
// 改前：
NSInteger alignment = isDark ? config.cardBgDarkAlignment : config.cardBgLightAlignment;

// 改后：
NSInteger alignment = config.cardBgAlignment;
```

**ProfileCardBgHook.m — 异步加载回调**（第 521-522 行）：

```objc
// 改前：
NSInteger alignment = capturedIsDark ? cfg.cardBgDarkAlignment
                                     : cfg.cardBgLightAlignment;

// 改后：
NSInteger alignment = cfg.cardBgAlignment;
```

### 1.4 UI — 替换新 UI 中的"深色模式对齐方式"

旧 UI 中的"浅色模式对齐方式"（`onLightAlignmentTap`，tag 205）和"深色模式对齐方式"（`onDarkAlignmentTap`，tag 206）会随[旧 UI 删除方案](file:///www/wwwroot/ios/文档/WCRefine圆角功能分析/卡片背景页面新旧UI清理改造文档.md)一并清理。

新 UI 中当前只有"深色模式对齐方式"行（第 104-112 行），替换为"对齐方式"单行：

```objc
// 改前：
NSArray *alignNames = @[@"底部对齐", @"居中对齐", @"顶部对齐"];
NSString *alignSub = (cfg.cardBgDarkAlignment >= 0 && cfg.cardBgDarkAlignment < (NSInteger)alignNames.count)
    ? alignNames[cfg.cardBgDarkAlignment] : @"底部对齐";
*e2y = [self addNavRowInGroup:e2
                        title:@"深色模式对齐方式"
                      subtitle:alignSub
                          tag:206
                       action:@selector(onDarkAlignmentTap)
                           cy:*e2y width:w];

// 改后：
NSArray *alignNames = @[@"底部对齐", @"居中对齐", @"顶部对齐"];
NSString *alignSub = (cfg.cardBgAlignment >= 0 && cfg.cardBgAlignment < (NSInteger)alignNames.count)
    ? alignNames[cfg.cardBgAlignment] : @"底部对齐";
*e2y = [self addNavRowInGroup:e2
                        title:@"对齐方式"
                      subtitle:alignSub
                          tag:???   // 新 tag，不与旧 UI 冲突即可
                       action:@selector(onAlignmentTap)
                           cy:*e2y width:w];
```

### 1.5 UI action 方法

将 `onDarkAlignmentTap` 改为 `onAlignmentTap`（逻辑改为读写 `cardBgAlignment`）：

```objc
// 改后：
- (void)onAlignmentTap {
    PluginConfig *config = [PluginConfig shared];
    NSArray *alignNames = @[@"底部对齐", @"居中对齐", @"顶部对齐"];

    UIAlertController *alert = [UIAlertController alertControllerWithTitle:@"对齐方式"
                                                                   message:nil
                                                            preferredStyle:UIAlertControllerStyleActionSheet];

    for (NSInteger i = 0; i < (NSInteger)alignNames.count; i++) {
        NSString *title = alignNames[i];
        if (i == config.cardBgAlignment) {
            title = [NSString stringWithFormat:@"✓ %@", title];
        }
        [alert addAction:[UIAlertAction actionWithTitle:title
                                                 style:UIAlertActionStyleDefault
                                               handler:^(UIAlertAction *action) {
            config.cardBgAlignment = i;
            [config save];
            [self buildUI];
        }]];
    }

    [alert addAction:[UIAlertAction actionWithTitle:@"取消" style:UIAlertActionStyleCancel handler:nil]];

    if (@available(iOS 13.0, *)) {
        alert.popoverPresentationController.sourceView = self.view;
        alert.popoverPresentationController.sourceRect = CGRectMake(
            self.view.bounds.size.width / 2, self.view.bounds.size.height / 2, 1, 1);
    }
    [self presentViewController:alert animated:YES completion:nil];
}
```

旧 UI 的 `onLightAlignmentTap` 方法可一并删除。

## 四、合并前后对比

| | 改前 | 改后 |
|--|------|------|
| 属性数 | 2个（light + dark） | 1个 |
| 持久化 | ❌ 从未保存到 NSUserDefaults | ✅ 已持久化 |
| UI 入口 | 旧 UI 2行 + 新 UI 1行（dark only） | 新 UI 1行「对齐方式」 |
| Hook 代码 | `isDark ? dark : light` 三元 x2 | 直接读取 `cardBgAlignment` |
| 用户心智负担 | 需配置2次（实际上只有深色生效） | 配置1次即可 |
