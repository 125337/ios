# 最终架构：总开关 + 各功能独立守卫

审查日期：2026-06-06
决策：`cardBgBeautifyEnabled` 是唯一总开关，关闭时所有逻辑不生效。

---

## 一、架构总纲

### 1.1 双层守卫原则

```
第1层 → 总开关守卫: if (!cardBgBeautifyEnabled) return; ← 关闭则全部不执行

第2层 → 功能级守卫: 每个功能检查自己的开关/配置 ← 决定该功能是否实际执行
```

**关键规则**：第2层守卫确保总开关 ON 但子功能全 OFF 时，不产生任何可见效果。

### 1.2 最终入口代码

```objc
+ (void)handleButtonLayout:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];

    // ══════════════════════════════════════════
    // ★ 第1层：总开关守卫
    // ★ cardBgBeautifyEnabled 关闭时，全部不生效
    // ══════════════════════════════════════════
    if (!config.cardBgBeautifyEnabled) return;

    // ══════════════════════════════════════════
    // 通用安全检查（与具体功能无关）
    // ══════════════════════════════════════════
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    if (![ProfileCardBgHook hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;
    BOOL isDark = [ProfileCardBgHook isDarkModeForVc:vc];

    // ══════════════════════════════════════════
    // ★ 第2层：功能级守卫（每个功能各自检查开关）
    // ══════════════════════════════════════════

    // ── 场景路由（隐藏 vs 美化） ──
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button isDark:isDark];
    } else if (config.cardBgMaterialEnabled || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button isDark:isDark];
    }

    // ── 高度调整（独立功能） ──
    if (config.cardBgHeight > 0) {
        [ProfileCardBgHook handleHeightAdjustment:button];
    }

    // ── 边距 + 圆角 + QR（统一归圆角管控） ──
    if (config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleMarginAdjustment:button];
    }

    // handleCornerAndQR 内部已有 cornerEnabled + listHideRightQRCode 守卫
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];
}
```

### 1.3 各功能的守卫一览

| 功能 | 方法 | 第2层守卫 | 守卫位置 |
|------|------|----------|---------|
| 隐藏路径 | `handleHiddenPath:` | `config.cardBgHidden` | 入口场景路由 |
| 美化路径（背景素材） | `handleVisiblePath:` | `config.cardBgMaterialEnabled \|\| config.cardBgCornerEnabled` | 入口场景路由 |
| 高度调整 | `handleHeightAdjustment:` | `config.cardBgHeight > 0` | 入口显式判断 |
| 边距调整 | `handleMarginAdjustment:` | `config.cardBgCornerEnabled` | 入口显式判断 |
| 圆角 | `handleCornerAndQR:` → `applyProfileCardCorner:` | `config.cardBgCornerEnabled` | 方法内部 |
| QR 码隐藏 | `handleCornerAndQR:` → `hideQRButtonInCell:` | `config.listHideRightQRCode` | 方法内部 |

## 二、行为矩阵

### 2.1 所有开关组合的预期行为

| # | beautify | hidden | material | corner | height | 实际执行的功能 | 可见效果 |
|---|----------|--------|----------|--------|-------|--------------|---------|
| 1 | **OFF** | ON | ON | ON | >0 | **全部不执行**（总开关拦截） | 无变化 |
| 2 | **OFF** | OFF | OFF | OFF | 0 | **全部不执行**（总开关拦截） | 无变化 |
| 3 | **ON** | OFF | OFF | OFF | 0 | **什么都不做**（第2层全部跳过） | 无变化 ✅ |
| 4 | **ON** | OFF | OFF | OFF | >0 | 仅高度调整 | 资料卡变高 ✅ |
| 5 | **ON** | OFF | ON | OFF | 0 | visiblePath(素材) | 背景图 ✅ |
| 6 | **ON** | OFF | OFF | ON | 0 | marginAdjustment + cornerAndQR | 圆角+边距 ✅ |
| 7 | **ON** | ON | OFF | OFF | 0 | hiddenPath | 卡片隐藏 ✅ |
| 8 | **ON** | ON | ON | ON | >0 | hiddenPath + height + margin + corner | 背景图+隐藏+圆角+边距+高度 ✅ |

**场景 3 是本次修复的核心**——只开 beautify 总开关，什么都不发生。

### 2.2 与旧架构的关键差异

| 场景 | 旧架构（OR守卫） | 最终架构（总开关+独立守卫） | 差异 |
|------|----------------|--------------------------|------|
| beautify=ON, 全OFF | height+margin 意外执行 ✅可见效果 | 第2层全跳过，**无效果** | ✅ **修复** |
| beautify=OFF, corner=ON | 被 OR 中的 beautify=OFF 拦截 | 被总开关 beautify=OFF 拦截 | 行为一致 |
| beautify=ON, corner=ON, height>0 | 全部生效 | 全部生效 | 一致 |
| beautify=ON, corner=ON, height=0 | 全部生效 | margin+corner 生效，height 跳过 | 一致 |

## 三、改动清单

### 改动 1：`handleButtonLayout` 入口 — 第2层守卫

**文件**：[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L588-L614)

**当前代码**：

```objc
+ (void)handleButtonLayout:(UIView *)button {
    // ★ 入口守卫：OR 聚合
    PluginConfig *config = [PluginConfig shared];
    BOOL anyFeatureEnabled = config.cardBgBeautifyEnabled
                          || config.cardBgHidden
                          || config.cardBgCornerEnabled;
    if (!anyFeatureEnabled) return;

    ...

    // 独立功能

    [ProfileCardBgHook handleMarginAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];

```

**改为**：

```objc
+ (void)handleButtonLayout:(UIView *)button {
    PluginConfig *config = [PluginConfig shared];

    // ★ 第1层：总开关守卫（唯一入口守卫）
    if (!config.cardBgBeautifyEnabled) return;

    // 通用安全检查
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    if (![ProfileCardBgHook hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;
    BOOL isDark = [ProfileCardBgHook isDarkModeForVc:vc];

    // ★ 场景路由
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button isDark:isDark];
    } else if (config.cardBgMaterialEnabled || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button isDark:isDark];
    }

    // ★ 第2层：独立功能各自的守卫
    if (config.cardBgHeight > 0) {
        [ProfileCardBgHook handleHeightAdjustment:button];
    }

    if (config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleMarginAdjustment:button];
    }

    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];
}
```

### 改动 2：`handleMarginAdjustment` — 删除硬编码默认值 9.0

**文件**：[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L657-L659)

**改前**：

```objc
CGFloat margin = config.cardBgCornerUseGlobal
    ? config.listCellMargin
```

## 六、与之前方案的关系

### 6.1 为什么最终方案保留了总开关，而不是彻底消除

| 方案 | 思路 | 问题 |
|------|------|------|
| OR 聚合入口 | `beautify \|\| hidden \|\| corner`，放行后全部执行 | 开了 beautify 触发 height+margin |
| 自我守卫（无入口守卫） | 每个功能自己检查，入口只做安全检查 | 子功能可在总开关 OFF 时生效 |
| **最终方案（本方案）** | 总开关 + 各功能独立守卫 | **总开关 OFF 时全部不生效，ON 时各功能独立决策** ✅ |

最终方案兼顾了「总开关的控制力」和「各功能的独立性」。

### 6.2 对本方案落地的影响

对 `独立路径重构方案.md` 的影响：

| 之前 Step 7 的内容 | 最终方案 | 需要改 |
|-------------------|---------|--------|
| OR 聚合入口 | 改为 `!beautify` 单开关入口 | ✅ 更新代码 |
| 独立功能不加守卫 | 高度+边距分别加第2层守卫 | ✅ 更新代码 |
| 场景验证表 | 需要更新行为描述 | ✅ 更新 |
