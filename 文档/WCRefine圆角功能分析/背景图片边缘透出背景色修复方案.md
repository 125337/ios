# 背景图片加载成功后背景色多出边缘问题修复方案

## 问题描述

同时开启「使用背景素材（有图片）」+「开启资料圆角」+ 设置「卡片背景颜色」时：
- 图片作为背景显示在卡片上
- 设置的颜色也在 button 上作为 backgroundColor
- 图片边缘（尤其是圆角处）会露出一条细边，看起来像多余的边框

```
┌── MMUIButton ─────────────────────────────┐
│                                            │
│  ░░░░░░ button.backgroundColor ░░░░░░░░    │  ← 用户设置的颜色
│  ┌──── UIImageView (图片) ──────────┐      │
│  │  ██████████████████████████████  │      │
│  │  ██████████████████████████████  │      │
│  │  ██████████████████████████████  │ ╳ ← │  ★ 图片边缘透出背景色
│  │  ██████████████████████████████  │      │
│  └──────────────────────────────────┘      │
│                                            │
└────────────────────────────────────────────┘
```

---

## 根因分析

### 图片创建与位置

`createBackgroundImageViewInButton:`（L516-L527）和 `configureBackgroundImageView:`（L532-L565）中：

```objc
UIImageView *newBg = [[UIImageView alloc] init];
newBg.frame = CGRectMake(config.cardBgOffsetX, config.cardBgOffsetY,
                         button.bounds.size.width,
                         button.bounds.size.height);
```

- frame 受 `cardBgOffsetX` / `cardBgOffsetY` 影响（可偏移）
- contentMode = `ScaleAspectFill`（缩放填充，但可能溢出）
- `clipsToBounds = NO`（图片内容可渲染到 frame 外）

### 颜色设置时序

```
handleButtonLayout:
  ├─ handleVisiblePath: Phase 1 Cleanup → clearColor（临时）
  ├─ handleVisiblePath: Phase 2 Material → setupBackgroundMaterialInButton:（异步）
  └─ handleCornerAndQR → applyProfileCardCorner:
       └─ cell.backgroundColor = 用户颜色（全局模式或独立模式色）  ★ 设色

         ... 时间流逝 ...

       异步回调 loadImageAsyncForImageView: 成功
         ├─ imageView.image = resultImage          ★ 图片加载完成
         ├─ configureBackgroundImageView: (frame)
         └─ button.backgroundColor 没有变化          ★ 仍是之前的用户颜色
```

图片加载成功后，button 的 `backgroundColor` **仍是用户设置的颜色**。图片 UIImageView 是 button 的子视图，虽然图片本身覆盖了按钮区域，但在以下情形下 button 的背景色会从边缘透出：

1. **`cardBgOffsetX / cardBgOffsetY ≠ 0`** — imageView 起始位置偏移，偏移侧的区域由 button.backgroundColor 填充
2. **`ScaleAspectFill` 渲染** — 图片缩放后实际渲染尺寸可能与 imageView.frame 不完全对齐（亚像素偏差）
3. **圆角 `masksToBounds = YES`** — cornerRadius 裁剪后，边缘抗锯齿处理可能让图片与背景色混合

## 修复方案

### 改动 1：图片加载成功后清除 button 背景色

**文件**：[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L581-L588)

```objc
// 改前（L581-L588）：
            if (resultImage) {
                strongBg.image = resultImage;
                strongBg.alpha = 1.0;
                strongBg.hidden = NO;

                // ★ 统一配置：此时 image 已存在，偏移能正确计算
                [ProfileCardBgHook configureBackgroundImageView:strongBg
                                                      inButton:strongButton];
            }

// 改后（L581-L591）：
            if (resultImage) {
                strongBg.image = resultImage;
                strongBg.alpha = 1.0;
                strongBg.hidden = NO;

                // ★ 清除 button 背景色，防止从图片边缘透出
                strongButton.backgroundColor = [UIColor clearColor];
                strongButton.layer.backgroundColor = [UIColor clearColor].CGColor;

                // ★ 统一配置：此时 image 已存在，偏移能正确计算
                [ProfileCardBgHook configureBackgroundImageView:strongBg
                                                      inButton:strongButton];
            }
```

### 全路径验证

| 时序 | 操作 | backgroundColor |
|:---:|------|:--------------:|
| 🕐 | `handleVisiblePath:` Phase 1 Cleanup | `clearColor` |
| 🕑 | `handleCornerAndQR:` → `applyProfileCardCorner:` | 用户颜色 |
| 🕒 | 异步：图片加载成功（本改动） | `clearColor` ✅ |
| 🕓 | 后续 layoutSubviews 再次触发 | 重新设为用户颜色（然后 🕒 再次异步改回 clearColor） |

> 🕓 不是问题：layoutSubviews 触发后 `loadImageAsyncForImageView:` 会重新异步加载图片，加载完再次清为 clearColor。

### 改动 2（可选）：创建 imageView 时同时清 button 背景

为了在**图片加载前**（过渡期）也不透出背景色，可以在 `createBackgroundImageViewInButton:` 中提前清色：

```objc
// L516-L527 中新增：
UIImageView *newBg = [[UIImageView alloc] init];
newBg.tag = kProfileCardBgImageTag;
...
[button insertSubview:newBg atIndex:0];

// ★ 创建 imageView 时同步清除 button 背景色
button.backgroundColor = [UIColor clearColor];
button.layer.backgroundColor = [UIColor clearColor].CGColor;
```

这样可以消除从 🕑 到 🕒 之间的过渡期可能出现的短暂边缘透出。

## 测试要点

| 场景 | 操作 | 预期 |
|:----|------|------|
| 1 | 素材(有图) + 圆角 + 设背景色 | 图片显示，边缘无背景色透出 |
| 2 | 素材(有图) + 圆角 + 设背景色 + 偏移量非零 | 图片按偏移显示，偏移侧无背景色透出 |
| 3 | 素材(无图) + 圆角 + 设背景色 | 圆角背景色正常（fallback） |
| 4 | 只开圆角 + 设背景色 | 圆角背景色正常 |
| 5 | 渐变背景 | 渐变图片正常显示，无边缘透出 |
