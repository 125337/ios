# 仅开启资料圆角时白色背景遮挡问题 — 深度修复方案

## 问题描述

- 开启「总开关」+「开启资料圆角」+ 设置「资料卡片圆角→背景颜色」
- **不开启**「使用背景素材」
- **不开启**「隐藏信息卡片」
- 结果：资料卡仍然显示白色，设置的背景色无法透出

只有当同时开启「隐藏信息卡片」时，背景色才正常显示，但这时卡片所有内容（头像、昵称等）都被隐藏了。

用户想要的：**不隐藏卡片内容，只显示自定义背景色**。

---

### 关键缺失

对比有素材路径的完整处理和当前无素材路径的处理：

| 操作 | 有素材路径 (L824-856) | 无素材路径-当前 (L857-883) |
|------|:-------------------:|:------------------------:|
| 清理 button.backgroundColor | ✅ | ✅ |

| **FIX-WHITE：遍历 subviews 隐藏白色子视图 (L847-L856)** | ✅ | **❌ 缺失** |
| 应用背景色 | ✅ | ✅ |

### 为什么只清理 `m_bgImageView` 不够？

`m_bgImageView` 是微信原生最大的白色背景视图，但 MMUIButton 下还有其他原生白色子视图。`isWhiteOrDynamicBackground:` 方法（L466-L478）检测这些子视图：

```objc
+ (BOOL)isWhiteOrDynamicBackground:(UIView *)sub {
    // 1. 动态颜色（深色模式白光）
    if ([cn containsString:@"DynamicProvider"]) return YES;
    // 2. 白色
    if ([bg isEqual:[UIColor whiteColor]]) return YES;
    // 3. RGB > 0.95（极亮色）
    if (r>0.95 && g>0.95 && b>0.95 && a>0.95) return YES;
    // 4. 无类型的 UIView（原生占位/容器）
    if ([NSStringFromClass([sub class]) isEqualToString:@"UIView"] && bg) return YES;
    return NO;
}
```

这些白色子视图**不是** `m_bgImageView`，它们是额外的 UIView、分隔线、占位容器等。有素材路径通过 FIX-WHITE 隐藏了它们，但无素材路径没有。

## 修复方案

### 改动 1：`handleVisiblePath:` 的 else 分支 — 加入 FIX-WHITE

**文件**：[ProfileCardBgHook.m](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L857-L883)

```objc
// 改前（L857-L883）：
    } else {
        // ══════════════════════════════════════════
        // 无素材 + 有圆角：清理按钮背景 + 原生白色 m_bgImageView，应用背景色
        // ══════════════════════════════════════════
        if (config.cardBgCornerEnabled) {
            // 清理按钮背景
            button.backgroundColor = [UIColor clearColor];
            button.layer.backgroundColor = [UIColor clearColor].CGColor;

            // 清理原生白色 m_bgImageView
            [ProfileCardBgHook cleanNativeBgImageView:button];

            // 应用背景色
            UIColor *bgColor = nil;
            if (config.cardBgCornerUseGlobal) {
                bgColor = isDark
                    ? [config colorFromHex:config.listCellDarkBgColor]
                    : [config colorFromHex:config.listCellLightBgColor];
            } else {
                bgColor = [config colorFromHex:isDark
                    ? config.cardBgCornerDarkBgColor : config.cardBgCornerBgColor];
            }
            if (bgColor) {
                button.backgroundColor = bgColor;
            }
        }
    }

// 改后（L857-L896）：
    } else {
        // ══════════════════════════════════════════
        // 无素材 + 有圆角：清理按钮背景 + 原生白色 m_bgImageView + 白色子视图，应用背景色
        // ══════════════════════════════════════════
        if (config.cardBgCornerEnabled) {
            // 清理按钮背景
            button.backgroundColor = [UIColor clearColor];
            button.layer.backgroundColor = [UIColor clearColor].CGColor;

            // 清理原生白色 m_bgImageView
            [ProfileCardBgHook cleanNativeBgImageView:button];

            // ★★★ FIX-WHITE：隐藏 button 下的白色原生子视图 ★★★
            for (NSInteger i = button.subviews.count - 1; i >= 0; i--) {
                UIView *sub = button.subviews[i];
                if ([ProfileCardBgHook isEssentialSubview:sub]) continue;
                if ([ProfileCardBgHook isWhiteOrDynamicBackground:sub]) {
                    sub.hidden = YES;
                }
            }

            // 应用背景色
            UIColor *bgColor = nil;
            if (config.cardBgCornerUseGlobal) {
                bgColor = isDark
                    ? [config colorFromHex:config.listCellDarkBgColor]
                    : [config colorFromHex:config.listCellLightBgColor];
            } else {
                bgColor = [config colorFromHex:isDark
                    ? config.cardBgCornerDarkBgColor : config.cardBgCornerBgColor];
            }
            if (bgColor) {
                button.backgroundColor = bgColor;
            }
        }
    }
```

> **注意**：与有素材路径的 FIX-WHITE 相比（L848），这里 **没有** `if (sub.tag == kProfileCardBgImageTag) continue;` 的跳过条件，因为无素材路径不会创建自定义背景图（`setupBackgroundMaterialInButton:` 不会被调用），所以不存在 `kProfileCardBgImageTag` 的视图，不需要跳过。

## 涉及的子视图类型总结

### Essential（保留，不隐藏）

| 类名 | 说明 |
|------|------|
| `MMHeadImageView` | 头像 |
| `UILabel` | 昵称、微信号等文字 |
| `MMCPLabel`, `MMUILabel` | 微信自定义 Label |
| `TextStatePublishEntryButton` | 状态发布按钮 |
| `TextStateFriendTopicButton` | 好友话题按钮 |
| `UIImageView` 且 tag != 0 | 二维码、图标等（tag 标识的有用图片） |

### White（被隐藏）

| 类型/条件 | 说明 |
|-----------|------|
| backgroundColor 含 `DynamicProvider` | 深色模式动态白 |
| backgroundColor == whiteColor | 纯白色 |
| backgroundColor RGB 均 > 0.95 | 极浅色 |
| 类名为 `UIView` 且有 backgroundColor | 原生占位容器/分隔线 |
