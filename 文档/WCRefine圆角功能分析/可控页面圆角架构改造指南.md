# 可控页面圆角边距系统 — 架构改造指南

## 概述

本文档从 WCRefine 全局圆角功能中提炼出一套 **通用的可控页面圆角边距架构**，指导你如何独立实现一个支持"按页面控制圆角边距"的 Hook 插件。

核心思想：**主开关控制 Hook 注册，页面开关控制运行时行为，页面识别决定在哪生效**。

---

## 二、Config 层设计

### 2.1 采用字典存储 + 单例模式（WCRefine 模式）

WCRefine 使用 `NSUserDefaults + objectForKey:` 的方式，而不是用属性（ivar）。优点是配置可以自动持久化，且适合动态扩展。

```objc
// YourCornerConfig.h
typedef NS_ENUM(NSInteger, YourPageType) {
    YourPageTypeHomepage,      // 主页
    YourPageTypeProfile,       // 个人页
    YourPageTypeContacts,      // 通讯录
    YourPageTypeDiscover,      // 发现
    YourPageTypeCount
};

@interface YourCornerConfig : NSObject

+ (instancetype)shared;

// 主开关
@property (nonatomic, assign, getter=isMasterCornerEnabled) BOOL masterCornerEnabled;

// 页面级开关 - 按枚举访问
- (BOOL)isCornerEnabledForPage:(YourPageType)page;
- (void)setCornerEnabled:(BOOL)enabled forPage:(YourPageType)page;

// 全局参数
@property (nonatomic, assign) CGFloat globalCornerRadius;
@property (nonatomic, assign) CGFloat globalCornerMargin;

// 便捷方法：某页面是否应应用圆角（主开关 && 页面开关）
- (BOOL)shouldApplyCornerForPage:(YourPageType)page;

@end
```

### 2.2 实现核心

```objc
// YourCornerConfig.m
#define kMasterCornerEnabled  @"masterCornerEnabled"
#define kGlobalCornerRadius   @"globalCornerRadius"
#define kGlobalCornerMargin   @"globalCornerMargin"

// 页面开关的 key 映射表
static NSString * const kPageEnabledKeys[] = {
    [YourPageTypeHomepage]  = @"homepageCornerEnabled",
    [YourPageTypeProfile]   = @"profileCornerEnabled",
    [YourPageTypeContacts]  = @"contactsCornerEnabled",
    [YourPageTypeDiscover]  = @"discoverCornerEnabled",
};

@implementation YourCornerConfig

+ (instancetype)shared {
    static id instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[self alloc] init];
    });
    return instance;
}

// 主开关 getter - WCRefine 风格
- (BOOL)isMasterCornerEnabled {
    // 直接从 NSUserDefaults 读取，懒初始化默认值
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:kMasterCornerEnabled];
    if (value == nil) {
        // 默认关闭
        [[NSUserDefaults standardUserDefaults] setObject:@NO forKey:kMasterCornerEnabled];
        return NO;
    }
    return [value boolValue];
}

- (void)setMasterCornerEnabled:(BOOL)enabled {
    [[NSUserDefaults standardUserDefaults] setObject:@(enabled) forKey:kMasterCornerEnabled];
    // 主开关打开时，自动同步打开所有页面开关（可选）
    if (enabled) {
        for (NSInteger i = 0; i < YourPageTypeCount; i++) {
            if (![self isCornerEnabledForPage:(YourPageType)i]) {
                [self setCornerEnabled:YES forPage:(YourPageType)i];
            }
        }
    }
}

// 页面开关 getter - WCRefine 风格
- (BOOL)isCornerEnabledForPage:(YourPageType)page {
    NSString *key = kPageEnabledKeys[page];
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:key];
    if (value == nil) {
        // 默认关闭
        [[NSUserDefaults standardUserDefaults] setObject:@NO forKey:key];
        return NO;
    }
    return [value boolValue];
}

- (void)setCornerEnabled:(BOOL)enabled forPage:(YourPageType)page {
    NSString *key = kPageEnabledKeys[page];
    [[NSUserDefaults standardUserDefaults] setObject:@(enabled) forKey:key];
}

// 圆角半径 - 带边界限制
- (CGFloat)globalCornerRadius {
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:kGlobalCornerRadius];
    if (value == nil) {
        return 15.0; // 默认值
    }
    CGFloat radius = [value doubleValue];
    if (radius <= 0) return 15.0;
    if (radius > 40) return 40.0;
    return radius;
}

- (void)setGlobalCornerRadius:(CGFloat)radius {
    if (radius <= 0) radius = 15.0;
    if (radius > 40) radius = 40.0;
    [[NSUserDefaults standardUserDefaults] setObject:@(radius) forKey:kGlobalCornerRadius];
}

// 圆角边距 - 带边界限制
- (CGFloat)globalCornerMargin {
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:kGlobalCornerMargin];
    if (value == nil) {
        return 8.0; // 默认值
    }
    CGFloat margin = [value doubleValue];
    if (margin <= 0) return 8.0;
    if (margin > 100) return 100.0;
    return margin;
}

- (void)setGlobalCornerMargin:(CGFloat)margin {
    if (margin <= 0) margin = 8.0;
    if (margin > 100) margin = 100.0;
    [[NSUserDefaults standardUserDefaults] setObject:@(margin) forKey:kGlobalCornerMargin];
}

// 便捷方法：检查是否应该应用圆角
- (BOOL)shouldApplyCornerForPage:(YourPageType)page {
    return [self isMasterCornerEnabled] && [self isCornerEnabledForPage:page];
}

@end
```

### 2.3 设计要点

| 要素 | 说明 |
|------|------|
| **字典存储** | 使用 `NSUserDefaults` + key-value，而非 ivar，便于持久化和动态扩展 |
| **懒初始化** | getter 中如果值为 nil 则写入默认值，避免单独初始化步骤 |
| **边界约束** | radius/margin 在 setter 中做范围限制，防止异常值 |
| **主从联动** | `masterCornerEnabled = YES` 时自动开启所有页面开关（可选） |

## 三、页面识别层设计

### 3.1 页面枚举定义

```objc
typedef NS_ENUM(NSInteger, YourPageType) {
    YourPageTypeUnknown   = -1,   // 未知页面
    YourPageTypeHomepage  = 0,    // 主页
    YourPageTypeProfile   = 1,    // 个人页
    YourPageTypeContacts  = 2,    // 通讯录
    YourPageTypeDiscover  = 3,    // 发现
};
```

### 3.2 页面检测器

```objc
// YourPageDetector.h
#import "YourCornerConfig.h"

@interface YourPageDetector : NSObject

/// 从任意 UIView 检测它属于哪个页面
+ (YourPageType)detectPageForView:(UIView *)view;

/// 从 UIView 向上查找所属的 UIViewController
+ (UIViewController *)findViewControllerForView:(UIView *)view;

/// 从 UIView 向上查找所属的 UITableView
+ (UITableView *)findTableViewForView:(UIView *)view;

@end
```

### 3.3 实现 - 三种识别策略

```objc
// YourPageDetector.m
#import "YourPageDetector.h"

// 引用目标 App 的 ViewController 类名
static NSString * const kHomepageVCClassName     = @"HomepageViewController";
static NSString * const kProfileVCClassName      = @"ProfileViewController";
static NSString * const kContactsVCClassName     = @"ContactsViewController";
static NSString * const kDiscoverVCClassName     = @"DiscoverViewController";

@implementation YourPageDetector

#pragma mark - 策略一：通过响应者链找到 ViewController + 类名识别（推荐）

+ (YourPageType)detectPageForView:(UIView *)view {
    UIViewController *vc = [self findViewControllerForView:view];
    if (vc == nil) return YourPageTypeUnknown;

    NSString *className = NSStringFromClass([vc class]);

    if ([className isEqualToString:kHomepageVCClassName])
        return YourPageTypeHomepage;
    if ([className isEqualToString:kProfileVCClassName])
        return YourPageTypeProfile;
    if ([className isEqualToString:kContactsVCClassName])
        return YourPageTypeContacts;
    if ([className isEqualToString:kDiscoverVCClassName])
        return YourPageTypeDiscover;

    return YourPageTypeUnknown;
}

+ (UIViewController *)findViewControllerForView:(UIView *)view {
    UIResponder *responder = view;
    while (responder) {
        responder = [responder nextResponder];
        if ([responder isKindOfClass:[UIViewController class]]) {
            return (UIViewController *)responder;
        }
    }
    return nil;
}

#pragma mark - 策略二：通过 Superview 链查找 UITableView

+ (UITableView *)findTableViewForView:(UIView *)view {
    UIView *superview = view;
    while (superview) {
        superview = [superview superview];
        if ([superview isKindOfClass:[UITableView class]]) {
            return (UITableView *)superview;
        }
    }
    return nil;
}

#pragma mark - 策略三：通过 isKindOfClass: 直接判断

+ (BOOL)isView:(UIView *)view underViewControllerOfClass:(Class)vcClass {
    UIViewController *vc = [self findViewControllerForView:view];
    return [vc isKindOfClass:vcClass];
}

@end
```

### 3.4 识别策略对比

| 策略 | 方法 | 优点 | 缺点 | 适用场景 |
|------|------|------|------|---------|
| **策略一** | `nextResponder` → VC → 类名字符串比较 | 精准、不依赖运行时类 | 需硬编码类名 | 主页面识别 |
| **策略二** | `superview` → UITableView | 快速、适用于 Cell | 只能判断是否为 TableView 内部 | Cell 级别的定位 |
| **策略三** | `isKindOfClass:` | 更稳健 | 需在运行时获取 Class 对象 | 已知目标类 |

## 四、Hook 注册层设计

### 4.1 核心思路：主开关控制 Hook 注册

模仿 WCRefine 的 `FUN_0015f858`，在你的插件初始化入口判断主开关：

```objc
// YourCornerHookManager.m
#import <substrate.h>
#import "YourCornerConfig.h"
#import "YourPageDetector.h"

// 原始函数指针
static void (*orig_MMTableViewCell_setFrame)(id, SEL, CGRect);
static void (*orig_MMTableViewCell_layoutSubviews)(id, SEL);
static void (*orig_MMTableViewCell_setHighlighted_animated)(id, SEL, BOOL, BOOL);
static void (*orig_YourTableView_layoutSubviews)(id, SEL);
static void (*orig_YourCell_layoutSubviews)(id, SEL);

@implementation YourCornerHookManager

/// 插件初始化入口 - 在 +load 或 constructor 中调用
+ (void)registerHooksIfNeeded {
    YourCornerConfig *config = [YourCornerConfig shared];

    /* ===== 主开关：只有开启才注册所有 Hook ===== */
    if ([config isMasterCornerEnabled]) {
        [self registerAllCornerHooks];
    }

    /* ===== 其他功能的 Hook 也可在此注册 ===== */
    // if ([config otherFeatureEnabled]) {
    //     [self registerOtherFeatureHooks];
    // }
}

+ (void)registerAllCornerHooks {
    // --- Hook 1: 主 Cell 的 setFrame: 调整边距 ---
    MSHookMessageEx(
        NSClassFromString(@"YourMainTableViewCell"),
        @selector(setFrame:),
        (IMP)&hooked_YourMainTableViewCell_setFrame,
        (IMP *)&orig_YourMainTableViewCell_setFrame
    );

    // --- Hook 2: 主 Cell 的 layoutSubviews 应用圆角 ---
    MSHookMessageEx(
        NSClassFromString(@"YourMainTableViewCell"),
        @selector(layoutSubviews),
        (IMP)&hooked_YourMainTableViewCell_layoutSubviews,
        (IMP *)&orig_YourMainTableViewCell_layoutSubviews
    );

    // --- Hook 3: Cell 高亮状态保持圆角 ---
    MSHookMessageEx(
        NSClassFromString(@"YourMainTableViewCell"),
        @selector(setHighlighted:animated:),
        (IMP)&hooked_YourMainTableViewCell_setHighlighted_animated,
        (IMP *)&orig_YourMainTableViewCell_setHighlighted_animated
    );

    // --- Hook 4: 通讯录专用 Cell ---
    MSHookMessageEx(
        NSClassFromString(@"YourContactsCell"),
        @selector(layoutSubviews),
        (IMP)&hooked_YourContactsCell_layoutSubviews,
        (IMP *)&orig_YourContactsCell_layoutSubviews
    );

    // --- Hook 5: 通讯录专用 TableView（识别通讯录页面） ---
    MSHookMessageEx(
        NSClassFromString(@"YourContactsTableView"),
        @selector(layoutSubviews),
        (IMP)&hooked_YourContactsTableView_layoutSubviews,
        (IMP *)&orig_YourContactsTableView_layoutSubviews
    );

    // --- Hook 6: 通用 TableView（覆盖"我的"、"发现"页面） ---
    MSHookMessageEx(
        NSClassFromString(@"YourBaseTableView"),
        @selector(layoutSubviews),
        (IMP)&hooked_YourBaseTableView_layoutSubviews,
        (IMP *)&orig_YourBaseTableView_layoutSubviews
    );

    NSLog(@"[YourCorner] All corner hooks registered.");
}

@end
```

### 4.2 关键设计点

> **所有与圆角相关的 Hook，只在 `masterCornerEnabled = YES` 时注册。**
> 页面级开关（profileCornerEnabled 等）不参与 Hook 注册决策，它们在运行时由 Hook 函数内部读取。

这样设计的好处：
- **关闭主开关 = 零性能开销**，没有任何 Hook 介入
- **页面开关仅在运行时查询**，无需动态注册/注销 Hook
- 代码结构清晰：注册层只问"要不要 Hook"，实现层只问"要不要应用"

## 五、Hook 实现层设计

### 5.1 setFrame: Hook — 调整圆角边距

模仿 WCRefine 的 `FUN_0015fd14`：

```objc
// MARK: - 主 Cell 的 setFrame: Hook

static void hooked_YourMainTableViewCell_setFrame(id self, SEL _cmd, CGRect frame) {
    YourCornerConfig *config = [YourCornerConfig shared];

    // 1. 检测当前页面
    YourPageType page = [YourPageDetector detectPageForView:self];

    // 2. 检查该页面是否要应用圆角边距
    if ([config shouldApplyCornerForPage:page]) {

        // 3. 获取 superview（通常是 UITableView）
        UIView *superview = [self superview];
        if (superview) {
            CGFloat margin = [config globalCornerMargin];

            // 4. 计算调整后的 frame
            //    WCRefine 逻辑：只有原 frame 左对齐（origin.x ≈ 0）时才调整
            CGFloat superviewWidth = CGRectGetWidth([superview bounds]);
            CGFloat newWidth = superviewWidth - margin * 2;

            if (newWidth > 0 &&
                newWidth + 0.5 < frame.size.width &&
                fabs(frame.origin.x) <= 0.5) {
                // 调整：让 Cell 居中并留出边距
                frame.origin.x = margin;
                frame.size.width = newWidth;
            }
        }
    }

    // 5. 调用原实现
    orig_YourMainTableViewCell_setFrame(self, _cmd, frame);
}
```

### 5.2 layoutSubviews Hook — 应用 cornerRadius

模仿 WCRefine 的 `FUN_00168d28`：

```objc
// MARK: - 组件 layoutSubviews Hook

static void hooked_YourComponent_layoutSubviews(id self, SEL _cmd) {
    // 1. 先调用原实现
    orig_YourComponent_layoutSubviews(self, _cmd);

    YourCornerConfig *config = [YourCornerConfig shared];

    // 2. 检测页面
    YourPageType page = [YourPageDetector detectPageForView:self];

    // 3. 检查是否应用圆角
    if ([config shouldApplyCornerForPage:page]) {

        // 4. 读取并约束圆角半径
        CGFloat radius = [config globalCornerRadius];
        if (radius <= 0) radius = 20.0;
        if (radius > 40) radius = 40.0;

        // 5. 应用圆角
        self.layer.cornerRadius = radius;
        self.layer.masksToBounds = YES;
    }
}
```

### 5.3 通讯录页面专用 Hook — 识别 VC + 应用圆角

模仿 WCRefine 的 `FUN_001723e0`，通过响应者链找到 ViewController 做页面识别：

```objc
// MARK: - 通讯录 TableView layoutSubviews Hook

static void hooked_YourContactsTableView_layoutSubviews(id self, SEL _cmd) {
    // 1. 先调用原实现
    orig_YourContactsTableView_layoutSubviews(self, _cmd);

    YourCornerConfig *config = [YourCornerConfig shared];

    // 2. 主开关检查（快速失败）
    if (![config isMasterCornerEnabled]) return;

    // 3. 通过响应者链找到 ViewController
    UIViewController *vc = [YourPageDetector findViewControllerForView:self];

    // 4. 类名判断：只有通讯录页面才处理
    if ([NSStringFromClass([vc class]) isEqualToString:@"YourContactsViewController"]) {

        // 5. 检查通讯录页面的开关
        if ([config isCornerEnabledForPage:YourPageTypeContacts]) {

            CGFloat radius = [config globalCornerRadius];
            if (radius <= 0) radius = 20.0;
            if (radius > 40) radius = 40.0;

            // 6. 遍历所有 section header 应用圆角
            NSInteger sectionCount = [(UITableView *)self numberOfSections];
            for (NSInteger section = 0; section < sectionCount; section++) {
                UIView *headerView = [(UITableView *)self headerViewForSection:section];
                if (headerView) {
                    // 为 headerView 及其子视图应用圆角
                    headerView.layer.cornerRadius = radius;
                    headerView.layer.masksToBounds = YES;
                    for (UIView *subview in headerView.subviews) {
                        subview.layer.cornerRadius = radius;
                        subview.layer.masksToBounds = YES;
                    }
                }
            }
        }
    }
}
```

### 5.4 通用 TableView Hook — 覆盖其他页面

```objc
// MARK: - 通用 TableView layoutSubviews Hook

static void hooked_YourBaseTableView_layoutSubviews(id self, SEL _cmd) {
    // 1. 先调用原实现
    orig_YourBaseTableView_layoutSubviews(self, _cmd);

    YourCornerConfig *config = [YourCornerConfig shared];
    if (![config isMasterCornerEnabled]) return;

    // 2. 检测页面
    UIViewController *vc = [YourPageDetector findViewControllerForView:self];
    YourPageType page = YourPageTypeUnknown;

    // 3. 根据 VC 类名判断页面类型
    NSString *clsName = NSStringFromClass([vc class]);
    if ([clsName isEqualToString:@"YourProfileViewController"])
        page = YourPageTypeProfile;
    else if ([clsName isEqualToString:@"YourDiscoverViewController"])
        page = YourPageTypeDiscover;
    else
        return;  // 不是目标页面，跳过

    // 4. 检查该页面开关
    if (![config isCornerEnabledForPage:page]) return;

    // 5. 应用圆角到所有子视图
    CGFloat radius = [config globalCornerRadius];
    if (radius <= 0) radius = 20.0;
    if (radius > 40) radius = 40.0;

    for (UIView *subview in [(UITableView *)self subviews]) {
        // 仅对 UIView 或 UIImageView 类型应用圆角
        if ([subview isMemberOfClass:[UIView class]] ||
            [subview isKindOfClass:[UIImageView class]]) {
            subview.layer.cornerRadius = radius;
            subview.layer.masksToBounds = YES;
        }
    }
}
```

### 6.2 开关切换实现

```objc
// YourCornerSettingsViewController.m

#pragma mark - 开关切换方法

- (void)toggleMasterCornerEnabled:(UISwitch *)sender {
    [self triggerHapticFeedback];
    BOOL isOn = sender.isOn;

    YourCornerConfig *config = [YourCornerConfig shared];
    config.masterCornerEnabled = isOn;

    // 发送设置变更通知（可选）
    [[NSNotificationCenter defaultCenter] postNotificationName:@"YourSettingsChanged"
                                                        object:nil];

    [self reloadTableData];

    // 提示重启生效
    [self showRestartAlert];
}

- (void)togglePageCornerEnabled:(UISwitch *)sender forPage:(YourPageType)page {

```

              │

              │
              ▼

              │
              ▼

              │

              │
              ▼

              │       │
              │       ▼
              │   注册所有 Hook
              │       │
              │       ▼
              │   Cell 的 setFrame:/layoutSubviews 被调用
              │       │
              │       ├── YourPageDetector.detectPageForView:
              │       │       │
              │       │       ▼
              │       │   响应者链遍历 → UIViewController
              │       │       │
              │       │       ▼

              │       │
              │       ├── YourCornerConfig.shouldApplyCornerForPage:

## 八、分层职责总结

| 层级 | 核心类 | 职责 | 关键决策 |
|------|--------|------|---------|
| **Config** | `YourCornerConfig` | 存储配置、提供查询接口 | 主开关 + 页面开关 + 参数约束 |
| **Hook 注册** | `YourCornerHookManager` | 决定哪些 Hook 需要注册 | 只依赖主开关 |
| **页面识别** | `YourPageDetector` | 从 UIView 识别所属页面 | 响应者链 + 类名判断 |
| **Hook 实现** | hook 函数（C 函数） | 调整 frame、应用 cornerRadius | 运行时读取 Config + 页面检测 |
| **设置 UI** | `YourCornerSettingsViewController` | 用户交互界面 | 开关切换 + 参数调整 + 重启提示 |

### 各层依赖关系

```
Config ← 设置 UI（写入配置）
  ↑
  ├── Hook 注册层（读取主开关）
  ├── Hook 实现层（读取所有配置）
  └── 页面识别层（不依赖 Config，纯检测逻辑）
```

## 九、扩展建议

### 9.1 新增一个页面

只需三步：

1. **枚举**：在 `YourPageType` 添加新值
2. **识别**：在 `YourPageDetector` 添加类名映射
3. **配置**：在 `kPageEnabledKeys` 添加 key

```objc
// 1. 枚举
typedef NS_ENUM(NSInteger, YourPageType) {
    ...
    YourPageTypeNewFeature,  // 新增
};

// 2. 识别
+ (YourPageType)detectPageForView:(UIView *)view {
    ...
    if ([className isEqualToString:@"NewFeatureViewController"])
        return YourPageTypeNewFeature;
    ...
}

// 3. 配置 key
static NSString * const kPageEnabledKeys[] = {
    ...
    [YourPageTypeNewFeature] = @"newFeatureCornerEnabled",
};
```

### 9.2 支持每个页面独立参数

如果想为每个页面设置不同的圆角半径/边距（而不是共用全局值）：

```objc
// 在 Config 中增加
- (CGFloat)cornerRadiusForPage:(YourPageType)page {
    NSString *key = [NSString stringWithFormat:@"cornerRadius_%@", kPageEnabledKeys[page]];
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:key];
    if (value == nil) return self.globalCornerRadius; // 降级到全局
    return [value doubleValue];
}
```

### 9.3 热重载支持（不重启生效）

若想实现切换开关后即时生效（不需要重启）：

- 在 Hook 函数中不要缓存配置，每次调用都从 `YourCornerConfig` 读取
- 设置页面切换开关后发通知，Hook 函数收到通知后刷新 UI（如 `reloadData`）
- 但注意：`setFrame:` Hook 不会自动重调，需要触发 TableView 刷新

```objc
// 切换开关后
- (void)togglePageCornerEnabled:(UISwitch *)sender forPage:(YourPageType)page {
    // ... 保存配置 ...
    [[NSNotificationCenter defaultCenter] postNotificationName:@"YourCornerSettingsChanged"
                                                        object:nil];
}

// 在 Hook 函数中监听通知（使用 dispatch_once 注册）
static void observeSettingsChanges(void) {
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        [[NSNotificationCenter defaultCenter] addObserverForName:@"YourCornerSettingsChanged"
                                                          object:nil queue:nil
                                                      usingBlock:^(NSNotification *note) {
            // 刷新所有可见 TableView
            // 但注意这需要持有 TableView 的引用
        }];
    });
}
```

## 十、与 WCRefine 方案对比

| 对比项 | WCRefine 方案 | 本指南方案 |
|--------|-------------|-----------|
| **配置存储** | NSUserDefaults（objectForKey:） | 同 WCRefine |
| **配置读取** | 内联在 Hook 函数中直接发消息 | 封装为 Config 单例 + 枚举方法 |
| **主开关** | homepageCornerEnabled | masterCornerEnabled |
| **页面开关** | 4 个独立 bool property | 统一按枚举访问 |
| **页面识别** | 私有函数 + 响应者链 | 响应者链 + 类名字符串比较 |
| **Hook 注册** | 在 C 函数中硬编码 | 封装在 Manager 类中 |
| **设置界面** | 自定义 ViewController | 自定义 ViewController |
| **可扩展性** | 添加页面需新增 property | 添加页面只需加枚举值 + key |
