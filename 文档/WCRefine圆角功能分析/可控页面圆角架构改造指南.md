# WCRefine 风格可控页面圆角 — 实现指南

## WCRefine 架构确认

基于反编译代码分析，WCRefine 的圆角控制模型为 **"主开关 + 排除开关"**：

```
homepageCornerEnabled (主开关) = YES
    │
    ├── Hook 注册阶段：注册所有圆角 Hook（setFrame: / layoutSubviews 等）
    │
    ├── 运行时阶段（在 Hook 函数内部）：
    │   ├── 页面是"发现页" → 检查 discoverPageCornerEnabled
    │   │   ├── YES → 应用圆角
    │   │   └── NO  → 不应用（排除）
    │   ├── 页面是"好友页" → 检查 friendProfileCornerEnabled
    │   ├── 页面是"我的页" → 检查 myPageCornerEnabled
    │   └── 页面是"其他页" → 自动应用圆角（不受排除开关影响）
    │
    └── 主开关关闭 → 不注册任何 Hook，所有页面无圆角
```

---

## 你的四开关 UI 映射

| UI 开关 | WCRefine 对应 | 语义 | 作用范围 |
|---------|--------------|------|---------|
| 主页圆角 | `homepageCornerEnabled` | **主开关** | 全局所有页面 |
| 我的页面 | `myPageCornerEnabled` | **排除开关** | 仅"我的页面" |
| 好友页面 | `friendProfileCornerEnabled` | **排除开关** | 仅"好友页面" |
| 发现页面 | `discoverPageCornerEnabled` | **排除开关** | 仅"发现页面" |

## 实现分层（你只需要关心灰色部分）

```
┌──────────────────────────────────────────┐
│          设置 UI 层（你已完成）            │ ← 已完成
│  四个 UISwitch + 参数输入 Cell            │
├──────────────────────────────────────────┤
│          Config 层（需要实现）             │ ← 本文档重点
│  YourCornerConfig 单例                   │
│  主开关 + 3个排除开关 + 全局参数           │
├──────────────────────────────────────────┤
│        Hook 注册层（需要实现）             │ ← 本文档重点
│  主开关 ON → 注册所有圆角 Hook            │
│  主开关 OFF → 不注册                      │
├──────────────────────────────────────────┤
│        Hook 实现层（需要实现）             │ ← 本文档重点
│  setFrame: Hook → 调整边距               │
│  layoutSubviews Hook → 应用 cornerRadius │
│  运行时：页面识别 → 排除检查 → 应用/跳过    │
├──────────────────────────────────────────┤
│         页面识别层（需要实现）              │ ← 本文档重点
│  响应者链遍历 → VC 类名 → 返回页面枚举     │
│  只识别 3 个受控页面，其余返回 -1           │
└──────────────────────────────────────────┘
```

## 第一步：Config 层

### 1.1 枚举定义

```objc
// YourCornerConfig.h

// 只有需要"排除控制"的页面才需要枚举
typedef NS_ENUM(NSInteger, YourExcludablePage) {
    YourExcludablePageProfile  = 0,   // 我的页面
    YourExcludablePageContacts = 1,   // 好友页面（通讯录）
    YourExcludablePageDiscover = 2,   // 发现页面
    YourExcludablePageCount
};
```

### 1.2 Config 接口（完整）

```objc
@interface YourCornerConfig : NSObject

+ (instancetype)shared;

// ── 主开关（对应 UI 的"主页圆角"）──
// YES = 全局开启，NO = 全部关闭
@property (nonatomic, assign, getter=isMasterCornerEnabled) BOOL masterCornerEnabled;

// ── 三个排除开关 ──
- (BOOL)isPageExcluded:(YourExcludablePage)page;
- (void)setPageExcluded:(BOOL)excluded forPage:(YourExcludablePage)page;

// ── 核心判断方法 ──
// 场景A：已知页面（在排除列表中的）
- (BOOL)shouldApplyCornerForPage:(YourExcludablePage)page;
// 场景B：未知页面（不在排除列表中的）
- (BOOL)shouldApplyCornerForUnknownPage;

// ── 全局参数 ──
@property (nonatomic, assign) CGFloat globalCornerRadius;    // 默认 15，范围 0-40
@property (nonatomic, assign) CGFloat globalCornerMargin;    // 默认 8，范围 0-100

// ── 可选参数（如果你 UI 里有）──
@property (nonatomic, assign) CGFloat globalCornerSpacing;   // 列表间距
@property (nonatomic, strong) UIColor *backgroundColor;      // 背景颜色
@property (nonatomic, assign) CGFloat strokeWidth;            // 描边粗细
@property (nonatomic, strong) UIColor *strokeColor;           // 描边颜色

@end
```

### 1.3 Config 实现（核心逻辑）

```objc
@implementation YourCornerConfig

+ (instancetype)shared {
    static id instance = nil;
    static dispatch_once_t onceToken;
    dispatch_once(&onceToken, ^{
        instance = [[self alloc] init];
    });
    return instance;
}

// 所有配置都存储于 NSUserDefaults

#pragma mark - 主开关

- (BOOL)isMasterCornerEnabled {
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:@"masterCornerEnabled"];
    if (value == nil) return NO;  // 默认关闭
    return [value boolValue];
}

- (void)setMasterCornerEnabled:(BOOL)enabled {
    [[NSUserDefaults standardUserDefaults] setObject:@(enabled) forKey:@"masterCornerEnabled"];
}

#pragma mark - 排除开关

- (BOOL)isPageExcluded:(YourExcludablePage)page {
    NSString *key = [NSString stringWithFormat:@"pageExcluded_%ld", (long)page];
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:key];
    if (value == nil) return NO;  // 默认不排除
    return [value boolValue];
}

- (void)setPageExcluded:(BOOL)excluded forPage:(YourExcludablePage)page {
    NSString *key = [NSString stringWithFormat:@"pageExcluded_%ld", (long)page];
    [[NSUserDefaults standardUserDefaults] setObject:@(excluded) forKey:key];
}

#pragma mark - 核心判断逻辑

/// 已知页面（在排除列表中的）是否应用圆角
/// 主开关 ON && 该页面未被排除 → 应用
- (BOOL)shouldApplyCornerForPage:(YourExcludablePage)page {
    return [self isMasterCornerEnabled] && ![self isPageExcluded:page];
}

/// 未知页面（不在排除列表中的）是否应用圆角
/// 只取决于主开关
- (BOOL)shouldApplyCornerForUnknownPage {
    return [self isMasterCornerEnabled];
}

#pragma mark - 全局参数（带边界约束）

- (CGFloat)globalCornerRadius {
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:@"globalCornerRadius"];
    if (value == nil) return 15.0;
    CGFloat r = [value doubleValue];
    if (r <= 0) return 15.0;
    if (r > 40) return 40.0;
    return r;
}

- (void)setGlobalCornerRadius:(CGFloat)radius {
    if (radius <= 0) radius = 15.0;
    if (radius > 40) radius = 40.0;
    [[NSUserDefaults standardUserDefaults] setObject:@(radius) forKey:@"globalCornerRadius"];
}

- (CGFloat)globalCornerMargin {
    id value = [[NSUserDefaults standardUserDefaults] objectForKey:@"globalCornerMargin"];
    if (value == nil) return 8.0;
    CGFloat m = [value doubleValue];
    if (m <= 0) return 8.0;
    if (m > 100) return 100.0;
    return m;
}

- (void)setGlobalCornerMargin:(CGFloat)margin {
    if (margin <= 0) margin = 8.0;
    if (margin > 100) margin = 100.0;
    [[NSUserDefaults standardUserDefaults] setObject:@(margin) forKey:@"globalCornerMargin"];
}

@end
```

## 第二步：页面识别层

### 2.1 接口

```objc
// YourPageDetector.h

@interface YourPageDetector : NSObject

/// 检测 UIView 所属的受控页面类型
/// 返回值：YourExcludablePage 枚举值
/// 不在三个受控页面中 → 返回 -1
+ (NSInteger)detectExcludablePageForView:(UIView *)view;

/// 从 UIView 向上查找所属的 UIViewController
+ (UIViewController *)findViewControllerForView:(UIView *)view;

@end
```

### 2.2 实现

```objc
// YourPageDetector.m
// ！！！重要：替换为你微信中实际的 VC 类名 ！！！

static NSString * const kProfileVCClassName   = @"MyProfileViewController";  // 我的页面 VC
static NSString * const kContactsVCClassName  = @"ContactsViewController";   // 好友页面 VC
static NSString * const kDiscoverVCClassName  = @"DiscoverViewController";   // 发现页面 VC

@implementation YourPageDetector

+ (NSInteger)detectExcludablePageForView:(UIView *)view {
    UIViewController *vc = [self findViewControllerForView:view];
    if (vc == nil) return -1;

    NSString *cls = NSStringFromClass([vc class]);

    if ([cls isEqualToString:kProfileVCClassName])
        return YourExcludablePageProfile;
    if ([cls isEqualToString:kContactsVCClassName])
        return YourExcludablePageContacts;
    if ([cls isEqualToString:kDiscoverVCClassName])
        return YourExcludablePageDiscover;

    return -1;  // 不在排除列表中
}

+ (UIViewController *)findViewControllerForView:(UIView *)view {
    UIResponder *responder = view;
    while (responder) {
        responder = [responder nextResponder];
        if ([responder isKindOfClass:[UIViewController class]]) {
            return (UIViewController *)responder;
        }
    }
    return nil;
}

@end
```

## 第三步：Hook 注册层

### 3.1 实现

```objc
// YourCornerHookManager.m
#import <substrate.h>
#import "YourCornerConfig.h"
#import "YourPageDetector.h"

// ── 原始函数指针 ──
static void (*orig_MMTableViewCell_setFrame)(id, SEL, CGRect);
static void (*orig_MMTableViewCell_layoutSubviews)(id, SEL);
static void (*orig_NewContactsItemCell_layoutSubviews)(id, SEL);
static void (*orig_MMMainTableView_layoutSubviews)(id, SEL);

@implementation YourCornerHookManager

/// 在插件 +load 或 constructor 中调用
+ (void)registerHooksIfNeeded {
    YourCornerConfig *config = [YourCornerConfig shared];

    // 只有主开关开启才注册所有圆角 Hook（WCRefine 风格）
    if ([config isMasterCornerEnabled]) {
        [self registerAllCornerHooks];
        NSLog(@"[YourCorner] 主开关开启，已注册所有圆角 Hook");
    } else {
        NSLog(@"[YourCorner] 主开关关闭，跳过圆角 Hook 注册");
    }
}

+ (void)registerAllCornerHooks {
    // Hook 1: 主 Cell 的 setFrame:
    MSHookMessageEx(
        NSClassFromString(@"MMTableViewCell"),
        @selector(setFrame:),
        (IMP)&hooked_setFrame,
        (IMP *)&orig_MMTableViewCell_setFrame
    );

    // Hook 2: 主 Cell 的 layoutSubviews
    MSHookMessageEx(
        NSClassFromString(@"MMTableViewCell"),
        @selector(layoutSubviews),
        (IMP)&hooked_layoutSubviews,
        (IMP *)&orig_MMTableViewCell_layoutSubviews
    );

    // Hook 3: 通讯录 Cell 的 layoutSubviews（好友页面用）
    MSHookMessageEx(
        NSClassFromString(@"NewContactsItemCell"),
        @selector(layoutSubviews),
        (IMP)&hooked_NewContactsItemCell_layoutSubviews,
        (IMP *)&orig_NewContactsItemCell_layoutSubviews
    );

    // Hook 4: 通讯录主 TableView 的 layoutSubviews
    MSHookMessageEx(
        NSClassFromString(@"MMMainTableView"),
        @selector(layoutSubviews),
        (IMP)&hooked_MMMainTableView_layoutSubviews,
        (IMP *)&orig_MMMainTableView_layoutSubviews
    );

    // 如果还需要 Hook 其他类，在此追加
}

@end
```

|----------------|-------------------|---------|------|

## 第四步：Hook 实现层（核心）

### 4.1 hooked_setFrame — 控制圆角边距

```objc
// 这是 WCRefine FUN_0015fd14 的对应实现

static void hooked_setFrame(id self, SEL _cmd, CGRect frame) {
    YourCornerConfig *config = [YourCornerConfig shared];

    // ==== 第一步：主开关快速失败 ====
    if (![config isMasterCornerEnabled]) {
        orig_MMTableViewCell_setFrame(self, _cmd, frame);
        return;
    }

    // ==== 第二步：页面识别 ====
    NSInteger page = [YourPageDetector detectExcludablePageForView:self];

    // ==== 第三步：判断是否应用 ====
    BOOL shouldApply = NO;
    if (page >= 0) {
        // 在排除列表中 → 查排除开关
        shouldApply = [config shouldApplyCornerForPage:(YourExcludablePage)page];
    } else {
        // 不在排除列表中 → 自动跟随主开关
        shouldApply = [config shouldApplyCornerForUnknownPage];
    }

    // ==== 第四步：应用边距 ====
    if (shouldApply) {
        UIView *superview = [self superview];
        if (superview) {
            CGFloat margin = [config globalCornerMargin];
            CGFloat svWidth = CGRectGetWidth([superview bounds]);
            CGFloat newWidth = svWidth - margin * 2;

            // WCRefine 条件：只调整原本左对齐的 Cell
            if (newWidth > 0 &&
                newWidth + 0.5 < frame.size.width &&
                fabs(frame.origin.x) <= 0.5) {
                frame.origin.x = margin;
                frame.size.width = newWidth;
            }
        }
    }

    // ==== 第五步：调用原实现 ====
    orig_MMTableViewCell_setFrame(self, _cmd, frame);
}
```

### 4.2 hooked_layoutSubviews — 应用圆角

```objc
// WCRefine 在 layoutSubviews 中通过 layer.cornerRadius 应用圆角

static void hooked_layoutSubviews(id self, SEL _cmd) {
    // 先调原实现
    orig_MMTableViewCell_layoutSubviews(self, _cmd);

    YourCornerConfig *config = [YourCornerConfig shared];
    if (![config isMasterCornerEnabled]) return;

    // 页面识别
    NSInteger page = [YourPageDetector detectExcludablePageForView:self];

    // 判断是否应用
    BOOL shouldApply = (page >= 0)
        ? [config shouldApplyCornerForPage:(YourExcludablePage)page]
        : [config shouldApplyCornerForUnknownPage];

    if (!shouldApply) return;

    // 应用圆角
    CGFloat radius = [config globalCornerRadius];
    if (radius <= 0) radius = 20.0;
    if (radius > 40) radius = 40.0;

    self.layer.cornerRadius = radius;
    self.layer.masksToBounds = YES;
}
```

### 4.3 hooked_NewContactsItemCell_layoutSubviews — 通讯录专用

```objc
// 好友页面的 Cell 可能有不同的类，单独处理

static void hooked_NewContactsItemCell_layoutSubviews(id self, SEL _cmd) {
    orig_NewContactsItemCell_layoutSubviews(self, _cmd);

    YourCornerConfig *config = [YourCornerConfig shared];
    if (![config isMasterCornerEnabled]) return;
    if (![config shouldApplyCornerForPage:YourExcludablePageContacts]) return;

    CGFloat radius = [config globalCornerRadius];
    if (radius <= 0) radius = 20.0;
    if (radius > 40) radius = 40.0;

    self.layer.cornerRadius = radius;
    self.layer.masksToBounds = YES;
}
```

### 4.4 attached_MMMainTableView_layoutSubviews — 通讯录 TableView 识别

```objc
// WCRefine FUN_001723e0 的对应实现
// 通过响应者链找到 VC，确认是通讯录页面才应用

static void hooked_MMMainTableView_layoutSubviews(id self, SEL _cmd) {
    orig_MMMainTableView_layoutSubviews(self, _cmd);

    YourCornerConfig *config = [YourCornerConfig shared];
    if (![config isMasterCornerEnabled]) return;

    // 找到当前 VC
    UIViewController *vc = [YourPageDetector findViewControllerForView:self];
    if (vc == nil) return;

    // 确认是通讯录页面
    NSString *clsName = NSStringFromClass([vc class]);
    if (![clsName isEqualToString:@"ContactsViewController"]) return;

    // 检查好友页面排除开关
    if (![config shouldApplyCornerForPage:YourExcludablePageContacts]) return;

    // 应用圆角到 section header
    CGFloat radius = [config globalCornerRadius];
    if (radius <= 0) radius = 20.0;
    if (radius > 40) radius = 40.0;

    NSInteger sections = [(UITableView *)self numberOfSections];
    for (NSInteger s = 0; s < sections; s++) {
        UIView *header = [(UITableView *)self headerViewForSection:s];
        if (header) {
            header.layer.cornerRadius = radius;
            header.layer.masksToBounds = YES;
        }
    }
}
```

## 第五步：设置 UI 的调用逻辑

因为你 UI 已经写好了，只需要在切换开关时调用 Config 的对应方法：

```objc
// 在你的 SettingsViewController.m 中

// 主开关切换（对应第1个 Switch）
- (void)switchMasterChanged:(UISwitch *)sender {
    [YourCornerConfig shared].masterCornerEnabled = sender.isOn;
    [self.tableView reloadData];  // 刷新 UI 联动（其他开关灰色禁用）
    [self showRestartAlert];
}

// 排除开关切换（对应第2-4个 Switch）
- (void)switchProfileExcludedChanged:(UISwitch *)sender {
    [[YourCornerConfig shared] setPageExcluded:sender.isOn
                                       forPage:YourExcludablePageProfile];
    [self showRestartAlert];
}

- (void)switchContactsExcludedChanged:(UISwitch *)sender {
    [[YourCornerConfig shared] setPageExcluded:sender.isOn
                                       forPage:YourExcludablePageContacts];
    [self showRestartAlert];
}

- (void)switchDiscoverExcludedChanged:(UISwitch *)sender {
    [[YourCornerConfig shared] setPageExcluded:sender.isOn
                                       forPage:YourExcludablePageDiscover];
    [self showRestartAlert];
}
```

UI 联动规则：

| 场景 | 主页圆角 Switch | 我的页面 Switch | 好友页面 Switch | 发现页面 Switch |
|------|---------------|---------------|---------------|---------------|
| 主开关 OFF | OFF | 灰色禁用 | 灰色禁用 | 灰色禁用 |
| 主开关 ON | ON | 可操作 | 可操作 | 可操作 |

```objc
// 在 cellForRow 中设置开关状态
UISwitch *sw = cell.accessoryView;
BOOL masterOn = [YourCornerConfig shared].isMasterCornerEnabled;

if (indexPath.row == 0) {
    // 主开关 - 永远可操作
    sw.on = masterOn;
    sw.enabled = YES;
} else {
    // 排除开关 - 主开关关闭时禁用
    sw.enabled = masterOn;
    // 根据具体行设置 on 状态
}
```

## 完整判断逻辑速查表

```
hooked_setFrame 被调用
    │
    ├── masterCornerEnabled = NO?
    │   └── YES → 直接 orig_setFrame，返回
    │
    ├── detectExcludablePageForView:
    │   │
    │   ├── page >= 0（在排除列表）
    │   │   └── shouldApplyCornerForPage:
    │   │       ├── YES（主开关 ON && 未排除）→ 应用边距
    │   │       └── NO（已排除）→ 跳过
    │   │
    │   └── page < 0（不在排除列表）
    │       └── shouldApplyCornerForUnknownPage:
    │           ├── YES（主开关 ON）→ 应用边距
    │           └── NO（主开关 OFF，理论上不会到这里）
    │
    └── orig_setFrame
```
