```objc
// ★★★ [WPSessionSpacingHook] NewMainFrameVC header height ★★★
static CGFloat (*_orig_NMFVC_heightForHeader)(id, SEL, id, NSInteger);
static CGFloat _hooked_NMFVC_heightForHeader(id self, SEL _cmd, id tableView, NSInteger section) {
    CGFloat height = _orig_NMFVC_heightForHeader(self, _cmd, tableView, section);

    PluginConfig *config = [PluginConfig shared];
    if (!config.globalCornerRadiusEnabled) return height;

    if (section == 1) {
        NSInteger spacing = (NSInteger)config.listPinnedSessionTopSpacing;
        height += (spacing > 0) ? spacing : 15;
    } else if (section >= 2) {
        NSInteger spacing = (NSInteger)config.listNormalSessionSpacing;
        height += (spacing > 0) ? spacing : 15;
    }
    return height;
}
```

## 注意事项（重要）

### 1. 其他 Hook 不受影响

删除的 `_hooked_NMFVC_heightForHeader` 是**独立函数**，不影响同文件中的其他 Hook：

| Hook 函数 | 是否受影响 | 原因 |
|-----------|:---------:|------|
| `_hooked_UIView_layoutSubviews` | ❌ 不受影响 | 不同函数，独立注册 |
| `_hooked_NMFVC_viewForHeader` | ❌ 不受影响 | 注册语句独立，只需删除第一行 MSHookMessageEx |
| `_hooked_setBgImageView` | ❌ 不受影响 | 不同函数，独立注册 |
| `replaced_MMTableViewCell_layoutSubviews` | ❌ 不受影响 | 不同函数 |

### 2. SwitchChanged 不受影响

SettingListCornerRadiusController 的 `switchChanged:` 中没有检查这两个 key，不涉及 UI 重建。

### 3. 用户数据残留

`ListPinnedSessionTopSpacing` 和 `ListNormalSessionSpacing` 两个 key 会残留在 NSUserDefaults 中，但不再读取，不影响功能。
