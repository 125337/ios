# 图片上传路径改造方案

## 一、改造目标

将图片存储路径改为统一管理：
- **新路径**: `Documents/Miopng/` 文件夹统一管理所有分隔符图片

---

## 二、目录结构设计

### 新目录结构

```
Documents/
└── Miopng/
    ├── separator_icon.png      # 静态分隔符图片
    └── separator_icon.gif      # GIF分隔符动图
```

### 优势

1. **统一管理**: 所有图片资源集中在同一文件夹
2. **便于清理**: 删除文件夹内文件即可清除所有图片
3. **易于维护**: 代码逻辑更清晰
4. **便于测试**: 可以直接查看文件夹内容验证功能

## 四、详细改造步骤

### 步骤1: 添加文件夹创建方法

在 `SettingChatTopBarController.m` 中添加一个创建 Miopng 文件夹的方法：

**位置**: 在 `@implementation SettingChatTopBarController` 之后，`viewDidLoad` 方法之前

**新增方法**:

```objc
#pragma mark - 创建图片存储目录

/// 确保图片存储目录存在，返回目录路径
- (NSString *)ensureMiopngDirectory {
    NSString *miopngPath = [NSHomeDirectory() stringByAppendingPathComponent:@"Documents/Miopng"];
    NSFileManager *fm = [NSFileManager defaultManager];

    if (![fm fileExistsAtPath:miopngPath]) {
        NSError *error = nil;
        BOOL success = [fm createDirectoryAtPath:miopngPath
                      withIntermediateDirectories:YES
                                       attributes:nil
                                            error:&error];
        if (!success) {
            WPLog(@"Mio-Separator", @"创建Miopng目录失败: %@", error);
        } else {
            WPLog(@"Mio-Separator", @"创建Miopng目录成功: %@", miopngPath);
        }
    }

    return miopngPath;
}
```

```objc
[result.itemProvider loadFileRepresentationForTypeIdentifier:(__bridge NSString *)kUTTypeGIF completionHandler:^(NSURL *url, NSError *error) {
    if (error || !url) {
        WPLog(@"Mio-Separator", @"    加载GIF失败: error=%@", error);
        return;
    }
    dispatch_async(dispatch_get_main_queue(), ^{
        WPLog(@"Mio-Separator", @"    GIF加载成功: url.path=%@", url.path);

        // 复制GIF到Miopng目录
        NSString *miopngDir = [self ensureMiopngDirectory];
        NSString *gifDestPath = [miopngDir stringByAppendingPathComponent:@"separator_icon.gif"];

        NSFileManager *fm = [NSFileManager defaultManager];
        NSError *copyError = nil;

        // 如果目标文件已存在，先删除
        if ([fm fileExistsAtPath:gifDestPath]) {
            [fm removeItemAtPath:gifDestPath error:nil];
        }

        // 复制文件到Miopng目录
        BOOL success = [fm copyItemAtPath:url.path toPath:gifDestPath error:&copyError];
        if (!success) {
            WPLog(@"Mio-Separator", @"    复制GIF失败: %@", copyError);
        } else {
            WPLog(@"Mio-Separator", @"    复制GIF成功: %@", gifDestPath);
        }

        config.chatSeparatorGIF = gifDestPath;
        WPLog(@"Mio-Separator", @"    设置 chatSeparatorGIF = %@", gifDestPath);
        [ConfigManager saveAll];
        WPLog(@"Mio-Separator", @"    调用 [ConfigManager saveAll]");
        [picker dismissViewControllerAnimated:YES completion:^{
            WPLog(@"Mio-Separator", @"    dismiss 完成，调用 buildUI");
            [self buildUI];
        }];
    });
}];
```

**修改说明**:
- 不再直接使用临时文件路径
- 将GIF复制到 `Documents/Miopng/separator_icon.gif`
- 如果目标文件已存在，先删除再复制

### 步骤5: 添加可选的辅助方法（扩展功能）

如果需要提供更多功能，可以添加以下辅助方法：

```objc
#pragma mark - 图片目录辅助方法

/// 删除整个Miopng目录及其内容
- (void)cleanMiopngDirectory {
    NSString *miopngDir = [NSHomeDirectory() stringByAppendingPathComponent:@"Documents/Miopng"];
    NSFileManager *fm = [NSFileManager defaultManager];

    if ([fm fileExistsAtPath:miopngDir]) {
        NSError *error = nil;
        BOOL success = [fm removeItemAtPath:miopngDir error:&error];
        if (success) {
            WPLog(@"Mio-Separator", @"Miopng目录已删除: %@", miopngDir);
        } else {
            WPLog(@"Mio-Separator", @"删除Miopng目录失败: %@", error);
        }
    }
}

/// 获取Miopng目录占用的磁盘空间
- (unsigned long long)getMiopngDirectorySize {
    NSString *miopngDir = [NSHomeDirectory() stringByAppendingPathComponent:@"Documents/Miopng"];
    NSFileManager *fm = [NSFileManager defaultManager];

    if (![fm fileExistsAtPath:miopngDir]) {
        return 0;
    }

    NSError *error = nil;
    NSArray *files = [fm contentsOfDirectoryAtPath:miopngDir error:&error];
    if (error) {
        return 0;
    }

    unsigned long long totalSize = 0;
    for (NSString *file in files) {
        NSString *filePath = [miopngDir stringByAppendingPathComponent:file];
        NSDictionary *attributes = [fm attributesOfItemAtPath:filePath error:nil];
        totalSize += [attributes fileSize];
    }

    return totalSize;
}

/// 获取文件大小描述字符串
- (NSString *)getFileSizeString:(NSString *)filePath {
    NSFileManager *fm = [NSFileManager defaultManager];
    NSDictionary *attributes = [fm attributesOfItemAtPath:filePath error:nil];
    unsigned long long size = [attributes fileSize];

    if (size < 1024) {
        return [NSString stringWithFormat:@"%llu B", size];
    } else if (size < 1024 * 1024) {
        return [NSString stringWithFormat:@"%.1f KB", size / 1024.0];
    } else {
        return [NSString stringWithFormat:@"%.1f MB", size / (1024.0 * 1024.0)];
    }
}
```

## 八、注意事项

### 1. 线程安全

`ensureMiopngDirectory` 方法在主线程调用，无需额外处理线程安全。

### 2. 错误处理

- 目录创建失败时记录日志，但不阻止后续操作
- 文件删除失败时忽略错误（不影响用户体验）

### 3. 磁盘空间

- 每次上传会覆盖旧文件，不会累积
- 清除操作彻底删除文件，无残留
