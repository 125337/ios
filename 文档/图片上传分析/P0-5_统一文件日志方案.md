# P0-5 修复方案：统一文件日志为单入口工具

## 问题概述

项目中存在 **3 处**独立的文件日志实现，均向 `Documents/MioPlugin_Logs/` 写入，但写到了 **3 个不同文件**，代码结构完全一致：

| 函数 | 文件 | 行号 | 写入文件 | 调用次数 |
|------|------|------|---------|---------|
| `groupExitLog()` | `GroupExit/GroupExitHook.m` | 10-26 | `groupexit.log` | 4次 |
| `atLog()` | `AutoTransfer/AutoTransferHook.m` | 14-30 | `autotransfer.log` | 4次 |
| `walertLog()` | `Core/MioAlertHelper.m` | 17-35 | `joker.log` | 32次 |

**共 40 次调用，3 个重复实现，写入 3 个不同文件。**

---

## 目标

- 统一为一个入口函数，写入同一个文件 `MioPlugin.log`
- 消除 3 处重复实现代码
- 40 个调用处逐个改造为统一入口
- 每行日志带模块标签，便于追踪

---

## 详细修改步骤

### Step 1: 在 LogManager 中添加统一方法

**文件**: `Core/LogManager.h`

在当前 `_WPLogManager` 接口中添加新方法声明：

```objc
/// 向统一日志文件追加一行（文件路径: Documents/MioPlugin_Logs/MioPlugin.log）
/// @param tag  模块标签，如 @"GroupExit" / @"AutoTransfer" / @"Alert"
/// @param line 日志内容（方法内部会自动拼接时间戳和换行）
+ (void)appendLineWithTag:(NSString *)tag content:(NSString *)line;
```

**文件**: `Core/LogManager.m`

添加实现：

```objc
+ (void)appendLineWithTag:(NSString *)tag content:(NSString *)line {
    @try {
        // 确保目录存在
        NSArray *paths = NSSearchPathForDirectoriesInDomains(NSDocumentDirectory, NSUserDomainMask, YES);
        NSString *folderPath = [paths.firstObject stringByAppendingPathComponent:@"MioPlugin_Logs"];
        [[NSFileManager defaultManager] createDirectoryAtPath:folderPath
                                  withIntermediateDirectories:YES
                                                   attributes:nil
                                                        error:nil];
        
        // 统一写入 MioPlugin.log
        NSString *filePath = [folderPath stringByAppendingPathComponent:@"MioPlugin.log"];
        
        // 格式: [2026-06-10 14:30:22][GroupExit] 内容
        NSDateFormatter *formatter = [[NSDateFormatter alloc] init];
        formatter.dateFormat = @"yyyy-MM-dd HH:mm:ss";
        NSString *timestamp = [formatter stringFromDate:[NSDate date]];
        NSString *logLine = [NSString stringWithFormat:@"[%@][%@] %@\n", timestamp, tag, line];
        
        // 追加写入
        NSFileHandle *handle = [NSFileHandle fileHandleForWritingAtPath:filePath];
        if (handle) {
            [handle seekToEndOfFile];
            [handle writeData:[logLine dataUsingEncoding:NSUTF8StringEncoding]];
            [handle closeFile];
        } else {
            [logLine writeToFile:filePath atomically:YES encoding:NSUTF8StringEncoding error:nil];
        }
    } @catch (NSException *e) {
        // 日志写入失败不抛异常
    }
}
```

> 注意：此处时间格式使用了毫秒精度（`yyyy-MM-dd HH:mm:ss.SSS`），与其他两处日志函数保持一致。如需统一为不带毫秒的格式可自行调整。
