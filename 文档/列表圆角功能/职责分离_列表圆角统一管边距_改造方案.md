> **术语澄清**：
> - **「卡片背景色」** = 列表圆角模块的配置项 `listCardLightBgColor`/`listCardDarkBgColor`，位于列表圆角设置页，控制资料卡 button 的纯色背景
> - **「卡片背景」** = 卡片背景模块的开关 `cardBgEnabled`，控制资料卡上的背景**图片**
> - 两者是完全不同的功能，分属不同模块，互不冲突

## 改动汇总

### 改动 1：Cell Hook 中资料卡 button 缩窄（已删除，被改动 6 替代）

因视图层级问题：MMUIButton 不是 `cellView` 的直接子视图，枚举找不到，代码无效。已从 ListCornerRadiusHook.m 中删除。

### 改动 2：handleButtonLayout 中删除 bgMargin + button margin 代码 ✅

ProfileCardBgHook.m 中创建 bg 的 margin 代码已删除，bg 填满 button 即可。

### 改动 3：DO_CORNER 圆角保持不动 ✅

当 `cardBgEnabled=YES` 且 `listCornerRadiusEnabled=NO` 时，DO_CORNER 仍为资料卡提供圆角兜底。

### 改动 4：Cell Hook 新增资料卡 button 背景色 ✅

ListCornerRadiusHook.m 中在 bgColor 设置后、corner 设置前，给 MoreViewController 的 MMUIButton 设 `listCardLightBgColor`/`listCardDarkBgColor`。

### 改动 5+6：handleButtonLayout 缩窄 button 宽度 + 修复 label 压缩 ✅

在 handleButtonLayout 的 height 调整之后、DO_CORNER 之前插入：

```objc
// ── 改动 6：资料卡 button 宽度匹配列表边距 ──
if (config.listCornerRadiusEnabled) {
    CGFloat margin = config.listCellMargin;
    if (margin > 0) {
        CGFloat screenW = [UIScreen mainScreen].bounds.size.width;
        CGFloat targetW = screenW - 2.0 * margin;
        if (fabs(button.frame.size.width - targetW) > 0.5) {
            CGRect bf = button.frame;
            bf.origin.x = 0;
            bf.size.width = targetW;
            button.frame = bf;
        }

        // 修复：label 内容压缩
        for (UIView *sv in button.subviews) {
            if ([sv isKindOfClass:[UILabel class]]) {
                UILabel *label = (UILabel *)sv;
                if (CGRectGetMaxX(label.frame) > button.bounds.size.width) {
                    label.numberOfLines = 0;
                    [label sizeToFit];
                }
            }
        }
    }
}
```
