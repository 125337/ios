# 列表圆角 + 卡片背景同时开启卡死 — 改造方案

## 问题

**列表圆角 + 卡片背景同时开启**，进入"我的"页面 → **看门狗超时**（0x8BADF00D）。

**根因**：两个 Hook 在 layoutSubviews 中多重修改 frame，形成永不收敛的布局循环。

## 当前状态

| 改造 | 文件 | 状态 |
|------|------|------|
| **A** `==` → `fabs > 0.5` | `ListCornerRadiusHook.m` L231 | ✅ 已完成 |
| **C** margin 移到 bg 创建分支内 | `ProfileCardBgHook.m` L469-479 | ✅ 已完成 |

## 仍需修复：改造 B - 仅跳过资料卡 cell margin

**当前代码**（L214-217）跳过**所有** `MoreViewController` cell，导致其他列表 cell 丢失边距：

```objc
if ([className isEqualToString:@"MoreViewController"]) {
    goto AFTER_MARGIN;  // ← 跳过了资料卡 cell + 所有其他列表 cell
}
```

**改为**：仅跳过含 `MMUIButton` 子视图的资料卡 cell：

```objc
if ([className isEqualToString:@"MoreViewController"]) {
    __block BOOL isProfileCardCell = NO;
    [cellView.subviews enumerateObjectsUsingBlock:^(__kindof UIView * _Nonnull sub,
                                                     NSUInteger idx, BOOL * _Nonnull stop) {
        if ([sub isKindOfClass:NSClassFromString(@"MMUIButton")]) {
            isProfileCardCell = YES;
            *stop = YES;
        }
    }];
    if (isProfileCardCell) {
        goto AFTER_MARGIN;
    }
}
```
