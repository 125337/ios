## 一、间距功能全景

该插件涉及 **4 类间距**，分别作用于不同 UI 层级：

```
┌──────────────────────────────────────────────────┐
│  NewMainFrameViewController (聊天列表页面)         │
│  ┌────────────────────────────────────────────┐  │
│  │  Section 0 Header (置顶对话区域)            │  │
│  │  ↑ PinnedSessionSpacing (置顶对话间距)      │  │
│  │  Section 1 Header (资料卡区域)              │  │
│  │  ↑ ProfileCardSpacing (资料卡间距)          │  │
│  │  Section 2+ Header                         │  │
│  │  ↑ NormalSessionSpacing (普通对话间距)      │  │
│  ├────────────────────────────────────────────┤  │
│  │  MMTableViewCell                           │  │
│  │  ←→ CellHorizontalMargin (Cell 左右边距)    │  │
│  └────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────┐  │
│  │  MMUIButton (资料卡按钮)                     │  │
│  │  ←→ 同 CellHorizontalMargin (按钮边距)       │  │
│  └────────────────────────────────────────────┘  │
│  ┌────────────────────────────────────────────┐  │
│  │  MainFrameSectionFoldView (折叠视图)        │  │
│  │  ←→ 同 CellHorizontalMargin (折叠视图边距)   │  │
│  └────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────┘
```

| 维度 | 反编译版 | MioPlugin | 结论 |

### 8.2 Cell 边距实现最小示例

```objc
// ===== 最小 Cell 边距 Hook =====

static void (*_orig_MMTableViewCell_layoutSubviews)(id, SEL);

static void _hooked_MMTableViewCell_layoutSubviews(UIView *cell, SEL _cmd) {
    _orig_MMTableViewCell_layoutSubviews(cell, _cmd);
    
    // 1. 读取配置
    NSInteger margin = [PluginConfig shared].listCellMargin;  // 默认 9pt
    if (margin <= 0) return;
    
    // 2. 计算新 x
    CGFloat targetX = (CGFloat)margin;
    UIView *superview = cell.superview;
    if (superview) {
        CGFloat superX = superview.frame.origin.x;
        targetX = MAX(margin - superX, 0);  // max(margin - superX, 0)
    }
    
    // 3. 计算新宽度
    CGFloat containerW = superview ? superview.frame.size.width : UIScreen.mainScreen.bounds.size.width;
    CGFloat targetW = containerW - 2 * (CGFloat)margin;
    
    // 4. 变更检测（避免无效重绘）
    CGRect currentFrame = cell.frame;
    if (currentFrame.origin.x != targetX || fabs(currentFrame.size.width - targetW) > 0.5) {
        cell.frame = CGRectMake(targetX, currentFrame.origin.y, targetW, currentFrame.size.height);
    }
}
```

```objc
    // ★ 追回间距
    CGFloat spacing = config.cardBgListSpacing;
    if (spacing > 0) height += spacing;
    
    return height;
}
```

## 九、关键注意事项

| 注意事项 | 说明 |
|---------|------|
| **变更检测** | 必须做 frame 变更检测（`currentX != targetX`），避免每次 `layoutSubviews` 都触发重绘 |
| **Section 识别** | 微信 Section 0 = 搜索框，Section 1 = 资料卡/置顶对话，Section ≥2 = 普通对话 |
| **VC 过滤** | 资料卡间距只在 `MoreViewController` 生效，需做 VC 类名校验 |
| **高度保护** | 自定义高度过大时可能导致 button/header 被截断，需 `max(result, customHeight)` |
| **浮点精度** | frame 比较用 `fabs(diff) > 0.5` 而非 `==`，避免浮点误差导致的无限递归 |
| **superview 偏移** | Cell 的 superview 可能有 x 偏移，公式 `targetX = max(margin - superX, 0)` 处理此情况 |
| **两个 Hook 冲突** | `WCTableViewManager` 被反编译版的两个 Hook 函数（`FUN_00008874` + `FUN_0000ca18`）同时 Hook，但因为 section 过滤不同（1 vs ≥1），实际不会冲突 |
