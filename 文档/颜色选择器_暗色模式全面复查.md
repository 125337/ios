> 复查日期：2026-06-09
> 复查范围：`/www/wwwroot/ios/MioPlugin/` 全部代码

---

## 1. 复查方法

扫描条件：
1. `PluginConfig.h` 中每个颜色 `@property` 的声明
2. 该属性是否有对应的暗色模式配对属性（如 `xxxDarkHex`）
3. 设置页（`Setting*Controller.m / WPUIPlaceholderTextVC.m`）是否传出 `darkKey/darkValue`
4. `ColorPairMap` 是否包含该属性的映射
5. Hook 文件读取该属性时是否做了 `isDarkMode / colorInLightMode` 判断

## 3. 详细分析

### 3.1 `senderBackgroundColorHex` / `receiverBackgroundColorHex` — 有 Hook 支持但无 UI

```objc
// MessageTimeHook.m L626-627, L636-637
NSString *bgHex = isSender ? config.senderBackgroundColorHex : config.receiverBackgroundColorHex;
NSString *bgDarkHex = isSender ? config.senderBackgroundColorDarkHex : config.receiverBackgroundColorDarkHex;
...
UIColor *bgColor = colorInLightMode(lightBgColor, darkBgColor);  // ✅ 有暗色判断
```

- 属性定义 ✅：PluginConfig.h L58-L59, L63-L64
- 加载/保存 ✅：PluginConfig.m L221-L256, L592-L597
- Hook 暗色判断 ✅：MessageTimeHook.m L637
- **设置页 UI ❌：没有任何 `addColorRowInGroup` 调用指向这两个 key**
- ColorPairMap ❌：不需要（因为没有 UI 行）

**修复方案**：如果需要在设置页添加气泡背景色编辑，需：
1. 在 `SettingMessageTimeController.m` 的 `subBuilder` 中添加两行 `addColorRowInGroup`（发送方背景色 + 接收方背景色）
2. 然后将这两对加入 `ColorPairMap`
3. 调整现有 UI 布局避免重叠

### 3.2 `listCellBorderColor` — 无暗色支持

```objc
// ListCornerRadiusHook.m L747
UIColor *borderColor = [config colorFromHex:config.listCellBorderColor];
if (!borderColor) {
    borderColor = isDark ? [UIColor colorWithRed:0.25 green:0.25 blue:0.25 alpha:1.0]
                          : [UIColor colorWithRed:0.82 green:0.82 blue:0.84 alpha:1.0];
}
```

```objc
// ProfileCardBgHook.m L76
UIColor *borderColor = [config colorFromHex:config.listCellBorderColor];  // ❌ 不查 isDark
cell.layer.borderColor = borderColor.CGColor;
```

- 用户设置的颜色**只有一个**，不分深浅
- 仅当 `colorFromHex:` 返回 nil（没设置）时 fallback 会区分 isDark
- 但只要用户设过一个颜色，浅色值就在深色下被硬用
- **两条独立的 Border 路径（列表 cell 边框 + 资料卡边框）都不分深浅**

### 3.3 `listCardBgColor` — 无暗色支持

```objc
// ProfileCardBgHook.m L595
UIColor *cardBg = [cfg colorFromHex:cfg.listCardBgColor];  // ❌ 不查 isDark
```

- 该属性只有单值，且设置页传入 `darkKey:nil`
- 资料卡背景无图片时 fallback 的单色背景，深色模式下仍用浅色值（默认 `#FFFFFF`）

### 3.4 `listProfileCardBorderColor` — 无人使用（疑似死代码）

- PluginConfig.h L171 有 `@property`
- PluginConfig.m L453-L454 有加载，L693 有保存
- SettingListCornerRadiusController L200-L205 有 `addColorRowInGroup` UI 行
- 但所有 Hook 文件（ListCornerRadiusHook、ProfileCardBgHook 等）均**未读取此属性**
- 实际资料卡边框颜色走的是 `listCellBorderColor`

### 3.5 `placeholderTextColorHex` — 无暗色支持

```objc
// PlaceholderTextHook.m L100
NSString *hexColor = config.placeholderTextColorHex;    // ❌ 不查 isDark
UIColor *color = hexColor.length ? [config colorFromHex:hexColor] : nil;
```

- 单色，无论深浅都使用相同占位文本颜色

### 3.6 `messageTimeTextColor` — 死代码

| 位置 | 代码 |
|------|------|
| PluginConfig.h L51 | `@property (nonatomic, copy) NSString *messageTimeTextColor;` |
| PluginConfig.m L196-L201 | 加载 UserDefaults，默认值 `#999999` |
| PluginConfig.m L584-L586 | 保存到 UserDefaults |
| 任何 Hook 文件 | **不存在任何读取** |

消息时间的文字颜色实际使用 `senderTextColorHex` / `receiverTextColorHex`（区分发送方/接收方，且区分深浅）。`messageTimeTextColor` 是一个废弃的属性，可安全删除。
