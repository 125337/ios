# 常用功能 - 折叠展开项改为二级页面 改造方案

## 现状分析

当前 [SettingGeneralFunctionController](file:///www/wwwroot/ios/WeChatPlugin/Settings/Controllers/SettingGeneralFunctionController.m) 中：

| 行号 | 类型 | 内容 |
|------|------|------|
| 38-44 | 单独开关 | 启用消息防撤回 |
| 48-54 | 单独开关 | 启用一键已读消息 |
| 58-64 | 单独开关 | 启用修改文字(小丑功能) |
| 68-74 | 单独开关 | 启用退群检测 |
| **81-112** | **总开关+折叠展开** | **显示消息时间**（展开后包含 **12 项**配置） |
| 115-121 | 单独开关 | 隐藏聊天时间分隔线 |

### 问题

"显示消息时间"使用 `addMasterSwitchRowInGroup:subBuilder:` 模式，展开后包含 **12 行**配置项：
- 显示位置（选择器）
- 字体大小（输入框）
- 粗体字体（开关）
- 自定义格式（跳转编辑页）
- 发送方颜色（颜色选择）
- 发送方颜色(深色)（颜色选择）
- 接收方颜色（颜色选择）
- 接收方颜色(深色)（颜色选择）
- 水平偏移（输入框）
- 垂直偏移（输入框）
- 气泡扩展宽度（输入框）

折叠/展开导致页面很长，体验不佳。

---

## 改造目标

1. "显示消息时间"入口改为**可点击行**（带箭头 `›`），右侧显示**状态预览**（`已开启` / `已关闭`）
2. 点击后 push 进入 **`SettingMessageTimeController`** 二级页面，里面包含总开关 + 所有 12 项详细配置
3. 开启/关闭总开关时：入口行状态预览实时更新，二级页面内的子配置项也会随之折叠/展开
4. 仅改造"显示消息时间"一项，其余短配置项保持不变

## 详细设计

### 一、SettingMessageTimeController（二级页面）

**页面标题**：`消息时间设置`

**页面结构**：

```
┌─────────────────────────────────────┐
│  启用消息时间显示          [开关]   │  ← 总开关
├─────────────────────────────────────┤
│  显示位置         头像下方      ›   │  ← 点击弹选择器
├─────────────────────────────────────┤
│  字体大小                 [输入]   │
├─────────────────────────────────────┤
│  粗体字体                 [开关]   │
├─────────────────────────────────────┤
│  自定义格式    {HH}:{mm}:{ss}   ›   │  ← 点击跳编辑页
├─────────────────────────────────────┤
│  发送方颜色              (●圆圈)   │
├─────────────────────────────────────┤
│  发送方颜色(深色)        (●圆圈)   │
├─────────────────────────────────────┤
│  接收方颜色              (●圆圈)   │
├─────────────────────────────────────┤
│  接收方颜色(深色)        (●圆圈)   │
├─────────────────────────────────────┤
│  水平偏移                 [输入]   │
├─────────────────────────────────────┤
│  垂直偏移                 [输入]   │
├─────────────────────────────────────┤
│  气泡扩展宽度             [输入]   │
└─────────────────────────────────────┘
```

**逻辑**：
- 继承 `SettingCategoryController`，直接复用 `buildUI` 方法体系
- 总开关用 `addMasterSwitchRowInGroup:subBuilder:` 保留折叠/展开行为（只在二级页面内生效）
- `onMessageTimePositionTap` / `onMessageTimeCustomFormatTap` 方法从 `SettingGeneralFunctionController` **移动**到这里
- 关闭总开关时，12 项子配置不显示（和原先 Primary 页面折叠效果一致）
- 回到一级页面时，状态预览自动更新

### 二、SettingGeneralFunctionController 改造

**改造前**（第 78-123 行）：
```objc
UIView *timeGroup = [self addTableGroupAtY:y width:w];
CGFloat timeY = 0;

timeY = [self addMasterSwitchRowInGroup:timeGroup
                                    title:@"显示消息时间"
                                      key:@"ShowMessageTime"
                                     isOn:config.showMessageTime
                               subBuilder:^(UIView *expand, CGFloat *ecy) {
    // ... 12行配置 ...
} cy:timeY width:w];

timeY = [self addSeparatorInGroup:timeGroup cy:timeY width:w];
timeY = [self addSwitchRowInGroup:timeGroup title:@"隐藏聊天时间分隔线" ...];
y = [self finishGroup:timeGroup atY:y height:timeY];
```

**改造后**：
```objc
UIView *timeGroup = [self addTableGroupAtY:y width:w];
CGFloat timeY = 0;

// 状态预览文字
NSString *timeStatus = config.showMessageTime ? @"已开启" : @"已关闭";
timeY = [self addNavRowInGroup:timeGroup
                         title:@"显示消息时间"
                      subtitle:timeStatus
                           tag:300
                        action:@selector(onMessageTimeSettingTap)
                            cy:timeY
                         width:w];

timeY = [self addSeparatorInGroup:timeGroup cy:timeY width:w];
timeY = [self addSwitchRowInGroup:timeGroup title:@"隐藏聊天时间分隔线" ...];
y = [self finishGroup:timeGroup atY:y height:timeY];
```

**新增方法**：
```objc
- (void)onMessageTimeSettingTap {
    SettingMessageTimeController *vc = [[SettingMessageTimeController alloc] init];
    vc.categoryName = @"消息时间设置";
    [self.navigationController pushViewController:vc animated:YES];
}
```

**移除方法**（移动到 SettingMessageTimeController）：
- `onMessageTimePositionTap`
- `onMessageTimeCustomFormatTap`
- `positionName:`

## 改造前后对比

| 维度 | 改造前 | 改造后 |
|------|--------|--------|
| 常用功能页面行数 | ~15 行（含展开项） | ~7 行 |
| "显示消息时间"交互 | 点击开关 → 展开/折叠 | 点击整行 → 进入二级页面 |
| 状态可见性 | 需要展开才看到总开关 | 右侧直接显示"已开启"/"已关闭" |
| 总开关位置 | 在折叠区域顶部 | 在二级页面顶部 |
| 代码复用 | 折叠逻辑耦合在一级页面 | 二级页面独立，复用基类 buildUI |

## 后续扩展

此方案形成模式后，其他页面（红包设置、其他功能等）如有类似长配置项，可参照相同方式改造：
1. 一级页面入口用 `addNavRowInGroup:subtitle:action:`，subtitle 为状态预览
2. 新建 `SettingXxxController` 继承 `SettingCategoryController`
3. 二级页面内继续用 `addMasterSwitchRowInGroup:subBuilder:` 保留折叠
