## Step 2: 实现 Hook 核心逻辑

### 2.1 Hook 会话 Cell 的右滑（trailing）手势配置

**目标**: 在微信会话列表 Cell 的 **trailing swipe（从右往左滑）** 侧，独立添加 `[免打扰] [备注] [置顶]` 三个按钮。与微信原生 leading swipe（从左往右的「标为已读」「不显示」「删除」）**互不干扰**。

> **微信滑动方向说明**（基于反编译代码 + 用户实际使用确认）:
> - **从左往右滑**（leading swipe）→ 微信原生显示「标为已读」「不显示」「删除」→ **不受影响**
> - **从右往左滑**（trailing swipe）→ 微信助手显示「免打扰」「备注」「置顶」→ **本功能 Hook 位置**
> - 两个方向**完全独立**，互不叠加

**Hook 目标分析**（来自微信助手反编译代码 [FUN_007f61c4](file:///www/wwwroot/ios/插件/微信助手反编译/wxzs%203.9-5.dylib.c#L654623)):

```c
// FUN_007f61c4 是微信助手替换的 swipe 配置方法
// 签名: (id self, SEL _cmd, UITableView *tableView, NSIndexPath *indexPath)
// 内部逻辑:
//   1. self (param_1) 通过 valueForKey: 获取会话管理器
//      例: [self valueForKey:@"m_sessionMgr"] 或类似属性
//   2. 调用 [sessionMgr getSessionInfoAtIndexPath:indexPath] 获取会话对象
//   3. 通过 [contactMgr getContactByName:userName] 获取 CContact
//   4. 检查 isContactSessionTop / isChatStatusNotifyOpen 确定按钮文字
//   5. 构建 3 个 UIContextualAction + 原生 actions → UISwipeActionsConfiguration
```

**需要 Hook 的类和方法**:

微信会话列表由 `NewMainFrameViewController`（或 `MMMainFrameViewController`）管理，该类实现了 `UITableViewDelegate` 协议。iOS 11+ 通过以下方法提供 trailing swipe：

```objc
- (UISwipeActionsConfiguration *)tableView:(UITableView *)tableView
    trailingSwipeActionsConfigurationForRowAtIndexPath:(NSIndexPath *)indexPath;
```

**Hook 策略**: 使用 `MSHookMessageEx` Hook 该方法。如果微信原生已在此方法返回按钮（某些版本可能有），则在原生 actions 前插入我们的按钮；如果原生返回 nil 或空数组，则直接返回只包含我们三个按钮的配置。

**具体实施逻辑**（伪代码）:

```objc
static IMP orig_trailingSwipeActionsConfig = NULL;

static id replaced_trailingSwipeActionsConfig(id self, SEL _cmd, 
    UITableView *tableView, NSIndexPath *indexPath) {
    
    // 1. 先调用原始方法获取微信原生的 trailing 滑动配置（可能为 nil）
    id origConfig = orig_trailingSwipeActionsConfig 
        ? ((id (*)(id, SEL, id, id))orig_trailingSwipeActionsConfig)(self, _cmd, tableView, indexPath)
        : nil;
    
    // 2. 检查功能开关
    if (![PluginConfig shared].quickActionsEnabled) {
        return origConfig;
    }
    
    // 3. 获取当前 Cell 对应的会话信息
    //    参考反编译代码: self → valueForKey → sessionMgr → getSessionInfoAtIndexPath:
    id sessionInfo = /* 从 self/tableView 获取对应 indexPath 的会话 */;
    NSString *userName = /* 从会话获取 m_nsUserName */;
    id contact = WXGetContactForWxid(userName);
    if (!contact) return origConfig;
    
    // 4. 查询当前状态（用于动态按钮文字）
    BOOL isTop = /* [contact isContactSessionTop] */;
    BOOL isMuted = /* [contact isChatStatusNotifyOpen] */;
    
    // 5. 构建三个 UIContextualAction
    UIContextualAction *muteAction = ...;  // 灰色, "免打扰"/"取消免打扰"
    UIContextualAction *remarkAction = ...; // 橙色, "备注"
    UIContextualAction *pinAction = ...;    // 红色, "置顶"/"取消置顶"
    
    // 6. 合并: 我们的3个按钮 + 微信原生 trailing 按钮（如果有的话）
    NSArray *ourActions = @[muteAction, remarkAction, pinAction];
    NSArray *origActions = origConfig ? /* origConfig.actions */ : @[];
    NSArray *merged = [ourActions arrayByAddingObjectsFromArray:origActions];
    
    // 7. 返回新配置
    return [UISwipeActionsConfiguration configurationWithActions:merged];
}
```

#### 关键点 — 如何找到正确的 Hook 目标

基于微信助手反编译代码分析，Hook 的核心流程如下：

1. **Hook 目标类**: `NewMainFrameViewController`（微信主界面控制器）
   - 该类通过 `valueForKey:` 持有会话管理器属性
   - 实现了 `getSessionInfoAtIndexPath:` / `logicGetSessionAtIndexPath:` 方法

2. **Hook 目标方法**: `tableView:trailingSwipeActionsConfigurationForRowAtIndexPath:`
   - 这是从右往左滑（trailing side）的配置方法
   - 微信原生可能在此方法返回 nil 或空数组（取决于版本）
   - 我们在原生数组前插入 [免打扰, 备注, 置顶]

3. **获取会话信息的方式**（参考反编译代码 [654771](file:///www/wwwroot/ios/插件/微信助手反编译/wxzs%203.9-5.dylib.c#L654771)):
   ```objc
   // 方式 A: self 直接有 getSessionInfoAtIndexPath:
   [self getSessionInfoAtIndexPath:indexPath];
   
   // 方式 B: 通过 valueForKey 获取 m_sessionMgr
   id sessionMgr = [self valueForKey:@"m_sessionMgr"];
   [sessionMgr getSessionInfoAtIndexPath:indexPath];
   ```

> **注意**: 实际属性名需要在运行时通过 LLDB `po [self valueForKey:...]` 或 `class_copyIvarList` 确认。反编译代码中的 key 字符串是 XOR 混淆的，无法直接读取。

**推荐调试步骤**:
1. 运行时 Hook `NewMainFrameViewController` 的 `viewDidLoad` 或 `viewDidAppear`
2. 打印 `[self valueForKey:@"m_sessionMgr"]` 等可能的 key
3. 用 `class_copyIvarList` 列出所有 ivar，找到持有一组会话的 ivar 名
4. 确认后 Hook `trailingSwipeActionsConfigurationForRowAtIndexPath:`

#### 获取会话对象的正确方法

基于微信助手反编译代码分析（[654771](file:///www/wwwroot/ios/插件/微信助手反编译/wxzs%203.9-5.dylib.c#L654771)），获取会话信息的流程：

```objc
// self 是 NewMainFrameViewController 实例，也是 UITableViewDelegate

// 方式 A: self 上直接调用（推荐先试）
id sessionInfo = [self getSessionInfoAtIndexPath:indexPath];
// 或
id sessionInfo = [self logicGetSessionAtIndexPath:indexPath];

// 方式 B: 通过 valueForKey 获取内部会话管理器
// （key 字符串在反编译代码中是 XOR 混淆的，运行时确认）
id sessionMgr = [self valueForKey:@"m_sessionMgr"];
id sessionInfo = [sessionMgr getSessionInfoAtIndexPath:indexPath];

// 从 sessionInfo 获取 userName
NSString *userName = [sessionInfo valueForKey:@"m_nsUserName"];
// 获取 CContact
id contact = WXGetContactForWxid(userName);
```

> **运行时确认步骤**: 在 `replaced_trailingSwipeActionsConfig` 函数中临时加入:
> ```objc
> WPLog(@"QuickActions", @"[DEBUG] self class: %@", [self class]);
> WPLog(@"QuickActions", @"[DEBUG] responds to getSessionInfoAtIndexPath: %d",
>     [self respondsToSelector:@selector(getSessionInfoAtIndexPath:)]);
> WPLog(@"QuickActions", @"[DEBUG] responds to logicGetSessionAtIndexPath: %d",
>     [self respondsToSelector:NSSelectorFromString(@"logicGetSessionAtIndexPath:")]);
> ```

### 2.2 实现三个操作按钮

#### 2.2.1 免打扰按钮

**按钮文字**: 根据 `isChatStatusNotifyOpen` 动态显示 "免打扰"（通知当前开启）或 "取消免打扰"（通知当前关闭）

**背景颜色**: 灰色 (`[UIColor grayColor]`)

**执行逻辑**:

```objc
// 1. 获取当前免打扰状态
BOOL isMuted = [contact respondsToSelector:NSSelectorFromString(@"isChatStatusNotifyOpen")]
    ? ((BOOL (*)(id, SEL))objc_msgSend)(contact, NSSelectorFromString(@"isChatStatusNotifyOpen"))
    : 1;

// 2. 翻转状态
BOOL newStatus = !isMuted;

// 3. 调用微信原生 API
id contactMgr = WXGetService(objc_getClass("CContactMgr"));
if (contactMgr) {
    SEL changeNotifySel = NSSelectorFromString(@"ChangeNotifyStatus:withStatus:sync:");
    if ([contactMgr respondsToSelector:changeNotifySel]) {
        ((void (*)(id, SEL, id, BOOL, BOOL))objc_msgSend)(contactMgr, changeNotifySel, contact, newStatus, YES);
    }
}

// 4. 同步本地状态
SEL setNotifySel = NSSelectorFromString(@"setChatStatusNotifyOpen:");
if ([contact respondsToSelector:setNotifySel]) {
    ((void (*)(id, SEL, BOOL))objc_msgSend)(contact, setNotifySel, newStatus);
}

// 5. Toast 提示
NSString *tip = newStatus ? @"已开启免打扰" : @"已取消免打扰";
WPLog(@"QuickActions", @"[INFO] mute: %@ -> %@", userName, tip);
```

**错误处理**: 如果微信 API 调用失败，不显示 Toast，静默失败。

#### 2.2.2 备注按钮

**按钮文字**: 固定 "备注"

**背景颜色**: 橙色 (`[UIColor orangeColor]`)

**执行逻辑**: 直接打开微信原生 ContactInfoViewController 并进入编辑模式：

```objc
// 1. 完成滑动动画（completion(YES) 接收来自 block 的 completion 参数）

// 2. 获取当前最上层的 ViewController
UIViewController *topVC = /* 获取当前 topViewController */;

// 3. 创建 ContactInfoViewController
Class contactInfoVCClass = objc_getClass("ContactInfoViewController");
if (!contactInfoVCClass) return;

id contactInfoVC = [contactInfoVCClass alloc];
((void (*)(id, SEL))objc_msgSend)(contactInfoVC, @selector(init));

// 4. 传入联系人
SEL setContactSel = NSSelectorFromString(@"setM_contact:");
if ([contactInfoVC respondsToSelector:setContactSel]) {
    ((void (*)(id, SEL, id))objc_msgSend)(contactInfoVC, setContactSel, contact);
}

// 5. 设置编辑状态（关键：直接进入编辑模式）
SEL setNeedEditSel = NSSelectorFromString(@"setNeedEditState:");
if ([contactInfoVC respondsToSelector:setNeedEditSel]) {
    ((void (*)(id, SEL, BOOL))objc_msgSend)(contactInfoVC, setNeedEditSel, YES);
}

// 6. Push 到 NavigationController
UINavigationController *nav = [[UINavigationController alloc] initWithRootViewController:contactInfoVC];
[(UIViewController *)topVC presentViewController:nav animated:YES completion:nil];
```

**获取 topViewController 的方法**:

```objc
static UIViewController *getTopViewController(void) {
    UIWindow *keyWindow = nil;
    if (@available(iOS 13.0, *)) {
        for (UIWindowScene *scene in [UIApplication sharedApplication].connectedScenes) {
            if (scene.activationState == UISceneActivationStateForegroundActive) {
                keyWindow = scene.windows.firstObject;
                break;
            }
        }
    }
    if (!keyWindow) {
        keyWindow = [UIApplication sharedApplication].keyWindow;
    }
    UIViewController *topVC = keyWindow.rootViewController;
    while (topVC.presentedViewController) {
        topVC = topVC.presentedViewController;
    }
    return topVC;
}
```

**备选方案**: 如果 `ContactInfoViewController` 在微信新版本中改名，使用字符串动态获取:
```objc
Class cls = NSClassFromString(@"ContactInfoViewController");
```

#### 2.2.3 置顶按钮

**按钮文字**: 根据 `isContactSessionTop` 动态显示 "置顶"（当前未置顶）或 "取消置顶"（当前已置顶）

**背景颜色**: 红色 (`[UIColor redColor]`)

**执行逻辑**:

    ? ((BOOL (*)(id, SEL))objc_msgSend)(contact, NSSelectorFromString(@"isContactSessionTop"))
    : NO;

// 3. 调用微信原生 API

if (contactMgr) {
    SEL setTopSel = NSSelectorFromString(@"setContact:sessionTop:sync:");
    if ([contactMgr respondsToSelector:setTopSel]) {
        ((void (*)(id, SEL, id, BOOL, BOOL))objc_msgSend)(contactMgr, setTopSel, contact, newTop, YES);
    }

// 4. 直接设置 bIsTop 标记（确保生效）
SEL setBIsTopSel = NSSelectorFromString(@"setM_bIsTop:");
if ([contact respondsToSelector:setBIsTopSel]) {
    ((void (*)(id, SEL, BOOL))objc_msgSend)(contact, setBIsTopSel, newTop);
}

// 5. Toast 提示

WPLog(@"QuickActions", @"[INFO] pin: %@ -> %@", userName, tip);

UIImpactFeedbackGenerator *feedback = [[UIImpactFeedbackGenerator alloc] initWithStyle:UIImpactFeedbackStyleLight];
[feedback impactOccurred];

static void showToast(NSString *text) {
    dispatch_async(dispatch_get_main_queue(), ^{
        UIWindow *window = [UIApplication sharedApplication].keyWindow;
        UILabel *label = [[UILabel alloc] init];
        label.text = text;
        label.textAlignment = NSTextAlignmentCenter;
        label.font = [UIFont systemFontOfSize:14];
        label.textColor = [UIColor whiteColor];
        label.backgroundColor = [[UIColor blackColor] colorWithAlphaComponent:0.7];
        label.layer.cornerRadius = 8;
        label.clipsToBounds = YES;
        [label sizeToFit];
        CGFloat w = label.frame.size.width + 30;
        CGFloat h = label.frame.size.height + 16;
        CGFloat x = (window.bounds.size.width - w) / 2;
        CGFloat y = window.bounds.size.height - 200;

            [label removeFromSuperview];
        });
    });

### 2.3 完整 install 方法

```objc
@implementation QuickActionsHook

+ (void)install {
    WPLog(@"QuickActions", @"[INFO] install start");
    
    // Hook 会话列表的 trailing swipe 配置
    // Hook 目标: NewMainFrameViewController 或 MMMainFrameViewController
    // Hook 方法: tableView:trailingSwipeActionsConfigurationForRowAtIndexPath:
    
    Class targetClass = objc_getClass("NewMainFrameViewController");
    if (targetClass) {
        SEL targetSel = @selector(tableView:trailingSwipeActionsConfigurationForRowAtIndexPath:);
        if ([targetClass instancesRespondToSelector:targetSel]) {
            MSHookMessageEx(targetClass, targetSel, 
                (IMP)replaced_trailingSwipeActionsConfig, 
                &orig_trailingSwipeActionsConfig);
            WPLog(@"QuickActions", @"[INFO] trailing swipe hooked on NewMainFrameViewController");
        }
    }
    
    // 如果 NewMainFrameViewController 未找到，尝试 MMMainFrameViewController
    if (!targetClass) {
        targetClass = objc_getClass("MMMainFrameViewController");
        if (targetClass) {
            SEL targetSel = @selector(tableView:trailingSwipeActionsConfigurationForRowAtIndexPath:);
            if ([targetClass instancesRespondToSelector:targetSel]) {
                MSHookMessageEx(targetClass, targetSel,
                    (IMP)replaced_trailingSwipeActionsConfig,
                    &orig_trailingSwipeActionsConfig);
                WPLog(@"QuickActions", @"[INFO] trailing swipe hooked on MMMainFrameViewController");
            }
        }
    }
    
    WPLog(@"QuickActions", @"[INFO] install complete");
}

@end
```

| 5. 取消免打扰 | 对已免打扰的会话点击"取消免打扰" | 取消免打扰，Toast 提示"已取消免打扰" |
| 6. 备注按钮 | 点击"备注"按钮 | 弹出微信原生联系人资料页并直接进入备注编辑状态 |
| 7. 置顶按钮 | 点击"置顶"按钮 | 该会话被置顶，按钮文字变为"取消置顶"，Toast 提示"已置顶"，触发触觉反馈 |
| 8. 取消置顶 | 对已置顶的会话点击"取消置顶" | 取消置顶，Toast 提示"已取消置顶" |
| 9. 按钮顺序 | 从右往左滑任意 Cell | 从左到右: 免打扰(灰) → 备注(橙) → 置顶(红) |
| 10. 触觉反馈 | 点击任意快捷按钮 | 感受到轻微震动反馈 |

### 4.4 常见问题排查

| 问题 | 可能原因 | 排查方法 |
|------|----------|----------|
| 开关开启后右滑无反应 | Hook 目标类/方法名不正确 | 1. 确认 `NewMainFrameViewController` 类是否存在<br>2. 确认是否实现了 `trailingSwipeActionsConfiguration` 方法<br>3. 运行调试代码打印方法列表 |
| 按钮出现但点击无反应 | 微信 API 方法名变化 | 检查 `isContactSessionTop` / `setContact:sessionTop:sync:` 等 selector 在当前版本是否存在 |
| 获取不到 contact 对象 | Cell 内部属性名变化 | 打印 Cell 的所有 ivar，确认存储 contact 的属性名 |
| 编译报错 | 缺少头文件导入 | 确认 `substrate.h` 和 `ServiceHelper.h` 路径正确 |
