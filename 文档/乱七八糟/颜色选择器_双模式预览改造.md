# 颜色选择器 · 双模式预览改造

## 现状

目前颜色选择器虽然支持亮色/深色双模式（通过 `currentLightHex` / `currentDarkHex`），但在 UI 上只有一个颜色预览块：

```
  ┌────────────────────────────────┐
  │  ○ 浅色   ○ 深色               │  ← 模式切换
  │  ┌────────────────────────────┐│
  │  │      当前模式色块           ││  ← 只显示一个颜色
  │  └────────────────────────────┘│
  │  色相条 / S/B 面板 / RGBA ...  │
  └────────────────────────────────┘
```

切换模式时预览块才跟着变，无法同时看到**两个颜色在一起的效果**。

## 改造目标

```
  ┌────────────────────────────────┐
  │  ○ 浅色   ○ 深色               │  ← 当前编辑哪个模式
  │  ┌──────────┐ ┌──────────┐     │
  │  │ #FFFFFF  │ │ #202020  │     │  ← 两个颜色始终同时显示
  │  │  浅色预览  │ │  深色预览  │    │
  │  └──────────┘ └──────────┘     │
  │  色相条 / S/B 面板 / RGBA ...  │
  └────────────────────────────────┘
```

- 两个预览块**始终并排显示**当前浅色和深色值
- 点击哪个预览块，模式就切换到哪个（选中的加边框高亮）
- Segmented control 和预览块同步
- 单色模式下只显示一个预览块

## 改动计划

### 改动 1：Header — 替换 `colorDisplayView`

```diff
- @property (nonatomic, strong) UIView *colorDisplayView;             // 颜色预览块
+ @property (nonatomic, strong) UIView *lightPreviewView;   // ★ 新增：浅色预览块
+ @property (nonatomic, strong) UIView *darkPreviewView;    // ★ 新增：深色预览块
```

### 改动 2：`setupUI` — 创建两个预览块

```diff
-     // ─── 颜色预览 ───
-     self.colorDisplayView = [[UIView alloc] init];
-     self.colorDisplayView.layer.cornerRadius = 8;
-     self.colorDisplayView.layer.borderWidth = 1;
-     self.colorDisplayView.layer.borderColor = [UIColor separatorColor].CGColor;
-     [self.contentView addSubview:self.colorDisplayView];
+     // ─── 双颜色预览 ───

```

新增方法：

```objc
/// 创建双模式预览块
- (void)setupDualPreviewViews {
    __weak __typeof(self) weakSelf = self;

    // ─── 浅色预览 ───
    self.lightPreviewView = [[UIView alloc] init];
    self.lightPreviewView.layer.cornerRadius = 8;
    self.lightPreviewView.layer.borderWidth = self.isLightMode ? 2.5 : 0.5;
    self.lightPreviewView.layer.borderColor = self.isLightMode
        ? [UIColor systemBlueColor].CGColor : [UIColor separatorColor].CGColor;
    self.lightPreviewView.userInteractionEnabled = !self.singleColorMode;
    [self.contentView addSubview:self.lightPreviewView];

    // ─── 浅色标签 ───
    UILabel *lightLabel = [[UILabel alloc] init];
    lightLabel.text = @"浅色";
    lightLabel.font = [UIFont systemFontOfSize:11 weight:UIFontWeightMedium];
    lightLabel.textColor = [UIColor secondaryLabelColor];
    lightLabel.textAlignment = NSTextAlignmentCenter;
    lightLabel.translatesAutoresizingMaskIntoConstraints = NO;
    [self.lightPreviewView addSubview:lightLabel];

    // ─── 深色预览 ───
    self.darkPreviewView = [[UIView alloc] init];
    self.darkPreviewView.layer.cornerRadius = 8;
    self.darkPreviewView.layer.borderWidth = self.isLightMode ? 0.5 : 2.5;
    self.darkPreviewView.layer.borderColor = self.isLightMode
        ? [UIColor separatorColor].CGColor : [UIColor systemBlueColor].CGColor;
    self.darkPreviewView.userInteractionEnabled = !self.singleColorMode;
    [self.contentView addSubview:self.darkPreviewView];

    // ─── 深色标签 ───
    UILabel *darkLabel = [[UILabel alloc] init];
    darkLabel.text = @"深色";
    darkLabel.font = [UIFont systemFontOfSize:11 weight:UIFontWeightMedium];
    darkLabel.textColor = [UIColor secondaryLabelColor];
    darkLabel.textAlignment = NSTextAlignmentCenter;
    darkLabel.translatesAutoresizingMaskIntoConstraints = NO;
    [self.darkPreviewView addSubview:darkLabel];

    // ─── 点击手势 ───
    if (!self.singleColorMode) {
        UITapGestureRecognizer *lightTap = [[UITapGestureRecognizer alloc]
            initWithTarget:self action:@selector(previewTapped:)];
        [self.lightPreviewView addGestureRecognizer:lightTap];

        UITapGestureRecognizer *darkTap = [[UITapGestureRecognizer alloc]
            initWithTarget:self action:@selector(previewTapped:)];
        [self.darkPreviewView addGestureRecognizer:darkTap];
    }

    // ─── 存储标签引用（更新 hex 文字用） ───
    self.lightPreviewView.tag = 100;
    self.darkPreviewView.tag = 200;
    lightLabel.tag = 101;
    darkLabel.tag = 201;
}
```

### 改动 3：点击预览 → 切换编辑模式

```objc
/// 点击预览块切换编辑模式
- (void)previewTapped:(UITapGestureRecognizer *)tap {
    if (self.singleColorMode) return;

    BOOL tapLight = tap.view == self.lightPreviewView;
    if (tapLight == self.isLightMode) return;  // 已经是该模式

    // 保存当前编辑
    [self updateColorFromComponents];

    // 切换模式
    self.isLightMode = tapLight;
    self.modeSegmentedControl.selectedSegmentIndex = self.isLightMode ? 0 : 1;

    // 刷新预览边框
    [self updatePreviewSelectionState];

    // 加载切换后模式的颜色
    [self updateCurrentColorFromHex];
}
```

辅助方法：

```objc
/// 刷新两个预览块的选中边框
- (void)updatePreviewSelectionState {
    if (self.singleColorMode) return;

    if (self.isLightMode) {
        self.lightPreviewView.layer.borderWidth = 2.5;
        self.lightPreviewView.layer.borderColor = [UIColor systemBlueColor].CGColor;
        self.darkPreviewView.layer.borderWidth = 0.5;
        self.darkPreviewView.layer.borderColor = [UIColor separatorColor].CGColor;
    } else {
        self.darkPreviewView.layer.borderWidth = 2.5;
        self.darkPreviewView.layer.borderColor = [UIColor systemBlueColor].CGColor;
        self.lightPreviewView.layer.borderWidth = 0.5;
        self.lightPreviewView.layer.borderColor = [UIColor separatorColor].CGColor;
    }
}
```

```diff

+     self.lightPreviewView.backgroundColor = [WPColorUtil colorFromHexString:self.currentLightHex];
+     self.darkPreviewView.backgroundColor = [WPColorUtil colorFromHexString:self.currentDarkHex];
+
+     // 更新预览块上的 hex 文字
+     [self updatePreviewHexLabels];
  }
```

新增方法：

```objc
/// 在预览块上显示当前 hex 值
- (void)updatePreviewHexLabels {
    UILabel *lightLabel = [self.lightPreviewView viewWithTag:101];
    UILabel *darkLabel = [self.darkPreviewView viewWithTag:201];
    lightLabel.text = self.currentLightHex;
    darkLabel.text = self.currentDarkHex;
}
```

### 改动 6：约束 — 两个预览块并排

```diff
-     // 5. 颜色预览
-     layout(self.colorDisplayView, 44);
+     // 5. 双颜色预览
+     [self setupDualPreviewConstraints];
```

新增方法：

```objc
- (void)setupDualPreviewConstraints {
    self.lightPreviewView.translatesAutoresizingMaskIntoConstraints = NO;
    self.darkPreviewView.translatesAutoresizingMaskIntoConstraints = NO;

    CGFloat gap = 12;
    CGFloat halfWidth = (self.contentView.bounds.size.width - kMargin * 2 - gap) * 0.5;
    // ⚠️ 因为 contentView 的 bounds 在 viewDidLoad 中不确定，
    //    用宽度等式约束来算，不依赖运行时值

    [NSLayoutConstraint activateConstraints:@[
        // 浅色预览
        [self.lightPreviewView.topAnchor constraintEqualToAnchor:prev.bottomAnchor constant:12],
        [self.lightPreviewView.leadingAnchor constraintEqualToAnchor:cv.leadingAnchor constant:kMargin],
        [self.lightPreviewView.trailingAnchor constraintEqualToAnchor:self.darkPreviewView.leadingAnchor
                                                            constant:-gap],
        [self.lightPreviewView.heightAnchor constraintEqualToConstant:60],

        // 深色预览
        [self.darkPreviewView.topAnchor constraintEqualToAnchor:self.lightPreviewView.topAnchor],
        [self.darkPreviewView.trailingAnchor constraintEqualToAnchor:cv.trailingAnchor constant:-kMargin],
        [self.darkPreviewView.widthAnchor constraintEqualToAnchor:self.lightPreviewView.widthAnchor],
        [self.darkPreviewView.heightAnchor constraintEqualToAnchor:self.lightPreviewView.heightAnchor],

        // 标签（居中于各自预览块）
        [[self.lightPreviewView viewWithTag:101].centerXAnchor
            constraintEqualToAnchor:self.lightPreviewView.centerXAnchor],
        [[self.lightPreviewView viewWithTag:101].centerYAnchor
            constraintEqualToAnchor:self.lightPreviewView.centerYAnchor],
        [[self.darkPreviewView viewWithTag:201].centerXAnchor
            constraintEqualToAnchor:self.darkPreviewView.centerXAnchor],
        [[self.darkPreviewView viewWithTag:201].centerYAnchor
            constraintEqualToAnchor:self.darkPreviewView.centerYAnchor],
    ]];

    prev = self.lightPreviewView;
}
```

### 改动 7：单色模式兼容

单色模式 (`singleColorMode = YES`) 时只需一个预览块。在 `setupUI` 中判断：

```diff
+     if (self.singleColorMode) {
+         // 单色模式：一个预览块，等价于旧 behavior
+         self.lightPreviewView = [[UIView alloc] init];
+         self.lightPreviewView.layer.cornerRadius = 8;
+         self.lightPreviewView.layer.borderWidth = 1;
+         self.lightPreviewView.layer.borderColor = [UIColor separatorColor].CGColor;
+         self.lightPreviewView.userInteractionEnabled = NO;
+         [self.contentView addSubview:self.lightPreviewView];
+
+         // 约束：全宽
+         // 在 setupDualPreviewConstraints 中处理
+     } else {
+         [self setupDualPreviewViews];
+     }
```

## 验证

| 步骤 | 预期 |
|------|------|
| `singleColorMode = YES` | 显示一个全宽预览块，无边框高亮 |
| `singleColorMode = NO`（双模式） | 两个预览块并排，浅色/深色各自显示 |
| 点击浅色预览 | 浅色预览蓝色边框，编辑区加载浅色值 |
| 点击深色预览 | 深色预览蓝色边框，编辑区加载深色值 |
| 拖拽色相条 | 当前编辑模式的 hex 实时变化，对应预览块同步变色 |
| 切换 segmented control | 预览边框同步更新，编辑区同步切换 |
| 确认回调 | `callback(lightHex, darkHex)` 两个值都是最新编辑结果 |
