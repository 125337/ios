# 隐藏箭码 — 改造：统一为状态隐藏风格

> **目标：** 将箭码隐藏从「独立 guard-wrap 风格」改造为「集中参数化风格」，与状态隐藏保持一致

---

## 改造前后对照

### 改前（改造前箭码）

```
replaced_MMUIButton_layoutSubviews:
  ├── handleArrowQRHiding:              ← 独立调用点
  │   └── if (myPageHideArrow)
  │       └── hideArrowQRInCell:        ← 无参数，永远 hidden=YES
  │
  └── handleButtonLayout:
      ├── hideStateElementsInCell:shouldHide:  ← 集中调用，有参数
      ├── guards
      ├── handleHiddenPath:
      │   ├── Scene B: if (myPageHideArrow) hideArrowQRInCell:
      │   └── Scene A: if (myPageHideArrow) hideArrowQRInCell:
      └── ...
```

### 改后（统一风格）

```
replaced_MMUIButton_layoutSubviews:
  └── handleButtonLayout:              ← 唯一入口
      ├── hideStateElementsInCell:shouldHide:   ← 集中调用
      ├── hideArrowQRInCell:shouldHide:         ← 集中调用
      ├── guards
      ├── handleHiddenPath:
      │   ├── Scene B: hideArrowQRInCell:shouldHide:YES
      │   └── Scene A: hideArrowQRInCell:shouldHide:YES
      └── ...
```

## 修改步骤

### 修改 ① — ListCornerRadiusHook.m · 移除独立调用

删除 [ListCornerRadiusHook.m L124-L126](file:///www/wwwroot/ios/MioPlugin/Modules/ListCornerRadius/ListCornerRadiusHook.m#L124-L126)：

```objc
// 改前：
    // ★ 独立功能：箭码隐藏（不受资料卡片美化总开关保护）
    [ProfileCardBgHook handleArrowQRHiding:(UIView *)self];

// 改后：
    // (删掉，合并到 handleButtonLayout 统一处理)
```

### 修改 ② — ProfileCardBgHook.m · 修改 hideArrowQRInCell 方法签名

将 [L121-L127](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L121-L127) 的参数改为 `shouldHide`，加入透明度重置：

```objc
// 改前：
+ (void)hideArrowQRInCell:(UIView *)cell {
    for (UIView *sub in cell.subviews) {
        if ([self isArrowQRView:sub]) {
            sub.hidden = YES;
        }
    }
}

// 改后：
+ (void)hideArrowQRInCell:(UIView *)cell shouldHide:(BOOL)shouldHide {
    if (!cell) return;
    for (UIView *sub in cell.subviews) {
        if ([self isArrowQRView:sub]) {
            sub.hidden = shouldHide;
            sub.alpha = 1.0;
            sub.layer.opacity = 1.0;
        }
    }
}
```

### 修改 ③ — ProfileCardBgHook.m · 在 handleButtonLayout 添加集中调用

在 [handleButtonLayout L656-L658](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L656-L658) 之后追加箭码调用（和状态隐藏同一位置，都在守卫之前）：

```objc
// 改前（L656-658）：
    // ☆ 独立功能：状态隐藏（不受总开关保护）
    [ProfileCardBgHook hideStateElementsInCell:button
                                   shouldHide:config.cardBgHideStateEnabled];

// 改后：
    // ☆ 独立功能：状态隐藏（不受总开关保护）
    [ProfileCardBgHook hideStateElementsInCell:button
                                   shouldHide:config.cardBgHideStateEnabled];

    // ☆ 独立功能：箭码隐藏（不受总开关保护）
    [ProfileCardBgHook hideArrowQRInCell:button
                              shouldHide:config.myPageHideArrow];
```

### 修改 ④ — ProfileCardBgHook.m · 删除 handleArrowQRHiding 方法

删除 [L753-L761](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L753-L761) 整个方法：

```objc
// 整个删除：
#pragma mark - 箭码隐藏（独立功能，不受总开关保护）

+ (void)handleArrowQRHiding:(UIView *)button {
    // 守卫交给 handleButtonLayout 处理
    PluginConfig *config = [PluginConfig shared];
    if (config.myPageHideArrow) {
        [ProfileCardBgHook hideArrowQRInCell:button];
    }
}
```

### 修改 ⑤ — ProfileCardBgHook.m · 更新 handleHiddenPath 中的调用

更新 [L786-L788](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L786-L788)（Scene B）和 [L810-L813](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L810-L813)（Scene A）：

```objc
// 改前（Scene B L786-788）：
        if (config.myPageHideArrow) {
            [ProfileCardBgHook hideArrowQRInCell:button];
        }

// 改后：
        // ★ 箭码：强制隐藏（隐藏模式下子视图已被全部隐藏，加调确保覆盖）
        [ProfileCardBgHook hideArrowQRInCell:button shouldHide:YES];
```

```objc
// 改前（Scene A L810-813）：
    // 4. 二维码隐藏
    if (config.myPageHideArrow) {
        [ProfileCardBgHook hideArrowQRInCell:button];
    }

// 改后：
    // ★ 箭码：强制隐藏（隐藏模式下子视图已被全部隐藏，加调确保覆盖）
    [ProfileCardBgHook hideArrowQRInCell:button shouldHide:YES];
```

> **说明：** 隐藏路径中所有子视图已被 `sub.hidden = YES` 覆盖，箭码在此处**实际上已冗余**。但保留清晰的调用可以明确表达意图，且改造统一了风格，所以保留调用但去掉 `if` 包裹，直接传 `YES`。

### 修改 ⑥ — ProfileCardBgHook.h · 更新声明

更新 [ProfileCardBgHook.h](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.h)：
