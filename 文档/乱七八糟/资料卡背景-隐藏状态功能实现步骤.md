> **风格**: 独立方法 + 隐藏箭码风格（无缓存、直接隐藏）

## 0️⃣ 设计思路

采用 **「隐藏箭码风格」**（参考 WCRefine `FUN_0032e7f0`），区别于「隐藏状态按钮」的带缓存细粒度方案：

| 维度 | 箭码风格（本方案采用） | 状态按钮风格（不采用） |
|------|---------------------|---------------------|
| 隐藏方式 | 遍历 subviews，直接 `setHidden:` | 通过 associated object 缓存原始状态 |
| 恢复方式 | 再次遍历传 `NO` | 从缓存读取原始值恢复 |
| alpha/opacity | 顺手重置为 1.0 | 不做处理 |
| 复杂度 | 低，无状态管理 | 高，需维护缓存 |
| 适用场景 | 隐藏后不需要精确恢复原始状态的元素 | 需要精确恢复到隐藏前状态 |

## 3️⃣ 核心隐藏方法

### 3.1 hideStateElementsInCell — 隐藏/恢复状态元素（箭码风格）

```objc
#pragma mark - 状态元素隐藏（箭码风格）

/// 隐藏/恢复资料卡按钮中的所有状态元素
/// 采用「隐藏箭码」风格：直接 setHidden: + 重置 alpha/opacity，无缓存
/// 参考 WCRefine FUN_0032e7f0
///
/// @param cell      资料卡 MMUIButton 实例
/// @param shouldHide YES=隐藏，NO=恢复
+ (void)hideStateElementsInCell:(UIView *)cell shouldHide:(BOOL)shouldHide {
    if (!cell) return;
    
    for (UIView *sub in cell.subviews) {
        // OR 组合匹配：两个精确类名任一个匹配即视为状态元素
        if ([self isStateEntryButton:sub] ||
            [self isStateTopicButton:sub]) {
            
            sub.hidden = shouldHide;
            // ★ 顺手重置透明度，防止其他逻辑残留
            sub.alpha = 1.0;
            sub.layer.opacity = 1.0;
        }
    }
}
```

## 4️⃣ 集成到 handleButtonLayout

箭码是怎么做的？看现有代码：箭码隐藏并没有通过 `handleArrowQRHiding:` 入口调用，而是在 `handleHiddenPath:` 内部直接调 `hideArrowQRInCell:`。所以状态隐藏也一样，不需要额外的入口包装方法。

在 [handleButtonLayout:](file:///www/wwwroot/ios/MioPlugin/Modules/ProfileCardBg/ProfileCardBgHook.m#L618-L640) 的场景路由之后，直接根据配置调用 `hideStateElementsInCell:shouldHide:`：

```objc
+ (void)handleButtonLayout:(UIView *)button {
    // ★ 第1层：总开关守卫
    PluginConfig *config = [PluginConfig shared];
    if (!config.cardBgBeautifyEnabled) return;

    // 通用守卫
    UIViewController *vc = [ProfileCardBgHook findMoreViewController:button];
    if (!vc) return;
    if (![ProfileCardBgHook hasHeadImageViewInView:button]) return;
    if (button.frame.size.height <= 50.0) return;
    BOOL isDark = [ProfileCardBgHook isDarkModeForVc:vc];

    // ★ 场景路由：隐藏 vs 可见
    if (config.cardBgHidden) {
        [ProfileCardBgHook handleHiddenPath:button isDark:isDark];
    } else if (config.cardBgMaterialEnabled || config.cardBgCornerEnabled) {
        [ProfileCardBgHook handleVisiblePath:button isDark:isDark];
    }

    // 独立功能
    [ProfileCardBgHook handleMarginAdjustment:button];
    [ProfileCardBgHook handleCornerAndQR:button isDark:isDark];

    // ★ 状态隐藏（直接调用，不包额外入口）
    [ProfileCardBgHook hideStateElementsInCell:button
                                   shouldHide:config.cardBgHideStateEnabled];
}
```

## 8️⃣ 测试要点

1. **开关独立生效**：`cardBgHideStateEnabled=YES` 时状态元素消失，`NO` 时恢复
2. **不依赖总开关**：`cardBgBeautifyEnabled=NO` + `cardBgHideStateEnabled=YES` 仍应生效（对照 `myPageHideArrow` 行为）
3. **页面回弹**：push/pop 返回后状态保持正确
4. **无损恢复**：关闭开关后各子视图恢复到正常显示状态
5. **不泄漏**：不会意外隐藏头像、昵称、微信号等核心元素（识别器仅匹配特定类名/特征）
