### 3.5 ListCornerRadiusHook.m — 边框颜色暗色适配

**文件：** `/www/wwwroot/ios/MioPlugin/Modules/ListCornerRadius/ListCornerRadiusHook.m`

L730-L740，旧代码：
```objc
    BOOL isDark = NO;
    if (@available(iOS 13.0, *)) {
        isDark = [ListCornerRadiusHook wp_isCurrentDarkMode];
    }

    UIColor *borderColor = [config colorFromHex:config.listCellBorderColor];
    if (!borderColor) {
        borderColor = isDark
            ? [UIColor colorWithRed:0.25 green:0.25 blue:0.25 alpha:1.0]
            : [UIColor colorWithRed:0.9 green:0.9 blue:0.9 alpha:1.0];
    }
```
新代码：
```objc
    BOOL isDark = [config isDarkMode];

    UIColor *borderColor = [config colorFromHex:isDark ? config.listCellBorderColorDarkHex : config.listCellBorderColor];
    if (!borderColor) {
        borderColor = isDark
            ? [UIColor colorWithRed:0.25 green:0.25 blue:0.25 alpha:1.0]
            : [UIColor colorWithRed:0.9 green:0.9 blue:0.9 alpha:1.0];
    }
```

### 5.1 设置页 UI 验证

| 行 | 改造前 | 改造后 |
|---|--------|--------|
| 边框颜色 | 1 个颜色预览按钮（单色） | 2 个颜色预览按钮（亮色+暗色） |
| 卡片背景色 | 1 个颜色预览按钮（单色） | 2 个颜色预览按钮（亮色+暗色） |
| 资料卡边框颜色 | 1 个颜色预览按钮（单色） | 2 个颜色预览按钮（亮色+暗色） |

### 5.2 运行时效果验证

- 系统切换到暗色模式 → 边框颜色自动变为 `listCellBorderColorDarkHex` 的值
- 系统切换到亮色模式 → 边框颜色自动变为 `listCellBorderColor` 的值
- 卡片背景色、资料卡边框颜色同理

### 5.3 独立存储

- 每个属性在 NSUserDefaults 中使用独立的 key 存储
- 修改亮色值不影响暗色值，反之亦然
- ColorPairMap 确保颜色选择器弹出时正确配对

## 6. 注意事项

- `listProfileCardBorderColor` 目前**没有任何 Hook 读取**（设置页中有 UI 但无实际效果），本次改造仅完成 UI 双色显示和独立存储，不影响运行时表现
- 颜色选择器弹出时使用双模式（如果用户设置了亮/暗两种颜色），否则使用单模式
- 默认值：暗色边框/资料卡边框 `#3A3A3C`（WeChat 原生暗色边框色）、暗色卡片背景 `#1C1C1E`（WeChat 原生暗色背景色）
