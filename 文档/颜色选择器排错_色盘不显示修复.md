# 颜色选择器色盘/色相条不显示 · 排错与修复

> 问题：自定义颜色选择器弹出后，色相条（Hue Slider）和饱和度/亮度面板（S/B Panel）显示为空白/纯色，无法看到渐变

---

## 1. 根因分析

**99% 的情况是同一个原因：CAGradientLayer 的 frame 在 setup 时为 CGRectZero。**

原因在于 Objective-C 的 `viewDidLoad` 执行时机：

```
viewDidLoad 被调用时
  ├── self.view.frame ✅ 已有（由 present 时设置）
  ├── self.hueSliderView.frame ❌ CGRectZero（Auto Layout 尚未执行）
  ├── self.hueSliderView.bounds  ❌ CGRectZero
  ├── self.saturationBrightnessView.bounds ❌ CGRectZero
  └── 所有 subview 的 frame 都是零
```

而你在这时调用了 `setupHueSlider` 和 `updateSaturationBrightnessBackground`：

```objc
// setupHueSlider: ❌ gradient.frame = (0,0,0,0)
CAGradientLayer *gradient = [CAGradientLayer layer];
gradient.frame = self.hueSliderView.bounds;  // ← bounds = zero!

// updateSaturationBrightnessBackground: ❌ 直接 return
CGRect bounds = self.saturationBrightnessView.bounds;
if (bounds.size.width <= 0 || bounds.size.height <= 0) return; // ← 触发了！
```

**结果**：色相条 gradient 有 layer 但尺寸为零不可见；S/B 面板的 gradient 压根没创建。

---

## 2. 修复方案

### 方案 A：在 viewDidLayoutSubviews 中初始化（推荐，改动最小）

```objc
// WPHsvColorPickerController.m

/// 标记是否已完成首次布局
@property (nonatomic, assign) BOOL hasPerformedInitialLayout;

- (void)viewDidLayoutSubviews {
    [super viewDidLayoutSubviews];

    // 只在首次布局完成后执行一次
    if (!self.hasPerformedInitialLayout) {
        self.hasPerformedInitialLayout = YES;

        // ─── 此时所有 subview 的 frame 已正确 ───
        // 重新设置色相条渐变（frame 正确）
        [self setupHueSliderGradient];

        // 重新绘制 S/B 面板背景（bounds 正确）
        [self updateSaturationBrightnessBackground];

        // 更新指示器位置
        [self updateIndicatorPositionsAnimated:NO];
    }
}

/// 仅创建色相条的 CAGradientLayer（独立出来，可从 setupHueSlider 和 viewDidLayoutSubviews 共用）
- (void)setupHueSliderGradient {
    // 移除旧的 gradient layer
    for (CALayer *layer in self.hueSliderView.layer.sublayers) {
        if ([layer isKindOfClass:[CAGradientLayer class]]) {
            [layer removeFromSuperlayer];
        }
    }

    CAGradientLayer *gradient = [CAGradientLayer layer];
    gradient.frame = self.hueSliderView.bounds;  // ✅ 此时 bounds 正确
    gradient.startPoint = CGPointMake(0, 0.5);
    gradient.endPoint = CGPointMake(1, 0.5);
    gradient.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;

    NSMutableArray *colors = [NSMutableArray array];
    for (NSInteger i = 0; i <= 360; i += 30) {
        UIColor *c = [UIColor colorWithHue:i / 360.0 saturation:1.0 brightness:1.0 alpha:1.0];
        [colors addObject:(id)c.CGColor];
    }
    gradient.colors = colors;
    [self.hueSliderView.layer addSublayer:gradient];
}
```

同时修改 `setupHueSlider`，移除其中的 CAGradientLayer 创建逻辑（手势和指示器保留）：

```objc
- (void)setupHueSlider {
    // ⛔ 不再在这里创建 CAGradientLayer（移到 viewDidLayoutSubviews）
    // 只做手势和指示器

    // 手势
    UIPanGestureRecognizer *pan = [[UIPanGestureRecognizer alloc]
                                    initWithTarget:self action:@selector(handleHueGesture:)];
    [self.hueSliderView addGestureRecognizer:pan];
    UITapGestureRecognizer *tap = [[UITapGestureRecognizer alloc]
                                    initWithTarget:self action:@selector(handleHueGesture:)];
    [self.hueSliderView addGestureRecognizer:tap];

    // 指示器
    self.hueIndicator = [[UIView alloc] initWithFrame:CGRectMake(0, 0, 20, 20)];
    // ... 指示器配置不变 ...
    [self.hueSliderView addSubview:self.hueIndicator];
}
```

**⚠️ 注意**：`viewDidLayoutSubviews` 可能会被多次调用，但 `hasPerformedInitialLayout` 标记确保初始化只做一次。

---

### 方案 B：使用 dispatch_once 延迟初始化（备选）

如果你不想改结构，也可以在 `viewDidLoad` 末尾延迟执行：

```objc
- (void)viewDidLoad {
    [super viewDidLoad];
    // ... 其他 setup ...

    // ⏳ 延迟到下一个 runloop，此时 Auto Layout 已完成
    dispatch_async(dispatch_get_main_queue(), ^{
        [self setupHueSliderGradient];
        [self updateSaturationBrightnessBackground];
        [self updateIndicatorPositionsAnimated:NO];
    });
}
```

**缺点**：会有短暂的闪烁（先看到空白再出现渐变）。

---

### 方案 C：移除 updateSaturationBrightnessBackground 中的 bounds 检查（不推荐）

```objc
- (void)updateSaturationBrightnessBackground {
    // ⛔ 不要删掉这个检查，否则 gradient 会以 (0,0) 尺寸创建，永远不可见
    // 即使后面 view 变大了，gradient 也不会自动 resize
    // 因为 CAGradientLayer 没有 autoresizingMask（除非你手动设置）
}
```

## 4. 完整修改对照

### 修改前

```
viewDidLoad
  ├── setupHueSlider()
  │     └── gradient.frame = hueSliderView.bounds  ← (0,0,0,0) ❌
  ├── setupSaturationBrightnessView()
  │     └── updateSaturationBrightnessBackground()
  │           └── bounds.size check → return ❌
  ├── updateCurrentColorFromHex()
  └── updateIndicatorPositions()
        └── 指示器在 (0,0) 位置 ❌
```

### 修改后

```
viewDidLoad
  ├── setupHueSlider()          ← 只加手势 + 指示器
  ├── setupSaturationBrightnessView()  ← 只加手势 + 指示器
  ├── updateCurrentColorFromHex()
  └── updateColorDisplay()      ← 颜色预览仍然有效

viewDidLayoutSubviews (首次)
  ├── setupHueSliderGradient()  ← gradient.frame = valid bounds ✅
  ├── updateSaturationBrightnessBackground()  ← valid bounds ✅
  └── updateIndicatorPositions()  ← 指示器正确位置 ✅
```

## 5. 其他可能导致色盘/色相条不显示的原因

| 现象 | 原因 | 修复 |
|------|------|------|
| gradient 创建了但看不见 | `hueSliderView` / `saturationBrightnessView` 的 `clipsToBounds = NO` 且父视图裁剪了 | 添加 `view.clipsToBounds = YES` |
| gradient 只有纯色（非渐变） | `colors` 数组只有 1 个元素或所有颜色相同 | 确认 `for` 循环正确生成 13 个颜色 |
| 面板显示为全黑 | `brightnessLayer` 的透明色用了 `[UIColor blackColor]` 而非 `[UIColor clearColor]` | 检查第二层 gradient 的 colors：`@[(id)[UIColor blackColor].CGColor, (id)[UIColor clearColor].CGColor]` |
| 面板显示为全白 | `saturationLayer` 的 `endPoint` 为白色 | 检查 `endPoint` 为 `pureColor.CGColor` |
| gradient 只有部分显示 | `startPoint` / `endPoint` 设置错误 | 色相条应为 `(0,0.5)→(1,0.5)`，亮度层应为 `(0.5,1)→(0.5,0)` |
| S/B 面板尺寸不对 | 自动布局约束缺失，宽度为 0 | 确认 `saturationBrightnessView.widthAnchor` 和 `heightAnchor` 约束 |

---

## 6. 快速验证 Checklist

确认以下每个点，在代码中检查：

- [ ] `hueSliderView.clipsToBounds = YES`
- [ ] `saturationBrightnessView.clipsToBounds = YES`
- [ ] `setupHueSlider` 中不再创建 CAGradientLayer（移到 `viewDidLayoutSubviews`）
- [ ] `viewDidLayoutSubviews` 中调用了 `setupHueSliderGradient` 和 `updateSaturationBrightnessBackground`
- [ ] `updateSaturationBrightnessBackground` 中的 `bounds.size` 检查未误杀
- [ ] `handleHueGesture:` 中调用了 `updateSaturationBrightnessBackground`（拖动色相时重建面板）
- [ ] Auto Layout 中 `saturationBrightnessView` 的宽度和高度约束正确
