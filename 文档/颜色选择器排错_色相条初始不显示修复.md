# 色相条初始不显示 · 修复文档

> 现象：
> 1. 弹出颜色选择器 → 色相条是空白/纯色，看不到彩虹渐变
> 2. 在 S/B 面板上拖拽一下 → 色相条突然出现并正常显示
> 3. 拖拽 S/B 面板时下面颜色都正常
> 4. 色相条的**指示器**能看到（圆形白点），但**渐变背景**看不到

---

## 1. 根因

**色相条的 CAGradientLayer 在 `viewDidLoad` 中以 `frame = (0,0,0,0)` 创建，layout 完成后没能正确 resize。**

具体原因：

```objc
// 在 viewDidLoad 中调用 setupHueSlider:
CAGradientLayer *gradient = [CAGradientLayer layer];
gradient.frame = self.hueSliderView.bounds;  // ← 此时 bounds = (0,0,0,0)
gradient.autoresizingMask = UIViewAutoresizingFlexibleWidth | UIViewAutoresizingFlexibleHeight;
```

`autoresizingMask` 的行为是：**当父 layer 的 `bounds` 变化时，子 layer 按 mask 规则调整 frame**。但有一个关键点：如果初始 `frame` 就是零，`autoresizingMask` 不确定能否从零自动伸展到正确尺寸（取决于 Core Animation 内部实现，实测不可靠）。

为什么拖 S/B 面板后会显示？

```
拖拽 S/B 面板
  → handleSBGesture:  →  updateColorFromComponents:  →  updateColorDisplay:
       ↓
  colorDisplayView.backgroundColor 变了
       ↓
  UIView 颜色变化会触发 setNeedsLayout
       ↓
  hueSliderView.layoutSubviews 执行
       ↓
  gradient 的 autoresizingMask 此时生效，frame 被修正
       ↓
  色相条突然出现 ✅
```

---

## 2. 修复

### 核心思路：不在 `viewDidLoad` 中设置 gradient.frame，改到 layout 完成后再创建

### 方案：viewDidLayoutSubviews 中延迟创建（推荐）

**修改一：在 setupHueSlider 中只做手势+指示器，不做 gradient**

```objc
// WPHsvColorPickerController.m

- (void)setupHueSlider {
    // ⛔ 移除所有 CAGradientLayer 相关代码
    // 只保留手势和指示器

    // 手势
    UIPanGestureRecognizer *pan = [[UIPanGestureRecognizer alloc]
                                    initWithTarget:self action:@selector(handleHueGesture:)];
    [self.hueSliderView addGestureRecognizer:pan];
    UITapGestureRecognizer *tap = [[UITapGestureRecognizer alloc]
                                    initWithTarget:self action:@selector(handleHueGesture:)];
    [self.hueSliderView addGestureRecognizer:tap];

    // 指示器（圆形白点）
    self.hueIndicator = [[UIView alloc] initWithFrame:CGRectMake(0, 0, 20, 20)];
    self.hueIndicator.layer.cornerRadius = 10;
    self.hueIndicator.layer.borderWidth = 2.5;
    self.hueIndicator.layer.borderColor = [UIColor whiteColor].CGColor;
    self.hueIndicator.layer.shadowColor = [UIColor blackColor].CGColor;
    self.hueIndicator.layer.shadowOffset = CGSizeMake(0, 1);
    self.hueIndicator.layer.shadowRadius = 2;
    self.hueIndicator.layer.shadowOpacity = 0.4;
    self.hueIndicator.userInteractionEnabled = NO;
    [self.hueSliderView addSubview:self.hueIndicator];
}
```

**修改二：在 viewDidLayoutSubviews 中创建 gradient**

```objc
// WPHsvColorPickerController.m

/// 新增标志
@property (nonatomic, assign) BOOL hueSliderGradientCreated;

- (void)viewDidLayoutSubviews {
    [super viewDidLayoutSubviews];

    // 等 bounds 确定后再创建色相条渐变（只会执行一次）
    if (!self.hueSliderGradientCreated &&
        self.hueSliderView.bounds.size.width > 0) {

        self.hueSliderGradientCreated = YES;

        CAGradientLayer *gradient = [CAGradientLayer layer];
        gradient.frame = self.hueSliderView.bounds;  // ✅ 此时 bounds 正确
        gradient.startPoint = CGPointMake(0, 0.5);
        gradient.endPoint = CGPointMake(1, 0.5);
        gradient.autoresizingMask = UIViewAutoresizingFlexibleWidth |
                                    UIViewAutoresizingFlexibleHeight;

        // 0~360°，每 30° 一个颜色
        NSMutableArray *colors = [NSMutableArray array];
        for (NSInteger i = 0; i <= 360; i += 30) {
            UIColor *c = [UIColor colorWithHue:i / 360.0
                                    saturation:1.0 brightness:1.0 alpha:1.0];
            [colors addObject:(id)c.CGColor];
        }
        gradient.colors = colors;
        [self.hueSliderView.layer insertSublayer:gradient atIndex:0];
    }

    // 首次布局时也更新 S/B 面板和指示器
    if (!self.hasPerformedInitialLayout) {
        self.hasPerformedInitialLayout = YES;
        [self updateSaturationBrightnessBackground];
        [self updateIndicatorPositionsAnimated:NO];
    }
}
```

## 3. 另一种简单修复：不移除 gradient 代码，只在 viewDidLoad 末尾加 dispatch

如果不想重构 `setupHueSlider`，最小改动方案：

```objc
- (void)viewDidLoad {
    [super viewDidLoad];
    // ... 所有已有 setup 代码不变 ...

    // ⏳ 等 Auto Layout 完成后再重建色相条 gradient
    dispatch_async(dispatch_get_main_queue(), ^{
        // 重建色相条的 gradient
        for (CALayer *layer in self.hueSliderView.layer.sublayers) {
            if ([layer isKindOfClass:[CAGradientLayer class]]) {
                layer.frame = self.hueSliderView.bounds;  // ✅ 修正 frame
            }
        }
        // 重建 S/B 面板
        [self updateSaturationBrightnessBackground];
        [self updateIndicatorPositionsAnimated:NO];
    });
}
```

> **缺点**：首次打开可能有短暂闪烁（先空白再出现）

## 4. 验证

修复后，在 `setupHueSlider` 和 `viewDidLayoutSubviews` 中各加一行日志：

```objc
// setupHueSlider 中
CAGradientLayer *gradient = [CAGradientLayer layer];
gradient.frame = self.hueSliderView.bounds;
NSLog(@"[HUE] setupHueSlider: gradient.frame = %@",
      NSStringFromCGRect(gradient.frame));  // 修复前: {{0,0},{0,0}}

// viewDidLayoutSubviews 中
NSLog(@"[HUE] viewDidLayoutSubviews: hueSliderView.bounds = %@",
      NSStringFromCGRect(self.hueSliderView.bounds));  // 修复后: {{0,0},{320,32}}
```

预期：

```
修复前：[HUE] setupHueSlider: gradient.frame = {{0,0},{0,0}}
修复后：[HUE] viewDidLayoutSubviews: hueSliderView.bounds = {{0,0},{320,32}}
```

## 5. 如果还是不显示，检查这些

- [ ] `hueSliderView.clipsToBounds = YES`（否则圆角 cornerRadius 不裁切）
- [ ] `hueSliderView.layer.cornerRadius = 6` 不要太大
- [ ] gradient 没有被其他 sublayer 挡住（用 `insertSublayer:atIndex:0` 放到底层）
- [ ] 没有其他代码调用了 `hueSliderView.layer.sublayers = nil` 之类
- [ ] Auto Layout 约束中 `hueSliderView` 的 width 约束正常（不要设成 0）
- [ ] 色相条没有被其他 view 盖住（检查 z-order）
