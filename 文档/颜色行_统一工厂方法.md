# 颜色行·统一单/双预览工厂方法

## 痛点

当前有两个平行的布局方法：

```
addColorRowInGroup:    → 单按钮 (原生工厂, 布局正确)
addDualColorRowInGroup: → 双按钮 (全新实现, 布局有偏差)
```

两套代码维护两套坐标计算，坐标公式不一致就会重叠/错位。

## 目标

删除 `addDualColorRowInGroup:`，改造 `addColorRowInGroup:` 使其内部同时支持单/双预览。所有调用方用**同一个方法**。

## 改动方案

改造 `addColorRowInGroup:` 的方法签名，增加可选参数：

```diff
  - (CGFloat)addColorRowInGroup:(UIView *)group
                          title:(NSString *)title
                            key:(NSString *)key
                          value:(NSString *)value
                             cy:(CGFloat)cy
-                          width:(CGFloat)w;
+                          width:(CGFloat)w
+                       darkKey:(nullable NSString *)darkKey
+                     darkValue:(nullable NSString *)darkValue;
```

- `darkKey` / `darkValue` 为 `nil` → 单按钮（和原来行为完全一致）
- 非 `nil` → 双按钮（左浅右深）

### 内部实现逻辑

```objc
- (CGFloat)addColorRowInGroup:(UIView *)group
                        title:(NSString *)title
                          key:(NSString *)key
                        value:(NSString *)value
                           cy:(CGFloat)cy
                        width:(CGFloat)w
                     darkKey:(NSString *)darkKey
                   darkValue:(NSString *)darkValue {
    CGFloat gw = w - kPad * 2;

    if (darkKey == nil) {
        // ─── 原单按钮逻辑（一字不改） ───
        UILabel *tl = [[UILabel alloc] initWithFrame:CGRectMake(kCellHPadding, cy + 4,
                                              gw - kCellHPadding - 36, kRowH - 8)];
        tl.text = title;
        tl.font = [UIFont systemFontOfSize:15];
        tl.textColor = WPT1();
        [group addSubview:tl];

        UIColor *color = [[WPColorUtil class] colorFromHexString:value] ?: [UIColor grayColor];
        UIButton *btn = [WPColorPicker makeColorButtonWithColor:color];
        btn.frame = CGRectMake(gw - kCellHPadding - 36, cy + (kRowH - 30) / 2, 30, 30);
        objc_setAssociatedObject(btn, "key", key, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
        [btn addTarget:self action:@selector(colorButtonTapped:)
          forControlEvents:UIControlEventTouchUpInside];
        [group addSubview:btn];
    } else {
        // ─── 双按钮逻辑（用同一套坐标常量） ───
        CGFloat btnSize = 24;
        CGFloat gap = 8;
        // 两个按钮占宽: btnSize + gap + btnSize + 4(右侧留白) = 60
        // 按钮们的右边界: gw - kCellHPadding
        // 按钮们的左边界: gw - kCellHPadding - 60

        UILabel *tl = [[UILabel alloc] initWithFrame:CGRectMake(kCellHPadding, cy + 4,
                                              gw - kCellHPadding - kCellHPadding - 60, kRowH - 8)];
        tl.text = title;
        tl.font = [UIFont systemFontOfSize:15];
        tl.textColor = WPT1();
        [group addSubview:tl];

        // 深色按钮（右侧）
        UIColor *darkColor = [[WPColorUtil class] colorFromHexString:darkValue] ?: [UIColor darkGrayColor];
        UIButton *darkBtn = [WPColorPicker makeColorButtonWithColor:darkColor];
        CGFloat darkX = gw - kCellHPadding - btnSize - 4;
        darkBtn.frame = CGRectMake(darkX, cy + (kRowH - btnSize) / 2, btnSize, btnSize);
        objc_setAssociatedObject(darkBtn, "key", darkKey, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
        [darkBtn addTarget:self action:@selector(colorButtonTapped:)
          forControlEvents:UIControlEventTouchUpInside];
        [group addSubview:darkBtn];

        // 浅色按钮（左侧）
        UIColor *lightColor = [[WPColorUtil class] colorFromHexString:value] ?: [UIColor whiteColor];
        UIButton *lightBtn = [WPColorPicker makeColorButtonWithColor:lightColor];
        lightBtn.frame = CGRectMake(darkX - gap - btnSize, darkBtn.frame.origin.y, btnSize, btnSize);
        objc_setAssociatedObject(lightBtn, "key", key, OBJC_ASSOCIATION_RETAIN_NONATOMIC);
        [lightBtn addTarget:self action:@selector(colorButtonTapped:)
          forControlEvents:UIControlEventTouchUpInside];
        [group addSubview:lightBtn];
    }

    return cy + kRowH;
}
```

### 调用方改动

所有原来调用 `addColorRowInGroup:title:key:value:cy:width:` 的地方：**不需要改，** 因为新增参数有默认值（`nil`）。

需要双按钮的地方，传 `darkKey` 和 `darkValue`：

```objc
// 单按钮 - 不用改
pcy = [self addColorRowInGroup:group title:@"边框颜色" key:@"listCellBorderColor"
                         value:cfg.listCellBorderColor cy:pcy width:w];

// 双按钮 - 只需加两个参数
pcy = [self addColorRowInGroup:group title:@"Cell背景色" key:@"listCellLightBgColor"
                         value:cfg.listCellLightBgColor cy:pcy width:w
                      darkKey:@"listCellDarkBgColor" darkValue:cfg.listCellDarkBgColor];
```

## 改动清单

| 文件 | 改动 |
|------|------|
| `SettingCategoryController.m` | ~ `addColorRowInGroup:` 方法内部扩展，签名加 `darkKey`/`darkValue`；**删除** `addDualColorRowInGroup:` 方法 |
| `SettingCategoryController.h` | ~ 方法声明加 `darkKey:darkValue:` |
| `*.m`（所有子 Controller） | ~ 双按钮处传 `darkKey`/`darkValue`，单按钮处不改 |

## 验证

| 步骤 | 预期 |
|------|------|
| 所有单按钮页面 | 行为完全不变（darkKey=nil，走原逻辑） |
| 双按钮页面（Cell 背景、卡片背景、名字颜色等） | 两个圆形按钮并排显示，不重叠 |
| 点击左/右按钮 | 分别弹出双模式选择器对应浅/深模式 |
