# 资料卡边框配置归属混乱 · 修复方案

---

## 1. 问题描述

"资料卡边框"属于"卡片背景美化"功能，但当前它的配置数据存储在 `ListCornerRadiusConfig` 中，而不是 `CardBgConfig` 中。

### 当前状况

```
设置页 UI (SettingCardBackgroundController.m)
  ↓ 读取
ListCornerRadiusConfig（圆角设置） ← 归属错误！
  ↓
Hook (ProfileCardBgHook.m) 读取
```

### 应该的状况

```
设置页 UI (SettingCardBackgroundController.m)
  ↓ 读取
CardBgConfig（卡片背景） ← 正确归属
  ↓
Hook (ProfileCardBgHook.m) 读取
```

## 3. 迁移清单

### 3.1 从 ListCornerRadiusConfig 移出的属性（5 个）

| 当前 key（ListCornerRadiusConfig） | 新 key（CardBgConfig） | 类型 | 默认值 |
|-----------------------------------|----------------------|------|--------|
| `listProfileCardBorderEnabled` | `cardBgBorderEnabled` | BOOL | NO |
| `listProfileCardBorderWidth` | `cardBgBorderWidth` | CGFloat | 2.0 |
| `listProfileCardBorderColor` | `cardBgBorderColor` | NSString | #E5E5E5 |
| `listProfileCardBorderColorDarkHex` | `cardBgBorderColorDarkHex` | NSString | #3A3A3C |
| `myPageHideArrow` | `cardBgHideArrow` | BOOL | NO |

> `listProfileCardBorderColor` 和 `listProfileCardBorderColorDarkHex` 当前在 PluginConfig 中也有对应的 `@property` 和加载/保存逻辑。迁移后一并从 PluginConfig 中删除。
